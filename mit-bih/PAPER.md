# 심전도 비트 분류에서 상심실성 이소성(SVEB) 검출은 형태가 아니라 리듬에 의존한다
### — 세 데이터셋에 걸친 검증과, 구조적 정교화의 한계에 관한 보고

> **문서 성격**: 논문 투고용 원자료 정리. 모든 수치는 실제 실행 로그에서 옮겼고,
> 각 수치가 **어떤 데이터셋·어떤 프로토콜**에서 나왔는지 명시한다.
> 프로토콜이 다른 수치를 나란히 비교하지 않는다(최우선 규칙).
> **최종 갱신**: 2026-07-27 (SVDB 벤치마크 반영)

---

## Abstract

심전도 비트 단위 상심실성 이소성 박동(SVEB, AAMI class S) 분류를 세 데이터셋
(MIT-BIH Arrhythmia, MIT-BIH Supraventricular Arrhythmia[SVDB], St. Petersburg INCART)
에서 환자 분리(inter-patient) 설정으로 연구했다. 주 지표는 **환자단위 매크로 F1**이며,
동일 프로토콜로 재구현한 기준선들과 비교했다.

**주요 결과 (SVDB, 73환자, 환자단위 매크로 F1, 대응 부트스트랩 95% CI)**

| 모델 | 매크로 F1 [95% CI] |
|---|---|
| 형태만 학습한 CNN | 0.164 [0.120–0.212] |
| **CNN + RR(리듬)** | **0.484 [0.404–0.564]** |
| 고전 LDA(형태+RR) | 0.476 [0.413–0.539] |
| 제안 모델(전체) | 0.534 [0.472–0.595] |

**(1) 리듬 축은 필수적이다.** 형태 정보만 사용한 CNN에 RR 정보를 추가하면 매크로 F1이
0.164 → 0.484로 상승한다(**Δ +0.320, 95% CI [+0.246, +0.396]**). 이 효과는 Bonferroni
보정 후에도 유지되며([+0.224, +0.416]), 관측된 다른 모든 효과(≈0.05)보다 6배 이상 크다.
동일한 결론이 INCART 교차DB 전이에서도 재현된다(리듬 축 부재 시 기저율 대비 1.8배,
추가 시 7.9배).

**(2) 구조적 정교화는 이득을 입증하지 못했다.** 제안 모델(샴 인코더, 게이트 융합,
프로토타입, 9개 특징군, 라벨프리 개인화)은 단순한 "CNN + RR" 대비 유의한 개선을 보이지
않았다(Δ +0.050 [−0.022, +0.122]). 2004년식 선형 판별분석 대비 이득은 보정 전 한계적
유의(Δ +0.058 [+0.003, +0.114])이나 **다중비교 보정 후 유의성을 상실**한다([−0.013, +0.129]).

**(3) 평가 구조에 관한 관찰.** MIT-BIH DS2에서는 단일 레코드(#232)가 S 비트의 75.2%를
차지하여 비트풀링(micro) 지표를 지배한다(동일 예측에서 micro 0.762 vs 매크로 0.334).
**이 현상은 MIT-BIH DS2에 특이적이며 SVDB에서는 재현되지 않는다**(최다 레코드 14.9%).
따라서 이는 일반적 방법론 결함이 아니라 특정 데이터셋의 성질로 보고한다.

**(4) 라벨프리 개인화의 범위.** 환자 본인 신호만 사용하는 강건 자기-템플릿 및 2성분
점수 센터링은 정밀도와 랭킹을 개선하나(MIT-BIH: #232 제외 S_PR 0.322→0.428, 위양성
−71%; SVDB: micro 정밀도 0.393→0.436), **환자단위 매크로 F1은 개선하지 않는다**
(MIT-BIH −0.004, SVDB −0.009; 두 데이터셋에서 독립적으로 기각).

## 1. Introduction

### 1.1 문제
SVEB(S)는 형태가 정상 박동(N)과 거의 같고 **조기성(timing)** 으로 정의된다.
심실성(V)이 형태로 구분되는 것과 대조적이며, 이 때문에 S는 전통적으로 가장 어려운
AAMI 클래스다. 본 연구의 중심 질문은 다음과 같다:

> **S 검출에서 형태 정보와 리듬 정보는 각각 얼마나 기여하는가? 그리고 모델 구조의
> 정교화는 얼마나 기여하는가?**

### 1.2 이 연구가 하지 않는 주장
- **최고 성능(SOTA) 주장을 하지 않는다.** 본 연구의 주 지표는 환자단위 매크로 F1이며,
  문헌 다수가 보고하는 비트풀링 micro와 **다른 잣대**다(§2.2).
- **문헌 수치가 부풀려졌다고 주장하지 않는다.** §5.2의 #232 지배는 MIT-BIH DS2에
  국한된 관찰이며(§6.4에서 SVDB로 반증됨), 타 연구를 재계산하지 않았다.
- **제안 모델이 기준선보다 우수하다고 주장하지 않는다.** §6.3의 검정 결과가 그것을
  지지하지 않는다.

### 3.1 데이터셋
| | MIT-BIH Arrhythmia | **MIT-BIH SVDB** | INCART |
|---|---|---|---|
| 용도 | 탐색·개발 | **확증 벤치마크** | 교차DB 외부검증 |
| 비트 수 | 99,871 | **184,397** | 175,571 |
| N / S / V | 90,082 / 2,781 / 7,008 | 162,262 / **12,196** / 9,939 | 153,607 / 1,958 / 20,006 |
| S 유병률 | 2.8% (DS2 3.73%) | **6.61%** | 1.12% |
| 레코드 | 44 (DS1 22 / DS2 22) | **78** | 75 (환자 32) |
| **S 보유 환자** | **DS2 16명** | **73명** | — |
| 리드 / 샘플링 | 2 / 360 Hz | 2 / 128→360 Hz | 12→2 / 257→360 Hz |

### 3.2 분할
- **MIT-BIH**: de Chazal DS1(학습)/DS2(테스트). DS1 S 944(1.87%), DS2 S 1,837(3.73%)
  → **유병률 2배 차이**(§6.8의 원인).
- **SVDB**: 환자 단위 GroupKFold(5). 각 폴드의 학습셋에서 환자를 분리해 calib으로 사용.
- **INCART**: MIT-BIH 전체 학습 → INCART 전체 테스트(zero-shot 전이).

### 3.3 무결성 프로토콜
1. 테스트셋은 **최종 평가에만** 사용. 테스트 라벨로 어떤 하이퍼파라미터도 조정하지 않는다.
2. 모든 전이 하이퍼파라미터는 **학습셋 통계에서 공식으로 유도**(§4.4).
3. 개인화는 **테스트 환자 본인의 신호만** 사용하며 라벨을 쓰지 않는다.
4. 임계는 **held-out calib**에서 결정. 테스트 라벨로 고른 임계는 "오라클"로 명시하고
   **상한 참고로만** 보고한다.
5. **SVDB에서는 구성을 재탐색하지 않았다.** MIT-BIH에서 확정한 구성(특징군 조합,
   `conf_cut=0.879`, `frac=0.6`)을 **동결**하여 적용했다. 이는 MIT-BIH에서 누적된
   선택 편향(campaign-level selection)이 확증 실험을 오염시키지 않도록 하기 위함이다.
6. **사전 등록**: 가설 H1–H5를 SVDB 결과를 보기 전에 고정했다(§6.9).
7. GPU 비결정성 통제: `cudnn.deterministic=True`, `CUBLAS_WORKSPACE_CONFIG=:4096:8`.

### 3.4 전처리 (SVDB·INCART)
- **R 재정합**: 주석 위치 ±50 ms 창에서 벡터크기 최대점 재탐색(라벨 미사용).
  SVDB 실측 평균 이동 **18.8 ms** — 주석 지터가 실재함을 확인.
- **per-beat z 정규화**: 진폭 스케일 차이 제거.
- ⚠ MIT-BIH 원본은 재정합하지 않았다. **SVDB 내부 CV에는 무관**(전부 일관 처리)하나
  MIT↔SVDB 교차 비교 시에는 MIT도 재정합해야 한다(미실시).

## 4. Methods

### 4.1 특징 축
| 군 | 차원 | 성격 |
|---|---|---|
| WST | 40(선택) | Wavelet Scattering, 이동불변 형태 |
| MORPHO / REPOL / DTW | 16 / 4 / 15 | 형태 편차·재분극·템플릿 정합 |
| **RHYTHM** | **10** | **리듬 innovation (핵심)** |
| KOOPMAN / AE / GNN | 5 / 5 / 5 | DMD 예측잔차 / 재구성오차 / kNN 구조 |
| RR (또는 feats0) | 2 (26) | 원 RR 간격 |

### 4.2 RHYTHM innovation
환자별 **인과적 EWMA**(= 이산 선형 SDE / 칼만 innovation)로 다음 박동을 예측하고
**잔차**를 이소성 신호로 사용한다.
```
pred[t] = acc;  acc = α·X[t] + (1-α)·acc          (α=0.3, 과거만 사용)
innov   = tanh( (X - pred) / max(MAD, 0.2·MAD_global) / 3 )     → (-1,1) 유계
```
- **보상성지수 = pre-innov + post-innov**: APC(불완전 대상성 휴지)와 PVC(완전 대상성
  휴지)를 분리하는 생리학적 근거를 가진 판별자.
- **전부 무차원**(비율 또는 환자별 MAD 정규화 + tanh) → 진폭·단위·샘플링에 불변하므로
  **교차DB 전이가 원리적으로 가능**(§6.5에서 검증).

### 4.3 라벨프리 개인화
**(a) 강건 자기-정상 템플릿**: 정상(동율동)이 다수라는 성질을 이용한 반복 절삭 M-estimator.
median에서 시작해 상관거리 상위 60% 인라이어만 유지하며 수렴시킨다. 신뢰도(인라이어 상관
중앙값)가 `conf_cut=0.879`(MIT-BIH DS1 분포의 5퍼센타일) 미만이면 median으로 폴백.
*합성 검증*: 정상 80%+이소성 20%에서 진짜 정상과의 편차 median 0.0146 → robust 0.0051.

**(b) 2성분 강건 점수 센터링**: 환자별 점수 baseline 차이를 흡수. 로짓을 1D 2-means로
나눠 **낮은 성분(정상 baseline)** 으로 센터링.
*설계 근거*: 단순 median 센터링은 "환자의 과반은 non-S"를 가정하는데, MIT-BIH #232는
S가 76%라 이 가정이 깨져 S 대부분이 임계 아래로 내려간다(실측 SEN 0.05로 붕괴).
*합성 검증*: median-center SEN 0.640 → 2성분 1.000.

### 4.4 손실·불균형 (학습셋 유도, 하드코딩 아님)
```
auto_weights(y_train, β=0.9999):  eff(n)=(1-β)/(1-βⁿ)  →  Sw = eff(n_S)/eff(n_N)
LDAM margin:  m_c ∝ 1/n_c^0.25, 최대 0.5로 정규화
```
MIT-BIH DS1 → Sw 10.99. **SVDB는 S가 6.61%로 더 흔하므로 Sw가 자동으로 작아진다** —
데이터셋별 수동 조정이 불필요하다는 설계 의도가 실제로 작동함을 확인했다.

### 4.5 모델 구조 (제안)
```
Enc: Conv1d(2→32,k7)-BN-ReLU-Pool → (32→64,k5) → (64→128,k3) → GAP → Linear(→64)
샴: [z1, z2, z1−z2, |z1−z2|] → Linear(256→64)      (z2 = 환자 레퍼런스 인코딩)
게이트 융합: z = z1 + σ(W[z1,zb])·zb
프로토타입: softmax(z·Pᵀ/√64)·P                    (P: 32×64)
분류: Linear(192→64→3)
```
AdamW(lr 1e-3, wd 1e-4), batch 512, 15 epoch, grad clip 1.0.

## 5. Evaluation Methodology

### 5.1 지표
- **환자단위 매크로 F1** (S 보유 환자만) — **주 지표**. 환자 부트스트랩 95% CI 병기.
- **대응 비교(paired bootstrap)**: 동일 환자를 평가하는 설계이므로, 모델 간 비교는
  환자별 F1 차이의 부트스트랩으로 검정한다(주변 CI 비교보다 정확·정밀).
- **micro F1**: 문헌 표준이나 레코드 크기에 지배됨 → **최다 레코드 기여율과 함께만** 인용.
- **S_PR-AUC**: 임계 무관(랭킹력만).
- **오라클 임계**: 테스트 라벨로 최적화 → 상한 참고로만.

### 5.2 단일 레코드 지배 (MIT-BIH DS2)
```
MIT-BIH DS2 총 S = 1,837 중 rec 232 = 1,382  →  75.2%
   (rec 232는 N 398 / S 1,382로 S가 76%인 예외적 구성)
```
동일 예측·다른 잣대: micro F1 **0.762** vs #232 제외 micro **0.392** vs 매크로 **0.334**.
> **단, 이 현상은 SVDB에서 재현되지 않았다**(§6.4). 데이터셋 특이적 성질로 한정 보고한다.

### 5.3 검정력과 데이터셋 선택
환자별 F1의 σ ≈ 0.32일 때 평균의 95% CI 반폭 = 1.96·σ/√N:

| 데이터셋 | S 보유 환자 N | 95% CI 반폭 | 검출 가능 최소 효과 |
|---|---|---|---|
| MIT-BIH DS2 | 16 | ±0.157 | 0.16 (사실상 불가) |
| **SVDB** | **73** | **±0.073** | **0.07** |
| (참고) 1,000 | 1,000 | ±0.020 | 0.02 |

**MIT-BIH 단독으로는 0.16 미만의 효과를 검정할 수 없다.** 본 연구가 MIT-BIH에서 관찰한
후보 효과들은 대부분 0.01~0.07이었으므로, **확증을 위해 SVDB(73환자)로 이동**했다.
실제 SVDB의 대응 비교 SE는 0.021~0.038로, 0.05~0.07 크기 효과의 검정이 가능해졌다.

### 5.4 다중비교
§6.3에서 4개의 사전 계획된 대응 비교를 수행했다. Bonferroni 보정(α=0.05/4=0.0125)
결과를 함께 보고하며, **보정 후 유의한 결과만을 확증된 것으로 취급**한다.

### 6.5 교차DB 외부검증 — 형태/리듬 이분법의 재현 (C1 보강)
MIT-BIH 전체 학습 → INCART zero-shot 적용(재학습·튜닝 없음):

| 특징집합 | S_PR | 기저율(1.12%) 대비 lift | V_PR |
|---|---|---|---|
| 형태만 (WST+MORPHO+REPOL+KOOPMAN+GNN) | 0.0197 | 1.8× | 0.690 |
| **+ RHYTHM(10)** | **0.0882** | **7.9×** | **0.854** |
| + BN 적응(무라벨) | 0.0762 | 6.8× | 0.781 |

1. **V는 리듬 없이도 전이된다**(V_PR 0.690) — 형태(넓은 QRS)가 DB·장비·인구에 불변.
2. **S는 리듬 없이는 우연 수준**(1.8×), 리듬 추가 시 **7.9×**. §6.2와 동일한 결론.
3. BN 적응이 개선을 주지 못함 → 문제는 입력 분포 shift가 아니라 **판별 축의 유무**.

**⚠ 교차DB 한계(미해결)** — 이 절 수치는 하한으로 읽어야 한다:
| # | 문제 | 성격 |
|---|---|---|
| L1 | INCART 주석이 R피크 기준이 아니며 argmax 재정합 미적용 | 코드+데이터 |
| L2 | MIT-BIH는 raw 비트, INCART는 z정규 비트로 특징 계산(**정규화 비대칭**) | 코드 결함 |
| L3 | PID를 레코드(75)로 셈. 실제 환자는 **32명** | 코드 |
| L4 | INCART에 AF 포함 → RR innovation 무의미 구간에서 위양성 | 데이터 고유 |
| L5 | 환자군 편향·S 유병률·라벨 기준 차이 | 환원 불가 |
> RHYTHM은 양쪽 모두 z정규 비트로 계산했고 RR 기반이라 L1·L2 영향이 작다.
> 따라서 7.9× lift는 형태 특징보다 신뢰도가 높다.

## 8. Discussion

### 8.1 무엇이 SVEB 검출을 결정하는가
본 연구의 가장 명확한 결론은 **정보의 종류가 모델의 정교함을 압도한다**는 것이다.
- 리듬 정보 추가: **Δ +0.320** (보정 후 유지)
- 모델 구조·특징 정교화: Δ +0.050 (비유의)
- 라벨프리 개인화: Δ −0.009 (비유의)

이는 생리학과 일치한다. SVEB는 정의상 **조기성**이며, QRS 형태는 정상 전도 경로를
따르므로 N과 거의 같다. 따라서 형태 기반 표현 학습에 얼마를 투자하든 그것만으로는
S를 구분할 수 없다(B2: F1 0.164).

### 8.2 실무·임상 함의
- **비트 분류기를 설계할 때 RR/리듬 특징은 선택이 아니라 필수**다. 형태 CNN만으로 S를
  다루는 시스템은 교차기관 배포에서 실패할 가능성이 높다(§6.5의 INCART 결과가 시사).
- **V는 잘 전이되나 S는 그렇지 않다** — 클래스별로 배포 신뢰도를 달리 평가해야 한다.
- **동작점은 목표 도메인의 유병률에 맞춰 재설정**해야 하며(§6.8), 논문·제품 사양은
  임계 무관 지표(PR-AUC)를 함께 보고해야 한다.

### 8.3 방법론적 함의
- 희소 클래스가 소수 레코드에 집중된 데이터셋에서 **비트풀링 micro는 오도할 수 있다**
  (MIT-BIH DS2가 실례). 최소한 환자단위 매크로를 병기할 것.
- inter-patient에서 **검증 성능 기반 선택이 무효일 수 있다**(§6.7).
- **검정력을 사전에 계산할 것.** MIT-BIH DS2(16환자)는 0.16 미만 효과를 검정할 수 없으며,
  이 사실을 모르면 노이즈를 개선으로 오인하게 된다(본 연구도 초기에 그러했다 — §7 N3).

### 8.4 왜 정교한 모델이 이기지 못했는가 (해석)
세 가지 가능성을 구분한다:
1. **정보 포화**: RR + 기본 형태로 이미 가용 정보가 대부분 포착되어 추가 특징이
   중복일 가능성. §6.2의 큰 격차와 §6.3의 작은 격차는 이 해석과 정합적이다.
2. **라벨 천장**: 주석 자체의 모호성(경계 APC)이 상한을 만들 가능성.
3. **표본 한계**: 73환자로도 0.05 크기 효과의 검정력이 충분치 않을 가능성
   (관측 SE 0.021~0.038 → 0.05 효과 검출력은 약 50~80%).
> 3을 배제하려면 수백 명 규모가 필요하다(§10).

## 9. Limitations
1. **제안 모델의 우위가 입증되지 않았다**(§6.3). 본 연구는 이를 결과로 보고한다.
2. **특징벡터 불일치**: SVDB에는 MIT-BIH의 `feats0`(26차원, 외부 제공)가 없어
   `pre_rr/post_rr`로 대체했다. B4의 입력이 두 데이터셋에서 동일하지 않다.
3. **MIT-BIH 미재정합**(§3.4) → MIT↔SVDB 교차 비교 미실시.
4. **교차DB 한계 L1–L5**(§6.5) 미해결 → INCART 수치는 하한.
5. **검정력**: SVDB 73환자로 0.05 효과의 검출력이 완전하지 않다(§8.4).
6. **`_pp_center2`는 transductive**(레코드 전체 비트로 중심 추정) → 스트리밍 적용에는
   인과적 버전이 필요. `sep=1.0`도 데이터로 정하지 않은 임의 상수다.
7. **탐색 편향**: MIT-BIH에서의 반복 실험이 구성 선택에 영향을 주었다. SVDB는 구성을
   동결해 이를 통제했으나(§3.3-5), MIT-BIH 자체 수치는 낙관적으로 편향되어 있다.
8. **단일 시드·단일 반복**(SVDB `n_rep=1`, 5폴드). 반복 확대 시 CI가 다소 변할 수 있다.
