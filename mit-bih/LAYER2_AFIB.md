# 2층(리듬·질환축) 설계 — AFIB / AFL

> 1층 = AAMI 비트(N/S/V/F/Q). 2층 = 리듬·질환(AFIB/AFL/…).
> 이 문서는 **결과를 보기 전에** 고정한다. 확정 후 판정 기준을 바꾸지 않는다.
> 코드: `afib_bench.py`, `ecg_multidb.py`(`RRDB_SPEC` / `build_rr_corpus`)

---

## 0. 왜 층을 나누는가 — 취향이 아니라 데이터 구조 때문

두 축은 **직교**한다. AFIB 구간의 박은 대부분 AAMI 클래스 N 이다. 하나의
다중클래스 softmax 로 합칠 수 없다. 더 결정적인 것은 **가용 DB 집합이 다르다**는 점:

| | 필요한 라벨 | 쓸 수 있는 DB | 환자 |
|---|---|---|---|
| 1층 | 감사된 비트 심볼 | mitdb, svdb, incartdb | 201 |
| 2층 | R위치 + 리듬 주석 | + afdb, ltafdb, nsrdb | 130+ |

층을 합치면 두 집합의 교집합(=201명, AFIB 10명)으로 줄어든다. **층을 나누는 것이
데이터를 안 버리는 유일한 방법이다.**

---

## 1. ★진입 전 판단 — 지금 데이터로는 2층을 돌려도 해석할 수 없다

현 `ecg_multi.npz` 의 AFIB 보유 레코드는 **10개**다. 환자단위 매크로 F1 의 MDE 는
그 리듬을 가진 환자 수로 정해진다(σ≈0.32 가정, `rr_audit_dbs()` 가 출력):

| AFIB 보유 환자 | MDE | 뜻 |
|---|---|---|
| **10 (현재)** | **0.198** | F1 0.75 와 0.95 를 구분 못 함 |
| +afdb(23) = 33 | 0.109 | 여전히 큼 |
| +ltafdb(84) = 117 | **0.058** | 비로소 판정 가능 |
| +nsrdb(18) = 135 | 0.054 | 특이도 음성대조 확보 |

**결론: 2층의 1단계는 모델링이 아니라 코퍼스 확보다.** §13.2(R7)에서 "실패를
고쳐서 다시 돌리지 않는다"고 정한 것과 같은 규율이다 — 판정 불가능한 실험은
돌려도 정보가 없다.

σ=0.32 는 1층 SVEB 에서 온 **가정**이다. AFIB 는 더 쉬운 과제라 σ 가 작을
가능성이 높다. 첫 실행 뒤 **환자별 F1 의 실측 표준편차로 갱신**하고, 그때
MDE 표를 다시 계산한다(가정을 결과처럼 쓰지 않는다).

## 2. 데이터 — ★신호(.dat)를 받지 않는다

리듬축은 R위치와 리듬 라벨만 있으면 된다. `.atr`/`.qrs` 주석만 받으면:

| DB | 레코드 | 길이 | 주석 | 받는 용량 |
|---|---|---|---|---|
| afdb | 23 (+2 주석전용) | 10h | `.atr` 리듬 / `.qrs` R위치 | ~10 MB |
| ltafdb | 84 | 24~25h | `.atr` (리듬+비트) | ~40 MB |
| nsrdb | 18 | 24h | `.atr` | ~10 MB |
| mitdb | 48 | 30m | `.atr` | ~1 MB |

신호까지 받으면 afdb ~620 MB / ltafdb ~2.8 GB, 주석만 받으면 **수십 MB**다.
(초안에 "~15 GB"라고 적었던 것은 과대 추정이었다.) 이 코퍼스 자체로는 형태축을
못 돌지만, §10 의 `build_atrial_feats` 가 레코드 하나씩 신호를 받아 **특징만 남기고
버리는** 방식으로 형태축을 붙인다(결과 파일 <1 MB).

**주의 — afdb 의 `.qrs` 는 자동검출·미감사다.** R위치로는 표준적으로 쓰이지만
AAMI 비트 클래스로는 절대 쓰면 안 된다. `RRDB_SPEC["afdb"]["beat_audited"]=False`
로 표시하고 `y5 = -1` 로 박아 오용을 차단한다.

**nsrdb 는 리듬 주석이 없다.** DB 정의상 전부 정상동조율이므로 `default_rhythm="N"`
으로 채운다 — 이것은 **가정**이며 코드가 그렇게 출력한다. 음성대조(특이도) 용도
외에는 쓰지 않는다.

## 3. 단위 — 비트가 아니라 창(window)

AF 는 에피소드 현상이고 문헌 표준 단위도 30초~128박 창이다. 현실적 제약도 같은
답을 가리킨다:

```
ltafdb 970만 박 × ±64박 문맥 실체화 = 4채널 × 129 × 4B = 20 GB   → 불가능
창(W=128, 비중첩)                 = 7.6만 창 × 4 × 128 × 4B = 156 MB
```

같은 정보를 128배 중복 저장하지 않는 것뿐이고, **인코더는 1층과 동일한 `_rsn`**
(형태 가지만 끔)이다. 그래서 "1층에서 유일하게 살아남은 효과(R1−R5 = +0.105)가
2층으로 전이되는가" 가 직접 검증된다.

- 채널은 1층 `rr_context` 와 동일한 무차원 4종. 정규화 통계(med/MAD)는 **레코드**
  기준이다 — 창 기준으로 잡으면 "이 구간이 기저보다 빠르다"가 창마다 지워진다.
- **전이구간 처리**: 창의 90% 이상이 한 리듬일 때만 그 리듬으로 라벨하고, 아니면
  `y=-1` 로 학습·평가에서 뺀다. 리듬이 바뀌는 경계를 한쪽으로 우겨넣으면 그
  오답이 모델 탓으로 계상된다.

## 4. 지표 — 창 F1 을 유일 지표로 쓰지 않는다

| 지표 | 왜 |
|---|---|
| **창단위 환자매크로 F1** | 1층과 **같은 추정량** → 층 간 비교가 성립 |
| **에피소드 Se/PPV** (중첩 기준) | 창 F1 은 긴 에피소드 하나가 지배한다. 임상 질문은 "발작을 놓쳤는가" |
| **AF burden r + Bland-Altman** | 항응고·재발감시가 전부 burden 기준. F1 이 같아도 burden 오차가 다르면 임상 가치가 다르다 |

- burden 은 **시간가중**이다(창 길이가 다르므로 개수로 세면 편향).
- 에피소드·burden 은 **비중첩 창만** 쓴다(중첩 창은 같은 에피소드를 여러 번 센다).
- 짧은 발작(≤3창)의 Se 를 따로 보고한다 — 여기가 burden 오차의 주 원인이다.

## 5. 팔(arm)

| arm | 내용 | 역할 |
|---|---|---|
| A0.자명 | 항상 다수 클래스 | 하한. 이 아래면 모델이 해로운 것 |
| **A1.RR산포** | RMSSD·pNN50·CV·ΔRR 엔트로피·Poincaré 10종 → MLP | **문헌 기준선**(1990~2010s AF 검출기 표준). 이걸 못 이기면 시퀀스 인코더는 값을 못 한 것 |
| **A2.RSN** | 1층과 같은 dilated TCN + 스칼라 보조 | 제안 |
| A2c.RSN(스칼라X) | 시퀀스만 | A2 의 이득이 스칼라 덕인지 가르는 대조군 |
| A3.RSN+도메인 | + DB 조건부 FiLM | ★같은 DB 안에서만 오르면 사전확률 암기 → 판정은 `split="db"` |

**2층-B(형태축)는 이 코퍼스에서 못 돈다.** mitdb 계열(신호 보유)로 따로 돌리고,
AFIB 10명 / AFL 4명 수준이라 **탐색적(exploratory)으로만** 보고한다.

## 6. 사전등록 가설 (결과 보기 전 고정, Bonferroni k=4)

판정 기준은 **MDE × 2.0** 이다(Bonferroni 로 z 1.96 → 2.50, 여유 포함).

| | 가설 | 판정 기준 |
|---|---|---|
| **H-J** | AFIB 에서 A2.RSN − A1.RR산포 > 0 | Δ > 2×MDE(AFIB) |
| **H-K** | A2 의 AFIB burden Bland-Altman LoA 폭이 A1 보다 좁다 | LoA 폭 비 < 1.0, 부트스트랩 CI 가 1 을 안 포함 |
| **H-L** | **AFL 에서 A2 − A1 ≤ 0** | ★영가설 방향의 예측. AFL 은 RR 이 규칙적이라 RR-only 는 구조적으로 실패한다 |
| **H-M** | LODO(`split="db"`)에서 A2 의 AFIB F1 하락 < 0.10 | afdb↔ltafdb 교차 |

**H-L 이 특별한 이유**: 이것은 "우리 모델이 이긴다"가 아니라 "**이 축으로는 안
된다**"를 미리 못 박는 예측이다. 확인되면 그것이 곧 **형태축(P/F파)이 필요하다**는
직접 근거가 되고, 기각되면 RR 만으로 AFL 이 되는 것이므로 그 자체가 발견이다.
어느 쪽이든 정보가 나온다 — §13(R7)에서 얻은 교훈의 적용이다.

**미리 정하는 것**: H-J 가 실패해도 A2 를 손보고 재실행하지 않는다. RR 기반 AF
검출은 문헌에서 이미 포화(Se/Sp 95%+)라 A1 을 못 이기는 것이 **정상적인 결과**다.
그 경우의 결론은 "RSN 은 2층 AFIB 에 추가 가치가 없다"이고, 값은 H-K(burden)·
H-L(AFL)·H-M(전이)에서 찾는다.

## 8. 알려진 한계 (미리 적어 둔다)

1. **레코드 = 환자 가정.** afdb/ltafdb 는 공식 환자 매핑이 없다. 한 사람이 두
   레코드에 걸쳐 있으면 환자분리가 깨진다. incartdb 에서 쓴 휴리스틱(§`incart_groups`)
   같은 안전장치가 여기엔 없다 — **검정력을 과대평가하는 방향**이므로 결과 해석에
   반영한다.
2. **nsrdb 의 "N" 은 주석이 아니라 가정이다**(§2).
3. **ltafdb 는 AF 가 매우 많다.** 클래스 사전확률이 DB 와 강하게 얽히므로 A3
   (도메인 FiLM)은 LODO 없이는 절대 판정하지 않는다.
4. **AFL 표본이 작다.** afdb 의 AFL 은 소수 레코드에 몰려 있어 H-L 은 방향만
   보고 크기는 보고하지 않는다.
5. **형태축은 이 코퍼스에 없다**(신호 미수집). 2층-B 는 별도·탐색적.

## 9. 1차 실측 (2026-07-28, afdb+mitdb, 환자 73, k=3)

창 10,362 (W=128 비중첩) / N 5,532 · AFIB 3,951 · AFL 89 / 전이구간 790 제외.

```
  arm                    N     AFIB      AFL     평균
  A0.자명             0.879    0.000    0.000    0.293
  A1.RR산포           0.950    0.916    0.441    0.769
  A2.RSN              0.953    0.920    0.371    0.748
  A2c.RSN(스칼라X)     0.960    0.928    0.376    0.755
  A3.RSN+도메인        0.959    0.901    0.386    0.749
  (보유 환자)             62       29        7
```

### 9.1 H-J 미달 — **사전등록대로의 결과**

AFIB 에서 A2 − A1 = **+0.004**. §6 에 "RR 기반 AF 검출은 이미 포화라 A1 을 못
이기는 것이 정상 결과이고, 그 경우 A2 를 손봐 재실행하지 않는다"고 미리 적었다.
그대로 따른다. 30년 된 고전 특징(RMSSD·pNN50·ΔRR 엔트로피·Poincaré)이 이미 천장에
닿아 있다.

### 9.2 ★그런데 burden 이 갈린다 — F1 을 유일 지표로 쓰지 않은 이유의 실증

| | AFIB burden r | Bland-Altman | LoA 폭 |
|---|---|---|---|
| A1.RR산포 | 0.912 [0.862,0.945] | +3.09 ± 28.6 %p | **57.2 %p** |
| **A2.RSN** | **0.970 [0.952,0.982]** | +2.12 ± 16.7 %p | **33.4 %p** |
| A2c | 0.956 | +2.79 ± 20.1 %p | 40.3 %p |
| A3 | 0.961 | +2.63 ± 19.0 %p | 38.0 %p |

**창 F1 은 +0.004 인데 burden 오차폭은 42% 좁아졌다.** 임상 언어로: 실제 burden
30%인 환자를 A1 은 1.4~58.6% 로, A2 는 13.3~46.7% 로 보고한다.

에피소드 Se(둘 다 0.987)와 PPV(0.667 vs 0.670)가 거의 같으므로, 두 모델은
**비슷한 양을 틀리되 틀리는 방식이 다르다** — A1 은 소수 환자에서 크게 빗나가고
A2 는 고르게 조금씩 틀린다는 가설. `burden_outliers()` 로 확인 대상.

⚠ **이 비교는 §6 사전등록 시점에 검정 코드가 없었다.** 두 r 의 CI 가 안 겹친다는
논리는 독립 표본용이고, 여기서는 같은 68명이라 짝지은 검정이 필요하다.
`paired_burden()` 을 구현했으므로 **재실행 시 그 결과로 판정한다.** 그전까지 이
발견은 "유망"이지 "확인"이 아니다.

### 9.3 H-L 확인 — 방향만

AFL 에서 A2 − A1 = **−0.070**(역행). 짧은 발작 Se 는 A1 0.333 → A2 **0.000**.
RR 시퀀스를 정교하게 모델링해도 AFL 은 안 잡힌다 — 2:1·3:1 전도로 **RR 이 오히려
규칙적**이라 RR 축에 정보가 없기 때문이다.

**단 AFL 환자 7명, MDE 0.237 이므로 −0.070 이라는 크기는 우연과 구분 불가다.**
§8.4 에 "방향만 보고 크기는 보고하지 않는다"고 미리 적은 대로 방향만 취한다.

### 9.4 알아야 할 한계

1. **AF 유병률이 부풀려져 있다** — 창의 38%가 AFIB. afdb 가 AF 전용 DB 이기
   때문이다. 실제 외래 홀터에서는 훨씬 드물다. **PPV 0.667 은 낙관적**이고
   실제로는 위양성 경보가 더 많을 것이다. nsrdb(정상 18명×24h)를 넣어야 교정된다.
2. **PPV 0.667 이 진짜 병목이다.** 발작 79건 중 78건을 잡았지만(Se 0.987) AF 라고
   외친 285건 중 95건이 헛경보다. 임상에서 문제되는 것은 놓친 발작보다 경보 피로다.
3. ltafdb 미포함 → AFIB 환자 29명(MDE 0.116). 넣으면 116명(MDE 0.058).

## 10. 2차 사전등록 — 심방활동 축 (결과 보기 전 고정)

§9.3 이 가리키는 곳은 하나다: **AFL 을 가르는 유일한 물리 신호는 심방 활동이고,
그건 파형에만 있다.** RR 축에는 원리적으로 없다.

### 10.1 무엇을 넣는가

| 리듬 | 심방 활동 | RR |
|---|---|---|
| N | 뚜렷한 P파, QRS 앞 1:1, 형태 일정 | 규칙적 |
| AFIB | f파 — 무질서, 350~600/분 | **불규칙** |
| AFL | F파 — 톱니, 240~340/분, **규칙적 반복** | **규칙적**(2:1·3:1) |

추출(`build_atrial_feats`, Bollmann/Stridh 계열 표준):
QRST **중앙값** 템플릿 감산 → 3~12 Hz 대역통과 → 창(≈100초)마다 Welch PSD →
`daf`(지배 심방주파수) · `sc`(스펙트럼 집중도) · `sent`(스펙트럼 엔트로피) ·
`afl_ratio`(3.5~5.5Hz / 5.5~9Hz) · `aa_rms` · `aa_snr` 등 8종.

- 템플릿을 평균이 아니라 **중앙값**으로: 이소성 박·잡음이 섞여도 안 끌려간다.
- 박 하나(TQ 0.45초)로 스펙트럼을 보면 분해능 2.2 Hz 라 AFL(4~5.7)과 AFIB(5.8~10)이
  안 갈린다 → **반드시 창 단위**.
- 신호는 저장하지 않는다. 레코드 하나씩 받아 특징만 남기고 버린다(결과 <1MB).

### 10.2 가설

| | 가설 | 판정 |
|---|---|---|
| **H-P** | AFL 의 `sc`(집중도)가 AFIB 보다 높고 `daf` 가 낮다 | `atrial_audit()`. **모델 이전의 기전 검증** — 안 나오면 추출이 틀린 것이지 모델 문제가 아니다 |
| **H-N** | AFL 에서 A4 − A2 > 0 | 짝지은 부트스트랩 CI 가 0 배제. **AFL 환자 ≥30 확보 후에만 판정**(현재 7명, MDE 0.237) |
| **H-O** | AFIB 에서 A4 − A2 ≈ 0 | 영가설 방향. RR 이 이미 포화이므로 심방축이 AFIB 를 더 올리면 오히려 의심스럽다 |
| **H-Q** | A4 − A4c > 0 (AFL) | 시퀀스와 심방축이 **둘 다** 필요한가. A4c 만으로 충분하면 RSN 은 AFL 에 불필요 |

**H-P 를 먼저 돌린다.** 모델을 붙이기 전에 특징 자체가 생리와 맞는지 확인해야,
실패했을 때 추출을 고칠지 모델을 고칠지 알 수 있다. §13(R7)에서 실패 원인을
사후에 뒤진 것보다 나은 순서다.

**미리 정하는 것**: H-N 이 실패해도 심방 특징을 바꿔가며 재시도하지 않는다.
실패는 (a) AFL 표본 부족 (b) QRST 소거 실패 (c) 축 자체가 무력 중 하나이고,
(a)·(b)는 H-P 와 표본 수로 사전에 구분되므로 그 판정을 먼저 확정한다.
