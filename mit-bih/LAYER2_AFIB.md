# 2층(리듬·질환축) 설계 — AFIB / AFL

> 1층 = AAMI 비트(N/S/V/F/Q). 2층 = 리듬·질환(AFIB/AFL/…).
> 이 문서는 **결과를 보기 전에** 고정한다. 확정 후 판정 기준을 바꾸지 않는다.
> 코드: `afib_bench.py`, `ecg_multidb.py`(`RRDB_SPEC` / `build_rr_corpus`)

---

## 0. 왜 층을 나누는가 — 취향이 아니라 데이터 구조 때문

두 축은 **직교**한다. AFIB 구간의 박은 대부분 AAMI 클래스 N 이다. 하나의
다중클래스 softmax 로 합칠 수 없다. 더 결정적인 것은 **가용 DB 집합이 다르다**는 점:

| | 필요한 라벨 | 쓸 수 있는 DB | 환자 |
|---|---|---|---|
| 1층 | 감사된 비트 심볼 | mitdb, svdb, incartdb | 201 |
| 2층 | R위치 + 리듬 주석 | + afdb, ltafdb, nsrdb | 130+ |

층을 합치면 두 집합의 교집합(=201명, AFIB 10명)으로 줄어든다. **층을 나누는 것이
데이터를 안 버리는 유일한 방법이다.**

---

## 1. ★진입 전 판단 — 지금 데이터로는 2층을 돌려도 해석할 수 없다

현 `ecg_multi.npz` 의 AFIB 보유 레코드는 **10개**다. 환자단위 매크로 F1 의 MDE 는
그 리듬을 가진 환자 수로 정해진다(σ≈0.32 가정, `rr_audit_dbs()` 가 출력):

| AFIB 보유 환자 | MDE | 뜻 |
|---|---|---|
| **10 (현재)** | **0.198** | F1 0.75 와 0.95 를 구분 못 함 |
| +afdb(23) = 33 | 0.109 | 여전히 큼 |
| +ltafdb(84) = 117 | **0.058** | 비로소 판정 가능 |
| +nsrdb(18) = 135 | 0.054 | 특이도 음성대조 확보 |

**결론: 2층의 1단계는 모델링이 아니라 코퍼스 확보다.** §13.2(R7)에서 "실패를
고쳐서 다시 돌리지 않는다"고 정한 것과 같은 규율이다 — 판정 불가능한 실험은
돌려도 정보가 없다.

σ=0.32 는 1층 SVEB 에서 온 **가정**이다. AFIB 는 더 쉬운 과제라 σ 가 작을
가능성이 높다. 첫 실행 뒤 **환자별 F1 의 실측 표준편차로 갱신**하고, 그때
MDE 표를 다시 계산한다(가정을 결과처럼 쓰지 않는다).

## 2. 데이터 — ★신호(.dat)를 받지 않는다

리듬축은 R위치와 리듬 라벨만 있으면 된다. `.atr`/`.qrs` 주석만 받으면:

| DB | 레코드 | 길이 | 주석 | 받는 용량 |
|---|---|---|---|---|
| afdb | 23 (+2 주석전용) | 10h | `.atr` 리듬 / `.qrs` R위치 | ~10 MB |
| ltafdb | 84 | 24~25h | `.atr` (리듬+비트) | ~40 MB |
| nsrdb | 18 | 24h | `.atr` | ~10 MB |
| mitdb | 48 | 30m | `.atr` | ~1 MB |

신호까지 받으면 afdb ~620 MB / ltafdb ~2.8 GB, 주석만 받으면 **수십 MB**다.
(초안에 "~15 GB"라고 적었던 것은 과대 추정이었다.) 이 코퍼스 자체로는 형태축을
못 돌지만, §10 의 `build_atrial_feats` 가 레코드 하나씩 신호를 받아 **특징만 남기고
버리는** 방식으로 형태축을 붙인다(결과 파일 <1 MB).

**주의 — afdb 의 `.qrs` 는 자동검출·미감사다.** R위치로는 표준적으로 쓰이지만
AAMI 비트 클래스로는 절대 쓰면 안 된다. `RRDB_SPEC["afdb"]["beat_audited"]=False`
로 표시하고 `y5 = -1` 로 박아 오용을 차단한다.

**nsrdb 는 리듬 주석이 없다.** DB 정의상 전부 정상동조율이므로 `default_rhythm="N"`
으로 채운다 — 이것은 **가정**이며 코드가 그렇게 출력한다. 음성대조(특이도) 용도
외에는 쓰지 않는다.

## 3. 단위 — 비트가 아니라 창(window)

AF 는 에피소드 현상이고 문헌 표준 단위도 30초~128박 창이다. 현실적 제약도 같은
답을 가리킨다:

```
ltafdb 970만 박 × ±64박 문맥 실체화 = 4채널 × 129 × 4B = 20 GB   → 불가능
창(W=128, 비중첩)                 = 7.6만 창 × 4 × 128 × 4B = 156 MB
```

같은 정보를 128배 중복 저장하지 않는 것뿐이고, **인코더는 1층과 동일한 `_rsn`**
(형태 가지만 끔)이다. 그래서 "1층에서 유일하게 살아남은 효과(R1−R5 = +0.105)가
2층으로 전이되는가" 가 직접 검증된다.

- 채널은 1층 `rr_context` 와 동일한 무차원 4종. 정규화 통계(med/MAD)는 **레코드**
  기준이다 — 창 기준으로 잡으면 "이 구간이 기저보다 빠르다"가 창마다 지워진다.
- **전이구간 처리**: 창의 90% 이상이 한 리듬일 때만 그 리듬으로 라벨하고, 아니면
  `y=-1` 로 학습·평가에서 뺀다. 리듬이 바뀌는 경계를 한쪽으로 우겨넣으면 그
  오답이 모델 탓으로 계상된다.

## 4. 지표 — 창 F1 을 유일 지표로 쓰지 않는다

| 지표 | 왜 |
|---|---|
| **창단위 환자매크로 F1** | 1층과 **같은 추정량** → 층 간 비교가 성립 |
| **에피소드 Se/PPV** (중첩 기준) | 창 F1 은 긴 에피소드 하나가 지배한다. 임상 질문은 "발작을 놓쳤는가" |
| **AF burden r + Bland-Altman** | 항응고·재발감시가 전부 burden 기준. F1 이 같아도 burden 오차가 다르면 임상 가치가 다르다 |

- burden 은 **시간가중**이다(창 길이가 다르므로 개수로 세면 편향).
- 에피소드·burden 은 **비중첩 창만** 쓴다(중첩 창은 같은 에피소드를 여러 번 센다).
- 짧은 발작(≤3창)의 Se 를 따로 보고한다 — 여기가 burden 오차의 주 원인이다.

## 5. 팔(arm)

| arm | 내용 | 역할 |
|---|---|---|
| A0.자명 | 항상 다수 클래스 | 하한. 이 아래면 모델이 해로운 것 |
| **A1.RR산포** | RMSSD·pNN50·CV·ΔRR 엔트로피·Poincaré 10종 → MLP | **문헌 기준선**(1990~2010s AF 검출기 표준). 이걸 못 이기면 시퀀스 인코더는 값을 못 한 것 |
| **A2.RSN** | 1층과 같은 dilated TCN + 스칼라 보조 | 제안 |
| A2c.RSN(스칼라X) | 시퀀스만 | A2 의 이득이 스칼라 덕인지 가르는 대조군 |
| A3.RSN+도메인 | + DB 조건부 FiLM | ★같은 DB 안에서만 오르면 사전확률 암기 → 판정은 `split="db"` |

**2층-B(형태축)는 이 코퍼스에서 못 돈다.** mitdb 계열(신호 보유)로 따로 돌리고,
AFIB 10명 / AFL 4명 수준이라 **탐색적(exploratory)으로만** 보고한다.

## 6. 사전등록 가설 (결과 보기 전 고정, Bonferroni k=4)

판정 기준은 **MDE × 2.0** 이다(Bonferroni 로 z 1.96 → 2.50, 여유 포함).

| | 가설 | 판정 기준 |
|---|---|---|
| **H-J** | AFIB 에서 A2.RSN − A1.RR산포 > 0 | Δ > 2×MDE(AFIB) |
| **H-K** | A2 의 AFIB burden Bland-Altman LoA 폭이 A1 보다 좁다 | LoA 폭 비 < 1.0, 부트스트랩 CI 가 1 을 안 포함 |
| **H-L** | **AFL 에서 A2 − A1 ≤ 0** | ★영가설 방향의 예측. AFL 은 RR 이 규칙적이라 RR-only 는 구조적으로 실패한다 |
| **H-M** | LODO(`split="db"`)에서 A2 의 AFIB F1 하락 < 0.10 | afdb↔ltafdb 교차 |

**H-L 이 특별한 이유**: 이것은 "우리 모델이 이긴다"가 아니라 "**이 축으로는 안
된다**"를 미리 못 박는 예측이다. 확인되면 그것이 곧 **형태축(P/F파)이 필요하다**는
직접 근거가 되고, 기각되면 RR 만으로 AFL 이 되는 것이므로 그 자체가 발견이다.
어느 쪽이든 정보가 나온다 — §13(R7)에서 얻은 교훈의 적용이다.

**미리 정하는 것**: H-J 가 실패해도 A2 를 손보고 재실행하지 않는다. RR 기반 AF
검출은 문헌에서 이미 포화(Se/Sp 95%+)라 A1 을 못 이기는 것이 **정상적인 결과**다.
그 경우의 결론은 "RSN 은 2층 AFIB 에 추가 가치가 없다"이고, 값은 H-K(burden)·
H-L(AFL)·H-M(전이)에서 찾는다.

## 8. 알려진 한계 (미리 적어 둔다)

1. **레코드 = 환자 가정.** afdb/ltafdb 는 공식 환자 매핑이 없다. 한 사람이 두
   레코드에 걸쳐 있으면 환자분리가 깨진다. incartdb 에서 쓴 휴리스틱(§`incart_groups`)
   같은 안전장치가 여기엔 없다 — **검정력을 과대평가하는 방향**이므로 결과 해석에
   반영한다.
2. **nsrdb 의 "N" 은 주석이 아니라 가정이다**(§2).
3. **ltafdb 는 AF 가 매우 많다.** 클래스 사전확률이 DB 와 강하게 얽히므로 A3
   (도메인 FiLM)은 LODO 없이는 절대 판정하지 않는다.
4. **AFL 표본이 작다.** afdb 의 AFL 은 소수 레코드에 몰려 있어 H-L 은 방향만
   보고 크기는 보고하지 않는다.
5. **형태축은 이 코퍼스에 없다**(신호 미수집). 2층-B 는 별도·탐색적.

## 9. 1차 실측 (2026-07-28, afdb+mitdb, 환자 73, k=3)

창 10,362 (W=128 비중첩) / N 5,532 · AFIB 3,951 · AFL 89 / 전이구간 790 제외.

```
  arm                    N     AFIB      AFL     평균
  A0.자명             0.879    0.000    0.000    0.293
  A1.RR산포           0.950    0.916    0.441    0.769
  A2.RSN              0.953    0.920    0.371    0.748
  A2c.RSN(스칼라X)     0.960    0.928    0.376    0.755
  A3.RSN+도메인        0.959    0.901    0.386    0.749
  (보유 환자)             62       29        7
```

### 9.1 H-J 미달 — **사전등록대로의 결과**

AFIB 에서 A2 − A1 = **+0.004**. §6 에 "RR 기반 AF 검출은 이미 포화라 A1 을 못
이기는 것이 정상 결과이고, 그 경우 A2 를 손봐 재실행하지 않는다"고 미리 적었다.
그대로 따른다. 30년 된 고전 특징(RMSSD·pNN50·ΔRR 엔트로피·Poincaré)이 이미 천장에
닿아 있다.

### 9.2 ★그런데 burden 이 갈린다 — F1 을 유일 지표로 쓰지 않은 이유의 실증

| | AFIB burden r | Bland-Altman | LoA 폭 |
|---|---|---|---|
| A1.RR산포 | 0.912 [0.862,0.945] | +3.09 ± 28.6 %p | **57.2 %p** |
| **A2.RSN** | **0.970 [0.952,0.982]** | +2.12 ± 16.7 %p | **33.4 %p** |
| A2c | 0.956 | +2.79 ± 20.1 %p | 40.3 %p |
| A3 | 0.961 | +2.63 ± 19.0 %p | 38.0 %p |

**창 F1 은 +0.004 인데 burden 오차폭은 42% 좁아졌다.** 임상 언어로: 실제 burden
30%인 환자를 A1 은 1.4~58.6% 로, A2 는 13.3~46.7% 로 보고한다.

에피소드 Se(둘 다 0.987)와 PPV(0.667 vs 0.670)가 거의 같으므로, 두 모델은
**비슷한 양을 틀리되 틀리는 방식이 다르다** — A1 은 소수 환자에서 크게 빗나가고
A2 는 고르게 조금씩 틀린다는 가설. `burden_outliers()` 로 확인 대상.

⚠ **이 비교는 §6 사전등록 시점에 검정 코드가 없었다.** 두 r 의 CI 가 안 겹친다는
논리는 독립 표본용이고, 여기서는 같은 68명이라 짝지은 검정이 필요하다.
`paired_burden()` 을 구현했으므로 **재실행 시 그 결과로 판정한다.** 그전까지 이
발견은 "유망"이지 "확인"이 아니다.

### 9.3 H-L 확인 — 방향만

AFL 에서 A2 − A1 = **−0.070**(역행). 짧은 발작 Se 는 A1 0.333 → A2 **0.000**.
RR 시퀀스를 정교하게 모델링해도 AFL 은 안 잡힌다 — 2:1·3:1 전도로 **RR 이 오히려
규칙적**이라 RR 축에 정보가 없기 때문이다.

**단 AFL 환자 7명, MDE 0.237 이므로 −0.070 이라는 크기는 우연과 구분 불가다.**
§8.4 에 "방향만 보고 크기는 보고하지 않는다"고 미리 적은 대로 방향만 취한다.

### 9.4 알아야 할 한계

1. **AF 유병률이 부풀려져 있다** — 창의 38%가 AFIB. afdb 가 AF 전용 DB 이기
   때문이다. 실제 외래 홀터에서는 훨씬 드물다. **PPV 0.667 은 낙관적**이고
   실제로는 위양성 경보가 더 많을 것이다. nsrdb(정상 18명×24h)를 넣어야 교정된다.
2. **PPV 0.667 이 진짜 병목이다.** 발작 79건 중 78건을 잡았지만(Se 0.987) AF 라고
   외친 285건 중 95건이 헛경보다. 임상에서 문제되는 것은 놓친 발작보다 경보 피로다.
3. ltafdb 미포함 → AFIB 환자 29명(MDE 0.116). 넣으면 116명(MDE 0.058).

## 10. 2차 사전등록 — 심방활동 축 (결과 보기 전 고정)

§9.3 이 가리키는 곳은 하나다: **AFL 을 가르는 유일한 물리 신호는 심방 활동이고,
그건 파형에만 있다.** RR 축에는 원리적으로 없다.

### 10.1 무엇을 넣는가

| 리듬 | 심방 활동 | RR |
|---|---|---|
| N | 뚜렷한 P파, QRS 앞 1:1, 형태 일정 | 규칙적 |
| AFIB | f파 — 무질서, 350~600/분 | **불규칙** |
| AFL | F파 — 톱니, 240~340/분, **규칙적 반복** | **규칙적**(2:1·3:1) |

추출(`build_atrial_feats`, Bollmann/Stridh 계열 표준):
QRST **중앙값** 템플릿 감산 → 3~12 Hz 대역통과 → 창(≈100초)마다 Welch PSD →
`daf`(지배 심방주파수) · `sc`(스펙트럼 집중도) · `sent`(스펙트럼 엔트로피) ·
`afl_ratio`(3.5~5.5Hz / 5.5~9Hz) · `aa_rms` · `aa_snr` 등 8종.

- 템플릿을 평균이 아니라 **중앙값**으로: 이소성 박·잡음이 섞여도 안 끌려간다.
- 박 하나(TQ 0.45초)로 스펙트럼을 보면 분해능 2.2 Hz 라 AFL(4~5.7)과 AFIB(5.8~10)이
  안 갈린다 → **반드시 창 단위**.
- 신호는 저장하지 않는다. 레코드 하나씩 받아 특징만 남기고 버린다(결과 <1MB).

### 10.2 가설

| | 가설 | 판정 |
|---|---|---|
| **H-P** | AFL 의 `sc`(집중도)가 AFIB 보다 높고 `daf` 가 낮다 | `atrial_audit()`. **모델 이전의 기전 검증** — 안 나오면 추출이 틀린 것이지 모델 문제가 아니다 |
| **H-N** | AFL 에서 A4 − A2 > 0 | 짝지은 부트스트랩 CI 가 0 배제. **AFL 환자 ≥30 확보 후에만 판정**(현재 7명, MDE 0.237) |
| **H-O** | AFIB 에서 A4 − A2 ≈ 0 | 영가설 방향. RR 이 이미 포화이므로 심방축이 AFIB 를 더 올리면 오히려 의심스럽다 |
| **H-Q** | A4 − A4c > 0 (AFL) | 시퀀스와 심방축이 **둘 다** 필요한가. A4c 만으로 충분하면 RSN 은 AFL 에 불필요 |

**H-P 를 먼저 돌린다.** 모델을 붙이기 전에 특징 자체가 생리와 맞는지 확인해야,
실패했을 때 추출을 고칠지 모델을 고칠지 알 수 있다. §13(R7)에서 실패 원인을
사후에 뒤진 것보다 나은 순서다.

**미리 정하는 것**: H-N 이 실패해도 심방 특징을 바꿔가며 재시도하지 않는다.
실패는 (a) AFL 표본 부족 (b) QRST 소거 실패 (c) 축 자체가 무력 중 하나이고,
(a)·(b)는 H-P 와 표본 수로 사전에 구분되므로 그 판정을 먼저 확정한다.

### 10.3 실행 순서

```python

# ② 심방활동 특징 (신호를 레코드마다 받고 버림)
```

## 11. P-QRS-T '관계' 축 추가 (사용자 제안, 2026-07-28)

> 제안 요지: *"AFL 은 P:QRS:T 의 1:1:1 비율이 무너진 경우다. P·T 의 높이와 시간 차,
> 탈분극·재분극 간격, 파동 사이 간격을 학습하면 AFL 뿐 아니라 정상/비정상 자체를
> 가를 수 있다."*

### 11.1 ★왜 §10 의 잔차 스펙트럼만으로는 부족한가 — 합성으로 확인된 구조적 한계

QRST 평균감산은 **R 에 시간고정된 성분을 전부 지운다**. 따라서:

| | 심방 활동이 R 에 고정? | 잔차에 남는가 |
|---|---|---|
| N | **예**(PR 일정) | **아니오 — P 가 템플릿과 함께 지워진다** |
| AFIB | 아니오(무질서) | 예 |
| AFL **고정비**(2:1·3:1) | **예**(정수비라 R 에 고정) | **아니오 — 조동파도 지워진다** |

`selftest_atrial()` 이 합성 심전도로 이를 재현한다: 2:1 AFL 에서 `daf` 가 조동
주파수(5 Hz)가 아니라 잡음(7.5 Hz)으로 나오고, `daf_vh`(심실 고조파와의 거리) = 0.000
으로 **"이 daf 는 심방 증거가 아니다"** 가 드러난다. 정상은 `aa_rel` = 0.002 로 잔차가
사실상 0 이다.

**즉 잔차 스펙트럼은 AFIB 전용이고, AFL 과 '정상 P 의 존재' 는 원신호에서만 잴 수
있다.** 제안하신 축이 추가가 아니라 **필수**인 이유다.

### 11.2 무엇을 재는가 — 임상 판독 순서 그대로 (원신호에서)

| 특징 | 임상 대응 | 정상 | AFL | AFIB |
|---|---|---|---|---|
| **`tp_rms`** | **등전위 구간이 비어 있는가** (T정점~다음P의 RMS/QRS진폭) | **0.030** | **0.158** | 0.051 |
| **`pr_cv`** | PR 이 일정한가 = 1:1 전도인가 | **0.026** | 0.027 | **0.441** |
| `p_amp` `t_amp` `pt_ratio` | P·T 높이와 그 균형 | | | |
| `pr_med` | 방실 전도 시간 | | | |
| `rt_med` `rt_cv` | R→T 정점 = 재분극 시간과 그 변동 | | | |
| `p_cons` | 박간 P 형태 상관 (P 가 매번 같은 모양인가) | 높음 | | 낮음 |
| `pqt_ok` | P·T 를 둘 다 잡은 박의 비율 = **1:1:1 이 유지되는 비율** | | | |

위 숫자는 `selftest_atrial()` 의 합성 실측이다. **`tp_rms` 가 AFL 을 정상의 5배로,
`pr_cv` 가 AFIB 를 정상의 17배로 벌린다** — 두 리듬이 서로 다른 특징으로 갈린다.

### 11.3 이 축의 일반성 — AFL 을 넘어

"한 박에 P 하나, PR 일정, 그 사이는 비어 있음" 이 무너지는 것은 AFL 만이 아니다:

| 소견 | 어떻게 무너지나 | 어떤 특징이 잡나 |
|---|---|---|
| 2:1 방실차단 | QRS 당 P 가 2개 | `tp_rms`↑ (TP 안에 P 하나 더) |
| 1도 방실차단 | PR 연장 | `pr_med`↑ |
| 접합부 율동 | P 소실 또는 역행성 | `p_amp`↓ `pr_med`↓ |
| QT 연장 | 재분극 지연 | `rt_med`↑ |

즉 이 축은 2층 전체의 **'정상 소견' 기준선**이 된다. 지금은 AFIB/AFL/N 3종만
평가하지만, 리듬 클래스를 늘릴 때 그대로 쓰인다.

### 11.4 추가 사전등록

| | 가설 | 판정 |
|---|---|---|
| **H-R** | AFL 에서 `tp_rms`(AFL) > `tp_rms`(N) 이고 AFIB 에서 `pr_cv`(AFIB) > `pr_cv`(N) | `atrial_audit()`. **모델 이전의 기전 검증.** 합성에서는 이미 확인됨 — 실데이터에서 재확인 |
| **H-S** | AFL 에서 A4 − A2 의 이득이 `tp_rms` 계열 제거 시 사라진다 | 절제(ablation). 이득의 출처를 특정한다 |

**미리 정하는 것**: H-R 이 실데이터에서 실패하면 원인은 (a) P/T 검출 실패
(b) 잡음 (c) 리드 선택 중 하나다. `pqt_ok`(P·T 를 잡은 박의 비율)가 낮으면 (a),
`aa_snr` 이 낮으면 (b) 다. **모델을 고치기 전에 이 둘로 먼저 가른다.**

## 12. 심방활동·P-QRS-T 축 실측 (2026-07-28, afdb+mitdb, 창 9,129 / 환자 71)

### 12.1 ★사용자 제안 축이 최강 판별자를 냈다 — `p_cons`

박간 P파 형태 상관(원신호에서 측정):

| | N | AFIB | AFL |
|---|---|---|---|
| `p_cons` | **0.861** | **0.140** | **0.772** |

| 대비 | 창 AUC | 환자 AUC | 판정 |
|---|---|---|---|
| AFIB vs N | 0.920 | **0.962** | ★일치(견고) |
| AFL vs AFIB | 0.891 | **0.986** | ★일치(견고) |

**생리학적으로 완벽히 맞는다**: N 은 조직화된 P 가 매번 같은 모양, AFL 은 조직화된
F 파가 매번 같은 모양(다만 빠름), AFIB 는 무질서한 f 파라 매번 다르다.
→ **AFIB 를 N·AFL 양쪽에서 동시에 가른다.** "1:1:1 이 무너지는 방식"을 직접 잰 것이다.

이 특징은 **잔차가 아니라 원신호에서만 얻을 수 있다**(§11.1). 잔차에서는 N 의 P 가
템플릿과 함께 지워지므로 `p_cons` 자체가 정의되지 않는다.

### 12.2 두 번째 발견 — `daf_vh` 는 진단값이 아니라 판별자였다

`daf_vh`(지배주파수와 심실 고조파의 거리)는 원래 "daf 를 믿어도 되는가"를 알려
주려고 넣은 **진단값**이었다. 실측에서 AFIB vs N 환자 AUC **0.964** 로 최상위
판별자가 됐다. 기전이 명확하다: AFIB 의 심방 활동만 R 에 안 묶여 있으므로
스펙트럼 피크가 심실 고조파에서 떨어진다. 같은 논리로 `av_int` 도 0.919.

### 12.3 AFL — `av_ratio` 가 정확히 2.000

| | N | AFIB | AFL |
|---|---|---|---|
| `av_ratio` (심실 1박당 심방 편위) | 3.987 | 2.970 | **2.000** |
| `av_int` (정수와의 거리) | 0.034 | **0.213** | **0.020** |
| `sc` (집중도) | 0.286 | 0.281 | **0.655** |
| `afl_ratio` | 0.939 | 0.817 | **3.565** |
| `sent` (엔트로피) | 0.889 | 0.936 | **0.564** |

AFL 의 av_ratio = **2.000** — 교과서적 2:1 전도다. 사용자가 제안한 "비율" 착안이
숫자로 그대로 나왔다. AFL vs AFIB 환자 AUC: sc 0.986 / sent 1.000 / afl_ratio 0.972.

**단 AFL 은 창 5개 이상을 가진 환자가 3명뿐이다**(전체 7명 중). n=3 vs 24 에서
AUC≈1.0 이 우연일 확률은 1/2925 ≈ 0.0003 이라 우연은 아니지만, **효과 크기와
새 환자로의 일반화는 이 표본으로 말할 수 없다**(사전등록 §8.4).

### 12.4 ✗ `daf` 는 못 쓴다 — 두 번 확인됨

`daf`: N 4.63 / AFIB 4.88 / AFL 5.00 Hz. 세 리듬이 같은 대역이고, 문헌의 AFIB
5.8~10 Hz 와 어긋난다. 결정적 증거는 **N 의 av_ratio = 3.987 ≈ 4** 이다 —
정상 동조율의 daf 가 심박수의 정확히 4배라는 것은, daf 가 심방 활동이 아니라
**QRST 소거 잔차(=심박수에 시간고정된 성분)** 를 재고 있다는 뜻이다.

→ `daf` 단독 사용 금지. 스펙트럼 **모양** 지표(sc·sent·afl_ratio)와 **고조파와의
거리**(daf_vh·av_int)는 이 오염에 견디므로 그쪽만 쓴다.

### 12.5 ⚠ `rt_med` 는 심박수 대리일 가능성이 높다

rt_med(R→T 정점): N 0.236 / AFIB 0.204 / AFL **0.132** 초. AFL 이 짧은 것은
2:1 전도로 심실 박동이 150/분이 되어 **QT 가 심박수 따라 짧아진 것**일 수 있다.

심박수는 **이미 RR 축이 갖고 있는 정보**이므로, RR 과 붙은 특징의 판별력을 형태축
기여로 계상하면 이중 계산이다. `atrial_audit` 에 **심박수 교란 점검**을 넣었다 —
각 특징과 창 중앙 RR 의 |Spearman ρ| 를 출력하고 0.5 초과면 `⚠심박수 대리` 를 찍는다.
(합성 검증: RR 에 비례시킨 가짜 특징을 |ρ|=0.991 로, 리듬에만 반응하는 특징을
`독립적`으로 정확히 분리.)

### 12.6 H-R 판정 — 방향은 맞으나 `tp_rms` 는 약하다

```
tp_rms: N 0.0368 / AFIB 0.0423 / AFL 0.0388   → ★방향 확인 (AFIB/N = 1.15배)
pr_cv : N 0.3928 / AFIB 0.4807                → ★확인 (환자 AUC 0.758)
```

합성에서는 tp_rms 가 AFIB/N 1.7배, AFL/N 5.3배였는데 실데이터에서는 1.15배·1.05배로
크게 줄었다. 원인은 실제 심전도의 **기저동요·근전도가 모든 리듬의 TP 구간을 채워
바닥을 올리기** 때문으로 보인다. 어느 대비의 상위 8개에도 들지 못했다.

→ **개념은 옳다(같은 축의 `p_cons` 가 증명한다). 다만 `tp_rms` 라는 구현이
잡음 한계에 걸렸다.** 등전위 구간을 잡음 대비로 정규화하는 개선이 다음 후보다.

## 13. ★1차 A4 실행 무효 — 배선 오류 (2026-07-28)

`attach_atrial(w)` 를 거친 뒤 돌린 첫 2층 벤치는 **결과로 읽으면 안 된다.**
사전등록 비교(H-J/H-K/H-N)가 전부 무효다. 감춰 두지 않고 여기 남긴다.

### 13.1 무엇이 잘못됐나

`attach_atrial(w)` 는 `w["aux"]` 를 10 → 31 열로 **통째로** 늘렸는데, 모든 팔이
`w["aux"]` 전체를 입력으로 쓰고 있었다. 그래서

- **A1(문헌 기준선)** 이 RR 산포 10종이 아니라 심방특징까지 받았다 → 기준선이 아니다
- **A2·A2c·A3** 도 마찬가지로 심방특징을 받았다
- `_arm_rsn` 과 `_arm_rsn_atrial` 이 **글자 그대로 같은 호출**이었다
  (`use_seq=True, use_aux=True`) → **A2 ≡ A4**

즉 팔의 정의가 조용히 바뀌었다. 코드는 에러 없이 돌고, 표에는 서로 다른 이름이
나란히 찍혔다.

### 13.2 어떻게 들켰나 — 값이 '너무 같았다'

| arm | N | AFIB | AFL |
|---|---|---|---|
| A2.RSN | 0.931 | 0.934 | 0.462 |
| A4.RSN+심방활동 | 0.931 | 0.934 | 0.462 |

창 F1 뿐 아니라 에피소드 Se 0.975(77/79)·PPV 0.562(108/192), burden r=0.919,
LoA [−23.11, +32.81] 까지 **소수점 끝자리가 전부 일치**했다. 서로 다른 입력을 쓰는
두 신경망이 다른 초기값에서 학습해 비트 단위로 같은 예측을 낼 확률은 0 이다.
**"차이 없음"으로 읽었으면 '심방축은 효과 없다'는 가짜 음성 결론이 남았을 것이다.**

교훈: *모델 비교에서 두 팔의 값이 완전히 같으면 그것은 결과가 아니라 버그다.*

### 13.3 고친 것

1. `_aux_cols(w, mode)` — 팔은 이제 `"none"/"rr"/"atrial"/"all"` 중 하나를
   **선언해야** 하고, 선언하지 않으면 열이 붙지 않는다. `attach_atrial` 이
   `w["n_rr"]` 로 RR/심방 경계를 기록한다.
2. `_fit_win(..., aux="rr")` — `use_aux` 불리언을 모드 문자열로 교체.
   불리언은 "보조를 쓴다/안 쓴다" 만 말할 수 있어 **어떤** 보조인지 구분 못 한다.
   이 표현력 부족이 사고의 직접 원인이다.
3. `_check_distinct(OUT)` — 벤치 끝에서 팔끼리 예측 벡터를 전부 비교하고,
   같으면 `✗✗ 배선 오류` 를 찍는다. 다음에 같은 실수를 해도 조용히 못 지나간다.
4. 벤치 시작 시 **팔별 실제 입력**(시퀀스 O/X, 보조 모드와 열 수)을 출력한다.
5. 자기검증에 5항목 추가: 모드별 열 수, 모든 팔의 모드 선언, A2≠A4 열 수,
   A4c 시퀀스 미사용, 심방특징 없이 `atrial` 요구 시 예외.

### 13.4 무효 실행에서 **살아남는** 것

무효는 '팔 사이 비교'다. 팔과 무관한 값은 그대로 쓴다.

- **실측 σ (환자별 F1 표준편차)** — 가정했던 0.32 를 대체한다.

  | 리듬 | 실측 σ | 환자 n | MDE = 1.96σ/√n |
  |---|---|---|---|
  | N | 0.278 | 63 | 0.069 |
  | AFIB | 0.260 | 29 | 0.095 |
  | **AFL** | **0.516** | 7 | **0.383** |

  AFL 의 환자 간 변동이 가정의 1.6배다. AFL 에서 MDE 0.07 을 보려면 **환자 약
  209명**이 필요하다 — afdb+ltafdb 전체를 넣어도 도달하지 못한다. **AFL 은 앞으로도
  '방향만 보고 크기는 유보'로 다룬다**(§8 한계에 이미 적어 둔 것이 수치로 확인됨).
- **A2 의 실행 간 변화** — 심방특징 결합 전후로 AFL 0.371 → 0.462, AFIB 0.920 →
  0.934. 이것이 심방축의 효과일 **가능성**을 시사하지만, 두 실행은 코퍼스·폴드가
  달라 짝지어지지 않았고 AFL 변화 +0.091 은 MDE 0.383 에 한참 못 미친다.
  **증거가 아니라 재실행 동기다.**

### 13.5 재실행 (사전등록 유지)

§6·§10 의 가설·판정 기준은 **바꾸지 않는다**. 결과를 본 뒤 기준을 고치면
사전등록이 무의미해지고, 이번 무효는 가설이 아니라 배관의 문제였다.

```python
go("afib_bench")
```

## 15. LODO 실측 — A3 기각 (2026-07-28, afdb vs mitdb)

`bench_afib(w, split="db")`. **§14.3 에서 보류했던 A3 판정.**

### 15.1 A3 는 사전확률 암기였다 — 사전등록대로 기각

| 비교 | split="patient" | **split="db" (판정용)** |
|---|---|---|
| A3−A1 창 F1 (AFIB) | +0.013 [−0.012, +0.042] | +0.008 [−0.092, +0.097] |
| A3 vs A1 burden LoA 폭 비 | **0.572 [0.495, 0.818] ★유의** | 0.662 [0.523, **1.013**] 미달 |

**같은 DB 안에서만 유의했고, DB 를 갈라놓자 CI 가 1 을 포함한다.** §5 에 적어 둔
예측 그대로다: *"같은 DB 안에서만 오르면 사전확률 암기다."*
→ **A3 기각.** DB 조건부 FiLM 은 2층에서 채택하지 않는다.

이 결론은 §14.3 에서 결과를 보기 전에 이미 내려져 있었다. 사전등록이 실제로
한 일이 이것이다 — **유일하게 '유의'했던 결과를 버리게 만든 것.**

### 15.2 이 LODO 자체의 한계 (해석 전에 알아야 할 것)

DB 가 2개뿐이라 폴드가 극단적으로 비대칭이다.

| 폴드 | 학습 창 | 테스트 창 |
|---|---|---|
| LODO:afdb | **589** | 8,983 |
| LODO:mitdb | 8,983 | 589 |

**창 589개로 학습한 결과를 성능으로 읽으면 안 된다.** LODO 의 전 팔 F1 이
patient-split 보다 낮은 것(A1 AFIB 0.909 → 0.796)은 모델이 나빠서가 아니라
학습량이 1/15 이기 때문이다. 여기서 읽을 수 있는 것은 **팔 사이의 상대 순위**,
그중에서도 A3 가 우위를 잃었다는 사실뿐이다.
DB 를 3개 이상(+ltafdb, +nsrdb)으로 늘리기 전까지 LODO 는 A3 기각 용도로만 쓴다.

### 15.3 ★AFL σ=0.000 은 '완벽한 검정력'이 아니다 (보고 결함 수정)

LODO 에서 AFL 이 이렇게 찍혔다.

```
AFL   7   σ(가정) 0.320   σ(실측) 0.000   MDE(실측) 0.000
[AFL] A2.RSN − A1.RR산포  Δ=+0.0000 [+0.0000,+0.0000]  미달(0 포함)
[AFL] A3.RSN+도메인 vs A1  비 1.071 [1.002,2.104]  역행
```

MDE 0.000 은 "AFL 을 완벽하게 판정할 수 있다"가 아니라 **전 팔이 AFL 을 한 번도
검출하지 못해 환자별 F1 이 전부 0 이라 표준편차도 0** 이라는 뜻이다. 정보가 없는
것이지 정밀한 것이 아니다. 같은 이유로 Δ=0 은 '차이 없음'이 아니라 **'0 대 0'**
이고, burden 의 '역행' 판정도 두 팔 다 AFL 을 거의 예측하지 않아 생긴 잡음이다.

수정: `paired_win` 은 두 팔의 환자별 F1 이 전부 0 이면 `✗판정 불가` 를 찍고,
`sigma_measured` 는 그 리듬에 `✗측정 불가` 를 붙이고 경고를 출력한다.
**숫자가 나온다고 검정이 성립한 것은 아니다** — §13(배선)·§14.4(빠진 검정)와
같은 계열의 결함이고, 이번에도 "그럴듯한 숫자"가 판정으로 둔갑할 뻔했다.

## 16. build_atrial_feats 이어하기 (2026-07-28)

ltafdb 를 포함해 돌리던 중 `ltafdb/113`(누적 24,994 창)에서 런타임이 끊겨
**계산 결과가 통째로 사라졌다.** 원인은 두 가지다.

1. **중간 저장이 없었다.** 모든 창을 메모리에 쌓아 두고 마지막에 한 번 저장했다.
   수십 분짜리 작업이 중간 산출물을 안 남기는 것은 그 자체가 결함이다.
2. **창마다 `sig[:, c]` 를 다시 잘랐다.** 비연속 슬라이스라 매번 복사본이 생긴다.
   ltafdb 한 레코드가 2,200만 샘플이므로 창 800개 × 리드 2개 = **복사 1,600회
   (회당 ~88MB)**. 여기에 `wfdb.rdrecord` 의 float64 원본(레코드당 ~350MB)이
   루프 내내 살아 있었다. 메모리가 죽은 유력한 경로다.

수정:
- 레코드 하나가 끝날 때마다 `{_BASE}/atrial_parts/{db}_{rec}_W{W}s{stride}.npz`
  에 조각 저장(레코드당 <20KB, Drive). 다시 부르면 **있는 레코드는 건너뛴다**.
- 리드 절편을 레코드마다 한 번만 만들고(`col`), `rdrecord` 결과는 즉시 버린다.
- `keep_sig=False`(기본): 계산이 끝난 `.dat/.hea` 를 지운다. 조각이 남으므로
  신호를 보관할 이유가 없고 ltafdb 전체는 ~3GB 다.
- `cache_status()` 가 조각 개수를 DB별로 보여 준다 — "어디까지 됐나"의 답.
- `max_rec=N` 으로 나눠 돌릴 수 있다.

부수적으로 잡힌 것: `for r in rpk[...]` 가 wfdb 레코드 객체 `r` 을 덮어쓰고
있었다(루프 이후 `r` 은 정수). 지금은 `rp` 로 바꾸고 `r` 은 일찍 버린다.

| A4c.심방활동만 | 0.874 | 0.807 | 0.261 |
| (환자) | 112 | 106 | 7 |

★**자명한 하한이 바뀌었다.** ltafdb 를 넣어 AFIB 가 창의 54.4% 가 되면서 다수
클래스가 N → AFIB 로 뒤집혔다. 그래서 A0 의 AFIB F1 이 0.000 → **0.659** 다.
**AFIB 의 0.95 는 0 이 아니라 0.659 를 기준으로 읽어야 한다**(순이득 +0.29).
반대로 N 은 이제 A0 가 0.000 이라 처음으로 의미 있는 지표가 됐다.
또한 이 코퍼스는 AF 전용 DB 로 채워져 AFIB 유병률이 54% 다 — **선별검사 집단이
아니므로 PPV 는 일반 인구로 옮겨 읽을 수 없다.**

### 17.5 H-Q — 심방축만으로는 안 된다(RR 축이 필수)

A4 − A4c = **+0.1441 [+0.0957, +0.1956]** (AFIB). 심방·P-QRS-T 특징 21개만으로는

환자 106명으로 유의). AFL 에서는 여전히 n=7 로 판정 불가.

### 17.6 H-N — 여전히 판정 불가, 그리고 재시도하지 않는다

AFL 은 ltafdb 를 넣어도 **89창 / 7명에서 하나도 늘지 않았다**(§17.7). 실측 σ 0.436,
MDE 0.323. §10.2 의 사전 약속대로 **심방 특징을 바꿔가며 재시도하지 않는다.**
실패 원인은 (a) 표본 부족으로 확정됐다 — (b) QRST 소거 실패나 (c) 축 무력이
아니다(H-P·H-Q 가 축의 유효성을 보였다).

다만 AFL 에서 A4 의 부작용이 하나 보인다: 에피소드 Se 는 최고(0.625)인데
**PPV 가 0.056 (11/196)** 로 최저다. 심방특징이 AFL 을 과다예측하게 만든다.
탐색적 관찰로만 남긴다.

### 17.7 왜 ltafdb 가 AFL 을 못 늘렸나 — 데이터가 아니라 창 정의

ltafdb 에 AFL 비트가 13,093개(환자 11명) 있는데 AFL 창은 **89개 / 7명으로 불변**이다.
ltafdb 의 AFL 은 짧게 흩어져 있어 **연속 128비트의 90%를 채우는 구간이 없다** →
전부 전이구간(y=−1)으로 빠졌다. 전이구간이 790 → **7,267개**로 늘어난 것이 그 흔적이다.

이건 "AFL 데이터가 없다"가 아니라 **"있는 데이터를 창 정의가 버린다"** 다. 대책이
다르다(수집 vs W·purity 조정). `make_windows` 가 리듬별 `비트/최대창/실제창/효율`을
찍고 효율 25% 미만이면 경고하도록 고쳤다.

### 17.8 종합 — 2층에서 무엇이 판정됐나

1. **AFIB 검출·burden 정량은 RR 축만으로 사실상 해결된다.** A1(스칼라 10개 + MLP)
   F1 0.953, burden r 0.990. 자명한 하한 0.659 대비 순이득 +0.29.
2. **RSN 시퉀스 인코더는 2층에 기여하지 않는다.** H-J 정밀 음성(최대 +0.022),
   H-K 는 반대 방향으로 유의. → **2층 채택 모델은 A1 이다.**
3. **DB 조건부 FiLM(A3)은 사전확률 암기였다**(§15, LODO 로 기각).
4. **심방·P-QRS-T 축은 단독으로 부족하고**(H-Q), AFIB 에서는 순효과가 없다(H-O).
   AFL 에서의 가치는 **표본 때문에 판정 불가** — 축이 틀렸다는 증거가 아니다.
5. RSN 의 가치는 1층(비트 형태)에 있고 2층(리듬)에는 없다. **층마다 다른 도구가
   맞다는 것이 §0 의 층 분리 논거를 사후에 지지한다.**

### 17.9 다음에 할 수 있는 것 (사전등록 전, 후보)

- **AFL 전용 창 실험**: `W=32`(≈27초) + 같은 purity. 4~5 Hz F파에 주파수 분해능은
  충분하다. AFL 창이 몇 배로 늘어나는지가 먼저이고, 늘어난 뒤에 H-N 을 다시 등록한다.
  ★새 실험이므로 AFIB 판정을 건드리지 않는 별도 가설로 등록한다.
- **작동점(threshold) 조정**: 지금은 argmax 다. AFIB 에피소드 PPV 가 0.64~0.83 에
  머무는데 Se/PPV 교환을 조정하지 않았다. 임상 용도(선별 vs 확진)에 따라 다른 점을
  고를 수 있다.
- 유병률 54% 코퍼스라 **PPV 의 외부 타당도가 없다.** 일반 인구 추정치로 옮기려면
  유병률 보정 또는 전향 코호트가 필요하다.

## 18. 작동점(operating point) 조정 — 사전등록 (결과 보기 전 고정)

### 18.1 왜

§17 까지의 모든 예측은 **argmax** 다. 그건 "사후확률이 가장 큰 클래스"이고 임상적
목표가 아니다. 선별검사는 놓치지 않는 것(Se)이, 항응고 결정은 헛경보를 줄이는
것(PPV)이 중요한데 argmax 는 둘 중 어느 것도 목표로 삼지 않는다.
§17 에서 AFIB 에피소드 PPV 가 0.64~0.83 에 머문 것은 **작동점을 안 고른 결과**일
수 있다 — 모델을 바꾸지 않고 남아 있는 여지다.

### 18.2 ★가장 중요한 함정 — 문턱을 고른 데이터로 성능을 재면 안 된다

문턱 200개를 훑어 가장 좋은 것을 골라 그 점수를 보고하면, 그것은 "이 표본에서
운 좋은 문턱"의 성능이라 **반드시 부풀려진다**(200번의 선택 = 200번의 다중비교).

그래서 **환자 단위 leave-one-out** 으로 고른다: 환자 p 의 문턱은 p 를 뺀 나머지
환자에서 고르고, p 는 그 값으로만 평가한다. p 자신의 라벨은 선택에 관여하지 않는다.
낙관 편향의 크기를 보이려고 '오라클'(자기 포함 선택) 값을 **함께** 찍는다.
자기검증에 `LOO ≤ 오라클` 을 못 박아 두었다 — 이게 깨지면 선택이 새는 것이다
(합성 검증에서 LOO 0.6859 / 오라클 0.7137, 편향 +0.028).

### 18.3 가설

| | 가설 | 판정 |
|---|---|---|
| **H-R2** | AFIB 에서 LOO 작동점의 창 F1 ≥ argmax | 짝지은 부트스트랩. **오라클 값으로 판정하지 않는다** |
| **H-S2** | `criterion="se_at_ppv"` 로 PPV ≥ 0.90 을 만족시키면서 Se ≥ 0.90 을 유지할 수 있다 | 못 하면 이 모델의 Se-PPV 교환이 그 지점에서 한계라는 뜻 |
| **H-T2** | 작동점을 옮겨도 burden r 은 나빠지지 않는다 | burden 은 문턱에 민감하다(과다예측 → 편향↑). Se 를 올려 얻은 것을 burden 에서 잃는지 본다 |

**미리 정하는 것**: 작동점은 **A1(§17.8 의 채택 모델)** 에서 고른다. 여러 팔에서
고르고 가장 좋은 것을 보고하면 팔 선택까지 다중비교가 된다. 다른 팔의 값은
참고로만 찍는다.

### 18.4 실행

```python
go("op_curve", "op_point", "report_op")
OUT = load_afib("run_ltaf_k3")          # 학습 0초
op_curve(OUT, "A1.RR산포", "AFIB")      # 기술용 — 여기서 눈으로 고르지 말 것
report_op(OUT, arms=["A1.RR산포"], cls="AFIB", criterion="f1")
report_op(OUT, arms=["A1.RR산포"], cls="AFIB", criterion="se_at_ppv", min_ppv=0.90)
```

## 19. P-QRS-T 축(사용자 제안)의 현재 판정 상태 — '기각' 아님

혼동하기 쉬우므로 무엇이 기각됐고 무엇이 아닌지 한 표로 고정한다.

| 명제 | 상태 | 근거 |
|---|---|---|
| 심방·P-QRS-T 특징이 리듬을 **판별한다** | **확인** | §12: `p_cons` N 0.861 / AFIB 0.140 / AFL 0.772. AFIB-vs-N 환자 AUC 0.962, AFL-vs-AFIB 0.986 |
| AFL 의 `sc`·`afl_ratio` 가 AFIB 와 다르다 (H-P) | **확인** | §12.2. AFL `av_ratio` = 2.000(교과서 2:1) |
| 이 축**만으로** 창 분류가 된다 | **기각** | H-Q: A4−A4c = **+0.144** [+0.096, +0.196]. A4c 단독 0.807 |
| **AFIB** 에서 이 축이 추가 이득을 준다 | **없음(예측대로)** | H-O: A4−A2 = −0.010. §10.2 에 "AFIB 는 RR 이 포화이므로 ≈0 이 예측"이라 **미리** 적었다 |
| **AFL** 에서 이 축이 이득을 준다 (H-N) | **판정 불가** | AFL 환자 7명, MDE 0.323. §10.2 의 "AFL ≥30 확보 후 판정" 조건 미달 |
| 시간축 델타(`pr_cv`·`rt_med`·`rt_cv`) | **약함 / 미해결** | `pr_cv` 환자 AUC 0.758(중간). `rt_med` 는 **심박수 교란** 판정을 받고 아직 점검 안 됨(§12.7) |
| 등전위 구간 RMS(`tp_rms`) | **약함** | 합성 5.3배 → 실데이터 1.05배. 잡음 바닥에 걸림(§12.6) |

**요약**: 제안의 **형태 일관성** 부분(`p_cons`)은 지금까지 찾은 가장 강한 단일
판별자이고 반증된 적이 없다. **시간 간격 델타** 부분이 약했다. 그리고 정작 이 축이
효과를 낼 표적(AFL)은 **측정 자체가 안 됐다** — 축이 틀렸다는 증거가 아니라
표본이 없다는 뜻이다. 따라서 '기각'으로 정리하면 사실과 다르다.

**남은 미해결 하나**: `rt_med` 의 심박수 교란 점검(Bazett 등 심박 보정 후 재평가)을
§12.7 에 "점검 후 판단"으로 남겨 두고 아직 하지 않았다. 이건 열린 고리다.

## 20. 작동점 실측 (2026-07-30, run_ltaf_k3, 학습 0초)

### 20.1 H-R2 미달 — argmax 가 이미 F1 최적점이었다

```
문턱 중앙값 0.500   F1  argmax 0.9527 → LOO작동점 0.9527 (+0.0000)
                        [오라클 0.9527, 편향 +0.0000]
```

LOO 가 **모든 환자에게 0.5 를 골랐다**. 문턱 200개를 훑어도 argmax 보다 나은 점이
없다. 낙관 편향이 정확히 0 인 것도 같은 사실의 다른 표현이다(넓고 평평한 최적점이라
누구에게나 같은 문턱이 이긴다). **F1 을 목표로 하는 한 작동점에 남은 여지는 없다.**

### 20.2 H-S2 — 제약은 만족되지만 임상적으로 쓸 수 없다

`criterion="se_at_ppv", min_ppv=0.90` → 문턱 0.020 선택:

| | argmax | 작동점(문턱 0.020) |
|---|---|---|
| 창 F1 | 0.9527 | **0.8405** |
| 에피소드 Se | 0.965 | **0.992** |
| 에피소드 PPV | 0.702 | **0.143** |
| 예측 에피소드 수 | 771 | **2,049** |
| burden r | 0.990 | **0.840** |
| burden LoA 폭 | 23.9 %p | **92.9 %p** |

에피소드 Se 를 0.965 → 0.992 로 올리는 대가로 PPV 가 0.702 → 0.143, burden LoA 가
4배가 된다. **H-T2 확인**: 작동점을 옮겨 Se 를 얻으면 burden 을 잃는다.

★**여기서 내 구현의 결함이 하나 드러났다.** `se_at_ppv` 의 제약을 **창 단위 통합
(pooled) PPV** 로 걸었는데, 헤드라인 지표는 **환자매크로** F1 이다. AFIB 가 창의
54% 라 통합 PPV 는 burden 높은 환자가 지배하므로, 통합 PPV ≥ 0.90 을 만족시켜도
burden 낮은 환자에서는 PPV 가 붕괴한다. 제약은 **환자매크로 PPV** 로 걸어야 한다.

### 20.3 ★진짜 병목은 문턱이 아니라 **파편화**다

| | 창 단위 | 에피소드 단위 |
|---|---|---|
| PPV (문턱 0.327) | **0.987** | — |
| PPV (argmax) | ~0.99 | **0.702** |

창 단위 PPV 가 0.987 인데 에피소드 PPV 는 0.702 다. 참 에피소드 254건에 대해
**771건을 예측**했다. 창은 거의 다 맞히는데 **띄엄띄엄 맞혀서** 가짜 에피소드가
517건 생긴 것이다. 이것은 문턱으로 못 고친다 — 문턱은 창 하나하나를 독립으로
보기 때문에 시간축의 파편을 합쳐 주지 않는다.

필요한 것은 **시간축 후처리**다(다음 후보):
- 최소 지속시간 규칙(연속 2~3창 미만 예측은 버림)
- 히스테리시스(진입 문턱 > 이탈 문턱) — 임상 홀터 소프트웨어의 표준
- 창 열에 중앙값 필터

★이것이 §17.9 에서 "작동점에 여지가 있다"고 적은 것의 실제 정체다. 여지는 있는데
**문턱이 아니라 후처리**에 있다. 작동점 실험은 그 위치를 특정한 것이 성과다.

## 21. 심박수 보정 감사 — §12.7 의 열린 고리 닫기 (구현, 결과 대기)

`rate_correct_audit()`. 보정식 `x_c = x / RR^α` (α=1/3 Fridericia, 1/2 Bazett,
2/3, 1.0, **그리고 N 창에서 데이터로 추정한 α**).

### 21.1 왜 α 를 추정도 하는가

α 를 고르는 것 자체가 가정이다. N 창에서 `log(x)` 를 `log(RR)` 에 회귀한 기울기가
곧 이 표본의 α 다. 부정맥 창을 쓰지 않는 이유: 거기서는 RR 자체가 리듬의 신호라
기울기가 오염된다.

### 21.2 ★판정 논리 — 보정은 '개선'이 아니라 '정체를 밝히는 검사'다

보정 뒤 판별력이
- **사라지면** → 원래 판별력은 심박수였다(형태축 기여로 세지 말 것)
- **남으면** → 심박수와 독립인 형태 정보가 있다

### 21.3 합성 검증이 잡은 결함 4개 (`test_rate_correct.py`)

정답을 아는 합성 특징 2종(`rt` = 순수 심박수 함수 / `pr` = 순수 형태)으로 검증했고,
**감사 자체의 결함 4개**가 드러났다.

1. **완전 보정된 특징은 상수가 되는데, 그 부동소수 잡음을 순위 매겨** AUC 0.667 →
   "형태 정보 있음" 이라는 정반대 결론. → 정보량(IQR/중앙값) 게이트 추가.
2. **교란 ρ 를 주변(marginal)으로 재면 안 된다.** 리듬이 심박수를 정하므로
   (AFIB 빠름·N 느림) 리듬을 잘 가르는 특징은 **무엇이든** RR 과 상관이 생긴다.
   판별 AUC 1.000 인 순수 형태 특징이 ρ=0.49 로 '심박수 대리' 판정을 받았다.
   → **N 창 안에서의 ρ** 로 교체.
   ★**§12.7 의 `rt_med` '⚠심박수 교란' 판정도 주변 ρ 로 내린 것이라 같은 결함을
     갖는다.** 그 판정 자체를 이 감사가 다시 내려야 한다.
3. 심박수 겹침 구간이 없을 때 `band=None` 을 넘겨 **비맞춤 AUC 로 조용히 되돌아갔다**
   → "심박수를 맞춰도 갈린다"는 결론이 위조될 수 있었다. (이번 세션에 반복해서
   나온 '조용한 되돌아감' 패턴이 또 나왔다.)
4. 적격 구간 1개 × 환자 3명에서 나온 AUC 0.667 을 판별력으로 계상 → 구간 ≥2,
   가중합 ≥12 게이트 추가.

### 21.4 그리고 이진 판정을 포기했다

`|AUC−0.5| > 0.10` 같은 **고정 문턱으로 '독립' 을 선언하는 것 자체가 검증 불가능**했다.
구간 폭(0.06초) 안에 남는 잔여 심박수 기울기 때문에 순수 심박수 특징도 맞춤 AUC 가
정확히 0.5 가 되지 않는다(합성에서 0.359). 그래서 **감소율을 보고**하고
애매한 구간은 `△부분적 — 판별력 N% 감소(해석 필요)` 로 남긴다.
검증할 수 없는 문턱으로 단정하는 것보다 낫다.

### 21.5 결정적 지표: 심박수 맞춘 AUC

RR 을 0.06초 폭 구간으로 층화해 **구간 안에서** 환자단위 AUC 를 내고, 양쪽 모두
환자 3명 이상인 구간만 가중평균한다. 구간 안에서는 심박수가 사실상 같으므로,
거기서도 갈린다면 그것은 심박수가 아니다. `ρ` 만으로는 부족하다 — Spearman 은
크기를 안 보므로 무한히 작은 의존도 ρ=1 을 낸다.

### 21.6 실행

```python
go("rate_correct_audit")
rate_correct_audit(atrial=f"{_BASE}/afib_atrial_all.npz", W=128,
                   targets=("rt_med", "pr_med"))
```

사전등록: **H-U** `rt_med` 는 심박수를 맞추면 판별력의 65% 이상을 잃는다(= §12.7 의
교란 의심이 옳다). **H-V** `pr_med`·`pr_cv` 는 50% 이상 유지한다(= 전도 일관성은
심박수와 독립인 정보다). 어느 쪽이든 **결과를 보고 기준을 바꾸지 않는다.**

## 22. 심박수 보정 실측 (2026-07-30, 창 74,131 / 환자 155) — §12.7 고리 닫힘

### 22.1 먼저 내 코드 결함 하나 (수치 재계산)

첫 출력에 `★심박수 맞춰도 160% 유지` 가 찍혔다. 비율이 1 을 넘을 수 없는데 넘었다.
원인: 유지율을 **전체 AUC 의 최대 ÷ 맞춤 AUC 의 최대**로 계산했는데, 맞춤이 되는
쌍은 AFIB/N 하나뿐이고(AFL 은 7명이라 구간마다 환자 3명이 안 됨) 전체 최대는 흔히
AFL 쌍에서 나온다 → **서로 다른 쌍을 나눴다.** 쌍별 계산으로 고쳤다.

또 비율 자체가 불안정하다: 분모(보정 후 전체 AUC)가 0.5 를 지나가는 α 가 있어
rt_med 의 비율이 α 에 따라 28% → 533% → 34% 로 튀었다. 반면 **맞춤 AUC 는
0.557~0.570 으로 거의 움직이지 않았다.** 움직이지 않는 쪽이 답이므로 **맞춤 AUC 를
주지표**로 바꿨다.

### 22.2 α 추정값 — Bazett 이 이 데이터에서 거의 맞는다

| 특징 | N 창에서 추정한 α | 참고 |
|---|---|---|
| **`rt_med`** | **0.558** | Bazett 0.5 / Fridericia 0.333 / 사용자 제안 0.667 |
| `pr_med` | 0.217 | PR 은 AV 전도라 심박 의존이 훨씬 약하다(생리와 부합) |
| `pr_cv` | −0.378 | ★무차원 특징 — 보정식이 성립하지 않는다 |
| `rt_cv` | −0.842 | ★같음 |

**R→T 정점 간격이 이 표본에서 RR^0.558 로 변한다.** 사용자가 물은 2/3(0.667)보다
**Bazett(0.5)에 가깝다.** 교과서 상수가 실측으로 확인된 셈이다.

★`pr_cv`·`rt_cv` 는 이미 **무차원**(SD/평균)이라 RR^α 로 나누는 것은 보정이 아니라
RR 의존을 **주입**하는 것이다. 추정 α 가 음수로 나온 것이 그 신호다. 이 둘은
**α=0 행만** 의미가 있다(경고를 코드에 넣었다).

### 22.3 판정 — 심박수를 맞춘 AUC (AFIB vs N)

| 특징 | 전체 환자 AUC | **심박수 맞춘 AUC** | 판정 |
|---|---|---|---|
| **`rt_med`** (보정 없음) | 0.298 | **0.557** | **✗ 판별력의 대부분이 심박수** |
| `rt_med` (α 를 뭘 써도) | 0.39~0.71 | **0.557~0.570** | 같음 — α 와 무관하게 못 가른다 |
| **`rt_cv`** | 0.692 | **0.585** | △ 약함 |
| **`pr_med`** | 0.625 | **0.751** | **★ 심박수와 독립** |
| **`pr_cv`** | 0.773 | **0.756** | **★ 심박수와 독립** |

**H-U 지지.** `rt_med` 는 보정 전 AUC 0.298(= AFIB 에서 rt 가 짧다)인데, 심박수를
맞추면 0.557 로 **방향이 뒤집히면서 거의 0.5** 가 된다. AFIB 에서 rt 가 짧아 보인 것은
**AFIB 가 빨랐기 때문**이다. §12.7 의 '⚠심박수 교란' 의심이 옳았다 —
다만 그때의 판정 근거(주변 ρ)는 결함이 있었고, 이번 검사가 제대로 확인했다.

**H-V 지지.** `pr_med`·`pr_cv` 는 심박수를 맞춰도 AUC 0.75 를 유지한다. **PR 간격과
그 변동은 심박수와 독립인 정보다.** 오히려 `pr_med` 는 맞추면 0.625 → 0.751 로
**올라간다** — 심박수가 신호를 가리고 있었다는 뜻이다(AFIB 가 빨라서 PR 이 짧아지는
효과가 진짜 AV 전도 차이를 상쇄했다).

### 22.4 사용자 제안(§11)의 최종 정리

제안은 세 부분이었고 성적이 갈렸다.

| 부분 | 대표 특징 | 결론 |
|---|---|---|
| **P파 형태 일관성** | `p_cons` | **최강** — 환자 AUC 0.962(AFIB/N)·0.986(AFL/AFIB) |
| **P-QRS 전도 간격·변동** | `pr_med` `pr_cv` | **★유효** — 심박수 맞춰도 AUC 0.75 |
| **재분극 시간(R→T)** | `rt_med` `rt_cv` | **✗ 심박수 중복** — 맞추면 0.56 |
| 등전위 구간 RMS | `tp_rms` | 약함(잡음 바닥, §12.6) |

즉 **"P파 쪽(전도)은 유효하고 T파 쪽(재분극)은 심박수의 대리"** 다. 시간축 델타를
통째로 기각할 것이 아니라 **PR 계열은 채택, RT 계열은 폐기**가 맞다.
`rt_med`·`rt_cv` 는 형태축 기여로 세지 않는다(어차피 RR 축이 그 정보를 갖고 있다).

★단, 이 판정은 전부 **AFIB vs N** 에서만 나왔다. AFL 쌍은 환자 7명이라 심박수를
맞출 수 있는 구간이 하나도 없었다(전부 `—`). **AFL 에 대해서는 여전히 아무것도
판정하지 못한다.**

### 22.5 남은 것

- `rt_med`·`rt_cv` 를 `ATR_NAMES` 에서 빼는 대신 **남겨 두고 표시만 한다**. 지우면
  이 판정을 재현할 수 없고, 모델에서는 A4 가 어차피 이득을 못 냈다(H-O).
- AFL 판정에는 §17.9 의 **W=32 실험**이 선행 조건이다. 그것 없이는 이 축의
  본래 표적을 영원히 못 잰다.

## 23. AFL 전용 창 실험 — 사전등록 (결과 보기 전 고정, 2026-07-30)

### 23.1 순서가 요점이다 — 신호를 받기 전에 라벨로 답을 낸다

§17.7 에서 ltafdb 의 AFL 비트 13,093개(환자 11명)가 **창을 하나도 만들지 못했다**
(연속 128비트의 90%를 채우는 구간이 없어서). 그래서 "W 를 줄이면 되찾는가" 가
다음 질문이다.

★그런데 이걸 확인하려고 신호 3.6GB 를 다시 받고 심방특징을 W=32 로 다시 만드는 것은
**순서가 틀렸다.** 창의 개수·환자 수는 **주석만으로** 결정된다 — 신호가 필요한 것은
심방특징뿐이다. `win_label_scan()` 은 라벨·순도만 세므로 몇 초에 끝나고, 창 텐서를
만들지 않아 RAM 도 안 쓴다.

즉 **관문을 먼저 통과해야 다운로드를 한다.**

### 23.2 관문 (H-W)

| | 조건 | 다음 행동 |
|---|---|---|
| **H-W 통과** | 어떤 W 에서 **AFL 환자 ≥ 30** | 그 W 로 심방특징 재생성 → H-N 을 처음으로 판정 |
| **H-W 미달** | 어떤 W 에서도 30명 미만 | **신호를 다시 받지 않는다.** AFL 은 탐색적 보고로 확정하고, 표본은 **다른 DB** 로만 늘릴 수 있다고 결론 |

30명 기준은 §10.2 에서 **결과를 보기 전에** 정한 값이다(실측 σ_AFL = 0.461 →
MDE 0.165, 여전히 크지만 방향+크기를 함께 말할 수 있는 하한). 지금 바꾸지 않는다.

### 23.3 W 를 표본만 보고 고르지 않는다

창을 줄이면 표본은 늘지만 대가가 있다.

| W | ≈초 | 심방파 스펙트럼 분해능 | 위험 |
|---|---|---|---|
| 128 | ~109 | 0.009 Hz | 전이구간 손실 큼(§17: 9.0%) |
| 32 | ~27 | 0.037 Hz | AFL 4~5Hz vs AFIB 6~9Hz 구분에 충분 |
| 16 | ~14 | 0.073 Hz | 창 안 RR 개수가 적어 산포 스칼라(RMSSD·pNN50)가 불안정 |

**W=32 가 하한이다.** 그 아래는 (a) RR 산포 스칼라의 표본이 16개뿐이라 A1 기준선이
망가지고 (b) `p_cons` 의 박간 상관도 표본이 줄어 불안정하다. 즉 **W=16 에서 AFL 환자가
30 을 넘어도 채택하지 않는다** — 이것도 결과 보기 전에 정해 둔다.

### 23.4 실행

```python
go("win_label_scan")
d = load_rr()
win_label_scan(d, dbs=("afdb", "ltafdb", "mitdb"))     # 몇 초. 신호 안 받음
```

관문을 통과하면(W ∈ {32, 48, 64} 에서 AFL ≥ 30):
```python
build_atrial_feats(dbs=("afdb","ltafdb","mitdb"), W=32, prefetch=3,
                   out=f"{_BASE}/afib_atrial_W32.npz")   # 조각은 W 별로 따로 저장됨
w32 = make_windows(d, W=32, dbs=("afdb","ltafdb","mitdb"))
w32 = attach_atrial(w32, path=f"{_BASE}/afib_atrial_W32.npz")
OUT32 = bench_afib(w32, k=3, tag="run_W32")
report_afib(OUT32)
```

★**AFIB·N 의 판정은 W=128 결과(§17)를 유지한다.** W 를 바꿔 다시 돌린 뒤 더 좋은
쪽을 보고하면 그것은 W 에 대한 다중비교다. W=32 실험의 목적은 **AFL 하나**이고,
AFIB·N 은 참고로만 본다.

## 24. H-W 미달 확정 — AFL 은 창 정의 문제가 아니었다 (2026-07-30)

`win_label_scan(d, dbs=("afdb","ltafdb","mitdb"))`, 주석만, 수 초. **신호를 받지 않았다.**

### 24.1 결과

| W | ≈초 | N 환자 | AFIB 환자 | **AFL 창** | **AFL 환자** | AFL MDE | 전이% |
|---|---|---|---|---|---|---|---|
| 16 | 14 | 115 | 116 | **781** | **10** | 0.286 | 6.5% |
| 24 | 20 | 115 | 116 | 514 | 9 | 0.301 | 7.3% |
| 32 | 27 | 115 | 116 | 382 | 9 | 0.301 | 7.3% |
| 48 | 41 | 115 | 113 | 250 | 8 | 0.319 | 8.2% |
| 64 | 54 | 115 | 110 | 189 | 9 | 0.301 | 8.3% |
| 96 | 82 | 113 | 107 | 120 | 7 | 0.342 | 8.7% |
| 128 | 109 | 112 | 106 | 89 | 7 | 0.342 | 9.0% |

**H-W 미달.** 어떤 W 에서도 AFL 환자 30명에 닿지 않는다(최대 W=16 에서 10명).
사전등록대로 **신호를 다시 받지 않는다.**

### 24.2 ★§17.7 의 강조점이 틀렸다 — 수정

§17.7 에 *"AFL 데이터가 없는 게 아니라 창 정의가 버린다"* 고 썼다. 창에 대해서는
맞지만 **구속조건을 잘못 지목했다.**

| W 를 128 → 16 으로 | 배수 |
|---|---|
| AFL **창** | 89 → 781 = **8.8배** |
| AFL **환자** | 7 → 10 = **1.4배** |

**환자매크로 F1 의 유효표본은 환자다.** 같은 사람에게서 창을 8.8배 더 뽑아도
검정력은 거의 안 오른다(MDE 0.342 → 0.286, 목표 0.165 에 한참 못 미침).

창 정의가 실제로 환자 3명을 버리고 있었던 것은 맞다(7 → 10). 그러나 **구속조건은
"afdb+ltafdb+mitdb 에 AFL 을 가진 사람이 애초에 11명뿐"** 이라는 사실이고, 창을
줄여 그중 10명까지 회수한 것이 한계다. 즉 **회수할 수 있는 것은 거의 다 회수됐다.**
§17.7 은 "창 정의도 일부 손실을 만든다(환자 3명)" 로 읽어야 하고, 주된 원인이
아니다.

### 24.3 그래서 AFL 에 대한 결론 (확정)

**MDE 0.165 를 위해 AFL 환자 30명이 필요하고, 이 세 DB 에는 11명이 존재한다.**
창 정의·모델·특징을 어떻게 바꿔도 이 수는 늘지 않는다. 따라서:

- **AFL 은 이 코퍼스에서 영구히 탐색적(exploratory)** 이다. §17.6·§22.4 의 AFL
  관련 서술은 모두 "방향만, 크기는 유보" 로 확정한다.
- H-N(심방축이 AFL 을 돕는가)은 **판정 불가로 종료**한다. 실패가 아니라 **측정
  불가**이고, §10.2 의 약속대로 특징을 바꿔가며 재시도하지 않는다.
- 사용자 제안(§11)의 AFL 표적 부분은 **반증된 적이 없고 확인된 적도 없다.**
  §22.4 의 판정(PR 계열 채택 / RT 계열 폐기)은 전부 AFIB vs N 에서 나온 것이다.

### 24.4 AFL 을 정말 하려면 — 단위가 바뀐다 (새 층의 문제)

AFL 라벨이 충분한 공개 데이터는 **CinC Challenge 2020/2021 계열**(CPSC, PTB-XL,
Chapman-Shaoxing, Ningbo, Georgia)이다. AFL 이 SNOMED 코드로 명시되고 사례가
수백~수천이다. 그런데 그것들은 **10초 12-lead 스트립**이다.

★**이 층의 프레임이 통째로 안 맞는다.** 10초에는 비트가 ~10개뿐이라
- 128비트 창·비중첩 창이 성립하지 않는다
- **burden·에피소드 지표가 정의되지 않는다**(발작의 시작·끝이 기록 안에 없다)
- RR 시퀀스 축(RSN)의 입력 길이가 확보되지 않는다

즉 그것은 "AFL 을 더 모은 2층" 이 아니라 **스트립 단위 리듬 분류라는 다른 과제**다.
12-lead 신호도 수십 GB 다. 하려면 **새 층으로 따로 설계**해야 하고, 이 층의
결론(§17.8)을 바꾸지 않는다.

### 24.5 부수 관찰 (판정에 쓰지 않는다)

W=16 에서 AFIB 환자가 106 → **116**, N 이 112 → 115 로 늘고 전이구간이 9.0% →
6.5% 로 줄었다. MDE 도 조금 좋아진다(AFIB 0.058 → 0.055).

★그러나 **§23.4 의 사전등록대로 AFIB·N 판정은 W=128(§17)을 유지한다.** W 를 7개
훑어 본 뒤 좋은 쪽으로 갈아타면 그것은 W 에 대한 다중비교이고, 이 실험의 목적은
AFL 하나였다. W=16 의 이득(환자 +10)이 §17 의 결론(RSN 미기여, A1 채택)을 뒤집을
크기도 아니다 — 그 판정은 CI 폭 0.026 의 정밀 음성이었다.

## 25. 시간축 후처리 — 사전등록 (결과 보기 전 고정)

### 25.1 무엇을 고치려는가

§20.3 진단: 창 PPV 0.987 인데 **에피소드 PPV 0.702**. 참 254건에 771건 예측.
창은 거의 다 맞히는데 **띄엄띄엄** 맞혀 가짜 에피소드가 517건 생겼다. 문턱은 창을
독립으로 보므로 못 고친다 → 시간축에서 파편을 합친다. 임상 홀터 소프트웨어의 표준:

- **히스테리시스**: 진입 문턱 `t_hi` > 이탈 문턱 `t_lo`. AF 는 지속하는 현상이라
  애매한 창 하나로 에피소드를 끊는 것이 더 부자연스럽다.
- **최소 지속시간**: 연속 `min_len` 창 미만 에피소드는 버린다(임상 '30초 규칙'과 같은 논리).
- **간극 메우기**: `gap` 창 미만으로 떨어진 두 에피소드를 잇는다.

### 25.2 규율 — §18 과 같다

파라미터 격자가 240개다. 고른 데이터로 성능을 재면 240번의 다중비교가 된다.
→ **환자 단위 LOO** 로 고르고 오라클을 함께 찍어 낙관 편향을 보인다.
자기검증에 `LOO ≤ 오라클` 을 못 박았다(합성: 에피소드 PPV 0.353 → 0.857).

### 25.3 가설

| | 가설 | 판정 |
|---|---|---|
| **H-X** | 에피소드 PPV 가 0.702 → **0.85 이상** | LOO 값으로만 판정. 오라클로 판정하지 않는다 |
| **H-Y** | 에피소드 Se 손실이 0.03 이하 (0.965 → ≥0.935) | 파편을 지우면서 짧은 참 발작도 지운다. 그 대가를 미리 상한으로 묶는다 |
| **H-Z** | burden r 이 0.990 에서 나빠지지 않는다 | 후처리는 창을 지우거나 채우므로 burden 을 움직인다 |

**미리 정하는 것**: 후처리는 **A1(§17.8 채택 모델)** 에만 적용한다. 여러 팔에서 고르고
가장 좋은 것을 보고하면 팔 선택까지 다중비교다.
그리고 **짧은 발작(≤3창) Se 를 반드시 함께 본다** — 최소 지속시간 규칙이 정확히
그것을 지우는 규칙이므로, 전체 Se 만 보면 손실이 가려진다.

## 26. 개인화 기준선 — 사전등록 (사용자 제안, 2026-07-30)

### 26.1 제안과 그 위치

"개인 신호를 파악해 예상 파형을 만들고, 실제와의 델타로 판단한다." 임상 판독의
"이전 심전도와 비교" 를 특징 수준에서 구현하는 것이다. 개인 기준선 b_p 를 만들고
각 창에 (x − b_p) 21열을 덧붙인다(aux 31 → 52).

★**RR 축은 이미 개인화되어 있다.** `_rec_channels` 가 `clip(log(RR/med_record))` 를
쓰고 `_win_aux` 10종도 전부 `med_rec` 으로 나눈 무차원량이다. 개인화가 **안 된** 것은
심방·P-QRS-T 21열이다(`p_amp`·`p_cons`·`pr_med` 전부 절대값을 환자 간 비교).
**거기가 이 제안의 미개척지**이고, 그래서 편차는 그 21열에만 붙인다.

### 26.2 ★누수 함정 — 무엇을 '평소'로 삼는가

가장 자연스러운 "환자 자신의 **정상 구간** 평균" 은 쓸 수 없다. 어느 창이 정상인지는
**라벨**이고, 테스트 환자의 라벨로 특징을 만들면 정답을 보고 특징을 만드는 것이다.
게다가 환자분리 교차검증에서는 그 환자의 학습 데이터가 아예 없다.
→ **라벨을 쓰지 않는 기준선만** 허용한다.

| mode | 기준선 | 위험 |
|---|---|---|
| `median` | 그 환자 전체 창의 중앙값 | ⚠**지속성 AF 는 '평소'가 AF** → 기준선이 AF 가 된다 |
| `quiet` | ΔRR 엔트로피 하위 25% 창의 중앙값(=가장 규칙적) | AF 가 불규칙하다는 성질을 이용한 **라벨 없는 정상 대리** |
| `calib` | 기록 앞부분 20창(홀터 부착 직후) | ⚠처음부터 AF 면 틀린 기준선 |

※ `quiet` 가 라벨을 안 쓰면서도 '정상 구간'에 가장 가깝다 → **주 후보**.

### 26.3 가설

| | 가설 | 판정 |
|---|---|---|
| **H-AA** | AFIB 에서 A5 − A4 > 0 | 짝지은 부트스트랩. **기준은 A4**(A1 과 비교하면 심방축 효과가 섞인다) |
| **H-AB** | `median` 기준선은 **발작성에서 이득, 지속성에서 손해** | `report_strata()` 로 층화. 전체 평균만 보면 두 효과가 상쇄돼 '효과 없음'으로 보인다 |
| **H-AC** | `quiet` > `median` (전체) | 라벨 없는 '정상 대리'가 단순 중앙값보다 낫다 |
| **H-AD** | A5c(편차만) < A5 | 절대값도 여전히 필요한가(H-Q 와 같은 논리) |

★**H-AB 가 이 실험의 핵심**이다. 개인화가 왜 통하거나 안 통하는지의 기전이 층마다
반대이므로, 전체 평균 하나로는 아무것도 못 배운다. 상쇄를 미리 예측해 둔다.

**미리 정하는 것**: AFIB 는 §17 에서 이미 포화다(A1 0.953, 어떤 팔도 CI 로 못 이겼다).
따라서 **H-AA 가 미달인 것이 기본 예상**이고, 미달이면 개인화를 손봐 재실행하지
않는다. 이 실험의 값어치는 H-AB 의 **기전 확인**에 있다.

### 26.4 실행

```python
go("personalize", "report_strata", "bench_afib")
d = load_rr()
w = make_windows(d, W=128, dbs=("afdb","ltafdb","mitdb"))
w = attach_atrial(w, path=f"{_BASE}/afib_atrial_all.npz")
w = personalize(w, mode="quiet")            # 라벨 안 씀
OUT5 = bench_afib(w, k=3, tag="run_pers_quiet",
                  only=["A1.RR산포","A2.RSN","A4.RSN+심방활동",
```

A1·A2·A4 를 다시 넣는 이유: 지문(§ 체크포인트)이 달라지므로 §17 의 결과와 **짝지을
수 없다**. 같은 실행 안에서 비교해야 한다.

## 27. 시간축 후처리 실측 — 사전등록 기준 **탈락** (2026-07-30, 학습 0초)

`op_smooth(OUT, "A1.RR산포", "AFIB")`, 격자 240개, 환자 152, LOO 선택.

### 27.1 결과

| | 에피소드 Se | PPV | 예측건수 | 짧은발작 Se | 창 F1 | burden r | LoA 폭 |
|---|---|---|---|---|---|---|---|
| 원본(argmax) | **0.965** | 0.702 | 771 | **0.911** | 0.953 | 0.990 | 23.9 |
| **★LOO 후처리** | 0.878 | **0.822** | 529 | **0.711** | 0.954 | 0.989 | 25.7 |
| 오라클 | 0.917 | 0.829 | 548 | 0.822 | 0.956 | 0.989 | 25.7 |

낙관 편향 = 오라클 PPV − LOO PPV = **+0.006**(작다 — 격자 240개를 훑었는데도 편향이
작은 것은 최적점이 넓고 평평하다는 뜻이다).

### 27.2 판정

| | 기준 | 실측 | 판정 |
|---|---|---|---|
| **H-X** | 에피소드 PPV ≥ 0.85 | **0.822** | **✗미달** (오라클 0.829 도 미달) |
| **H-Y** | Se 손실 ≤ 0.03 | **0.087** | **✗위반 — 한도의 2.9배** |
| **H-Z** | burden r 유지 | 0.990 → 0.989 | 사실상 유지 |

**→ 후처리를 채택하지 않는다.** H-Y 를 크게 위반했다. PPV 가 0.702 → 0.822 로 오른
것은 사실이지만, 그 대가로 참 에피소드 **22건**을 놓치고 **짧은 발작 Se 가 0.911 →
0.711 로 0.2 떨어졌다.** H-Y 의 0.03 한도는 정확히 "PPV 가 올랐다" 를 성과로 팔지
못하게 하려고 결과 보기 전에 걸어 둔 것이다.

★그리고 Se ≥ 0.935 를 **제약으로** 걸어 다시 고르면 PPV 는 0.822 보다 **낮아진다**
(지금이 더 느슨한 Se 에서 얻은 값이다). 따라서 H-X 와 H-Y 를 동시에 만족하는 점은
이 모델의 Se-PPV 곡선에 **존재하지 않는다.** 파라미터를 더 훑을 이유가 없다.

### 27.3 ★§20.3 의 진단이 틀렸다 — 파편이 아니라 '확신 낮은 구간'이었다

LOO 가 152명 중 **150명에게 고른 파라미터는 `진입0.9 / 이탈0.5 / 최소1창 / 간극0창`**
이다. **최소 지속시간과 간극 메우기를 안 골랐다.** 이득은 전부 히스테리시스에서 왔다.

§20.3 에 *"창은 거의 다 맞히는데 띄엄띄엄 맞혀서 가짜 에피소드가 생긴다"* 고 썼다.
그렇다면 `최소 2창` 규칙이 이겼어야 한다. 이기지 않았다는 것은 **가짜 에피소드가
단발 창이 아니라는 뜻**이다. 진입 문턱 0.9 가 이긴 것은, 가짜 에피소드들이
**최고 점수가 0.5~0.9 사이인 '확신 낮은 구간'** 이었다는 것이다(길이는 충분하다).

즉 파편화 문제가 아니라 **확신 보정(calibration) 문제**다. 그리고 확신이 낮은 구간을
잘라내면 참 에피소드 중 확신이 낮은 것(짧은 발작)이 같이 잘린다 — 그것이 짧은발작
Se 0.2 하락의 정체다. **후처리로는 이 교환을 깰 수 없다.**

### 27.4 정리 — 2층에서 에피소드 PPV 는 여기까지다

작동점(§20)·후처리(§27) 둘 다 사전등록 기준 미달이다. 남은 것은 창 단위 확신 자체를
개선하는 것뿐이고, 그것은 §17 에서 이미 **정밀 음성**(RSN 최대 +0.022)으로 닫혔다.
**에피소드 PPV 0.702 는 이 데이터·이 단위에서 A1 의 한계로 기록한다.**
필요하면 운용상 선택지로 `smooth_pred(..., t_hi=0.9, t_lo=0.5)` 를 쓸 수 있다 —
Se 0.878 / PPV 0.822 는 **판정이 아니라 운용 결정**이다(burden 정량이 목적이면
PPV 쪽이 나을 수 있다).

## 28. 사용자 제안 3단계 개인화 (A6) — 사전등록

### 28.1 제안

> ① 여러 사람·많은 데이터로 normal 학습 → ② 개인 ECG 에서 normal 로 보이는 부분·
> 가장 많은 패턴에 가중치를 주어 개인화 → ③ 새로 변한 ECG 로 추가 판단

**비효율적이지 않다. 오히려 §26 의 내 설계보다 낫다.** 이유:

§26 의 `quiet` 모드는 '정상 대리'로 **ΔRR 엔트로피 하나**를 썼다. 심방 21열을 전혀
안 보므로, RR 이 우연히 규칙적인 AF 구간(**2:1 고정 전도 AFL** 이 정확히 그렇다)을
'정상' 으로 잡을 수 있다. 제안의 ①단계가 만든 **모집단 모델은 31열을 전부 보고**
정상성을 판단하므로 정보가 훨씬 많다. **①이 ②를 게이팅하는 것이 이 설계의 핵심
이점**이고, 내 설계에는 없었다.

구현(`_arm_pers_model`, A6):
1. tr 환자로 A4(RR+심방) 학습 — **모집단 정상 모델**
2. 그 모델의 P(N) 상위 25% 창으로 환자별 기준선 → 편차 21열
3. 절대값 + 편차(52열)로 재학습·예측

폴드당 학습 2회 = 대략 2배 비용. 추론은 값싸므로 **효율 문제는 없다.**

### 28.2 누수는 없다

- 라벨 y 를 어디서도 참조하지 않는다.
- 테스트 환자의 P(N) 은 **그 환자를 학습에서 본 적 없는** 폴드 모델이 낸다
  (환자분리 교차검증이 이를 보장).
- 학습 환자의 기준선은 자기를 본 모델의 점수로 만들어져 다소 낙관적이지만, 그것은
  학습 데이터 품질 문제이고 **테스트 누수가 아니다.**

### 28.3 ★위험: 오류 증폭 (자기학습의 고전적 실패)

지속성 AF 환자에서 모집단 모델이 AF 창을 '정상' 으로 잘못 보면 **기준선이 AF 가 되고
2단계가 그 오류를 고착시킨다.** 자기검증으로 이 위험이 실재함을 확인했다:
모집단 모델을 일부러 뒤집으면 편차의 부호 관계가 역전된다(올바른 모델 AF 3.00 >
정상 0.00 / 뒤집힌 모델 AF 0.89 < 정상 1.30).

### 28.4 가설

| | 가설 | 판정 |
|---|---|---|
| **H-AE** | AFIB 에서 A6 − A4 > 0 | 짝지은 부트스트랩. 기준은 **A4** |
| **H-AF** | A6 > A5(quiet) | ①의 모집단 게이팅이 엔트로피 대리보다 낫다 |

**미리 정하는 것**: AFIB 는 §17 에서 포화(A1 0.953, CI 폭 0.026 정밀 음성)이므로
**H-AE 미달이 기본 예상**이다. 미달이면 개인화를 손봐 재실행하지 않는다.
이 실험의 값어치는 **H-AG 의 기전 확인**에 있다 — 개인화가 층마다 반대로 작동하는지가
확인되면 그것은 정확도와 별개의 지식이다.

### 30.5 A6 구현의 알려진 불완전 — 보수적 방향

`_arm_pers_model` 의 1단계 모델은 **학습 환자를 본 적 있다.** 그래서 학습 환자의
P(N) 은 낙관적이고, 그들의 기준선·편차가 테스트 환자보다 정확하다. 3단계 모델은
"편차는 믿을 만하다" 를 과대학습하게 되고, 테스트에서는 그만큼 손해를 본다.

★**이것은 누수가 아니라 그 반대다** — 성능을 **낮추는** 쪽의 불완전이다.
따라서 지금 관찰된 A6 의 이득은 이 불완전에도 불구하고 나온 것이다.
고치는 방법은 학습 환자의 P(N) 을 **내부 교차검증(nested CV)** 으로 뽑는 것이고,
비용은 폴드당 학습 (k+1)회가 된다. ★그러나 H-AE 가 아직 판정되지 않았으므로
**지금 손대지 않는다** — 판정 전에 구현을 바꾸면 무엇을 판정한 것인지 알 수 없다.

→ **개인화 팔을 손보지 않는다.**

**H-AD 는 Bonferroni(k=8, z 1.96→2.73)를 적용해도 하한 +0.212 로 생존한다.**
→ **개인편차는 절대값을 대체할 수 없다.** A5c(편차만)는 창 F1 0.671, 참 254건에
**8,466건** 예측으로 붕괴했다. 개인 기준선은 **보조 특징**이어야 하고 표현의
전부가 될 수 없다. (AFL 에서도 +0.073 [+0.019, +0.138] 로 방향이 같지만
§24 대로 AFL 은 판정 대상이 아니다.)

### 31.2 H-AE 를 다시 보면 — '정밀 음성' 이 아니다

H-J(RSN)는 CI 폭 0.026 에 점추정 +0.0085 로 **효과 자체가 없다**고 말할 수 있었다.
H-AE 는 다르다: 점추정 **+0.0113**, CI 폭 0.032, **상한 +0.025**.
즉 *"A6 의 이득은 최대 2.5 F1 포인트이고, 없을 수도 있다"* 가 정확한 진술이다.
**효과가 없다는 증거가 아니라 표본이 부족하다는 뜻**이고, 판정하려면 환자 **약
218명**(현재 106명의 2배)이 필요하다. afdb+ltafdb+mitdb 는 이미 소진했으므로
새 DB 없이는 도달할 수 없다.

★따라서 A6 를 **"기각"으로 적지 않는다.** "미달, 표본 2배 필요" 로 적는다.
이 구분이 중요하다 — 기각이면 버리는 것이고, 표본 부족이면 남겨 두는 것이다.

### 31.3 기전 관찰(판정 아님) — 두 개인화가 다른 층에서 이긴다

| arm | 정상(n=11) | 발작성(n=46) | 지속성(n=49) |
|---|---|---|---|
| A1 | 0.749 | 0.965 | 0.987 |
| A4 | 0.770 | 0.954 | 0.988 |
| **A5**(quiet) | **0.786** | 0.958 | 0.989 |
| **A6**(3단계) | 0.744 | **0.982** | **0.991** |

A6 는 **발작성**에서, A5 는 **정상(초저 burden)**에서 최고다. 제안한 기전과 맞는다:
발작성은 정상 구간과 AF 가 섞여 있어 ①모집단 모델이 정상 구간을 골라낼 수 있고
→ ②기준선이 옳게 잡히고 → ③편차가 정보가 된다.
**전부 MDE 미달이다**(발작성 0.084 vs +0.028). 결과가 아니라 **다음 가설**이다.

### 31.4 2층 최종 상태

| 축 | 판정 |
|---|---|
| **AFIB 검출·burden** | **A1 채택** — F1 0.953, burden r **0.990**, LoA 23.9%p |
| RSN 시퀀스 | **미기여** (H-J 정밀 음성 최대 +0.022, H-K 역행 유의) |
| DB 조건부 FiLM(A3) | **기각** (LODO) |
| 심방 P파 형태(`p_cons`) | 최강 판별자 — 창 분류 순이득은 없음(H-O) |
| PR 전도(`pr_med`·`pr_cv`) | **유효** — 심박수 맞춰도 AUC 0.75 (H-V) |
| RT 재분극(`rt_med`·`rt_cv`) | **폐기** — 심박수 중복 (H-U) |
| 작동점(문턱) | **여지 없음** (LOO 가 argmax 선택) |
| 시간축 후처리 | **탈락** — H-Y 위반(Se 손실 0.087) |
| 개인편차 단독 | **기각** (H-AD, Bonferroni 생존) |
| **개인화 보조(A5·A6)** | **미달 — 표본 2배 필요**(기각 아님) |
| AFL | **판정 불가로 종료** (환자 11명이 상한, §24) |

### 31.5 사전등록이 실제로 무엇을 했나

이 층에서 **기각·탈락시킨 것이 8건**이다: RSN(2층), A3, 문턱 조정, 시간축 후처리,
개인편차 단독, 그리고 AFL 관련 전부. 그중 **A3 와 후처리는 "좋아 보이는 숫자"가
나온 뒤에 버린 것**이다(A3 는 유일하게 유의했고, 후처리는 PPV 를 0.12 올렸다).

채택된 것은 **A1 하나**이고, 그것은 1990~2010년대의 RR 산포 스칼라 10개다.
**제안한 신기술이 전부 떨어지고 고전 기준선이 남은 것이 이 층의 결론이다.**

## 32. 1층 축의 2층 전이 — 무엇이 전이되고 무엇이 안 되는가 (2026-07-30)

사용자의 1층(비트 S/V) 실험 이력을 2층에 대응시킨 판단. ★사용자 경고를 지킨다:
1층 이력의 기준선·지표가 블록마다 달라 **블록을 가로지르는 크기 비교는 하지 않는다.**
아래는 "어느 **기전**이 2층에 옮겨갈 수 있는가" 만 본다.

### 32.1 ★전이 가능성을 결정하는 것은 알고리즘이 아니라 클래스 구조다

| | 유병률 | 환자 내 최대 | "그 환자는 대체로 정상" |
|---|---|---|---|
| 1층 S | ~2.5% | 수 % | ✔ 항상 성립 |
| 1층 V | ~7% | ~30% | ✔ 대체로 성립 |
| **2층 AFIB** | **54.4%** | **100%** | **✗ 지속성 환자에서 붕괴** |

환자 자신의 점수·특징 분포를 '정상 기준'으로 쓰는 기법은 **전부** 이 가정에 기댄다.
이 하나로 세 가지가 동시에 설명된다.

1. 1층 `psa_rel`(본인 정상비트 median 감산)이 +0.147 로 통한 이유 → S 는 드물다
2. 2층 A5(quiet)·A6 가 미달한 이유(§31) → 지속성 환자에서 기준선이 AF 가 된다
3. **1층의 "무라벨 개인화 v24~26 = 전부 0" 과 2층 A5/A6 미달의 일치**
   → 층을 넘어 같은 결론이 재현됐다. 우연이 아니다.

### 32.2 전이 판단

| 1층 축 | 2층 전이 | 근거 |
|---|---|---|
| **소량라벨 개인화**(+33.6%) | **★최우선 후보** | 라벨이 '어느 창이 정상인지'를 **직접** 알려주므로 지속성 환자에서도 기준선이 옳다. 2층에서 시도한 적 없다(우리는 누수 우려로 라벨을 피했다) |
| **환자별 β policy**(+13.4%) | 후보(소량라벨 뒤) | 환자마다 개인화 비중을 다르게. §31.3 에서 A5·A6 가 **서로 다른 층에서** 이긴 것이 이 축의 근거다 |
| **강건 환자센터**(+5.3%, 임계무관) | **실패 예측** — §32.3 | 중앙값을 정상 기준으로 삼는다 → 지속성에서 붕괴 |
| WST 특징(+0.072) | 낮은 우선순위 | 2층 형태축은 순이득이 없었다(H-O). 새 특징족을 넣어도 같은 천장 |
| inter-beat 문맥(Mamba) | **중복** | 2층의 RSN 이 곧 그것이고 H-J 정밀 음성으로 닫혔다 |
| oracle_ft | 상한 실증용 | 배포 불가. 2층에서도 '표본이 문제인가 방법이 문제인가'의 상한으로만 유용 |
| stable 산출(σ −40%) | 후보(부수) | 정확도가 아니라 분산 축소. 지금 2층은 폴드당 1시드다 |
| **재시도 금지** | — | 전역개입(z정규화·혼합게이트·환자균형가중), 사후 재보정, cascade 라우팅, 함수학습, 백본교체 단독 — 1층에서 전부 0 또는 음수. 2층에서 다시 볼 이유가 없다 |

### 32.3 강건 환자센터 — **실패를 미리 예측하고 반증 가능하게 적는다**

`pp_center(OUT, arm, cls, mode)` 를 구현했다(학습 0초, 저장된 점수만 씀).
결정 규칙: `score − center_p ≥ c`.

★**사전 예측: 2층에서는 실패한다.** 지속성 AF 환자의 점수 중앙값은 '정상 수준'이
아니라 'AF 수준'이므로, 중앙값을 빼면 그 사람의 AF 창 절반이 문턱 아래로 떨어진다.

합성 검증(지속성 95% + 발작성 10%, 연속 점수): 창 F1 **0.985 → 0.499**.
→ 기전이 실재함을 확인했다.

★**반증 조건을 함께 적어 둔다**: 실패가 **지속성 층에 집중되지 않으면** 내 설명이
틀린 것이다. 실패가 전 층에 고르게 퍼지면 원인은 다른 데 있다.

```python
go("pp_center")
OUT = load_afib("run_ltaf_k3")
for md in ("median", "q25", "trimmean"):
    pp_center(OUT, "A1.RR산포", "AFIB", mode=md)
```

## 33. 소량라벨 개인화 — 사전등록 (1층 최대 이득 축의 2층 이식)

### 33.1 ★이것은 **다른 과제**다 — 절대 섞어 보고하지 않는다

지금까지의 2층 전부는 **무라벨** 프로토콜이다(테스트 환자에 대해 아무 라벨도 없다).
소량라벨은 **환자당 K개 창의 라벨을 받는다** — 임상적으로는 "홀터 부착 시 판독자가
짧은 구간을 확인해 준다" 에 해당하고, 실제 제품에서 흔한 설정이다.

**따라서 §17·§31 의 숫자와 나란히 놓고 비교할 수 없다.** 다른 정보를 받는 과제다.
별도 표로, 프로토콜을 명시해 보고한다.

### 33.2 프로토콜 (누수를 막는 규칙)

1. 테스트 환자마다 **시간순 앞쪽에서** 라벨 창 K개를 취한다(부착 직후 확인이라는
   현실을 반영. 무작위 표집은 미래를 보는 것이라 금지).
2. **그 K개 창은 평가에서 완전히 제외한다.** 이것이 핵심이다 — 라벨을 준 창으로
   성능을 재면 당연히 잘 맞고, 그것은 성능이 아니다.
3. K개의 라벨로 개인 기준선(정상으로 표시된 창의 중앙값)과 개인 보정을 만들고,
   **나머지 창**에서만 평가한다.
4. K 를 여러 값(0/4/8/16/32)으로 훑고 **K=0 이 §31 의 무라벨 결과와 일치**하는지
   확인한다. 일치하지 않으면 배관이 틀린 것이다.

★K 를 결과 보고 고르지 않는다. **K 별 곡선을 전부 보고**하고, 임상적으로 감당
가능한 K(판독자가 확인할 수 있는 분량)를 미리 정한다 → **K=8**(창 8개 ≈ 15분)을
주 보고값으로 사전에 고정한다.

### 33.3 가설

| | 가설 | 판정 |
|---|---|---|
| **H-AH** | K=8 에서 AFIB 창 F1 이 무라벨(K=0)보다 높다 | 짝지은 부트스트랩(같은 평가 창) |
| **H-AI** | 이득이 **지속성 환자에서도** 나타난다 | 무라벨 개인화가 실패한 이유가 '기준선 오류' 라면, 라벨이 그것을 고치므로 지속성에서 특히 커야 한다. **이 예측이 §32.1 설명의 핵심 검증**이다 |
| **H-AJ** | K 를 늘리면 단조 증가하고 K≈16 에서 포화 | 단조가 아니면 잡음을 보고 있는 것 |

**미리 정하는 것**: H-AH 가 미달이면 개인화 축을 **종료**한다. 무라벨(A5/A6 미달)에
이어 소량라벨까지 안 되면 "2층에서 개인화는 값을 못 한다"가 확정되고, 그때는
표본을 늘려도(§②) 개인화가 아니라 다른 것을 봐야 한다.

### 33.4 ② ③ 과의 순서

사용자가 하려는 두 가지와의 관계:

- **② 새 DB로 환자 2배 → A6 재판정**: H-AE 판정에 환자 ~218명이 필요하다(§31.2).
  **그런데 소량라벨은 지금 데이터로 바로 된다.** 데이터 수집 몇 시간을 쓰기 전에,
  개인화 축이 살아 있는지를 **오늘** 판정할 수 있다. → **소량라벨이 먼저다.**
- **③ CinC 스트립 층**: §24.4 에 적은 대로 **burden·에피소드가 정의되지 않는
  다른 과제**다. 새 층으로 따로 설계해야 하고 이 층의 결론을 바꾸지 않는다.
  AFL 을 하려면 유일한 길이므로 값어치는 크지만, ②③ 둘 다 **데이터 확보가
  병목**이므로 오늘 할 수 있는 것부터 한다.

권장 순서: **§32.3(학습 0초) → §33(소량라벨, 학습 있음) → ② → ③**
