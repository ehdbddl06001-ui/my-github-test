# 무엇이 효과가 있었나 — 전체 정리
### 목표: 심전도로 모든 심장 문제·질환을 정확도 99% 이상으로 판정하는 AI

이 문서는 1층(비트)·2층(리듬) 실험 전체에서 **살아남은 것만** 모은 것이다.
근거는 `SVDB_RHYTHM_DESIGN.md`(1층)와 `LAYER2_AFIB.md` §13~§47(2층)에 있고,
여기서는 절 번호로만 가리킨다. **떨어진 것도 같이 적는다** — 다시 하지 않기 위해.

---

## 0. 목표를 먼저 숫자로 바꾼다 (이것이 정리의 축이다)

`MDE = 1.96σ/√n`, n = **그 클래스를 가진 환자 수**. "99% 다" 를 ±1%p 로 주장하려면
MDE ≤ 0.01 이어야 한다.

| 실측 σ | 필요 환자수 |
|---|---|
| N 0.204 (§37) | **1,599** |
| AFIB 0.221 (§37) | **1,876** |
| AFIB 0.30 (보수적) | **3,457** |
| AFL 0.461 (§14.5) | **8,164** |

**현재 보유: MIT-BIH 계열 전체 175명** (AFIB 116 / N 136 / SVTA 52 / VT 47 / SBR 36 / AFL 11).
지금 표본으로 정직하게 말할 수 있는 하한:

| 클래스 | n | MDE |
|---|---|---|
| N | 136 | 0.034 |
| AFIB | 116 | 0.040 |
| SVTA | 52 | 0.082 |
| VT | 47 | 0.086 |
| SBR | 36 | 0.098 |
| AFL | 11 | 0.272 |

> ★**결론 1: "99% ±1%p" 는 MIT-BIH 로 원리적으로 도달 불가다. 모델 문제가 아니다.**
> 클래스당 수천 명이 필요하고, 그것이 있는 곳은 **CinC 2020/2021 계열 12-lead**
> (약 88,000 기록 / 30+ SNOMED 클래스)다. 목표가 사는 곳은 거기다.
> 단 10초 스트립이라 burden·에피소드가 정의되지 않는다(§24.4) — **다른 층**이다.

## 2. 판정 규율 — 그대로 다음 프로젝트로 가져갈 것

| 도구 | 왜 |
|---|---|
| **환자매크로 F1** | 층 간 비교가 성립한다. 비트가 많아도 소수 환자에 몰리면 무의미 |
| **MDE 먼저 계산** | 못 미치면 "판정 불가" 로 남긴다. 크기를 지어내지 않는다 |
| **환자 단위 짝지은 부트스트랩** | CI 폭 0.026 vs MDE 0.055 — 짝지으면 필요 표본이 절반 이하 |
| **LODO(`split="db"`)** | DB 신원을 볼 수 있는 팔은 반드시 이것으로 판정(§15 에서 A3 기각) |
| **Bonferroni** | 비교 수로 나눈다. §37 의 "★유의" 가 여기서 탈락했다 |
| **'판정 불가' ≠ '미달'** | σ=0 가드(§15.3·§37.2), 표본 게이트(§44.3). **코드에 박아 둔다** |
| **사전등록 + 재시도 금지 조항** | 결과를 본 뒤 기준을 바꾸면 그 뒤 전부가 무의미 |

★**사전등록이 실제로 한 일**: 2층에서 **8건을 기각·탈락**시켰고, 그중 **A3 와 후처리는
"좋아 보이는 숫자가 나온 뒤에" 버린 것**이다(A3 는 유일하게 유의했고, 후처리는
PPV 를 +0.12 올렸다). 이것이 없었으면 둘 다 성과로 남았다.

## 3. ★측정의 함정 — 여기서 배운 것이 가장 이식성이 높다

### 3.1 에피소드 PPV 의 파편화 인공물 (§42.2·§47.2)
에피소드 PPV 는 '참과 겹치는 예측 에피소드' 비율이다. **참 하나를 N조각으로 쪼개면
TP 가 N개**가 되어 PPV 가 오른다. 실제로 두 번 가짜 승리를 만들었다:
`bigem` 규칙(PPV 0.948인데 예측 721→1,790), 잡음 실험(PPV 0.99+인데 창 F1 0.126).
→ **판정 조건에 "예측 에피소드 수가 늘지 않을 것" 을 넣는다.**

### 3.2 σ 가 작은 것은 정밀함이 아닐 수 있다 (§15.3·§37.2)
전 팔이 실패하면 환자별 F1 이 전부 0 근처라 σ 가 작아지고 **MDE 가 좋아 보인다.**
VT 에서 σ 0.077 → MDE 0.040 이 '충분' 으로 찍혔는데 전 팔 F1 이 0.000~0.024 였다.
→ **전 팔 최고 F1 < 0.10 이면 '측정 불가(전원 실패)'.**

### 3.3 다수 클래스가 바뀌면 하한이 바뀐다 (§17.1)
ltafdb 를 넣어 AFIB 가 54% 가 되자 자명 하한(A0)의 AFIB F1 이 **0.000 → 0.659** 로
뒤집혔다. **F1 0.95 는 0 이 아니라 0.659 를 기준으로 읽어야 한다.**

### 3.4 절대 오차가 작은 것과 잘 맞히는 것은 다르다 (§14.6)
AFL burden LoA 폭이 AFIB 의 6분의 1이라 정밀해 보였지만 r 은 0.295 vs 0.897 이었다.
**드문 사건에서 "항상 없다" 고 답하면 절대 오차는 작고 정보량은 0 이다.**

### 3.5 주변 상관으로 교란을 판정하면 안 된다 (§22·§40.2)
리듬이 심박수를 정하므로 **리듬을 잘 가르는 특징은 무엇이든 RR 과 상관이 생긴다.**
판별 AUC 1.000 인 순수 형태 특징이 ρ=0.49 로 '심박수 대리' 오판을 받았다.
→ **심박수를 좁은 구간으로 층화해 낸 AUC** 가 결정적 지표다. Bazett 보정만으로는 부족.

### 3.6 파라미터를 고른 데이터로 성능을 재면 안 된다 (§18·§25)
문턱 200개·후처리 격자 240개를 훑어 최선을 보고하면 그만큼의 다중비교다.
→ **환자 단위 LOO 로 고르고 오라클(자기 포함) 값을 함께 찍어 낙관 편향을 보인다.**

## 4. 효과가 있었던 구조·알고리즘

### 4.1 ★무차원 정규화 — 2층이 성립한 이유
`_rec_channels`: `clip(log(RR / med_record), ±1.5)`, `clip(dRR/med, ±1.5)`,
`tanh(innov/3MAD)`, 마스크. `_win_aux` 10종도 전부 `med_rec` 으로 나눈다.
→ **심박수 1.5배에도 채널이 불변**(자기검증). 이것이 afdb(250Hz)·ltafdb(128Hz)·
mitdb(360Hz)·nsrdb 를 한 코퍼스에서 쓸 수 있게 한 유일한 이유다.
**심박수 개인화는 이미 여기 들어 있다**(§26.1).

### 4.2 ★2층 채택 모델 — A1 (스칼라 10개 + 작은 MLP)
`Linear(10→64) → ReLU → Dropout(0.1) → Linear(64→64) → ReLU → Linear(64→3)`
특징: `med_w/med_rec`, `RMSSD/med`, `pNN50`, `CV`, `ΔRR 샤논엔트로피`,
`SD1/med`, `SD2/med`, `SD1/SD2`, `IQR/med`, `valid`.

**AFIB 창 F1 0.953, burden r 0.990 [0.986, 0.993] (환자 152).**
burden 은 항응고 결정에 쓰이는 양이고, 이것이 2층에서 가장 임상적으로 값있는 숫자다.

### 4.3 창 단위(128비트)로 리듬을 다룬 것 (§3)
- AF 는 에피소드 현상이라 비트 단위 라벨이 부자연스럽다
- **burden·에피소드 Se/PPV 가 정의된다** — 비트 단위로는 안 된다
- 비트마다 ±64 문맥을 물리적으로 만들면 ltafdb 20 GB, 창은 **156 MB**

### 4.4 ★우선순위 라벨링 + 동반 기록 (§36·§37)
순도 0.90 규칙은 **가장 중요한 창을 버리고 있었다.** 같은 코퍼스에서 규칙만 바꿔:

| | 순도 0.90 | 우선순위 |
|---|---|---|
| VT 환자 | **0** | **14** |
| SVTA 환자 | 2 | 19 |
| AB 환자 | 3 | 21 |
| 전이구간 | 6,829 | **1,231** |

규칙: 창 라벨 = `min_frac` 을 넘긴 것 중 **우선순위 최고**(VT 최상위, `min_frac` 0.05),
`present`(다중핫)·`frac`(비율)을 **함께 저장**해 "함께 나왔음" 을 잃지 않는다.
→ **라벨 정의가 데이터의 절반을 결정한다.**

### 4.5 ★기전 먼저, 모델 나중 (§10.2·§38.4)
`atrial_audit`(H-P)를 모델 전에 돌렸고, `ectopy_audit`(H-AP)를 A7 전에 돌렸다.
H-AP 가 **위양성 창의 79.3% 에 PAC**(참양성 0.28%, 283배)을 보였고, 그 다음에야
규칙을 만들었다. 원인을 알고 고쳤기 때문에 **교환이 없었다**:

| | 에피소드 PPV | Se | 짧은발작 Se |
|---|---|---|---|
| §27 후처리(원인 모름) | 0.702→0.822 | **0.965→0.878** | **0.911→0.711** |
| §42 PAC 철회(원인 앎) | **0.693→0.906** | **0.945→0.945** | **0.859→0.859** |

### 4.6 형태축에서 살아남은 특징 3개
| 특징 | 성적 | 조건 |
|---|---|---|
| **`p_cons`** (P파 박간 형태 일관성) | AFIB-vs-N 환자 AUC **0.962**, AFL-vs-AFIB **0.986** | **원신호**에서만(잔차는 정상 P 를 함께 지운다) |
| **`pr_med`·`pr_cv`** (PR 간격·변동) | 심박수 맞춘 AUC **0.75** 유지 | — |
| `daf_vh` (고조파 비) | AFIB-vs-N 환자 AUC 0.964 | 진단용으로 만든 것이 판별자가 됐다 |

### 4.7 ★규칙이 모델을 이긴 사례 (§42.3)
같은 특징(`s_frac`)을 (a) 신경망 입력으로 주기 (b) 명시적 if문으로 쓰기:
**규칙 +0.213 vs 모델 +0.026 — 규칙이 8배.**
이유: **신경망은 창 라벨의 교차엔트로피를 최적화하고 에피소드 PPV 를 모른다.**
→ **목표가 에피소드/구간 지표일 때는 명시적 규칙을 먼저 시도한다.**

### 4.8 공학 기반 (없으면 진도가 안 난다)
- **팔별 체크포인트 + 지문**: 런타임이 8번 죽었는데 결과를 잃지 않았다(§30.1 에서
  `_meta` 누락으로 한 번 잃고 고쳤다)
- **결정론적 시드**(crc32): `hash()` 는 프로세스마다 달라 재현이 안 됐다
- **aux 열 블록 명시 등록**(§40.1): 같은 배선 사고가 **네 번** 재발한 뒤 구조를 바꿨다
- **합성 데이터 자기검증 115항목**: 심박수 보정 감사 하나에서만 **결함 4개**를 잡았다
- **SHA 고정 코드 동기화**: 브랜치 URL 은 CDN 캐시로 옛 파일을 준다

## 6. ★목표를 향한 로드맵 (여기서 배운 것을 그대로 적용)

### 6.1 층 구조는 유지한다 — 그리고 검증됐다
**층마다 이기는 도구가 다르다**(RSN 은 1층에서 이기고 2층에서 진다). 단일 거대
모델로 전부 하려 했다면 이것을 알 수 없었다. 축이 다르면 층을 나눈다.

| 층 | 단위 | 표적 | 필요한 것 |
|---|---|---|---|
| 1층 | 비트 | N/S/V/F/Q | 감사된 비트 기호 |
| 2층 | 창(128비트) | 리듬·burden·에피소드 | R 위치 + 리듬 주석 |
| **3층(신설)** | **10초 12-lead 스트립** | **30+ 진단 클래스** | **12-lead 신호 + 진단 라벨** |

### 6.2 목표가 사는 곳은 3층이다
"모든 심장 문제·질환" 은 형태(넓은 QRS·ST·T·전기축·전도지연)를 요구하고, RR 축은
원리적으로 못 본다(§37.6 에서 VT 로 실증: A1 의 VT F1 0.024).
→ **CinC 2020/2021 계열**(CPSC·PTB-XL·Chapman-Shaoxing·Ningbo·Georgia,
약 88,000 기록, 30+ SNOMED). **클래스당 수백~수천이 실제로 있다.**

★그러나 **burden·에피소드는 정의되지 않는다**(10초에 비트 10개). 그래서 2층의
결론(A1·PAC 철회·burden r 0.990)은 **3층으로 이전되지 않고 각자 남는다.**
홀터 축(2층)과 스트립 축(3층)은 **다른 임상 질문**이다.

### 6.3 3층 첫 단계 (이 문서의 규율을 그대로)
1. **라벨 재고부터**(신호 0): 클래스별 기록 수·기관 수 → MDE 표. `win_label_scan`
   과 같은 역할. **MDE 로 판정 가능한 클래스만 표적으로 삼는다.**
2. **기관 분리 교차검증**(LODO 의 3층 대응). 기관이 곧 도메인이다 — §15 의 A3 사고가
   여기서 훨씬 크게 재발할 수 있다.
3. **다중라벨**이 3층의 기본이다(한 기록에 여러 진단). §36 의 우선순위 라벨링은
   홀터용이고, 3층은 클래스별 이진 헤드 + 클래스별 MDE 가 맞다.
4. **기준선을 먼저 세운다**: 12-lead 형태의 고전 특징(QRS 폭·QTc·전기축·ST 편위)
   + 작은 MLP. **§4.2 의 교훈** — 고전 기준선을 못 이기면 딥러닝은 값을 못 한 것이다.
5. 그 다음에 형태 인코더(1층 RSN 의 3층 대응)를 **사전등록해서** 붙인다.

### 6.4 정직한 목표 재설정
- **"99% ±1%p" 를 클래스별로 주장하려면 클래스당 ~1,600~3,500 환자**가 필요하다.
  CinC 계열에서 흔한 클래스(AF·1도 AV 차단·좌각차단 등)는 가능하고,
  **드문 클래스는 원리적으로 불가**하다 — 그 클래스는 처음부터 "판정 불가" 로 둔다.
- 그러므로 목표를 **"모든 질환 99%"** 가 아니라
  **"판정 가능한 클래스는 99%, 나머지는 판정 불가임을 명시"** 로 두는 것이
  이 프로젝트에서 배운 규율과 일치한다. 그것이 임상적으로도 정직한 산출물이다.
