## 0. 새 세션에게 (한 문단 요약)

MIT-BIH 부정맥 DB에서 SVEB(상심실성 이소성, AAMI class S) 비트 분류를 70여 스텝 연구했다.
결론은 **"S 검출을 결정하는 것은 리듬(RR 타이밍)이며, 모델 구조의 정교화는 이득이 없다"**
이다. 이 결론은 3개 데이터셋에서 확증됐다. 이제 **환자 수가 4.6배 많은 SVDB(73환자)에서,
MIT-BIH 유산을 이식하지 말고 처음부터 리듬 중심으로 모델을 설계**하려 한다.
넘어야 할 기준선은 **환자단위 매크로 F1 0.534**(현행 최고)이며, 통계적으로 유의하려면
**+0.07 이상**의 개선이 필요하다.

## 2. 데이터 사실 (SVDB)

```
SVDB (MIT-BIH Supraventricular Arrhythmia Database)
  비트 184,397   N 162,262 / S 12,196 (6.61%) / V 9,939
  레코드 78개, 그중 73개가 S 보유          ← MIT-BIH DS2는 16개뿐이었음
  2리드, 원본 128 Hz → 360 Hz 리샘플, R중심 300샘플
  R 재정합 적용(주석 지터 실측 평균 18.8 ms)
  per-beat z 정규화 적용
  최다 S 레코드 = rec 48 (S 1,818 = 전체의 14.9%)   ← 단일 레코드 지배 없음
```
**검정력**: 73환자, 환자별 F1의 σ≈0.32 → 매크로 F1 95% CI **±0.073**.
대응 비교(paired)의 실측 SE는 0.021~0.038.
> **따라서 +0.07 이상 개선해야 유의하다고 말할 수 있다.** 0.02~0.05는 검정 불가.

**`svdb_data.npz` 키**: `beat[N,2,300]`, `y`(0=N/1=S/2=V), `pid`(0~77), `pre_rr`, `post_rr`
> ⚠ MIT-BIH의 `feats[N,26]`(feats0)에 해당하는 것이 **SVDB에는 없다**. RR은 `pre_rr/post_rr`로 직접 제공된다.

## 3. 지금까지 무엇을 알아냈나 (핵심 3개)

### ★ 결론 1 — 리듬이 전부다 (확증됨, 가장 강한 결과)
| 모델 | 환자매크로 F1 [95% CI] |
|---|---|
| CNN (형태만, raw beat) | **0.164** [0.120–0.212] |
| CNN + RR | **0.484** [0.404–0.564] |

**Δ +0.320, 95% CI [+0.246, +0.396], Bonferroni 보정 후에도 [+0.224, +0.416] 유의.**
- 다른 모든 효과(≈0.05)보다 6배 크다.
- INCART 교차DB에서도 재현: 형태만 기저율 대비 1.8배 → 리듬 추가 시 **7.9배**.
- 생리학적으로 당연: S는 조기성으로 정의되고 QRS 형태는 정상과 같다.

### ★ 결론 2 — 구조적 정교화는 이득이 없다 (음성, 중요)
| 비교 | Δ | 95% CI | Bonferroni |
|---|---|---|---|
| 제안모델(9특징군+샴+게이트+프로토타입) − (CNN+RR) | +0.050 | [−0.022, +0.122] | 비유의 |
| 제안모델 − 고전 LDA(2004) | +0.058 | [+0.003, +0.114] | **비유의**([−0.013, +0.129]) |
| 라벨프리 개인화 추가 | −0.009 | [−0.051, +0.031] | 비유의 |

**즉 70스텝 동안 쌓은 정교한 구조가 "CNN + RR" 대비 입증 가능한 이득을 못 냈다.**

### ★ 결론 3 — 평가 규율 (반드시 지킬 것)
- **주 지표는 환자단위 매크로 F1**(S 보유 환자만). micro는 최다 레코드 기여율과 함께만 인용.
- **모델 비교는 대응 부트스트랩**(같은 환자의 F1 차이). 주변 CI 비교는 부당하게 둔감하다.
- **다중비교 보정**(Bonferroni)을 적용하고, 보정 후 유의한 것만 "확증"이라 부른다.
- **임계는 held-out calib에서만** 결정. 테스트 라벨로 고른 임계는 "오라클"로 명시.
- **검증 성능으로 모델을 고르지 말 것** — inter-patient에서 val↔test 상관이 비유의
  (Spearman ρ=0.07, p=0.78; 순열 p=0.23). 무지도 앙상블을 쓸 것.

## 5. 새 목표 — SVDB 네이티브 리듬 중심 모델

### 5.1 설계 원칙
1. **리듬을 1급 시민으로.** 지금까지 RR은 "특징 10개"로 요약돼 분류기에 곁들여졌다.
   결론 1에 따르면 **RR 시퀀스 자체가 주 신호**다. 형태를 보조로 두는 구조로 뒤집는다.
2. **단순하게 시작.** 결론 2에 따라 복잡한 구조는 이득이 없었다. **CNN+RR(0.484)에서
   출발**해 리듬 표현만 강화하며, 매 단계 대응 부트스트랩으로 검정한다.
3. **MIT-BIH 유산 이식 금지.** 기존 특징군·구조를 그대로 옮기면 MIT-BIH에서 누적된
   선택 편향이 따라온다. 필요하면 재유도하되, **SVDB 학습 폴드에서만** 결정한다.
4. **+0.07 미만은 개선이라 부르지 않는다.**

### 5.2 넘어야 할 기준선 (SVDB, 환자매크로 F1)
```
B0 다수결          0.000
B2 CNN(raw)        0.164 [0.120–0.212]
B1 LDA(형태+RR)    0.476 [0.413–0.539]
B3 CNN+RR          0.484 [0.404–0.564]   ← 실질적 출발점
B4 기존 제안모델    0.534 [0.472–0.595]   ← ★넘어야 할 목표
```
**목표: 매크로 F1 ≥ 0.60** (B4 대비 +0.07 → 유의한 개선)

### 5.3 유망한 방향 (우선순위)
| # | 아이디어 | 근거 | 비고 |
|---|---|---|---|
| **A** | **RR 시퀀스 모델링** — 단일 비트 innovation이 아니라 앞뒤 RR 창(예: ±8박)을 1D-CNN/GRU/Transformer로 직접 처리 | 결론 1. 현재는 EWMA 잔차 스칼라로 압축해 정보 손실 | **가장 유망** |
| B | Poincaré/Lorenz 표현 — (RR_n, RR_n+1) 평면의 국소 구조를 이미지/특징으로 | AF("확산 구름")와 이소성("이산 군집") 분리. N1 실패의 원리적 수정 | 중간 |
| C | P파 표적 분석 — S의 유일한 비-RR 물리 신호(이소성 P파 형태/축 변화) | N10은 MIT-BIH(저검정력)에서 기각. SVDB에서 재검정 가치 | 재검정 |
| D | 리듬 문맥 정규화 — 환자별 RR 분포로 조기성을 정규화(현 tanh+MAD보다 정교하게) | 유병률·심박수 차이 흡수 | 중간 |
| E | 다중 태스크 — S/V 동시 + 보상성 휴지 보조 손실 | 보상성지수가 APC/PVC를 분리 | 낮음 |

> **A부터 시작할 것을 강력히 권장.** 결론 1이 "리듬이 전부"라고 말하는데, 현재 모델은
> 리듬을 10차원 스칼라로 압축해 버린다. 그 병목을 푸는 것이 가장 큰 기대이득이다.

### 5.4 평가 하니스 (그대로 재사용 가능)
`svdb_bench.py`의 `bench_models()`가 이미 다음을 제공한다:
- 환자 단위 GroupKFold(5), calib 분리, 임계 결정
- 환자매크로 F1 + 부트스트랩 CI, micro, 최다레코드 지배율
- 대응 부트스트랩 비교(사용자가 직접 실행한 셀 — §6.2에 코드 있음)

**새 모델은 이 하니스에 arm 하나로 추가**하면 기존 5개 기준선과 자동으로 같은 조건에서 비교된다.

> ✅ **구현됨**: `svdb_bench.py` 에 arm 레지스트리(`register_arm` / `clear_arms` / `list_arms`)를
> 추가했다. `fn(ctx) -> bool[len(te)]` 계약이며, `bench_models()` 가 각 폴드에서
> B0~B4C 와 **동일한 tr/cal/te/Sw/mc/seed** 로 호출한다 → 대응 부트스트랩이 유효해진다.
> arm 이 실패해도 그 arm 만 제외되고 실행은 계속된다. 사용 예는 `svdb_rhythm.attach_arms()`.

### 6.2 대응 비교 코드 (모델 비교 시 반드시 사용)
```python
import numpy as np
R = OUT['res']                     # bench_models() 반환값
def paired(a, b, B=5000, seed=0):
    d = R[a]['fper'] - R[b]['fper']            # 같은 환자끼리의 F1 차이
    rng = np.random.RandomState(seed); n = len(d)
    bs = np.array([d[rng.randint(0,n,n)].mean() for _ in range(B)])
    lo, hi = np.percentile(bs, [2.5, 97.5])
    print(f"{a} − {b}: Δ={d.mean():+.3f} [95%CI {lo:+.3f}, {hi:+.3f}]"
          f"  {'★유의' if (lo>0 or hi<0) else '유의하지 않음'}")
```
> Bonferroni: 비교 k개면 z=2.498(k=4) 등으로 CI를 넓혀 재판정할 것.

## 7. 무결성 규칙 (반드시 준수)

1. **테스트 폴드 라벨로 어떤 결정도 하지 않는다.** 임계·하이퍼파라미터·구성 선택 모두
   학습 폴드(또는 그 안의 calib)에서만.
2. **하이퍼파라미터는 학습셋 통계에서 공식으로 유도**한다(`auto_weights` 등). 상수 하드코딩 금지.
3. **개인화는 테스트 환자 본인 신호만** 사용하고 라벨은 쓰지 않는다.
4. **결과가 좋게 나오면 먼저 의심한다.** N3(SMOTE 0.821)은 재실행에서 0.796으로 무너졌다.
   반드시 시드/반복을 늘려 재현 확인.
5. **음성 결과를 기록한다.** PAPER.md §7에 추가.
6. **CI가 겹치면 "개선"이라 쓰지 않는다.**
