## R1. 채점 대상 마스크는 **한 곳에서** 정의하고 모든 집계가 인자로 받는다

같은 오염이 **세 곳**에서 반복됐다:

| # | 어디 | 무슨 일 | 발견 |
|---|---|---|---|
| ① | 부위별 채점 | `GMIN_PT=20` 적용 ✅ | — |
| ② | OR 게이트 | **적용 안 함** ❌ | 실험20c P-3 |
| ③ | 임계값 CV 평균 | **적용 안 함** ❌ | 실험20c 사후 검토 |

②의 대가: 특이도 **0.196 → 0.678**, LR+ **1.24 → 2.74**.
③의 대가: 결론이 **뒤집혔다**(전체 7부위 0.700 vs 0.743 → 채점 3부위 0.790 vs 0.627).

```python
SCORE_MASK = np.array([Y[:, j].sum() >= GMIN for j in range(K)])   # 한 번만
CONFIG["score_mask"] = [SITES[j] for j in np.where(SCORE_MASK)[0]]
def agg(x, mask=SCORE_MASK): ...    # 모든 집계가 받는다
```

### 감사 결과 (2026-08-02)

| 실험 | 상태 |
|---|---|
| 15 · 15c · 15d · 16 · 17 · 18 · 19 · 22 | **해당 없음** — PTB-XL 내부는 `NMIN=50` 을 라벨 수준에 걸었고 7부위가 전부 통과한다. 배제 대상이 애초에 없다 |
| 20 | 정상 — 표에 `⚠️채점제외` 를 찍고 `SCORE_SITES` 로 채점 |
| **20b** | **오염** — 7부위 OR 에 제외 부위를 그대로 넣었다 |
| **20c** | **오염** — CV 평균에 제외 부위를 그대로 넣었다 |
| 20d | 수정 — `SCORE_MASK` 도입 |
| 21 | 설계에 반영됨(미실행) |

⚠️ **다만 내부 실험에 별개의 사촌 문제가 있다.** 실험16~19 의 `최악 D = max(부위)` 는
7부위 전체의 최댓값이라 **가장 시끄러운 부위가 지배**한다 — 실제로 `IPLMI`(n=51,
`NMIN=50` 을 겨우 넘김, SD 0.043)가 끌고 갔다. 이건 배제 대상이 아니므로 오염은
아니지만, **max 통계량은 항상 "무엇이 끌고 가는지" 와 중앙값을 함께 보고**해야 한다
(실험18 카드가 이미 그렇게 했다).

## R4. 유병률에 붙은 지표로 **코호트를 비교하지 않는다**

| 지표 | 코호트 간 비교 | 이유 |
|---|---|---|
| **AUROC** | ✅ | 순위 기반 · 유병률 무관 |
| 민감도·특이도 | ✅ | 조건부 확률 |
| PPV·PR-AUC | ❌ | 유병률에 직접 붙는다 |
| lift (= PR / 기저율) | ⚠️ | **천장이 `1/기저율`** 이라 코호트마다 다르다 |

→ **축·코호트를 가로지르는 비교는 AUROC 로 한다.**

## R5. 집계 방식이 **결론을 만들어내지 않는지** 확인한다

실험20c 의 P-2 는 `|narrow − wide| < 0.05` 였는데, `wide` 를 두 헤드 AUROC 의
**산술평균**으로 잰 탓에

```
강 − 평균 = (강 − 약) / 2
```

이 되어 **약한 헤드가 문턱의 2배만 뒤처지면 자동 기각**됐다. 실측 `(0.8660−0.5684)/2
= 0.1488` 로 문턱 0.05 를 구조적으로 넘었다. 실험20d 가 결합 점수 `max()` 로 다시
재니 차이가 **0.0017** 이었다 — **데이터가 아니라 통계량이 말한 것**이었다.

→ 관문을 쓰기 전에 **영가설에서 그 통계량이 어떤 값을 내는지** 픽스처로 확인한다.

같은 종류로 걸렀던 것: 실험21 의 P-4 를 `단일 SD / LOO앙상블 SD ≥ 1.5` 로 재려 했는데,
LOO 앙상블 5개는 서로 4/5 를 공유해 **효과가 0 이어도 비가 정확히 4.00** 이 나온다.

## R10. 확률을 저장할 때 **정답 라벨과 인덱스를 같이** 저장한다

2026-07-17 실행의 pkl 10개에는 `proba`·`pred`·`f1`·`macro4` 가 들어 있는데
**`y` 가 없다.** 그래서 실험22-A 가 라벨을 현재 파이프라인의 DS2 배열에서
빌려오려 했고, 길이가 **47,801 vs 49,295** 로 어긋나 재계산이 막혔다.

두 가지가 동시에 걸린 것이다:

| # | 문제 | 결과 |
|---|---|---|
| ① | 라벨 미저장 | 확률만으로는 어떤 지표도 재계산할 수 없다 |
| ② | 비트 추출 파이프라인이 그새 바뀜 | 외부에서 빌린 라벨과 **정렬이 안 맞는다** |

②가 없었다면 ①은 티가 안 났을 것이다 — 그래서 **둘 다** 위험하다.
길이가 우연히 같으면 어긋난 라벨로 조용히 **다른 실험**을 하게 된다.

→ 저장 규격: `proba` 와 함께 **`y`·`pid`·`beat_index`** 를, 그리고 그 실행이 쓴
**데이터 캐시 파일명과 해시**를 넣는다. 길이만 맞는지 보고 정렬을 가정하지 않는다.

### R10-b. **길이 일치는 정렬의 증거가 아니다** — 클래스 구성까지 대조한다

47,801 은 **서로 반대 방향 두 오차의 상쇄값**일 가능성이 높다:

```
겉보기 차이 = (N/S/V 부족)  −  (제4클래스 F 초과)
```

07-17 실행은 **4클래스**(N/S/V/F)였다. 그 증거가 pkl 안에 이미 있었다 — 키 이름이
`macro4` 이고, `nsv` 는 N/S/V **셋만** 센다. 따라서 `nsv` 합과 `len(proba)` 의 차액이
곧 F 개수다. 이걸 안 보면 부족과 초과가 상쇄돼 겉보기 차이만 작아 보인다.

**최악의 경우 길이가 정확히 일치하면서 정렬은 완전히 어긋난다.** 그러면 아무 경고
없이 채점된다. 이번엔 운 좋게 안 맞아서 걸린 것이다.

→ 정렬을 인정하는 조건은 **길이 AND 클래스별 개수**다. 하나만으로는 안 된다.

### R10-d. 데이터 손실을 **풀링 비율**로 보고하지 않는다

2026-08-02 실측. 07-17 캐시가 현재 파이프라인보다 3,260비트(3.26%) 적었다.
"전 레코드에 3~4% 씩 고르게" 로 읽혔는데, 레코드별로 보니 정반대였다:

| | |
|---|---:|
| 손실 **0** 인 레코드 | 13 / 44 |
| 손실률 5% 초과 | 3개 (#114 · #203 · #228) |
| **#228(80.6%) + #114(46.0%)** | 전체 부족의 **77.2%** |

풀링 비율 3.26% 는 **두 레코드의 사고를 42개로 나눠 희석한 값**이었다.

→ 손실은 항상 **① 레코드별 최악값 ② 손실 0 인 레코드 수 ③ 상위 2개의 누적 기여**
와 함께 보고한다. 평균만 내면 "고르게 조금씩" 으로 오독된다.

### R10-e. **N 이 멀쩡한데 특정 클래스만 빠지면 검출이 아니라 라벨 매핑이다**

R파 검출·분절 실패는 **클래스에 눈이 멀다**(class-blind) — 라벨을 보고 비트를 고르지
않는다. 그러므로 다음은 검출 실패로 **산술적으로 불가능**하다:

| rec | N 손실 | S 손실 | V 손실 |
|---|---:|---:|---:|
| #201 | 1/1,635 (0.06%) | **66/128 (51.6%)** | 0 |
| #210 | 4/2,421 (0.17%) | **13/22 (59.1%)** | 35/195 (17.9%) |
| #124 | 0/1,535 (0%) | 0/31 (0%) | **31/47 (66.0%)** |
| #202 | 0/2,060 (0%) | 7/55 (12.7%) | **12/19 (63.2%)** |

같은 기록 안에서 시간적으로 섞여 있는 비트들이다. 남은 설명은 **심볼→AAMI 매핑**뿐:
S군 = `A`+`a`+`J`+`S` (aberrated APB `a` 누락 의심) · V군 = `V`+`E`
(ventricular escape `E` 누락 의심).

→ 손실을 진단할 때 **클래스별 손실률을 레코드 안에서** 비교한다. N 손실률 ≈ 0 인데
다른 클래스만 크면 검출 가설을 버린다. 확정은 `wfdb.rdann` 심볼 카운트로.

### R10-c. '레코드 소실 vs 분산 손실' 은 **클래스 프로파일**로 가른다

비트 수 차이만 보면 애매하다(DS2 레코드당 평균 약 2,241비트라 1,872 는 0.84
레코드분이다). 그런데 DS2 는 **한 레코드(#232)가 S 의 75.2% 를 갖는다**
(`mit-bih/PAPER.md` 관찰3). 그래서:

| 관측 | 함의 |
|---|---|
| S 손실이 최대 보유 레코드에 근접 | 그 레코드가 통째로 빠졌다 |
| S 손실이 그보다 훨씬 작고 클래스별로 고르다 | **전 레코드 분산 손실** |

⚠️ 이때 기준값(#232 의 S 개수)은 **인용하지 말고 우리 배열에서 직접 센다.**
픽스처 `pipelines/test_exp22a_g1.py` 의 A/E 시나리오가 이 판별을 검정한다 —
가짜 07-17 배열을 **현재 배열에서 파생**시켜야 한다는 것까지 포함해서(독립 난수로
만들면 #232 편중이 사라져 A 와 E 가 구분 불가능해진다).

→ 이미 저장된 것에서 되살리는 순서:
**그 실행 자신의 데이터 캐시**(`data_mit.npz` 등)에서 라벨을 찾는다 →
DS2 마스크 길이가 `len(proba)` 와 **정확히** 같을 때만 쓴다 → 안 맞으면
**레코드별 비트 수를 비교**해 원인(레코드 누락 vs 전 구간 소실)을 남기고 잠근다.

⚠️ 이때 `f1`·`macro4` 같은 **저장된 지표는 라벨 없이 회수된다**. 다만 이들은
**동작점(임계값)에 붙어** 있어 Δ 안에 판별력 변화와 임계값 이동이 섞인다 —
AUROC 를 대체하지 못하고, 인용 잠금을 해제하지도 못한다.

## R11. **맥락정의 클래스는 환자를 단위로 채점한다**

실험22-A G1-c 에서 부분과 전체가 반대로 나왔다:

| 코호트 | S 기저율 | PR-AUC Δ | R-prec Δ |
|---|---:|---:|---:|
| 전체 (S 1,808) | 3.78% | **−0.2194** | −0.2094 |
| **#232 만** (S 1,381 = 76%) | 77.63% | **+0.0053** | **+0.0130** |
| #232 제외 (S 427) | 0.93% | −0.0746 미결 | −0.1171 |

**S 의 76% 를 가진 환자 안에서는 오히려 나아졌는데 전역은 무너졌다.**
"전역 S 지표" 는 사실상 **#232 한 명의 지표 + 환자 간 눈금** 이었다.

기전은 상위 목록 구성에서 보인다 — 진짜 S 가 **9·7·0** 개뿐인 #210·#219·#221 이
상위 1,808 슬롯을 **497개** 가져가 다른 환자의 진짜 S 를 밀어냈다.

### 규약

1. **주 지표는 환자 매크로.** 환자별로 재고 평균한다. 전역 풀링은 **보조**다.
2. **최소 양성 수 `GMIN_S`** 를 걸고, 제외된 환자를 **명시**한다(R1 · R7).
3. **지배 지분을 반드시 보고**한다 — `최대 환자 양성 / 전체 양성`.
   이 값이 50% 를 넘으면 **전역 지표를 단독으로 인용하지 않는다.**
4. **환자 간 절대 점수를 비교하지 않는다.** 비교가 필요하면 **환자 내 정규화** 후에.
5. **동작점은 환자별 경보율로 고정**한다 (`colab_step69_ratepoint.py::_t_for_rate`).

### R11-b. **매크로 평균도 지배당한다** — 개체별 값을 전부 보고한다

2026-08-02, 나는 매크로 하나만 보고 "SVDB 증강이 S 를 개선했다" 고 썼다. **틀렸다.**

| 레코드 | S | R-prec Δ |
|---|---:|---:|
| **#213** | 28 | **+0.4857** |
| #232 | 1,381 | +0.0130 |
| #234 · #202 · #100 · #200 · #222 | 50·48·33·30·204 | −0.0040 ~ −0.0294 |

매크로 **+0.0631** 인데 **#213 하나가 +0.0694 를 기여**한다(110%).
#213 을 빼면 **−0.0073** 로 부호가 뒤집힌다. **7개 중 5개는 악화**였다.

레코드 부트스트랩 CI **[−0.0143, +0.2058]** — 0 을 포함한다. 시드 CI 폭의 2.15배.

왜 #213 이 튀나: S 가 28개뿐이라 R-prec 해상도가 `1/28 = 3.6%p` 다. 상위 28개 안에서
13~14개만 달라져도 Δ 가 0.49 가 된다. **작은 n 에서 비율 지표는 폭발한다.**

→ 매크로를 낼 때 항상 **① 개체별 값 전량 ② 최대 기여 개체를 뺀 값 ③ 개체
부트스트랩 CI ④ 개선/악화 개체 수**를 함께 낸다. 평균 하나로는 R10-d 와 **같은
함정**에 빠진다 — 이번엔 풀링이 아니라 매크로가 지배당했다.

→ 그리고 `GMIN_S` 는 지표의 **해상도**를 보고 정한다. R-prec 에 20 은 너무 낮다.

### 어떤 클래스에 거나

정의가 **개인 기준 상대량**인 클래스(S = '평소보다 이르다')는 전역 점수 눈금이
성립할 이유가 없다. 정의가 **내재적 형태**인 클래스(V = '넓은 QRS')는 상대적으로
안전하지만 **면제는 아니다** — 판단 기준은 클래스 이름이 아니라 **지배 지분**이다.
지분을 재고 나서 정한다.

⚠️ 표현(features)과 채점(metric)은 **다른 층위**다. `_medref`·환자상대 리듬특징은
표현 층위의 환자 정규화이고, 위 규약은 채점 층위다. 하나를 했다고 다른 하나가
해결되지 않는다.

## R12. **근사 SE 로 극단값을 판정하지 않는다** — 최대값은 부트스트랩으로만

퀘스트46 Q1 실측. 환자별 AUROC 의 Hanley–McNeil SE 와 부트스트랩 SE 를 대조했다.

| 지점 | Hanley/부트 |
|---|---:|
| **중앙값** | 1.49 ~ 16.07 (Hanley 가 보수적) |
| **최대값** | **0.36 ~ 1.35** (뒤섞임 — 극단에서는 Hanley 가 **과소**) |

중앙에서는 보수적인데 **양성이 3~6개인 레코드에서는 오히려 작게** 나온다. Hanley 의
분산 공식은 이항정규를 가정하는데, 양성이 몇 개뿐이면 부트스트랩이 잡는 '그 몇 개가

**나는 여기서 틀렸다.** 중앙 비 2.76 을 보고 "최대 SE 0.1976 도 2.76 으로 나누면
0.072 라 통과한다" 고 예측했다. 실측 부트 최대는 **0.2661** 로 Hanley 보다 **컸다**.

→ **하나의 배수로 근사를 환산할 수 없다.** 구속 조건이 최대값이면 **부트스트랩으로
직접 잰다**. 근사는 후보를 좁히는 **스크리닝**에만 쓴다.

→ 그리고 검증이 선택에 의존하게 짜지 않는다. Q1 1차 설계는 '근사로 고르고 → 고른
것만 검증' 이라 **근사가 틀리면 검증도 안 돌았다**. 검증이 필요한 바로 그 경우에.

## R13. 지배 지분만으로 **분포가 고른지** 판단하지 않는다

R11-3 은 `최대 개체 양성 / 전체 양성` 을 보라고 했다. 그것만으로는 부족하다.

## R14. **가중치는 개체를 늘리지 않는다** — 유효표본크기를 함께 내고, ESS 가 무너지면 CI 폭을 읽지 않는다

퀘스트46 Q8. Q1 이 남긴 딜레마는 "버리면 12명, 다 받으면 SE 폭발" 이었다. 제3의 길로
**역분산 가중**(`w = 1/SE²`, 메타분석 표준)을 놓고, 픽스처 합성 코호트로 먼저 쟀다.

**① 가중은 개체 수를 늘려주지 않는다.** Kish 유효표본크기 `ESS = (Σw)² / Σw²` 로 잰다.
모두 같은 가중이면 `ESS = n`, 한 개체에 몰리면 `ESS → 1`.

| 합성 코호트 | 개체 | CI 폭(역분산) | CI 폭(단순) | **ESS** |
|---|---:|---:|---:|---:|
| 양성 3,000개 1개 + 12개짜리 26개 | 27 | **0.0206** | 0.0386 | **1.8** |
| 양성 30개 15개 + 90개 15개 | 30 | 0.0214 | 0.0217 | 23.5 |

**② 좁아진 CI 가 정밀도의 증거가 아니다.** 위 첫 줄에서 CI 폭은 **46.6% 좁아졌다.**
폭만 보면 이겼다. 그런데 좁아진 이유는 정밀해져서가 아니라 **가중이 한 개체로
붕괴**해서다 — 사실상 그 한 명의 값을 반복 측정한 것이고, R11-b 의 #213 사고를
가중치로 다시 저지른 것이다. → **관문에 판독 순서를 준다: ESS 관문이 기각이면 CI
폭과 편향 관문은 읽지 않는다.**

**③ 역분산 가중은 SE 가 *참값*일 때만 최적이다.** 우리가 쓰는 SE 는 부트 **추정치**다.
SE 가 코호트 안에서 균질하면 `1/SE²` 는 '우연히 SE 가 작게 나온 개체' 에 가중을
몰아준다 — 순수한 잡음이다. 실측: 25개체가 **전부 같은 조건**일 때 역분산 CI 폭
0.0425 vs 단순 0.0254 — **1.7배 나빴다.** ESS 도 25 → 18.

→ 가중을 쓸 거면 **추정 잡음이 없는 가중**(예: `w = n_pos`)을 나란히 놓고 비교한다.
다만 그게 항상 낫지도 않다: 완만한 이질성에서는 양성수 가중 ESS 24.0 > 역분산 23.5
였지만, 한 개체가 압도하는 코호트에서는 양성수 1.2 < 역분산 1.8 로 뒤집혔다.

**④ 개체 1개짜리는 arm 이 아니다.** 개체가 하나면 개체 부트스트랩이 늘 같은 값을
뽑아 **CI 폭이 0** 으로 나온다. 그걸 기준선으로 쓰면 '폭 0.0000 의 최정밀 기준선' 이
된다(실제로 나눗셈에서 터져서 발견했다). → 매크로 arm 은 **개체 2개 이상**일 때만
성립시키고, 안 서면 관문을 조용히 비우지 말고 **미결**로 남긴다.

### R14-b. 천장이 있는 지표에서 **역분산 가중은 발산한다** — 실데이터가 R14 보다 나빴다

퀘스트46 Q8 실측(INCART · S · `ailab-2026-0050`). 합성 픽스처는 "추정 잡음이 증폭된다"
까지만 잡았는데, 실데이터는 한 단계 더 나쁜 것을 보여줬다.

```
AUROC 는 천장이 1 이다.
개체의 분리가 완벽에 가까우면 → 부트 재표집이 거의 늘 같은 값
                            → 부트 SE → 0
                            → w = 1/SE²  →  ∞
```

**역분산 가중은 '가장 쉬운 개체' 에 무한대 가중을 준다.** 잡음은 방향이 없지만 이건
**천장 쪽으로 편향**된다. 실측 결과:

| 구성 | 개체 | ESS | 최대가중 | 점추정 | CI 폭 |
|---|---:|---:|---:|---:|---:|
| 단순 매크로 (GMIN 10) | 12 | 12.0 | 8.3% | 0.9599 | 0.0330 |
| 양성수 가중 (GMIN 2) | 27 | 5.3 | 30.2% | 0.9510 | 0.0488 |
| **역분산 가중 (GMIN 2)** | 27 | **2.0** | **55.8%** | **1.0000** | 0.0118 |

점추정이 **정확히 1.0000** 이고 CI 가 단순 점추정 0.9599 를 **품지 못했다**. CI 폭은
64.3% 좁아졌다 — R14 ②의 판독 순서가 없었으면 이걸 성과로 썼다.

→ **천장(또는 바닥)이 있는 지표 — AUROC · 정확도 · 민감도 · Dice — 에는 역분산
가중을 쓰지 않는다.** 굳이 쓸 거면 SE 에 바닥을 깔고, 바닥에 걸린 개체 수를 보고한다.

**② `w = n_pos` 도 안전하지 않다.** 정의상 `최대가중 = max(n_pos)/Σn_pos = 지배 지분`
이다. 실측이 그대로 맞았다(30.2% vs INCART 지배 30.1%). 즉 **양성수 가중은 매크로를
전역 지표 쪽으로 되감는다** — R11 이 피하려고 만든 방향이다. 합성 픽스처에서 이게
안전해 보였던 건 거기서 `n_pos` 가 개체마다 같았기 때문이다(= 균등 가중).

**③ SE=0 필터를 전체 arm 에 걸지 않는다.** 0 나눗셈을 막는 `se > 0` 조건을 모든 arm 에
걸면 **완벽 분리 개체를 채점에서 조용히 뺀다** — 가장 쉬운 개체를 빼는 것이라 기준선이
왜곡된다. 필터는 그게 필요한 arm 에만 걸고, 떨어진 개체 수를 로그에 남긴다.

**④ 합성 픽스처에 '완벽 분리 개체' 를 반드시 넣는다.** Q8 픽스처는 분리도를 0.85
근처로 깔아서 AUROC 가 천장에 붙는 개체를 안 만들었다. 그래서 발산을 못 봤다.
경계값이 있는 지표를 검정할 때는 **경계에 붙은 개체**가 시나리오에 있어야 한다.
시나리오를 추가하니 실데이터보다 선명하게 재현됐다 — 완벽 분리 개체 1개 + 보통 개체
20개에서 **그 하나가 가중의 100.0%** 를 가져갔다(ESS 1.00 · 점추정 1.0000). 단순
매크로는 같은 코호트에서 21개체를 전부 유지하고 0.8628 을 낸다.

## R15. 매크로 CI 폭을 만드는 건 **측정오차가 아니라 개체 간 이질성**이다

퀘스트46 Q7-B 실측(SVDB · S · 28레코드 · `ailab-2026-0051`).

| 성분 | CI 폭 |
|---|---:|
| **관측** | **0.0617** |
| 개체 간 이질성만 (개체 AUROC SD 0.0848) | 0.0628 |
| 측정오차만 (RMS SE 0.0228 · 중앙 0.0104) | 0.0169 |

분산비 = **13.8배**. 관측 폭이 이질성 성분과 사실상 같다.

→ **GMIN 을 올려 per-record SE 를 줄여도 매크로 CI 는 거의 안 좁아진다.** 좁히는 건
**개체 수를 늘리는 것**뿐이다.

### ⚠️ R15-a. 단, "개체를 늘리면 좁아진다" 는 **개체 간 동질성을 가정한 문장**이다

Q7-B′ 실측(`ailab-2026-0053`). 개체를 28 → 72 로 **2.6배** 늘렸는데 CI 폭이
**0.0617 → 0.0726 으로 오히려 넓어졌다.**

| | 28개체 | 72개체 |
|---|---:|---:|
| CI 폭 | 0.0617 | **0.0726** |
| 역산 개체간 SD | 0.0833 | **0.1572** (1.89배) |
| √n | — | 1.60배 |
| 이질성/측정오차 분산비 | 13.8 | **49.2** |

새로 들어온 개체 중에 **AUROC 0.0595 짜리**(`#865` — 모델이 역전된 환자)가 있었다.
**SD 가 √n 보다 빨리 자라면 CI 는 넓어진다.** → 개체를 늘릴 때는 **SD 도 같이 보고**
하고, 폭이 안 좁아지면 "표본이 모자라다" 가 아니라 **"새 개체가 다른 분포에서 왔다"**
로 읽는다. Q1 이 '최대 SE ≤ 0.10' 에 매달려 코호트 셋을 기각한 건
필요조건으로서 옳았지만, 정작 Q2 를 가로막는 CI 폭의 **주 원인은 아니었다**.
→ 채점 설계에서 두 가지를 **분리해서** 보고한다: ① per-record SE(그 환자 값을 믿을 수
있나) ② 개체 간 SD(코호트가 얼마나 다양한가). 문턱도 따로 건다.

### R15-b. per-record SE 는 **모델 의존적**이다 — 코호트의 성질이 아니다

같은 실행에서:

| 개체군 | 개수 | 중앙 SE |
|---|---:|---:|
| AUROC ≥ 0.99 | 5 | **0.0010** |
| AUROC < 0.90 | 7 | **0.0153** |

15배 차이다. R14-b 그대로 — AUROC 는 천장이 있어 분리가 좋을수록 부트 SE 가 0 으로
간다.

**★ 바닥 쪽에서도 같다 — SE 관문은 '확신에 찬 오답' 을 못 잡는다.** Q7-B′ 실측:
최대 SE 관문(≤0.10)이 0.0824 로 통과했는데, **가장 망가진 개체 `#865`(AUROC 0.0595 —
역전)의 SE 는 0.0044** 로 실패 목록에서 **가장 촘촘했다.** 모델이 일관되게 틀리면
부트 재표집도 일관되게 틀린 값을 낸다.

→ **정밀도 관문 통과를 성능 근거로 읽지 않는다.** 관문은 「잴 수 있다」는 말이지
「좋다」는 말이 아니다. 성능은 값 자체로 판단하고, 개체별 값을 **전량** 본다(R11-b). 그래서 "SVDB 는 최대 SE 0.0821 로 정밀하다" 는 **"이 코호트 + 이 모델"** 의
성질이지 코호트만의 성질이 아니다. 더 나쁜 arm 을 태우면 같은 코호트에서도 SE 가
커진다. → **SE 관문을 통과한 GMIN 을 다른 arm 에 그대로 물려주지 않는다.** 여유를 둔다.

### R15-c. **반쪽 재현**을 보고한다 — 한 반쪽 통과는 코호트 통과가 아니다

Q7-B 는 SVDB 를 DEV/TEST 로 반씩 갈라 TEST 에서만 채점했다(GMIN 선택 오염 차단, R12).
그 덕에 **같은 DB 의 두 반쪽 값을 나란히 볼 수 있었다**:

| 반쪽 | 개체 | 매크로 | CI 폭 |
|---|---:|---:|---:|
| TEST | 28 | 0.9256 | **0.0617** ✅ |
| DEV | 27 | 0.8382 | **0.1533** ❌ |

개체 수는 거의 같은데 **폭이 2.5배** 다르고, DEV 였다면 CI 폭 관문(≤0.10)이 **기각**
이었다. 분할을 반대로 뒀으면 결론이 뒤집혔다는 뜻이다.

→ 분할을 쓰는 실험은 **반대쪽 반쪽 값도 반드시 같이 낸다.** 두 값이 크게 갈리면
관문 통과는 '이 반쪽에서 통과' 이지 '코호트가 통과' 가 아니다. 확정하려면 전수를
채점해야 한다(선택이 끝난 뒤라면 전수 채점은 정당하다 — 고를 게 더 없다).

### R11-c. '최대기여 개체' 는 **두 정의**가 있고, 관문의 힘은 **n 에 의존**한다

퀘스트46 Q7-B 실측(`ailab-2026-0052`). R11-b 는 "최대 기여 개체 제외값" 을 내라고 했다.
그런데 '기여' 의 정의가 하나가 아니다.

| 정의 | 무엇을 찾나 | Q7-B 실측 |
|---|---|---|
| **제거영향** — 빼면 지표가 얼마나 움직이나 | 보고값을 흔드는 개체 | **#843** AUROC 0.7167 · S **17** |
| **부담가중 영향** — `|편차| × 개체 양성수` | 실제 양성 비트가 몰린 곳의 실패 | **#853** AUROC 0.7251 · S **454** |

**다른 개체를 가리켰다.** 비가중 매크로에서 제거영향은 곧 평균으로부터의 편차라
'양성 17개짜리 극단값' 이 잡히는데, 정작 S 비트 대부분이 있는 곳의 실패는 못 잡는다.
→ **둘 다 낸다.**

**②-b 그리고 n 이 커질수록 **더** 무력해진다.** Q7-B′ 실측: n=28 Δ0.0077 → n=72
Δ0.0116 인데 CI 폭은 0.0617 → 0.0726 이라 **관문 대비 비율**은 12% → 16% 로 여전히
작다. n=72 에서는 **AUROC 0.0595 짜리 명백한 이상치(`#865`)조차 통과시켰다.**

→ 제거영향 관문은 **최소 검출 가능 편차**를 같이 낸다:
`|편차|_min = (관문이 잡으려는 이동) × n`. 그 값이 **0.5 를 넘으면**(=AUROC 척도에서
불가능한 편차를 요구하면) **「통과」가 아니라 「적용 불가」** 로 기록한다.

**② 관문의 힘이 n 에 의존한다.** 비가중 매크로에서 개체 하나를 빼면 최대 `|편차|/n`
만큼 움직인다. Q7-B 는 n=28 이라 실측 Δ **+0.0077** — CI 폭 0.0617 의 12% 다.
**사실상 자동 통과**다. R11-b 를 낳은 #213 사건은 **n=7** 이었고 그때 한 개체가 매크로의
110% 를 만들었다. → n 이 크면 제거영향 관문을 "통과했다" 고 쓰지 말고
**"이 n 에서는 무력한 관문"** 이라고 쓴다.

**③ 매크로와 부담가중이 갈리면 집계를 갈아타지 말고 상관을 보고한다.** Q7-B 실측:

| | 값 |
|---|---:|
| 단순 매크로 | 0.9256 |
| 양성수 가중 | 0.8821 |
| 양성수 vs AUROC 스피어만 | **rho = −0.389 (p = 0.041)** |

| S 부담 | 개체 | 매크로 | 보유 S |
|---|---:|---:|---:|
| S ≥ 100 | 7 | **0.8765** | 2,234 (**75.8%**) |
| 50 ≤ S < 100 | 4 | 0.9562 | 266 (9.0%) |
| S < 50 | 17 | 0.9386 | 449 (15.2%) |

즉 매크로 0.9256 은 **S 가 8~40개뿐인 작은 레코드가 끌어올린 값**이고, 실제 S 비트의
76% 가 있는 곳은 0.88 근처다. 그렇다고 **가중값으로 갈아타면 안 된다** — `w = n_pos` 는
최대가중이 정의상 지배 지분과 같아서(R14-b ②) 매크로를 전역 지표 쪽으로 되감는다.
R11 이 피하려던 방향이다. → **부담 층화표 + 상관계수**를 낸다. 두 값이 갈린다는
사실 자체가 결과다.

### R15-d. 문턱 없는 지표를 primary 로 골랐으면 **그 대가를 결론 문장에 쓴다**

Q7-B 는 AUROC 를 primary 로 뒀다. 이유는 타당하다 — 동작점을 테스트에서 고르는 오염을
원천 차단한다. 그런데 07-17 에 전례가 있다:

| 지표 | 대조군 → 실험군 | 판정 |
|---|---|---|
| S ROC-AUC | 0.9223 → 0.9020 (Δ −0.020) | "애매" |
| **S PR-AUC** | **0.5138 → 0.2944 (Δ −0.219)** | **"결정적"** |

ROC 로는 거의 아무 일도 없어 보이는데 PR 로는 반토막이었다. **AUROC 0.926 은 PR-AUC
0.30 과 완벽히 양립한다.**

→ 순위 지표를 primary 로 쓰면 결론 문장에 **"확인한 것은 순위 능력이고 정밀도는
확인하지 않았다"** 를 박고, PR-AUC 를 **탐색적 부지표**로 병기한다(관문 판정은 바꾸지
않는다 — 그건 사후등록이다).

⚠️ PR-AUC 는 **유병률에 붙은 지표**다(R4). 개체마다·코호트마다 유병률이 다르므로
원값을 비교하면 안 된다. **유병률과 우연수준 대비 lift 를 반드시 같이 낸다.**

**Q7-B 실측 — 예측이 틀렸고, 대신 R4 의 교과서적 실례가 나왔다.**
붕괴를 걱정했는데 PR-AUC 매크로는 **0.4978** [0.3973, 0.6031] · lift 30.3배였다.
정밀도도 전이됐다. 그런데 부담군별로 보면:

| 구간 | 개체 | AUROC | 원 PR-AUC | 보유 S |
|---|---:|---:|---:|---:|
| S ≥ 100 | 7 | **0.8765** (최저) | **0.6177** (최고) | 75.8% |
| S < 50 | 17 | 0.9386 | **0.4467** (최저) | 15.2% |

**AUROC 와 원 PR-AUC 가 군 순서를 정반대로 매긴다.**

### ★ 여기서 내가 처방한 교정이 **실측으로 반증됐다**

처음에 "정규화PR `(AP−π)/(1−π)` 과 lift 로 읽으면 된다" 고 썼다. **셋 다 유병률에서
자유롭지 않았다.** 같은 실행을 다시 돌려 열을 붙여 봤다:

| 구간 | AUROC | PR-AUC | 유병률 | lift | **lift 천장(1/π)** | 정규화PR |
|---|---:|---:|---:|---:|---:|---:|
| S ≥ 100 | **0.8765** (최저) | 0.6177 | 0.1404 | 6.6 | **7.1** (92.7% 포화) | **0.552** (최고) |
| 50 ≤ S < 100 | 0.9562 | 0.5052 | 0.0303 | 17.3 | 33.0 | 0.490 |
| S < 50 | 0.9386 | 0.4467 | 0.0120 | 43.2 | 83.3 | 0.441 |

- **정규화PR 은 순서를 못 뒤집었다** — 원 PR 과 같은 순서다. 고정 ROC 에서 `AP ≈ cπ`
  이므로 `정규화PR ≈ π(c−1)` 이고, π→0 이면 **같이 0 으로 간다**. 유병률 무관이 아니다.
- **lift 는 천장이 `1/π`** 다. 부담 큰 군은 천장이 7.1 뿐이고 실측 6.6 — **92.7% 포화**다.
  "lift 가 낮다" 가 아니라 **"더 올라갈 데가 없다"** 이다.
- **lift 를 평균하면 안 된다.** 이 코호트에서 평균 lift 30.3 × 평균 유병률 0.0467
  = **1.42 > 1** 이다. 한 개체에서는 물리적으로 불가능한 값 — 유병률이 다른 개체를
  섞어 평균한 결과다. (노트북이 이 자기검증을 자동으로 찍는다.)

→ **개체·군을 비교하는 지표는 AUROC 뿐이다.** 순위만의 함수라 유병률과 무관하다.
  `AP` 와 `유병률` 은 **그 개체를 서술**하는 데 쓰고, 군 순위를 매기는 데 쓰지 않는다.

### 그럼 두 지표가 반대인 건 무슨 뜻인가 — 모순이 아니다

**부담 큰 레코드는 순위 품질이 나쁜데(AUROC↓) 정밀도는 높다(PR↑).** 양성이 흔하면
어설픈 순위로도 상위권에 진짜가 많이 담긴다. 둘 다 참이고 서로 다른 질문의 답이다.
유병률 17% 인 레코드에서 AUROC 0.7251 은 "순위가 나쁘다" 를, PR 0.3194 는 "그래도
상위권 셋 중 하나는 진짜다" 를 말한다.

→ 보고할 때 **둘 다** 낸다. 단 **비교는 AUROC 로, 서술은 AP+유병률로.**

→ 그리고 **매핑 결과를 자가검증**한다: 만든 식별자가 원본 목록의 부분집합인가.
   한 줄이면 된다 — `set(num) - set(recs)` 가 비어 있는지.

### R16-b. 집합 대조는 **양방향**으로 한다

첫 감사 셀은 `주석 − 빌드` 만 봤고 결과를 "17레코드 손실" 이라고 이름 붙였다. 같은
출력에 `빌드 성공 78레코드 (100.0%)` 가 찍혀 있었다 — **자기모순**이다. |A|=|B|=78 인데
|A−B|=17 이면 |B−A|=17 이므로 **손실일 수 없다**(손실이면 B ⊆ A 여야 한다).

→ 두 집합을 대조할 때는 **교집합·A−B·B−A 를 전부** 낸다. 한쪽만 보면 '어긋남' 을
'손실' 로 오독하고, 없는 원인(다운로드 실패)을 찾으러 간다.

### R16-c. 복원은 **탐색이 아니라 연역**으로 — 그리고 독립 신호로 검증한다

1차 복원 시도는 S 개수로 그리디 짝짓기를 했다. 결과가 78/78 이었지만 **믿을 수 없다** —
S=0 인 레코드끼리는 아무렇게나 붙고, 실제로 가짜 시프트(9, 42)가 섞여 나왔다.

원인을 알고 나면 복원은 **결정론**이다: `참 번호 = recs[라벨 − 800]`. 그리고 검증은
**독립 신호**로 한다 — S 하나가 아니라 `(N, S, V)` 삼중값을 주석과 대조한다.
실측 확인: 라벨 #868 (예측 S 399) → 참 #885, 주석 S **399** ✓ ·
라벨 #872 (예측 S 152) → 참 #889, 주석 S **152** ✓.

## R19. 상대 정의 클래스에서 **기준(reference)은 다수에서 뽑지 않는다**

퀘스트46 Q7-D 실측(`ailab-2026-0054`). SVDB `#865` 는 비트의 **57.6% 가 S** 이고
모델 AUROC 가 **0.0595** — 거의 완벽히 뒤집혔다(반전하면 0.9405).

### ① 반전은 **거리형 특징에서만** 생긴다 (구조적)

| 점수 형태 | 기준을 바꾸면 | 왜 |
|---|---|---|
| **위치형** `base − x` | **AUROC 불변** | 상수 이동은 순위를 안 바꾼다 |
| **거리형** `‖x − ref‖` | **뒤집힐 수 있다** | ref 가 바뀌면 순위 자체가 바뀐다 |

실측: RR 위치형 **0.9695**(어떤 기준을 써도 같다) vs 형태 거리형은 다수결 기준에서
**전부 반전**(전파형 0.0856 · P영역 0.2103 · QRS 0.0149).

→ **`_medref`(레코드 중앙 파형)처럼 「중심에서의 거리」로 만든 특징이 위험 지점**이다.
축을 형태로 옮기는 것은 처방이 아니다 — **형태 축이 오히려 더 심하게 뒤집힌 축**이었다.

### ② 정보는 있다. 기준만 틀렸다

같은 레코드, 같은 특징, **기준만** 바꿨을 때:

| 기준 | 형태·P영역 AUROC |
|---|---:|
| 다수결(`_medref`) | 0.2103 (뒤집힘) |
| 무감독 · 큰 군 | 0.0405 (더 심함) |
| **무감독 · 긴 RR 군** | **0.9666** |
| 오라클(N군 중앙 · 라벨 사용) | 0.9667 |

무감독 클러스터링은 P 영역만으로 S/N 을 **0.985 / 0.043** 로 이미 갈라놨다. 남은
문제는 **둘 중 어느 쪽이 '평소' 냐** 뿐이었다.

→ **다수에 의존하지 않는 앵커를 쓴다.** 여기서는 「이소성 리듬이 더 빠르다」는
생리 사전지식으로 **긴 RR 쪽을 기저**로 삼았고, **라벨 없이 오라클 상한에 도달**했다.

⚠️ 한계: 이 앵커는 「이소성 쪽 RR 이 짧다」에 의존한다. **서맥성 이소성이 기저인
환자에서는 같은 방식으로 틀린다.** 그리고 검증 개체가 1개다. 앵커를 도입할 때는
**정상 개체를 망가뜨리지 않는지**를 전수에서 확인한다.

### ③ 진단 절차 (개체가 뒤집혔을 때)

1. **정렬부터 배제한다** — 원본 주석 직독으로 클래스 카운트 대조(R16-c)
2. **`1 − AUROC` 를 본다** — 0.85 이상이면 정보 부재가 아니라 **방향 오류**다
3. **축 × 기준 격자**를 돌린다. 방향을 접지 않는다 —
   `max(AUROC, 1−AUROC)` 로 재면 **완벽히 뒤집힌 기준도 만점**을 받는다
4. **null 은 라벨 셔플**이다. '무작위 부분집합의 중앙을 기준으로' 는 null 이 아니다 —
   그 중앙도 **다수 모드에 앉는다**(실측 0.0000)
5. **'뒤집힘' 은 신호가 있는 축에서만 센다**(정보량 ≥ 0.60). 신호 없는 축은 0.48 처럼
   0.5 근처를 오가는데 그걸 반전으로 세면 정상 개체도 늘 걸린다

## R20. **개체별 문턱은 표본수와 검정 횟수를 모른다** — 점추정 문턱 → SE → 다중검정 보정

R19 의 진단 절차 5번(`정보량 ≥ 0.60 인 축에서만 반전을 센다`)은 **한 개체를 볼 때는**
맞지만, **전수 개체에 그대로 걸면 오발한다.** Q7-E 픽스처가 합성 **null 코호트**
(S 와 N 의 형태를 **아예 같게** 만든 것 — 형태 축에 신호가 0)를 돌려 두 번 잡았다.

| 반전 판정 규칙 | null 코호트 14개체에서 잡힌 '반전' |
|---|---|
| 점추정 < 0.5 & 정보량 ≥ 0.60 | **1개** — `#901`(S 16비트) AUROC 0.344 · 정보량 0.656 |
| 개체별 95% CI 상한 < 0.5 | **1개** — 같은 개체. CI [0.208, **0.491**] |
| 개체별 SE + **본페로니**(z=2.914) | **0개** ✅ |

### 왜 두 번 다 걸렸나

- **1차**: 정보량 문턱은 **점추정**에 걸린다. S 가 16개뿐인 개체는 AUROC 의 SE 가
  0.07 이라 0.34 쯤은 우연히 나온다. 문턱은 그 개체에 표본이 몇 개인지 모른다.
- **2차**: 개별 95% CI 로 바꾸면 개체 하나는 옳게 판정하지만, **개체마다 검정을
  반복**한다. n개면 약 n × 2.5% 가 우연히 걸린다 — 14개면 0.35개. 실제로 1개 나왔다.

### 규칙

1. 개체 단위 판정은 **점추정이 아니라 (점추정, SE)** 로 한다. SE 는 레코드 **내부**
   (비트) 부트스트랩으로 낸다 — 레코드를 재표집하는 매크로 부트스트랩과 다른 물건이다.
2. 개체를 **전수로 훑을 때는 다중검정 보정**을 건다. 본페로니면 충분하다:
   `z = Φ⁻¹(1 − α/2n)`, 판정은 `점추정 + z·SE < 문턱`.
3. **SE = 0 은 예외로 명시 처리**한다(완전 분리). R14-b 와 같은 함정 — SE 를 분모로
   쓰면 발산한다. `SE ≤ 0` 이면 점추정으로 판정하고 그 사실을 남긴다.
4. 보정 전 규칙으로 셌을 때의 개수를 **참고로 병기**한다. 몇 개를 걸러냈는지가
   보정의 값어치다(위 표가 그 형식이다).

### 이 규칙을 만든 방법 자체가 규칙이다

두 번 다 **데이터를 보기 전, 합성 null 위에서** 걸렸다. 실측 결과를 보고 문턱을 고치면
사후 조정이지만, **신호가 0인 걸 내가 아는 코호트**에서 관문이 뭘 잡는지 미리 보는 건
사전등록의 일부다. **새 관문을 쓸 때는 null 코호트를 먼저 통과시킨다** — 관문이
'아무것도 없을 때 아무것도 안 잡는지' 부터 확인한다.

## R21. **기준을 다수에서 떼는 건 공짜가 아니다** — 편향을 줄이는 대신 분산을 산다 (R19 단서)

R19 는 「상대 정의 클래스에서 기준(reference)을 다수에서 뽑지 마라」였다. 한 개체
(`#865`)에서는 맞았다. **전수 70개체에서는 기각됐다**(Q7-E · `ailab-2026-0055`).

| 관문 | 결과 |
|---|---|
| E1 개선(짝지은 앵커−다수결) | ⚠️ 미결 −0.0018 [−0.0224, +0.0274] |
| E2 반전 0 | ❌ 기각 — 2개 남음(하나는 **새로 생긴** 반전) |
| E3 정상 개체 비열등 | ⚠️ 미결 −0.0128 [−0.0263, −0.0023] |

**`#865` 하나를 빼면 짝지은 차가 −0.0128 [−0.0255, −0.0024]** — CI 전체가 0 아래다.
개선은 **한 개체 이야기**였고 나머지는 순손해였다.

### 왜 — 두 기준은 **편향-분산이 반대**다

| 기준 | 편향 | 분산 |
|---|---|---|
| 다수결(레코드 중앙) | 다수가 오염되면 **파국적** | 작다 (전 비트로 만든 중앙) |
| 다수 비의존 앵커 | ~0 (제대로 고르면) | **크다** (부분집합으로 만든 중앙) |

앵커를 고르는 신호(여기서는 두 군의 중앙 RR 차)가 약하면 **선택 자체가 잡음**이 되고,
기준은 「N 의 임의의 부분집합 중앙」으로 전락한다.

### 전수 감사가 이것을 훨씬 날카롭게 만든다 (`audit_anchor.py`)

노트북 로그만 보면 「분리도가 높으면 앵커가 이긴다([0.30,∞) Δ +0.0319)」로 읽힌다.
**틀렸다. 그 층의 +0.0319 는 통째로 `#865`(분리도 0.783) 다** — 빼면 −0.0026, 즉 0 이다.
경사가 아니라 **문턱**이다: 분리도가 낮으면 지고, 높아도 이기지는 않는다.

더 결정적인 세 가지:

1. **앵커가 큰 군과 같은 개체가 59/70(84%)** — 처방은 **11개체에서만 발동**했다.
2. **발동한 11개 중 이득은 1개, 손해가 10개.** 발동 개체 Δ 평균 −0.0229,
   `#865` 제외 **−0.1008**. 미발동 59개는 +0.0021(본전).
3. **손해 본 10개 전부 `오라클 ≈ 다수결`** 이었다(`#862` 는 소수 넷째 자리까지 동일).
   **그 개체들의 기준은 이미 최적이었다.** 고칠 편향이 없는 곳에서 기준을 바꾸면
   분산만 산다. 농축비 0.00 인 `#856` 조차 −0.0842 다 — **농축만으로도 설명이 안 된다.**

그리고 문제 클래스 자체가 희소하다:

| 유병률 | 개체 | (오라클 − 다수결) 평균 |
|---|---:|---:|
| [0.00, 0.20) | 64 | ≤ +0.0061 |
| [0.20, 0.35) | 5 | **+0.0879** |
| [0.35, 1.00] | 1 | **+0.7564** |

**오라클이 다수결보다 0.02 이상 나은 개체는 70개 중 5개(7%)** 다. 처방을 전수에 거는
건 **7% 를 고치려고 93% 에서 분산을 사는 비대칭 도박**이었다.

### 규칙

1. 기준을 바꾸는 처방은 **전수 짝지은 비교 + 최대 기여 개체 제외 재계산**을 통과해야
   한다. 한 개체에서 극적으로 좋아진 것은 처방의 근거가 **아니다**(R11-c).
2. **비열등 관문을 반드시 같이 건다.** "고치는 개체"만 보면 "깎는 개체"가 안 보인다.
3. 조건부로 쓸 거면 **조건이 라벨 없이 계산 가능**해야 하고, **「처방이 이기는 조건」이
   아니라 「고칠 게 있는 조건」**을 잡아야 한다. 이 둘은 다르다 — RR 분리도는 전자에
   가깝고(rho +0.454) 설명력이 없는 반면, 실제로 이득을 결정한 건 **기준 오염의 크기**
   이고 그건 유병률이 정한다. 사후 층화에서 나온 문턱은 그대로 못 쓴다 — 다른 코호트나
   DEV 반쪽에서 사전등록한다.
3-b. **처방이 몇 개체에서 실제로 발동했는지를 먼저 센다.** 84% 에서 앵커가 다수결과
   같은 물건이었는데 매크로만 보면 「거의 차이 없음」으로 읽힌다. 발동/미발동을 나눠
   보면 **발동하면 10/11 확률로 해로웠다** — 정반대의 결론이다.
4. **감사 문턱은 절대값이 아니라 기저 대비로 잡는다.** Q7-E 의 사후 셀은 「앵커가
   S 우세 군(S비율 > 0.5)을 골랐나」를 물어 **0개**를 얻었는데, 같은 실행에서 앵커는
   정상 개체를 깎고 있었다. 유병률 0.029 인 개체의 앵커군 S비율 0.139 는 **4.8배
   농축**인데 0.5 문턱에 안 걸린다. 기저 대비 비율로 세면 전부 보인다
   (→ `pipelines/audit_anchor.py`).
5. **실패 기전을 하나만 연습해 두지 않는다.** Q7-E 픽스처는 「늦은 이소성이면 앵커가
   S 군을 고른다」를 합성해 관문이 기각하는 걸 확인했는데, **실제 실패는 그 기전이
   아니었다**(S 우세 군 선택 0건). 픽스처가 준비한 실패가 안 일어났다고 처방이
   안전한 게 아니다 — **관문이 기각했으면 기전은 새로 찾는다.**

## R22. **템플릿을 자기 비트로 만들어 자기를 채점하지 않는다** — 신호 0에서도 0.89 가 나온다

Q7-H 를 짜면서 픽스처가 **데이터를 보기 전에** 두 번 잡았다. 둘 다 「지표가 새는」 종류다.

### ① 인-샘플 템플릿 누수

두 템플릿 점수 `g(b) = ‖b − medN‖ − ‖b − medS‖` 를 만들 때, 처음엔 `medS`·`medN` 을
레코드 **전체 비트**로 만들고 **그 비트들을 그대로 채점**했다. 합성 **null 코호트**
(S 와 N 의 형태를 아예 같게 만든 것 — 형태 신호 0)에서:

| 점수 | 인-샘플 | **K겹 교차적합** |
|---|---:|---:|
| 단일 · 다수결 `‖b−med(전체)‖` | 0.501 | 0.502 |
| 단일 · 오라클 `‖b−med(N)‖` | **0.545** | 0.502 |
| **두 템플릿** | **0.8916** | **0.505** |

`medS` 가 채점 대상 S 비트의 중앙값이니 **S 는 자기 템플릿에 가까울 수밖에 없다.**
**S 가 적을수록 심하다** — SVDB 유병률 중앙이 0.035 라 정확히 그 조건이고, 그대로
돌렸으면 **가짜 상한**을 보고 "형태 축이 리듬을 이겼다" 고 썼을 것이다.

단일 오라클도 같은 병을 약하게 앓는다(0.545). **클래스가 하나만 적합돼서 덜할 뿐이다.**
→ 비교하는 모든 팔을 **똑같이** 교차적합한다. 산포(`σ_N`·`σ_S`)도 **겹 밖 거리**로 잰다 —
인-샘플이면 과소추정된다.

### ② 겹 배정 잡음이 SE 에서 빠진다

교차적합을 넣어 매크로는 0.505 로 내려왔는데, **개체 하나가 여전히 '유의 반전'** 으로
찍혔다(AUROC 0.3847, 본페로니까지 걸고도). 신호 0인 코호트에서.

원인: **겹 배정이 무작위라 점수 자체에 잡음이 얹히는데, 비트 부트스트랩은 점수를
고정으로 보므로 그 몫을 못 센다.** R20 의 본페로니는 SE 가 옳다는 전제 위에 있다 —
SE 가 과소추정되면 보정을 해도 샌다.

→ 교차적합을 **되풀이**하고 `SE = √(부트스트랩SE² + 되풀이간 분산)` 으로 합친다.

### 규칙

1. **적합과 채점을 분리한다.** 템플릿·기준·정규화 상수처럼 데이터에서 추정한 것은
   전부 해당된다. 「중앙값일 뿐인데」는 이유가 안 된다 — 위 표가 0.89 다.
2. **비교하는 팔을 똑같이 교차적합한다.** 한쪽만 하면 그 차이가 곧 결론이 된다.
3. **추정 절차의 무작위성을 SE 에 넣는다.** 겹 배정·초기값·부분표집이 결과를 흔들면
   그 분산은 오차의 일부다. 되풀이해서 더한다.
4. **null 코호트를 먼저 통과시킨다**(R20 마지막 절과 같은 처방). 위 두 결함은 실측
   데이터에서는 **그럴듯한 성공으로 보였을 것**이다 — 신호가 0인 걸 내가 아는
   코호트에서만 「아무것도 없는데 뭔가 나온다」가 눈에 띈다.

## R23. **관문이 지지해도 사전등록한 교란 통제가 뒤집으면 기각으로 읽는다**

Q7-H 의 H5(가설 B · 산포 비대칭)가 정확히 이 모양으로 나왔다.

| | 값 | 판정 |
|---|---:|---|
| 주관문 `rho(σN/σS, 오라클 AUROC)` | **−0.499** [−0.724, −0.230] | ✅ 지지 |
| **사전등록한 SNR 통제 부분상관** | **+0.040** | **→ 실질 기각** |

오라클 점수가 `‖b − med(N)‖` 이므로 **σ_N 은 그 지표의 분모로 이미 들어가 있다.**
`SNR = sep/σ_N` 을 고정하면 `σ_N/σ_S` 는 아무 정보도 안 남긴다 — 겉보기 상관은
**구조적 잔상**이었다. 「N 의 산포가 크면 거리형 지표가 비전형성을 재게 된다」는
가설은 이 데이터로 지지되지 않고, 더 단순한 설명(**그 환자의 신호가 약하다**)이 이긴다.

### 규칙

1. 두 양이 **정의상 연결**돼 있으면(한쪽이 다른 쪽의 계산에 들어가면) 그 둘의 상관은
   **관문이 될 수 없다.** 관문을 세울 때 통제 변수를 **함께 사전등록**하고, 최종
   판정은 통제 후 값으로 한다. 통제를 나중에 붙이면 그건 사후조정이다.
2. **층화표에 속지 않는다.** Q7-H 의 σN/σS 층별 표는 높은 층에서 다수결 0.4599 로
   깔끔한 경사를 보였다. 그 층은 SNR 도 같이 낮았다 — 층화는 교란을 못 가른다.
3. 이런 결과는 **"미결"이 아니라 "기각"으로 기록**한다. 주관문이 ✅ 였다는 사실과
   통제가 뒤집었다는 사실을 **둘 다** 남긴다 — 다음 사람이 같은 함정에 빠지지 않게.
4. 뒤집힌 가설을 **누가 세웠는지도 적는다.** 이 산포 가설은 내가(클로드) `#822` 의
   오라클 0.6055 를 보고 세운 것이었다. 관문을 만든 사람이 자기 가설을 검정할 때
   통제 변수를 미리 못 박아 두는 게 유일한 방어다.

## R24. **R 기준 고정창 형태 특징은 심박수의 대리변수다** — 정합·음성창 없이 「형태」라고 쓰지 않는다

Q7-D·E·H 세 실험이 「형태 축(P영역)」을 파고들었다. Q7-F 가 그 셋을 한 번에 뒤집었다.

| 검사 | 값 |
|---|---|
| 심박수 정합 시 매크로 | **0.9008 → 0.6890** (짝지은 차 **−0.1915** [−0.2351, −0.1466]) |
| P 파 자리 vs 직전 T 자리 | `P_late` **0.8290** < `P_early` **0.8604** |
| **음성 대조(ST/T)** | **0.8515 — P 파 자리보다 높다** |
| S 비트의 창-T 중첩률 | **0.557** (N 0.103 · 격차 **+0.454**) |

원인은 산수다. `_RPRE` 기준 고정창은 **시간 좌표가 R 에 고정**돼 있는데, 그 창 안에
무엇이 들어오는지는 **직전 R 이 얼마나 떨어져 있느냐**, 즉 `pre_rr` 이 정한다.
S 는 정의상 이르므로 **S 와 N 의 창 내용물이 체계적으로 다르다.** 형태를 안 봐도 갈린다.

### 규칙

1. **고정창 형태 특징으로 「형태가 X 를 가른다」고 쓰려면 세 가지를 같이 낸다.**
   ① **심박수 정합** 재채점(같은 `pre_rr` 대역 안에서만 쌍을 센다) ② **음성 대조 창**
   (신호가 있을 이유가 없는 다른 구간) ③ **관심 파형이 사는 자리 vs 안 사는 자리**의 분리.
   셋 중 하나라도 없으면 그건 형태 주장이 아니라 **심박수 주장**이다.
2. **음성 대조 창은 관심 창과 폭이 같아야 한다.** 차원 수 차이가 곧 결론이 된다.
3. **정합의 대가를 관문보다 먼저 낸다** — 남은 표본·쌍·개체 수. 겹치는 구간이 없어
   못 재는 것과 재서 기각되는 것은 다르다(R17). Q7-F 는 정합 가능 46/59 · 남은 S 비율
   중앙 0.800 이라 **검정력 있게 기각**됐다.
4. **교란 지표가 원인 변수의 결정론적 함수면 원인을 특정하지 못한다.** Q7-F 의
   「직전 T 중첩률」은 `pre_rr` 의 함수라 `RR 격차` 와 사실상 같은 양이었다 —
   T 가 닿지 않는 `P_late`(중첩 0.000)에서도 상관이 남았다(rho +0.289).
   → **「T 때문」이 아니라 「심박수 때문」이 옳은 진술**이다(R23 의 같은 함정).
5. **비트 추출 단계가 상한을 정한다.** `_RPRE = 100`(278ms @360Hz)이면 직전 R(보통
   250~450샘플)이 배열 밖이라 **RR 정규화 창 자체를 만들 수 없다**. 형태를 제대로
   보려면 `_RPRE ≥ 최대 RR` 로 **데이터를 다시 빌드**해야 한다 — 특징 설계로는 못 넘는다.
6. **지속 런은 「형태로 쉬운 개체」처럼 보인다.** Q7-F 실측: 런 우세 5개체에서
   `P_full` 0.9889 인데 **RR 위치형이 0.9905** 다. 자기만의 심박수를 가진 구간이라
   리듬만으로 갈린다 — 그 층의 성능을 형태의 근거로 쓰지 않는다.

### R24-b. **정합은 「했다/안 했다」가 아니라 「얼마나 남았나」다**

Q7-I 가 R24 를 자기 자신에게 되돌려줬다. 사전등록에 이렇게 썼었다 —
*「`f1`(=`med(pre)−pre`)은 `pre_rr` 의 함수라 **심박수를 정합하면 정의상 0.5 로 간다**」*.
실측:

| | 정합 전 | **정합 후** |
|---|---:|---:|
| S/N 중앙 RR 격차 | 0.320 | **0.080** (−75%) |
| `f1` 매크로 | 0.9367 | **0.5779** ← 0.5 가 아니다 |
| `f3`(`post_rr`) 매크로 | 0.7287 | **0.5745** |

대역폭이 `0.05 × 중앙 RR` 이라 **같은 대역 안에서도 S 는 계속 짧은 쪽에 몰린다.**
그래서 `f1` 이 0.578 을 유지하고, **`f3` 의 0.5745 를 「`post_rr` 의 독립 기여」라고
읽을 수 없다** — 잔여 조기성일 수 있고 두 값이 거의 같다는 게 그 근거다.

### 규칙

1. **정합 후 잔여를 반드시 재고 보고한다.** 「정합했다」는 절차 서술이고, 결과를 읽을
   때 필요한 건 **잔여 격차**다. 정합 전·후를 나란히 낸다.
2. **정합으로 무력화됐어야 할 변수를 함께 채점한다.** Q7-I 는 `f1` 을 같이 재서
   정합의 불완전함을 스스로 드러냈다. 이 「무너져야 할 대조군」이 없으면 남은 값이
   신호인지 잔여인지 알 수 없다.
3. **잔여가 남으면 통제를 한 겹 더 건다.** 대역을 좁히거나, 대역 안에서 교란 변수를
   회귀로 제거하고 나서 다시 잰다. 관문이 ✅ 라도 그 전엔 인용하지 않는다(R23 정신).
4. **합성 픽스처가 실제보다 쉬울 수 있다.** Q7-I 픽스처에서는 정합 후 `f1` 이 0.540 ·
   0.536 으로 잘 무너졌는데 실제 데이터는 0.578 이 남았다. **픽스처 통과는 설계가
   말이 된다는 뜻이지 실데이터에서 조건이 충족된다는 뜻이 아니다** — 조건 충족 여부는
   실행 때 **숫자로** 확인한다.
5. **단독 AUROC 가 0.5 밑이라고 특징을 버리지 않는다.** `f5`(직전 비트의 조기성)는
   0.4693 · `<0.5` 33/59 로 **부호가 반대**인데, 그건 「PAC 뒤에는 휴지가 온다」는
   생리 그대로다. 조합 모형이 부호를 뒤집어 쓴다. **방향이 아니라 정보량으로 판단**하되,
   최종 판정은 방향 있는 지표로 한다(R19 ③과 짝을 이룬다).

### R24-b ⑥. **영가설은 「우연」이 아니라 「무력화됐어야 할 변수의 실측치」다**

R24-b ②(무너져야 할 대조군을 함께 채점하라)의 자연스러운 귀결인데, Q7-I 는 대조군을
**옆에 찍어만 두고 영가설로 쓰지 않아서** 판정을 틀렸다.

| 정합 조건 실측 | 매크로 |
|---|---:|
| `f1` (`pre_rr` 함수 · **0.5 여야 했다**) | 0.5779 |
| `STT` (창 음성 대조 · 0.5 근처여야 했다) | 0.5833 |
| `f3` (주장 특징) | **0.5745** ← 셋 중 최저 |

관문은 「`f3` > 0.5」로 ✅ 였다. **그런데 그 조건의 실제 바닥은 0.578 이고 `f3` 는 못
넘는다.** 우연(0.5)을 영가설로 쓴 순간 관문이 **잔여 교란을 신호로 인증**했다.

### 규칙

1. **통제 조건에서의 영가설은 그 조건의 실측 바닥이다.** 「우연 수준」은 통제가 완벽할
   때만 바닥이다. 통제가 불완전하면 **무력화됐어야 할 변수와 음성 대조의 실측치 중
   더 큰 쪽**이 바닥이다 — `max(·)` 로 보수적으로 잡는다.
2. **대조군을 「참고」로 찍어두지 말고 관문 식에 넣는다.** 옆에 있는데 안 쓰면 없는 것과
   같다. Q7-I 는 `f1`·`STT` 를 정확히 찍어놓고도 판정에 안 넣었다.
3. **관문이 ✅ 인데 대조군이 더 높으면 「지지」가 아니라 「적용 불가」로 재분류**하고,
   올바른 영가설로 **재판정한 값을 따로 낸다**. 원래 판정과 재판정을 **둘 다** 남긴다.

## R25. **`max` 로 만든 바닥은 문턱이 0 이 아니다 — 그리고 정합은 클래스 정의에 못 건다**

R24-b ⑥ 을 코드로 옮긴 게 Q7-I″ 다. 규칙은 지켰는데 **그 규칙이 만든 통계량의
영분포를 몰라서** 새 편향을 만들었다.

관문 J1 은 영가설을 개체별 `max(정합 f1, 정합 STT)` 로 잡고 **문턱을 0** 으로 뒀다.

| 정합 조건(대역 0.010 · 33개체) | 매크로 |
|---|---:|
| `f1`(무너져야 할 변수) | 0.5331 |
| `STT`(음성 대조) | 0.5708 |
| **바닥 = 개체별 `max`** | **0.6440** |
| `f3`(주장 특징) | 0.5735 |

**바닥이 두 성분 중 높은 쪽보다도 +0.0732 위에 있다.** 잡음 있는 추정치 둘의 개체별
최댓값은 각각의 평균 위로 뜬다(`E[max] ≥ max E`). 그래서 **`f1`·`STT` 와 실력이
같은 제3의 특징도 이 바닥에는 진다.** 숫자가 정확히 그렇게 나왔다 —

```
바닥 팽창        = 0.6440 − 0.5708 = +0.0732
J1 본항 − 참고항  = (−0.0705) − (+0.0028) = −0.0733
```

**J1 의 「기각 −0.0705」는 전부 바닥 구성이 만든 것**이고, 편향 없는 짝지은 비교
(`f3 − f1` +0.0405 [−0.0161, +0.0943] · `f3 − STT` +0.0028 [−0.0802, +0.0835])는
둘 다 0 을 걸쳐 **미결**이다.

### 규칙

1. **`max`(또는 `min`·최상위 선택)로 만든 바닥과 비교할 땐 문턱을 0 으로 두지 않는다.**
   둘 중 하나로 한다 — (a) **각 대조와 따로 짝지어 비교**하고 다중검정을 보정하거나
   (b) **라벨셔플·순열로 `주장 − max(대조)` 의 영분포를 실측**해 그 분위수를 문턱으로 쓴다.
   (a) 가 싸고 해석이 명확하니 기본값으로 쓴다.
2. **바닥과 그 성분을 항상 나란히 찍는다.** 바닥이 성분 최대보다 크게 위면 그 차이가
   곧 편향 크기다. Q7-I″ 는 셋을 다 찍어놨기 때문에 사후에 스스로 잡아낼 수 있었다.
3. **판정 기호를 읽지 말고 값과 설계를 읽는다.** 같은 실행에서 J1 은 ❌ 인데 읽으면
   미결이었고, J4 는 ⚠️ 인데 읽으면 기각(사전등록 대조가 뒤집음 · R23)이었다.
   **기호는 코드가 찍고, 판정은 사람이 한다.**
4. **정합(matching)은 정합 대상이 클래스 정의의 일부이면 원리적으로 실패한다.**
   S 는 **정의가 조기성**이라 `pre_rr` 을 정합하면 클래스를 만드는 축을 지운다.
   실측이 그대로다 — 대역을 `0.05 → 0.01` 로 좁혀 잔여 RR 격차를 `0.080 → 0.0428`
   까지 줄여도 `f1` 은 `0.5779 → 0.5331` 에서 멈추고, **S 의 81.2% 가 여전히 남는다.**
   표본을 버려서 실패한 게 아니라 **남겨도 방향이 남는다.**
   → 사전등록 단계에서 먼저 묻는다: **「정합 대상이 라벨 정의에 들어가는가?」**
   들어가면 정합이 아니라 다른 설계(층화·잔차화·다른 코호트)를 쓴다.
5. **미결의 원인이 검정력이면 그 크기를 적는다.** 짝지은 차이의 CI 반폭 ≈0.055(n=33)
   이면 개체 수 서너 배가 필요하다는 뜻이고, **SVDB 는 채점 가능 59개체가 전부**다.
   「더 해보자」가 아니라 **「이 데이터로는 안 된다」를 결론으로 쓴다.**
6. **`np.nanmax` 를 마스크 밖에서 부르지 않는다.** 두 팔이 모두 NaN 인 개체가 있으면
   `All-NaN slice` 경고가 뜬다. 값에는 영향이 없더라도(그 개체는 유효 마스크에서
   빠진다) **경고는 설계가 마스크를 늦게 적용하고 있다는 신호**다.

## R26. **「정합했다」가 아니라 「무엇을 정합했나」 — 그리고 학습이 끼면 영분포는 0.5 가 아니다**

R24-b(정합은 「얼마나 남았나」)와 R25(바닥 구성)의 다음 칸이다. Q7-I‴ 가 정합기를
**값 단위로 완전히 옳게** 만들고 나서야 드러났다.

```
정확 정합 (pre_rr 값이 같은 비트끼리만 · 짝 단위 잔여 0.000000 · 22개체)
  f1     0.5000   ← pre_rr 의 함수라 빈 안에서 동점뿐. 정의대로 무너졌다
  f2_16  0.6688   ← 살아남았다.  f2 − f1 = +0.1688 [+0.0760, +0.2535]
```

`f2 = 1 − pre/국소기저선` 이다. `pre` 를 값 단위로 고정해도 **분모가 다르면 갈린다** —
**같은 절대 RR 이라도 S 는 국소 기저선이 긴 자리에서 나오기 때문**이다. 즉 **절대 RR
정합은 조기성의 「눈금」만 맞추고 「상대성」은 손대지 않는다.** 그래서 Q7-F 의
「심박수 정합 후 0.6890」, Q7-I 의 「정합 후 `f3` 0.5745」를 **「조기성 통제 후」로
읽으면 안 된다.**

같은 실행이 두 번째 함정도 보여줬다.

| | 실측 | 라벨셔플 null | 초과 |
|---|---:|---:|---:|
| `f1` (순수 특징) | 0.5000 | 0.5000 | +0.0000 |
| `lr_f1` (**같은 정보**를 로지스틱에) | **0.4123** | **0.4256** | −0.0133 |

정보가 같은데 값이 다르다. **겹 배정** 때문이다 — 두 비트의 `f1` 이 같아도 서로 다른
겹에 들어가면 정규화(`mu`·`sd`)와 계수가 달라 **점수가 갈린다.** 순수 특징의 영분포는
0.5 지만 **학습이 끼면 아니다.**

### 규칙

1. **정합을 보고할 때 「무엇을 정합했나」를 특징 이름으로 쓴다.** 「심박수 정합」이
   아니라 「**절대 `pre_rr` 정합**」이다. 그리고 **정합됐어야 할 변수의 사촌**(같은 것을
   다른 정규화로 재는 특징)을 **함께 채점**해서 사각지대를 드러낸다 — Q7-I‴ 는 `f2` 를
   같이 재서 「정합이 조기성을 통제한 적이 없다」를 스스로 찾았다(R24-b ② 의 확장).
2. **학습이 낀 팔은 반드시 자기 라벨셔플 null 위 초과분으로 읽는다.** 0.5 를 바닥으로
   쓰면 `lr_f1` 같은 팔에서 −0.09 를 「신호 없음」이 아니라 「역방향 신호」로 오독한다.
   순수 특징(0.5)과 학습 팔(실측)을 **같은 표에 나란히** 낸다.
3. **정합의 대가를 숫자로 적는다.** 정확 정합에서 채점 개체 **59 → 22**, 남은 S
   **51%** 였다. 관문이 미결이면 **효과가 없어서인지 표본이 없어서인지 먼저 가른다**
   (R25 ⑤ 와 짝을 이룬다).
4. **음성 대조가 계속 이기면 음성 대조가 아니라 좋은 특징이다.** `STT`(ST/T 창 형태)는
   Q7-F 에서 「P 창보다 높은 음성 대조」였는데, 정확 정합에서 초과 **+0.1380** 으로
   `f3`(+0.0887)를 앞선다. **대조군을 두 번 이상 놓쳤으면 이름을 바꾼다.**

## R27. **잔여를 줄이는 것 ≠ 통제하는 것 · 봉인된 조건에서도 「대조」와 「반응」은 읽는다**

Q7-K 는 관문 여덟 중 전제(L2)가 미결이라 **스스로 봉인**됐다. 그런데 봉인 아래에서
더 나은 결론이 나왔다. 두 가지가 갈렸다.

### ① 정합 대상이 점수의 **결정론적 단조함수**면 정확 정합 말고는 안 죽는다

| 대역 | 짝 단위 `f1` 잔여 | `f1ₘ` |
|---|---:|---:|
| 정확 pre | **0.000000** | **0.5000** |
| 0.02 | 0.006116 (**≈1.7 샘플**) | **0.5526** |

`f1 = 중앙 − pre` 는 `pre` 의 단조함수다. 잔여가 중앙 RR 의 **0.6%** 밖에 안 남아도
**방향이 일정하면 순위가 그대로 살아난다** — AUROC 는 크기가 아니라 순위를 센다.
반면 잡음이 섞인 `f2` 는 같은 잔여에서 훨씬 잘 무너진다(0.6517 → 0.5445).

Q7-K 는 `f2` 잔여를 0.0717 → 0.0081(11%)로 줄이려고 **정확 pre 를 대역으로 바꿨고,
그 순간 `f1` 통제를 팔았다.** 둘 다 잡으려면 **칸(cell) 정합이 아니라 1:1 캘리퍼
정합**이 필요하다 — 칸은 「같은 칸에 S ≥ 3 그리고 N ≥ 3」을 요구해 표본을 통째로
버리지만(19/59 개체 · S 의 25%), 1:1 은 S 하나에 짝 하나만 찾으면 된다.

**규칙**: 정합을 설계할 때 **각 점수가 정합 변수의 결정론적 함수인지 먼저 확인**한다.
그렇다면 **잔여 목표를 「작게」가 아니라 「정확히 0」으로 잡고**, 그게 불가능하면
그 변수는 통제된 것이 아니라고 적는다.

### ② 봉인은 **수준**에 걸리지 **대조와 기울기**에는 덜 걸린다

잔여 교란은 **모든 팔을 비슷하게** 오염시킨다. 그래서 같은 조건에서 잰 두 팔의 **차이**와,
통제를 조일 때의 **반응 곡선**은 그 오염이 상쇄돼 수준보다 훨씬 강건하다.

| 국소 기저선 대역 | 정확pre | 0.10 | 0.06 | 0.04 | 0.02 |
|---|---:|---:|---:|---:|---:|
| `f3` (`post_rr`) | 0.5815 | 0.5405 | 0.5373 | 0.5181 | **0.4886** ↓ |
| `STT` (형태) | 0.6241 | 0.6200 | 0.6176 | 0.6370 | **0.6507** — |

**`f3` 는 통제를 조일수록 단조로 죽고 형태는 꿈쩍도 않는다.** 관문 L5 가 같은 대조를
확인했다 — `STT` 초과 − `f3` 초과 = **+0.1867** [+0.0532, +0.3300].

**규칙**: 전제 관문이 미결이라 봉인이 걸렸을 때,
1. **수준은 인용하지 않는다**(「독립 기여는 +0.1753 이다」 ❌).
2. 대신 **① 같은 조건 두 팔의 차이 ② 통제 강도에 대한 반응 곡선**을 낸다.
   이 둘은 공통 오염에 강건하므로 **봉인 아래에서도 결론으로 쓸 수 있다**
   (「통제를 조일수록 `f3` 는 죽고 형태는 안 죽는다」 ✅).
3. **봉인 목록을 코드에 하드코딩하지 않는다.** Q7-K 는 봉인 문구를 「L3~L6」으로
   써놨는데 나중에 L7·L8 을 추가하면서 목록을 안 고쳤다. **전제에 딸린 관문은
   자동으로 모아 표시**하거나, 관문을 추가할 때 봉인 목록을 같이 고친다.

### ③ 폭이 다른 창은 초과분도 다르다 — 창 비교는 **같은 폭**끼리

`P_full`(폭 85) +0.2055 · `P_late`(85) +0.2033 · `STT`(85) +0.1753 vs
`P_early`(**폭 32**) +0.0828. 폭 85 인 셋은 서로 구별되지 않는데(`P_late` − `STT` =
+0.0279 [−0.0344, +0.0878] 미결) 폭 32 만 낮다. **「어느 창이 좋은가」를 물을 때
폭을 통제하지 않으면 폭을 재는 것**이다(R24 의 창 버전).

## R28. **파라미터화된 통제 · 하류 변수 금지 · 물려받은 상수 감사**

Q7-M 이 처음으로 두 축을 동시에 통제했다(`f1ₘ` 0.5000 · `f2ₘ` 0.5078). 그 성공이
셋을 동시에 드러냈다.

### ① 「통제했다」는 그 특징의 **특정 파라미터화**에만 성립한다

정합 축을 `LB_K = 16`(국소 기저선 16박동)으로 잡았다. 결과:

| 팔 | 초과 |
|---|---:|
| `f2_16` (정합 대상) | +0.0090 ← 죽었다 |
| **`f2_8`** (같은 개념 · 창만 다름) | **+0.0632** ← 살아 있다 |

**「상대 조기성을 통제했다」가 아니라 「`f2_16` 을 통제했다」가 정확한 진술이다.**
개념을 통제하려면 여러 스케일을 동시에 맞춰야 하는데 그러면 표본이 없다.

**규칙**: 어떤 개념을 통제했다고 쓸 때, **같은 개념의 다른 파라미터화를 함께
채점**하고 그것도 죽었는지 확인한다. 안 죽었으면 **통제한 것은 개념이 아니라 그
변수 하나**라고 적는다. 그리고 그 조건에서 **수준보다 차이**를 쓴다(R27 ②).

### ② **교란만 정합한다 — 하류 변수를 정합하면 신호를 지운다**

Q7-K L8 과 Q7-M M4 는 `post_rr` 을 정합 축에 넣어 `STT` 가 사라지는지 봤다. 표본이
없어 둘 다 판정 불가였는데, **표본이 있었어도 해석이 안 됐다.**

`post_rr` 은 **현재 박동보다 뒤에 오는 간격**이다. 현재 박동의 형태가 미래 간격의
원인일 수는 있어도 그 반대는 아니다. 즉 `post_rr` 은 교란이 아니라 **「S 이기 때문에
생기는 결과」**(하류/매개 변수)다. 그걸 통제하면 신호가 지워지는 게 당연하고,
`STT` 가 사라져도 **「형태가 가짜였다」가 아니라 「매개 경로를 막았다」**일 뿐이다.

**규칙**: 정합 축에 넣기 전에 **시간 순서와 인과 방향**을 적는다.
- **원인 쪽(선행 · 교란)** → 정합해도 된다 (`pre_rr` · 국소 기저선)
- **결과 쪽(후행 · 매개)** → **정합하지 않는다** (`post_rr`)
후자를 통제한 결과를 「신호가 가짜였다」의 근거로 쓰지 않는다.

### ③ **물려받은 상수는 실험마다 감사한다**

`MIN_CELL_S = MIN_CELL_N = 3` 은 Q7-F 의 `matched_auc` 에서 물려받아 Q7-F·I·I″·I‴·K
가 전부 그대로 썼다. 정당화된 적이 없다. 조건부 일치도는 **칸마다 추정치를 만들지
않고** 이긴 쌍/전체 쌍을 누적할 뿐이라 **S 1 · N 1 칸도 유효한 쌍 1개**다.

| `MIN_CELL` | 정확 pre 개체 | 남은 S |
|---:|---:|---:|
| 3 | 25 | 0.462 |
| **1** | **40** | **0.812** |

**이 상수 하나 때문에 Q7-K 는 「정확 pre 에 축을 얹으면 칸이 안 남는다」고 판단해
설계를 바꿨고, 그 바꾼 설계가 실패했다.** 상수를 고치니 원래 설계가 그대로 작동한다.

**규칙**: 이전 실험에서 그대로 가져온 상수는 **첫 셀에서 감사표를 낸다** — 값을
바꿨을 때 표본·개체가 어떻게 변하는지. 특히 **표본을 버리는 상수**(최소 개수·최소 쌍)는
반드시. 그리고 **합성 픽스처만 보고 설계를 버리지 않는다**(R24-b ④) — 픽스처는
「설계가 말이 되나」만 답하고, 「이 데이터에서 되나」는 실측이 답한다.

### ④ 0 근처 값의 LOO 부호 반전은 경고가 아니다

M3a(−0.0141)는 개체 하나를 빼면 +0.0044 가 되어 노트북이 「⚠️ 부호가 바뀐다」를
찍었다. **효과가 0 인 양은 당연히 부호가 흔들린다** — 오히려 0 이라는 결론에 부합한다.
경고는 **효과 크기 대비 LOO 변동폭**으로 판단한다: `|LOO 범위| / |기준|` 이 크더라도
기준이 CI 안에서 0 이면 경고가 아니다. (M3b 는 기준 +0.1642 · LOO [+0.1227, +0.1821]
로 **진짜 안정**이다.)

## R29. **미결은 등가가 아니다 · 「측정 불가」는 결론이 아니다 · 내 규칙을 내가 어긴다**

Q7-M 은 관문 설계가 잘 돌아간 실행인데, **요약과 카드 문장에서 세 번 넘어갔다.**
셋 다 값이 아니라 **말**의 문제였고, 셋 다 외부 검토가 잡았다.

### ① **미결 ≠ 등가.** 「우월하지 않다」와 「차이가 없다」는 다른 주장이다

```
(P_late 초과) − (STT 초과) = −0.0141 [−0.0892, +0.0476]  → 미결
```

이걸 「P 파 고유의 신호는 없다」로 썼다. **그건 등가성 주장**이고, 미결은 「차이가
있는지 모른다」일 뿐이다. 반폭 0.0684(SE 0.0286 · n=18)이므로:

| 등가 여유 | 필요 개체 |
|---|---:|
| ±0.05 | **34** |
| ±0.04 | 53 |
| ±0.03 | 94 |

이 프로젝트는 실험1′ 에서 **제대로 했다** — `B3R − B3` 반폭 **0.0287 < 사전등록 0.03**
이라 「기각(확정)」이었다. 규칙이 이미 있었는데 안 썼다.

**규칙**: 「없다 / 같다 / 차이 없다」를 쓰려면
1. **등가 여유를 사전등록**하고,
2. CI **전체가** 그 여유 안에 들어가야 하며,
3. 안 들어가면 **「우월성 미확립」까지만** 쓴다.
사전등록 때 **필요 표본을 미리 계산**해 적는다 — 도달 불가면 그 질문은 이 데이터로
답할 수 없다는 뜻이고, 그게 결과다(R25 ⑤).

### ② **「측정 불가」를 발화한 관문은 어떤 결론 분기도 타지 않는다**

```
M4   ⛔ 측정 불가   3축 가능 개체 6 < 10 — 표본이 없다
...
관문 요약   ★ post 를 맞추면 STT 가 사라진다 → 형태 축 종료
```

원인은 한 줄이다 — `elif "M4" in VERD:`. **「⛔ 측정 불가」도 `VERD` 에 들어 있으므로**
측정 못 한 항목이 기각 분기를 탔다. 표본 없음이 결론으로 승격됐다.

**규칙**: 요약·결론 분기는 **판정 문자열을 명시적으로 검사**한다.
`ok(k) = VERD[k].startswith("✅")` 뿐 아니라 **`unmeasured(k) = VERD[k].startswith("⛔")`
를 먼저 걸러** 어떤 분기도 안 타게 한다. 관문 존재 여부(`k in VERD`)로 분기하지 않는다.
그리고 **「측정 불가」는 카드의 확정 목록에 절대 올리지 않는다.**

### ③ **사전등록 체크리스트에 「기존 규칙」을 넣는다**

R27 ③(창 비교는 같은 폭끼리)을 쓴 바로 다음 실험에서, 주지표를
**`P_late`(폭 32) vs `STT`(폭 85)** 로 골랐다. 폭이 넓은 쪽이 기계적으로 유리하므로
**세 가능한 비교 중 P 에 가장 불리한 것**을 고른 셈이다. 폭을 맞추면 부호가 뒤집힌다:

```
85 vs 85 :  p_full − stt      = +0.0332 [−0.0201, +0.0857]
32 vs 45 :  p_late − stt_safe = +0.0076
32 vs 85 :  p_late − stt      = −0.0141   ← 사전등록 주지표
```

**규칙**: 사전등록 셀에 **직전까지 확정된 규칙 목록을 항목별 체크로 적는다** —
「R24-b 잔여 보고 ✓ / R25 max 바닥 없음 ✓ / R26 자기 null ✓ / R27 ③ 폭 정합 ✓ /
R28 ② 하류 변수 없음 ✓」. 규칙을 아는 것과 다음 사전등록에서 적용하는 것은 다른 일이고,
**체크리스트 없이는 반드시 어긴다**(이번이 그 증거다).

### ④ 검정력 없는 강건성 검사는 강건성 증거가 아니다

상쇄 검증 `rho = −0.007 **[−0.540, +0.523]**`(n=18). `rho = ±0.5` 도 배제 못 한다.
**「0 을 포함한다」는 확인이 아니라 검정력이 없다는 뜻**이다.

**규칙**: 강건성 검사도 **CI 를 내고, 그 CI 가 의미 있는 크기를 배제하는지** 본다.
못 배제하면 **「검사했다」가 아니라 「검사할 수 없었다」**로 적고 판단에서 뺀다.

## R30. **등가 여유는 전부 표본 계산 · 봉인은 정량으로 풀 수 있다 · 폭은 축이다**

Q7-N 은 정합에서 잔차화로 갈아탄 실행이고, 셋을 새로 배웠다.

### ① **등가 여유를 거는 관문은 전부** 필요 표본을 계산한다

같은 노트북에서 절반만 지켰다.

| 관문 | 여유 | 필요 표본 계산 | 결과 |
|---|---|---|---|
| N3 (등가) | ±0.05 | **했다** — 59개체 → 반폭 ≈0.038 | 판정 가능 |
| **N2 (프로브)** | ±0.02 | **안 했다** | `f2_5` CI 반폭 **0.035** → **원리적으로 불가** |

`f2_5` 는 점추정 −0.0110 으로 사실상 0 인데 「미결」로 찍혔다. **효과가 없어서가 아니라
그 여유를 판정할 정밀도가 없어서**다. 그러면 전제 관문이 영원히 안 열린다.

**규칙**: `equiv()` 를 쓰는 **모든** 관문에서
1. 예상 CI 반폭을 **사전등록 때 계산**하고,
2. 여유가 반폭보다 작으면 **여유를 넓히거나 관문을 포기**한다(그 사실이 결과다),
3. 미결이 나오면 **「누수가 있다」와 「판정할 정밀도가 없다」를 반드시 구분**해 적는다 —
   CI 가 0 을 떼면 전자(`f2_10` +0.0251 [+0.0082, +0.0416]), 0 을 걸치면 후자다.

### ② **봉인은 이분법이 아니다 — 누수 크기를 알면 깎아본다**

전제 관문이 미결이면 「수준을 인용하지 않는다」가 기본이다(R24-b · R27 ②). 그런데
**누수의 크기를 실측했다면 최악의 경우로 깎아서** 결론이 사는지 볼 수 있다.

```
STT 초과 (lin)                  +0.2144
  − 최대 k 누수 상한 0.0416  →  +0.1728
  − 함수형 누수     0.0924  →  +0.1220    ← 여전히 0 을 한참 넘는다
STT 초과 (rank 기저)            +0.2465    ← 누수를 정의상 흡수했더니 **더 높다**
```

마지막 줄이 결정적이다. `rank` 기저는 단조 비선형(= 함수형 누수)을 구조적으로
흡수하는데, 거기서 신호가 **줄기는커녕 오른다**. → **누수가 신호를 만든 게 아니다.**

**규칙**: 봉인이 걸린 실행에서도
1. **누수 크기를 실측**하고(프로브의 CI 상한),
2. 주장 값에서 그만큼 **깎은 하한**을 함께 내고,
3. **누수를 구조적으로 제거하는 대안 기저/설계**를 사전등록해 두고 거기서 값이
   어떻게 움직이는지 본다. **깎아도 살고 대안에서 더 세지면 봉인 아래에서도 인용 가능**하다.
   (그렇게 못 하면 그냥 봉인한다 — 사후에 「깎아보니 살더라」는 금지다. 대안 기저는
   **사전등록**돼 있어야 한다.)

### ③ **창 폭은 교란이 아니라 축이다 — 정량화해서 보고한다**

Q7-M 은 `P_late`(폭 32)를 `STT`(폭 85)와 비교해 **−0.0141** 을 얻었고 그걸
「P 창이 못 이긴다」로 썼다. 폭을 맞추니 **+0.0745(우월성 지지)** 로 **부호가 뒤집혔다.**
그리고 폭 효과 자체가 단조다:

| | 폭 32 | 폭 45 | 폭 85 |
|---|---:|---:|---:|
| `STT` 계열 | 0.1806 | 0.1875 | **0.2144** |
| `P` 계열 | 0.2116 / 0.2426 | — | **0.2889** |

**규칙**: 창(또는 차원 수가 다른 특징)을 비교할 때
1. **같은 폭끼리만** 비교하고(R27 ③),
2. **폭-성능 곡선을 별도로 낸다** — 폭이 축이면 그 축의 기울기를 보고해야
   「이 창이 좋다」와 「이 창이 넓다」가 갈린다,
3. 폭이 다른 비교를 **주지표로 사전등록하지 않는다**.

### ④ 두 결론이 동시에 성립할 수 있다 — 배타로 읽지 않는다

Q7-N 에서 「R 앞쪽 창이 ST/T 창을 이긴다」(폭 85 우월성 ✅)와 「P 파 고유 신호는 없다」
(`p_early` 0.2426 > `p_late` 0.2116 · 둘 다 폭 32)가 **동시에** 나왔다. 모순이 아니다 —
앞쪽 창이 담는 게 **P 파가 아니라 직전 T** 라면 둘 다 맞다.

**규칙**: 창 비교 결과를 「창 A 가 이겼다 ⇒ 창 A 의 해부학적 이름표가 원인이다」로
읽지 않는다. **창 안을 다시 쪼개** 어느 부분이 이기는지 본다 — 이름표가 아니라
**위치가 답한다**.

## R31. **등가 프레임 오용 · 누출 바닥은 가장 보수적으로 · 감쇠는 강건성이 아니다**

Q7-N 은 규칙을 가장 많이 지킨 실행인데(사전등록 체크리스트까지 박았다) **여전히 다섯을
놓쳤다.** 다섯 다 「값」이 아니라 「무엇과 비교했는가」의 문제다.

### ① 점추정이 여유 밖이면 **어떤 표본으로도 등가 판정이 불가능**하다

`p_full − stt` = **+0.0745**, 등가 여유 ±0.05. 점추정이 이미 여유 밖이므로 표본을
아무리 늘려도 CI 가 여유 안에 들어갈 수 없다. 그런데 관문은 「⚠️ 미결」을 찍었고
요약은 **「등가도 우월도 아니다」**로 적었다 — **Bonferroni CI 하한이 +0.0387 로 0 을
떼는데도** 그랬다.

**규칙**: 등가 관문을 걸 때
1. **등가와 우월성은 서로 다른 물음**이다. 한 관문에서 **둘 다** 판정해 출력한다.
2. 사전등록 때 **「점추정이 여유를 넘으면 등가 프레임은 폐기하고 우월성 + 효과크기로
   전환한다」**를 미리 적는다.
3. 미결이면 **등가에 필요한 개체 수를 그 자리에서 계산해 출력**한다 —
   `n × (반폭 / (여유 − |점추정|))²`. 음수면 **불가능**이라고 찍는다.
   (Q7-N 실측: 폭 32 는 **276개체** 필요 · SVDB 는 78. 폭 85 는 **불가능**.)

### ② 누출 바닥은 **기저 밖에 남은 것 중 가장 큰 것**으로 잡는다

Q7-N 은 `f2` 프로브(≤0.03)를 바닥으로 썼다. 그런데 같은 표에 **기저에 안 넣은 리듬
특징**이 훨씬 크게 살아 있었다 — `f4` **+0.1180** · `f5` **+0.1170**(`f5` 는 무잔차
0.4668 에서 잔차화 후 0.6170 으로 **오른다** — 전형적 억제 변수).

```
STT +0.2144  −  f2 프로브 0.0416  =  +0.1728   ← 낙관적
STT +0.2144  −  f4·f5     0.1180  =  +0.0964   ← 정직
```

**규칙**: 「형태만 남았다」 류의 주장을 할 때 **기저 밖에 남은 모든 팔**을 훑어
**최댓값을 바닥으로** 삼는다. 프로브만 보면 바닥을 3배 과소평가한다.
(⚠️ R25 와 헷갈리지 말 것 — 여기 `max` 는 **팔별 매크로**의 max 이고 주장 값에서
**빼는** 쪽이라 방향이 보수적이다. R25 가 금한 건 **개체별** max 로 부풀린 바닥을
문턱 0 과 비교해 **기각을 만드는 것**이다.)

### ③ **통제를 조일수록 효과가 줄면 그건 강건성이 아니라 잔여 교란의 신호**다

```
lin +0.0745 → hist +0.0621 → quad +0.0564 → rank +0.0466 → 층화 +0.0359
```

Q7-N 은 이걸 「네 기저 전부 부호 일치 → 강건」으로 읽었다. **부호는 유지되면서 크기가
절반으로 단조 감쇠**하는 건 다른 이야기다 — 통제 강도에 대한 **깨끗한 용량-반응**이고,
**남은 차이의 상당 부분을 잔여 교란이 만들고 있다**는 뜻이다.

**규칙**: 여러 통제 강도에서 같은 양을 재면 **부호가 아니라 기울기를 본다.**
- 평평 → 강건
- **단조 감쇠 → 잔여 교란**. 가장 강한 통제의 값을 **주 추정치**로 보고하고,
  약한 통제의 값을 헤드라인으로 쓰지 않는다.

### ④ **층 분해도 폭(차원)을 맞춘다** — 안 맞추면 헤드라인의 층 분해가 안 된다

Q7-N 층별 표는 `STT`(폭 85)와 `P_late`(폭 32)를 나란히 놨다. 그래서 헤드라인(N3)의
층 분해가 불가능하고, 굳이 계산하면 **고립 −0.007 · 혼합 −0.016 · 런 5개체 +0.061** 로
**헤드라인이 5개체에 얹혀 있을 가능성**을 배제하지 못한다.

**규칙**: 폭 정합 규칙(R27 ③)은 **헤드라인뿐 아니라 모든 하위 분석**에 적용한다.
층별·민감도·삼각검증에서 **다른 팔 조합을 쓰면 헤드라인과 연결이 끊긴다.**

### ⑤ **잔차 AUROC 는 팔 사이에 비교할 수 없다**

잔차의 크기는 「그 팔이 라벨 정보를 얼마나 더 갖나」가 아니라 **「그 팔의 분산이
기저와 얼마나 겹쳤나」**에 좌우된다. 겹침이 큰 팔은 잔차가 잡음만 남고, 작은 팔은
자기 신호를 대부분 보존한다. 증상:

```
lr_all (전부 넣은 결합기) 초과 +0.1424  <  stt (단일 성분) 초과 +0.2144
```

**결합기가 성분보다 나쁠 수 없다.** 이건 신호가 아니라 **잔차화가 만든 인공물**이다.

**규칙**: 잔차화 결과에서 **팔 간 수준 비교를 하지 않는다.** 같은 팔의
**조건 간 비교**(기저 A vs B, 층 A vs B)나 **사전등록한 짝의 차이**만 읽는다.
그래서 봉인(R27 ②)이 옳다 — 봉인은 검정력 문제가 아니라 **비교 가능성** 문제였다.

## R32. **raw 가 교란 판정의 앵커다 · 컷이 현상을 자르면 그 코호트로 판정하지 않는다 · 바닥은 양의 초과만**

Q7-P 는 「직전 T 침입」을 **표본**으로 치려고 마스크를 만들었다. 노출은 실재했고
(S 비트 **74.9%** vs N 20.0%) 마스크도 기하적으로 정확했다. 그런데 **아무것도
통제하지 못했고**, 그 과정에서 내가 R31 ③ 을 **거꾸로 적용**했다. 다섯을 배웠다.

### ① ★★ **정확 정합 층화는 그 변수의 결정론적 함수를 전부 통제한다**

```
f1 = median(pre) − pre      (개체 안에서 median 은 상수)
  ⇒ f1 정확 일치 ⇔ pre_rr 정확 일치 ⇒ 직전 T 위치도 정확히 일치 ⇒ 침입량도 정확히 일치
```

칸 안에서 S 와 N 은 **직전 T 가 같은 자리에 있는 비트끼리만** 비교된다. 마스크가 더한
통제는 **0**, 대가는 **S 비트 90% · 개체 59→9** 였다. 실측이 그대로 말한다 — 마스크
유무로 추정치가 안 변한다(+0.0100 [−0.1070,+0.1173] vs +0.0314 [−0.0424,+0.1150]).

**규칙**: 표본을 버리는 통제(마스크·정합)를 설계하기 전에 **「층 키(또는 기저)가 이
교란의 결정론적 함수를 이미 담고 있나?」**를 먼저 계산한다. 담고 있으면 마스크는
**검정력만 태운다.**

### ② ★★ **`raw`(무통제)를 사다리에서 빼지 말고 앵커로 쓴다** — R31 ③ 의 정정

Q7-P 초판은 「`raw` 가 단조성을 깨니 사다리에서 빼라」고 적었다. **정확히 거꾸로다.**

```
raw +0.0469  |  lin +0.0745 → hist +0.0621 → quad +0.0564 → rank +0.0466 → strat +0.0314
└ 무통제      └────────────────── 통제 축 ──────────────────┘
```

**교란이 차이를 만든다면 무통제인 `raw` 가 최댓값이어야 한다.** 아니다 — `lin` 이
`raw` 보다 **높다.** 그러므로 `lin → strat` 의 단조 감쇠는 「교란이 제거되는 과정」이
아니라 **「잔차화가 부풀린 것이 기저가 촘촘해지며 꺼지는 과정」**이다. 실제 통제 효과는
**`raw → strat` = −0.0155** 뿐이다.

R31 ③ 은 「단조 감쇠 = 잔여 교란」이라고 했는데, **그 판정에는 `raw` 앵커가 필요하다.**
`raw` 없이 사다리만 보면 잔차화 인공물을 용량-반응으로 오독한다(Q7-N §5 가 그랬고,
Q7-P 가 같은 오독을 반복할 뻔했다).

**규칙**: 통제 사다리는 **반드시 `raw` 를 포함**해 보고한다.
1. `raw` 가 최댓값이 아니면 → **감쇠를 교란으로 읽지 않는다.** 중간 추정량의 인공물이다.
2. 교란 크기는 사다리 내부 낙차가 아니라 **`raw` 대비 가장 강한 통제의 변화량**으로 잰다.
3. 이 진단은 R31 ⑤(잔차 AUROC 는 팔 간 비교 불가)와 같은 뿌리다 — 잔차화는 **억제
   변수 효과**로 값을 올릴 수 있다.

### ③ ★ **컷이 현상 자체를 자르면 그 코호트로 헤드라인을 판정하지 않는다**

Q7-P 의 마스크는 `pre ≥ 262샘플` 을 요구했는데 이는 중앙 RR(≈282)의 **93%** 다.
즉 **거의 조기가 아닌 S 만** 남는다. 증거는 n 이 아니라 **부호 반전**이다:

```
f3(보상성 휴지) strat 초과   [all] +0.0715  →  [safe] −0.2289
f3_glob                      [all] +0.0174  →  [safe] −0.3093     (raw 도 0.7367 → 0.4800)
```

보상성 휴지가 **약해진 게 아니라 뒤집혔다.** SAFE 9명은 SVEB 일반이 아니라 **느슨하게
결합한 SVEB** 라는 다른 모집단이다. 검정력 문제가 아니라 **추정 대상이 바뀐** 것이다.

**교란원이 곧 관심 현상의 정의일 때(SVEB = 조기), 교란원을 자르면 현상도 잘린다.**

**규칙**: 컷으로 만든 코호트는 **컷 전후의 ⓐ 유병률 ⓑ 핵심 특징의 부호**를 관문보다
먼저 보고한다. **부호가 뒤집힌 특징이 하나라도 있으면 그 코호트로 헤드라인을 판정하지
않는다** — 구제도 반증도 못 한다.

### ④ **누출 바닥은 「양의 초과분」 중 최댓값이다 — 음의 초과는 따로 진단한다**

R31 ② 를 그대로 쓰면 Q7-P 의 바닥이 `f3_glob` 의 **0.3167**(초과 **−0.3093** 의 절댓값)로
잡혀 무엇을 재든 음수로 끝난다. 그런데 −0.31 은 **누출 용량이 아니라 부호 반전**이다 —
「칸 안에서 `f3` 가 S 를 강하게 **반**예측한다」는 실제 구조이지 「조기성이 0.31 남아
있다」가 아니다.

**규칙**: 누출 바닥 = **양의 초과분 중 최댓값**(Q7-P 실측: [all] `f2_5` **+0.1197** ·
[safe] `f2_20` +0.1648). **음의 초과분은 「과잉보정·부호반전 진단」으로 분리 보고**한다.
그리고 **표본 선택에 쓰인 변수의 함수는 후보에서 제외**한다(`q_safe` 가 `post_rr` 을
조건화하면 `f3` 는 누출이 아니라 마스크 인공물이다).

### ⑤ **바닥은 「수준」에만 뺀다 — 짝의 차이에서는 상쇄된다**

Q7-P 가 `P1 − LEAK_MAX = +0.0100 − 0.3167 = −0.3067` 을 찍었다. **범주 오류다.**
공통 누출은 두 팔에 같이 들어가 **차이에서 상쇄**된다(R27 ②). 바닥은
「`STT` 가 남는다」 같은 **수준 주장**을 깎을 때만 쓴다.

### ⑥ (미결 과제) **가장 강한 통제 = 주 추정치**의 분산 대가를 검증한다

R31 ③ 은 가장 강한 통제를 주 추정치로 쓰라고 했다. Q7-P 에서 `strat` 의 CI 폭은
`rank` 의 **2.49배**(0.1260 vs 0.0506)다. 편향을 줄이려 **분산을 6배** 샀고, 그 교환이
이득인지 검증한 적이 없다. → **AIPW/이중강건 추정량**으로 층화의 편향 보호를 잔차
모형의 효율과 함께 얻는 쪽이 정공법이다. 다음 실행에서 병기해 비교한다.

## R33. **검출 바닥은 「효과크기 단위」로 보고한다 · 교정기는 교정 범위를 먼저 잡는다**

Q7-Q 는 처음으로 **양성 대조**(크기를 아는 합성 섭동)를 넣었다. 옳은 방향이었고, 실제로
결론 하나를 뒤집었다. 그런데 **교정기를 쓰는 방법**에서 셋을 틀렸다.

### ① ★★ **양성 대조는 「관문에 통과시킨 것」만 검출력 근거다**

Q7-Q 사전등록 판정표가 이렇게 적혀 있었다.

```
Q1 미달 + 검출 바닥 < 0.03  →  「측정기는 멀쩡한데 신호가 없다」
```

두 가지가 틀렸다.

**ⓐ 단위가 다르다.** 검출 바닥은 「주입 진폭 `a`」(R 진폭 대비 비율), 0.03 은 「초과분」
(AUROC 차이)이다. 비교할 수 없는 두 수를 부등호로 묶었다.

**ⓑ 더 근본적으로, 양성 대조가 검정한 건 관문이 아니라 「수준 추정기」다.** 주입 회수
+0.1936 이 보인다는 건 개체별 점수 계산과 null 뺄셈이 작동한다는 뜻이다. 그런데
**관문의 CI 반폭 0.1170 은 주입과 아무 상관이 없다** — 개체 간 분산과 `n=55` 가 정한다
(필요 개체 **1761** 이 그 증거다).

정확한 진술은 **「측정기는 멀쩡하고, 관문이 무력하다」**이다. 이 둘을 섞으면
**「검출력이 있는데 신호가 없다」는 잘못된 음성 결론**이 나온다 — 실제로 나왔다.

**규칙**: 양성 대조를 검출력 근거로 인용하려면
1. **관문 자체에 그대로 통과**시킨다 — 주입 → 같은 짝의 차이 → 같은 부트스트랩 → 같은
   Bonferroni. 산출물은 **「이 관문이 `n` 에서 잡을 수 있는 최소 차이(MDE)」**다.
2. 수준 추정기만 검정한 양성 대조는 **민감도(편향) 진술**로만 쓴다. 관문의 결론은
   **분산(MDE)** 이 정한다.
3. 관측 효과가 MDE 아래면 ⛔ **측정 한계**이지 「효과 없음」이 아니다(R29 ②).

### ② **교정기는 「교정 범위」를 먼저 잡는다** — 격자가 바닥을 감싸야 한다

Q7-Q 의 주입 격자 `a ∈ {0.05, 0.10, 0.20}` 은 **셋 다 검출**됐다. 그래서 알아낸 건
「바닥 ≤ 0.05」뿐이고 **바닥이 어디인지는 모른다.**

**규칙**: 양성 대조 격자는 **최소 한 점이 미검출**이어야 한다. 전부 검출이면 격자를
**아래로 확장**하고, 전부 미검출이면 위로 확장한다. **바닥을 괄호로 감싸기 전에는
「검출 바닥 = …」이라고 쓰지 않는다.**

### ③ **양성 대조는 추정량 선택 도구다** — 규칙으로 고르지 말고 재서 고른다

R31 ③(가장 강한 통제를 주 추정치로)과 R32 ⑥(그 분산 대가는 미검증)이 계속 충돌했다.
Q7-P 에서 `strat`/`rank` CI 폭 비 **2.49배**, Q7-Q 에서 **3.0~3.3배**, 게다가 Q7-Q 의
Q1c 는 **부호까지 갈렸다**(strat −0.0466 vs rank +0.0330).

**양성 대조가 생긴 순간 이 교환은 잴 수 있는 양이 된다.**

```
편향의 대리 = 알려진 주입에 대한 **회수량**
분산        = **CI 폭**
선택 기준   = **MDE(= 효과크기 단위 최소 검출 효과)가 가장 작은 추정량**
```

**규칙**: 주 추정량은 **사전등록된 규칙이 아니라 양성 대조 실측으로 고른다.**
후보(`raw`·`lin`·`rank`·`strat`·AIPW)를 같은 데이터에서 돌려 **(회수량 × CI 폭) 표**를
내고, MDE 최소인 것을 **다음 실행의 주 추정량으로 사전등록**한다. 고른 근거를 함께
적는다 — 그래야 R31 ③ 과 충돌해도 어느 쪽이 왜 이겼는지 남는다.

### ④ 「단조 감쇠」라고 쓰려면 **단조성을 검사한다**

Q7-Q 의 `ladder_read()` 는 **끝값/시작값 ≤ 0.7** 만 보고 세 관문 모두 「단조 감쇠」로
찍었는데, 실제 사다리는 오르내렸다(`raw .0477 · lin .0214 · hist .0261 · quad .0096 ·
rank .0326 · strat .0293`). **문구가 사실보다 강했다.**

**규칙**: 감쇠 판정 문구는 실제로 검사한 것까지만 쓴다 — 단조성을 안 봤으면
**「`raw` 가 최댓값이고 끝값이 낮다」**까지다.

### ⑤ **±0.05 등가 관문을 폐기한다 — 「리듬 대비」 임계로 갈아탄다**

Q7-Q 의 세 관문이 요구한 등가 필요 개체는 **1761 · 2000 · 43823** 이다. `±0.05` 여유는
이 추정량·이 표본에서 **원리적으로 도달 불가능**하고, 그걸 계속 거는 건 미결을 양산할 뿐이다.

**규칙**: 「창 A 가 창 B 를 이기는가」 류의 **팔 간 등가 관문을 주지표로 걸지 않는다.**
대신 **의사결정에 붙는 양**으로 묻는다 — 예: **리듬 전용 모형 대비 창 특징 추가의
ΔAUPRC(또는 동작점 부분 AUC)** 에 등가 임계를 건다. 이유 셋:
① 공통 누출이 두 모형에 같이 들어가 **상쇄**된다
② 임상적으로 답이 필요한 질문이다
③ Q7-Q 실측에서 이 경로는 **이미 결정 가능한 음성**을 냈다(네 창 모두 ΔAUROC CI 상한 <0.01)
— 관문들이 필요 개체 1761 을 부르며 아무것도 못 정하는 동안.

⚠️ 단, **천장효과를 먼저 제거**한다 — Q7-Q 의 `lr_rhy` 무잔차 AUROC 는 **0.9600** 이라
그 위의 Δ 는 압축된다. 유병률 0.08 이면 **AUPRC · 고특이도 부분 AUC · 순재분류**로
재측정해야 하고, **그 전에는 「형태 축 종료」를 확정하지 않는다.**

## R34. **검출은 「회수 > MDE」다 · 추정량은 「필요 진폭」으로 고른다 · 음성 대조는 구성으로 보장한다**

Q7-R 은 R33 을 따라 양성 대조를 관문에 통과시켰다. 방향은 맞았는데 **판정식 둘이
틀려서 추정량 선택이 통째로 무효**가 됐다. 그리고 6회 동안 써온 음성 대조가
**추정 대상을 바꾸자 1등을 했다.**

### ① ★★ 검출 판정은 **「주입값이 0 을 넘나」가 아니라 「회수가 MDE 를 넘나」**다

Q7-R 은 `det = (주입된 짝의 차이 CI 하한 > 0)` 으로 판정했다. 그런데 기저가 이미
유의한 추정량은 **주입이 0 이어도 검출로 찍힌다.**

```
raw   기저 +0.0934 [+0.0630, +0.1230]   ← 하한이 이미 0 초과 → a=0 에서도 ✅
strat 기저 +0.0298 [−0.0891, +0.1370]   ← 0 을 걸침 → 주입이 있어야 ✅
```

그래서 「바닥 a≥0.005」는 검출 바닥이 아니라 **「기저가 이미 유의하다」의 재표현**이었고,
통제를 하나도 안 하는 `raw` 가 주 추정량으로 뽑혔다.

**규칙**: 양성 대조의 검출은 **회수 = (주입 결과 − 기저)** 로 정의하고,
**회수 > MDE** 를 검출로 본다. 기저의 유의성은 검출 판정에 **들어가면 안 된다.**

### ② ★★ 추정량은 **MDE 단독이 아니라 「관문을 넘기는 데 필요한 진폭」**으로 고른다

R33 ③ 이 「MDE 최소」라고만 적어서 **감도(편향)를 안 봤다.** 실측:

| | MDE | 감도 기울기 | **필요 진폭** | 프로브 누출 |
|---|---:|---:|---:|---:|
| `raw` | 0.0300 | 1.07 | 0.0301 | — |
| `strat` | 0.1131 | **3.50** | 0.0329 | +0.1357 |
| `dr` | 0.1211 | 3.25 | 0.0380 | **+0.0322** |

**큰 MDE 가 큰 감도로 정확히 상쇄된다** — 다섯이 1.26배 안에서 동률이었다. 그리고
누출을 4배 죽인 `dr` 이 MDE 만 보면 꼴찌였다.

**규칙**: 선택 기준은 **필요 진폭 = MDE / 감도 기울기**(= 회수 곡선이 MDE 를 넘는 최소
주입량)다. **MDE 와 감도를 함께 보고**하고, 프로브 누출(편향)을 **세 번째 열로 병기**한다.
셋이 다 비슷하면 **「추정량으로는 못 푼다」가 결과다** — 그 문장을 쓴다.

### ③ ★★ 음성 대조는 **「그럴듯한 무관 창」이 아니라 구성으로 무관함이 보장된 것**이어야 한다

Q7-N~Q7-Q 는 `stt`(ST/T 구간)를 음성 대조로 썼다. 개체 내 층화에서는 실제로 누출만
날랐다(고유항 +0.0012). 그런데 **추정 대상을 교차환자로 옮기자 두 지표에서 1등**을 했다.

```
ΔAUPRC     stt_22 **+0.0706**  vs  P 창들 −0.0116 · −0.0115 · −0.0156
Δ부분AUC   stt_22 **+0.0591**  vs  P 창들 +0.0132 · −0.0061 · +0.0011
```

T 파 형태는 **심박수 의존**이고 그 의존성은 **개체 간에 전이된다**(R24 의 교차환자 판본).
개체 내에서는 `f1` 정확 매칭이 죽이지만 전역 모형엔 그런 통제가 없다.

**규칙**: 음성 대조는 **해부학적 무관함으로 고르지 않는다.** 구성으로 보장한다 —
예: **같은 창을 같은 레코드의 무작위 다른 비트에서** 가져오기(형태 통계 동일 · 라벨 무관),
또는 창 내용을 **라벨과 독립인 방식으로 치환**하기. 그리고 **추정 대상을 바꾸면
음성 대조의 유효성을 다시 검증한다** — 한 프레임에서 음성이라고 다른 프레임에서도
음성인 게 아니다.

### ④ 분기 문턱을 **근거 없이 하드코딩하지 않는다**

Q7-R 의 R4(b)는 `abs(지터 − 정렬) < 0.02` 로 (A)/(B)를 갈랐는데, 실측이 **0.0205** 로
간발의 차로 넘어 **「(A) 타이밍 정보」**를 출력했다. 나머지 증거는 전부 반대였다
(PR 단독 −0.0571 · PR 잔차화 변화 +0.0034 · 정렬 페널티 −0.0071).

**규칙**: 판정 문턱은 **MDE 나 CI 같은 실측량에서 유도**한다. 상수를 쓸 수밖에 없으면
**그 값의 근거를 사전등록에 적고**, 실측이 문턱의 ±20% 안에 들면 **⚠️ 경계**로 찍어
어느 분기도 타지 않는다(R29 ②와 같은 정신).

### ⑤ **퀘스트에 종결 조건을 미리 박는다**

퀘스트46 은 **멈출 규칙 없이 7회** 돌았다. 매번 새 결함이 나와 다음 실행이 정당화됐고,
그 자체는 정직한 과정이었지만 **언제 「답이 안 난다」로 끝낼지가 없었다.**

**규칙**: 퀘스트 큐 카드에 **사전등록 종결 조건**을 넣는다 — 「이 관문이 미결이고
필요 표본이 N 을 넘으면, 「이 데이터 규모에서 측정 불가능하다」를 최종 문장으로 쓰고
갈래를 닫는다」. 조건을 만족하면 **더 돌지 않는다.**

## R35. **자를 먼저 세워라 · 「도드라진다」 ≠ 「~처럼 보인다」 · 팔 비교는 작동점을 맞추고 대조는 구성으로 항등이게**

Q7-T·Q7-U 는 **처음으로 외부 정답**(BUT PDB 전문가 P 주석)에 자를 맞춘 런이다.
그 두 런에서 배운 건 「가설이 맞나」가 아니라 **「가설을 잴 수 있나」** 쪽이었고,
Q7-D~Q7-S 가 쌓은 미결의 상당 부분이 **측정기 탓**이었다는 게 드러났다.

### ① ★★★ 자가 부정확하면 가설의 참/거짓을 **가를 수 없다** — 자를 먼저 세운다

Q7-T 는 자체 검출기(`argmax|잔차|`, 12줄)로 **Se 0.4375** 를 냈고, 사전등록 종결
조건이 발동해 「자체 검출기를 버리고 공개 방법으로」 갔다. Q7-U 에서 공개
delineator(NeuroKit2 웨이블릿)를 빌리자 **Se 0.9109 / PPV 0.7145** 가 나왔다.

```
Q7-T 자체 검출기   Se 0.4375 / PPV 0.3783   F1 0.4058
Q7-U 공개 자       Se 0.9109 / PPV 0.7145   F1 0.7705
벤치마크(Saclova)  Se 0.9307 / PP  0.8860   F1 0.9078
```

**「P 는 측정 불가」가 아니라 「내 측정기가 부족」이었다.** 이 구분을 못 하면
측정기의 한계를 **현상의 부재**로 잘못 읽는다 — Q7-T 의 T3(P 부재 AUROC 0.5190 ❌)이
정확히 그 함정이었다. 그 지표는 **T1 이 실패한 그 검출기의 출력**을 썼으므로
독립 증거가 아니었고, 검출기를 갈자 0.6118 로 올라갔다.

> **자기 출력으로 자기를 평가하는 지표는 상위 관문이 실패하면 같이 무효다.**
> 관문 사이의 **의존 그래프**를 사전등록에 적고, 상위가 ❌ 면 하위를 인용하지 않는다.

### ② ★★★ 「도드라진다」 ≠ 「~처럼 보인다」 — 진폭 지표와 형태 검출은 다른 것을 잰다

같은 QRST 소거를 두 자로 쟀더니 **부호가 반대**로 나왔다.

```
Q7-T T2   주석 P 위치가 창 안에서 얼마나 도드라지나 (백분위 순위)   +0.2825  ✅
Q7-U U2   delineator 가 P 를 얼마나 잘 찾나 (F1)                   −0.1984  ❌
```

둘 다 참이다. 소거는 P 의 **상대 진폭**을 올리지만 **파형 모양을 부순다** —
웨이블릿 구획은 부호 반대인 modulus maximum 쌍, 즉 **모양**을 찾는데 템플릿을 빼면
P 자신의 모양이 깎이고 템플릿 불일치가 고주파 인공물을 남긴다.

> **전처리가 「신호를 키웠다」는 증거는 「검출이 좋아졌다」의 증거가 아니다.**
> 하위 과제가 형태에 의존하면 **하위 과제의 지표로** 다시 재라.

### ③ ★★ 팔 비교는 **작동점을 맞추고** 한다 — 안 그러면 「얼마나 자주 쏘았나」를 잰다

Q7-U 1판은 기권 문턱을 팔마다 Youden 으로 최적화했다. 그 결과 **발화율이
0.038~0.977 로 26배** 벌어졌고, 거기서 나온 「소거 승리」

```
ΔSe +0.1413 [+0.1111, +0.1741]     ← CI 하한이 0 에서 멀다. 그럴듯했다
```

는 순전히 **6.7배 더 쏜 결과**였다. 문턱을 **점수 분위수**로 잡아 발화율을 강제로
맞추자 부호가 뒤집혔다.

- 팔마다 문턱을 따로 최적화하면 **작동점이 자유변수**가 된다 → Se·PPV 비교 불가
- **발화율 격자 전체**에서 재라. 한 점이 아니라 **곡선이 이겨야** 한다
- 지표도 작동점 위 한 좌표(Se)가 아니라 **균형점(F1)** 으로

### ④ ★★ 전처리 팔의 대조는 **구성으로 항등**이어야 한다

Q7-U 2판까지는 비트 잔차를 Voronoi 로 되붙여 연속 신호를 만들었다. 그 이음매가
파형이라 **재구성만으로 F1 0.7705 → 0.6132**. 소거 이득(+0.01~0.09)보다 **구현
비용(−0.16)이 10배** 컸다 — 즉 재던 것이 소거가 아니라 **내 되붙이기**였다.

전처리를 `raw − 추정치` 로 뒤집자 덮이지 않은 구간이 raw 그대로가 되어
`none` 이 **정의상 raw** 가 됐고, 대조가 **공짜로 구성 보장**됐다.

```
U3 항등 점검   none vs raw 의 ΔF1 = 0.0000  (전 발화율 · 두 검출기)
               0 이 아니면 AssetError 로 **중단**
```

> 대조군은 **가정이 아니라 항등식**으로 만들어라. 그리고 그 항등을 **런타임에
> 검사**해서 깨지면 판정하지 말고 멈춰라(R34 ③ 의 강화판).

### ⑤ ★★ 문헌의 방법은 **기하가 같을 때만** 옮겨진다

Shah et al. 2004(PMID 15485519)는 *"an averaged template offers a higher SNR,
**the immediately preceding QRST provides the best match** ... **without distorting
the underlying P-wave**"* 라고 명시한다. 우리 U2 실패의 원인이 「중앙값 템플릿의
P 왜곡」이라면 직전 비트 템플릿이 격차를 **좁혀야** 했다. 안 좁혔다 — **더 나빴다.**

```
dwt @발화율 1.00 F1
raw 0.7705 ≫ abs 0.6276 ≈ st 0.6270 > blend 0.6220 > local 0.6061
           > blendfit 0.5973 > prevfit 0.5915 > prev 0.5847
           └─ 템플릿이 개별 비트에 잘 맞을수록 **단조로 나빠진다**
```

기하가 달랐다.

```
Shah    이소성 P 가 **앞 비트**의 T-U 에 가림  →  **앞 비트** QRST 를 뺀다
        (P 와 빼는 대상이 **다른 비트**에 속한다 → 잘 맞출수록 이득)
우리    **그 비트 자신의** 심실 추정치를 뺀다
        (P 와 빼는 대상이 **같은 비트**다 → 잘 맞출수록 P 를 더 지운다)
```

> 인용은 **결론이 아니라 조건부 주장**이다. 옮기기 전에 **전제(기하·측정 대상)가
> 같은지** 확인하고, 다르면 **양끝을 감싼 격자로** 실측해라(R33 ②).
> 사용자가 제안한 가중 혼합(w·중앙값 + (1−w)·직전)이 그 격자였고, 최적은 안쪽이
> 아니라 **w=1 끝**이었다 — 감쌌기 때문에 **확정적**으로 말할 수 있다.

### ⑥ ★ 신규성 주장은 **검증 가능한 형태**로 쓴다

Q7-U 초안은 「이 조합은 아무도 안 했다」고 썼다. **거짓이었다** — Diaz et al. 2001
(QRS 소거 3방식 비교)과 Shah et al. 2004 가 이미 QRST 를 빼고 심방 활동을 봤다.
사용자가 문헌으로 잡아냈다.

```
❌  No one has removed QRST before P-wave detection.
✅  Previous studies have used QRS(T) cancellation to expose concealed atrial
    activity. However, contemporary deep-learning ECG delineation operates
    predominantly on the original signal. To our knowledge, the effect of
    substituting the QRST-cancelled residual as input to the *same* delineator,
    evaluated by paired within-record comparison, has not been systematically
    established.
```

- 「아무도 안 했다」는 **반증만 가능하고 입증은 불가능**하다 — 쓰지 마라
- 「to our knowledge ... not systematically established」로 **범위를 한정**하라
- **픽스처로 회귀를 걸어라** — Q7-U 픽스처 ⑩b 는 금지 문구가 소스에 있으면 실패하고,
  선행연구 인용(PMID 포함)과 한정 표현을 강제한다

### ⑦ ★ 자산 생성 런에는 **관문을 두지 마라** — 대신 **정합을 증명**하라

Q7-P0(SVDB P-위치 표)는 가설을 검정하지 않는다. 그런 런에서 지킬 것은 판정의
타당성이 아니라 **좌표의 타당성**이다.

- 판정 표식(✅/❌/⚠️)이 **소스에 하나도 없어야** 한다 — 픽스처로 강제
- 대신 **구성적 증명**을 관문 자리에 놓아라: `(pid, sym)` 수열이 원소 단위로
  일치하지 않으면 **첫 불일치 인덱스를 찍고 중단**
- 증명은 **비싼 계산 전에** 끝나야 한다(35분 구획 뒤에 어긋남을 발견하면 35분을 버린다)
- **생리학적 자기검증**을 넣어라 — P 위치 중앙값이 PR 120~200ms 근처가 아니면
  좌표가 틀린 것이다. 도메인 지식은 공짜 단위검사다

## R36 — 미결에서 말할 수 있는 것 · 프로브도 LORO · 개인화는 S1≈S2 로 갈린다

**출처**: Q7-S′(`quest46_q7s2_p_aligned` · 공식 실행 `20260804T0658` · 56/34 개체).
퀘스트 46 의 실제 질문("리듬 너머로 P 형태가 정보를 더하는가")에 처음 답을 시도한 런.
S4(영점) ✅ · S1·S2·S3 전부 ⚠️ 미결 · 사전등록 종결 조건 발화.

### ① ★★ 미결의 결론은 「없다」가 아니라 **「있어도 CI 상단 이하」** 다

미결을 그냥 "못 정했다"로 두면 다음 실험을 설계할 수 없다. 미결에서도 **한쪽 방향은
확정**된다 — 상한이다.

```
❌  P 형태는 리듬 너머로 정보를 더하지 않는다        (미결을 null 로 읽음 · R33 ①)
❌  결론을 못 냈다                                   (행동 불가 · 다음 실험을 못 짬)
✅  교차환자 ΔAUPRC 의 CI 상단이 +0.0213 이다 —
    있어도 AUPRC +0.02 를 넘지 않는다
```

- 상한이 **비용보다 작으면** 그 갈래는 실무적으로 접힌다. 판정은 미결이어도
  **의사결정은 가능하다** — 「닫는다(❌)」와 「접는다(⚠️ + 상한)」를 구분해서 써라
- 접은 갈래는 **조건부 재개**로 남긴다: 필요 표본을 숫자로 박고, 그 표본이 확보되는
  코호트가 생기면 **노트북을 그대로** 다시 돌린다(그래서 동결한다)

### ② ★★ 선택을 LORO 하려면 **모든 선택**을 해야 한다 — 프로브도 선택이다

Q7-S′ 는 개인화 `k` 를 LORO 로 골랐다. 그런데 S3 의 「최량 프로브」는 5개 중 그냥
`max` 로 골랐다. **같은 종류의 편의를 한 군데만 막았다.**

```
❌  BEST = max(PROBES, key=lambda p: AUC[p])        # 보고할 그 수치로 고른다
✅  프로브도 LORO — 레코드마다 자기를 뺀 레코드들에서 프로브를 고른다
✅  최소한: 「최대를 골랐으면 얼마였는지」를 병기해 선택 편의를 정량하라
```

- 편의가 남았으면 **필요 표본 계산도 그만큼 낙관적**이다 → 종결 판단에 직접 영향
- 체크리스트: 문턱 · 팔 · 하이퍼파라미터 · **프로브** · 코호트 필터. 다섯 자리 전부다

### ③ ★ 개인화 가설은 **S1 vs S2 의 격차**로만 갈린다

"보편 템플릿은 없어도 환자 안에서는 성립한다"는 가설의 검정은 개인 내 성능이
높다는 게 **아니다** — 개인 내가 교차환자보다 **얼마나 높은가**다.

```
S1(개인 내)  +0.0029      S2(교차환자)  +0.0035      →  S1 ≈ S2
```

- 둘이 같으면 **개인화가 아무것도 안 한 것**이다. k 를 바꿔도 안 움직이면
  (k=5/10/20 에서 +0.0036/+0.0034/+0.0030) 「k 를 잘못 골랐다」로도 도망 못 간다
- ⚠️ 앞선 런의 「개체 내에서만 오른다」(Q7-R R5 +0.0974)는 **누출 통제를 제대로 걸자
  남지 않았다**. 개체 내 수치는 누출에 가장 약하다 — 통제 전 값을 인용하지 마라

### ④ ★ 영점의 MDE 와 처치의 MDE 가 크게 다르면, 그게 **이질성의 측정치**다

```
noise5  MDE 0.0005      palign  MDE 0.0143      (같은 56개체 · 같은 부트스트랩)
```

같은 표본·같은 절차인데 분해능이 28배 다른 건 잡음이 아니다. 영점은 모든 레코드에서
똑같이 0 이라 개체 간 분산이 없고, 처치는 **레코드마다 부호가 갈린다**는 뜻이다.

- 이건 버리는 정보가 아니라 **다음 실험의 설계 입력**이다 — 효과가 이질적이면
  평균 Δ 를 키우는 게 아니라 **어느 개체에서 발동하는지**를 물어야 한다
- 영점 팔은 「0 인가」만 보는 게 아니라 **CI 폭도 같이 읽어라**

### ⑤ ★ 차이(A−B)의 부호를 성분 없이 인용하지 마라

```
S5 = palign − pmorph = +0.0134   (전 k 에서 일관)
     성분:  palign +0.0035 ≈ 0     pmorph −0.0100 < 0
```

- 「정렬이 이득을 준다」가 **아니다** — 「고정창이 해롭고, 정렬이 그 해악을 없앤다」다
- 차이가 양수인 이유가 **분자가 커서**인지 **분모가 작아서**인지는 차이값만으론
  구분이 안 된다. 성분을 항상 병기하고, 성분이 0 근처면 그렇게 써라

## R37 — 필요 표본은 **프레임을 밝혀야** 수다 · 자는 **감쇠 상한**으로 감사한다

**출처**: Q7-S′ 외부 검토(사용자 제공) → **Q7-S″**(`quest46_q7s3_recompute`) ·
**Q7-V**(`quest46_q7v_ruler_audit`). 새 데이터 없이 **판정이 바뀔 수 있는** 종류의
오류 하나와, 「신호 없음 vs 자가 무딤」을 가르는 도구 하나.

### ① ★★★ 필요 표본에는 **두 개의 다른 수**가 있다 — 어느 쪽인지 밝혀라

```
등가(equivalence)  n = n₀ × (반폭 / (여유 − |효과|))²    「효과가 없다」를 증명
우월(superiority)  n = n₀ × (반폭 / |효과|)²             「효과가 0 이 아니다」를 보임
                   × 2.04                                 검정력 50% → 80%
```

두 수는 **순위까지 뒤집는다**. Q7-S′ 실측:

| 관문 | 효과 | 반폭 | 등가 | 우월 50% | 우월 80% |
|---|---:|---:|---:|---:|---:|
| S2 | +0.0035 | 0.0143 | 269 | 935 | 1,907 |
| **S3** | **+0.0272** | 0.0531 | **도달 불가** | **213** | **435** |

- Q7-S′ 는 등가 식만 돌렸고, S3 는 효과가 여유(0.01) **밖**이라 분모가 음수가 되어
  **「도달 불가」**로 찍혔다. **신호가 약해서가 아니라 등가를 선언할 수 없어서다** —
  가장 싼 관문을 가장 비싼 것으로 오분류했다
- 「도달 불가」를 그대로 **종결 조건의 근거로 썼다**. 프레임 오류가 판정을 바꿨다
- **체크리스트**: 필요 표본을 찍을 때 ⓐ 등가·우월 중 무엇인지 ⓑ 검정력 몇 %인지
  ⓒ 단위가 무엇인지(전체 개체? 조건을 만족하는 개체?) — 셋 다 없으면 그 수는 못 쓴다
- ⚠️ **CI 가 0 을 배제하는 기준은 검정력 50%다.** 관례(80%)로 말하려면 ×2.04.
  50% 수만 적고 80% 를 괄호로 흘리면, 도달권처럼 보이는 표가 만들어진다

### ② ★★ 대비의 기준은 **영점**이지 다른 실패한 팔이 아니다

Q7-S′ 의 주 대비는 `palign − pmorph` 였는데 `pmorph`(−0.0100)가 자기 영점
`shuf5`(−0.0013 · MDE 0.0107)의 CI 안에 통째로 들어간다 — **둘 다 비어 있었다**.

```
❌  palign − pmorph        빈 것 − 빈 것. 창 특이성을 증명하지 못한다
✅  palign − shuf5         영점 기준. 이 차이가 곧 **창 내용의 특이성**이다
```

- 짝지은 차로 하라 — 같은 폴드·같은 개체면 공통 분산이 상쇄돼 CI 가 좁아진다
  (실측: 반폭 0.0074 → 0.0014)
- 실패한 팔은 **보조 비교**로 남기되, 주 대비 자리에 두지 마라

### ③ ★★★ 「정확 매칭」은 **자신을 통과시켜** 증명하라 (항등 대조의 매칭판)

매칭 키가 `round(f1)` 이면 한 층 안에서 `f1` 이 **최대 1 단위 흔들린다**. 그 잔여로
조기성이 새면 「조기성을 통제했다」가 거짓이 된다. 확인 방법은 하나뿐이다 —
**통제하려는 변수 자신을 같은 매칭에 통과시킨다.**

```
층 안에서 f1 이 상수      → 항등 대조 = 0.500000  (구성으로 보장)
층 안에 잔여 조기성 존재  → 항등 대조 = 1.0000    (즉시 발화)
```

- ⚠️ **잔차화한 값을 넣지 마라** — `resid(f1)` 은 정의상 0 이라 항상 통과한다
- 폭을 넓혀 개체를 늘리려면 **먼저 누출을 재라**. 폭 곡선(1·2·4·8·16)에서 항등 대조가
  0.5 를 유지하는 구간만 읽을 수 있다
- 이 대조가 깨지면 관문을 **철회**한다 — 표본을 늘려도 편향은 안 줄어든다

### ④ ★★★ 자가 병목인지는 **감쇠 상한**으로 가른다 — 답 없는 자료에서도

「신호가 없다」와 「자가 무뎌서 못 잰다」는 미결로는 안 갈린다. 정답이 있는
**다른** 자료에서 같은 비트의 특징을 **두 번** 재면 갈린다.

```
x_true = feature(정답 위치)      x_obs = feature(검출 위치)
λ = corr(x_true, x_obs)
d_true = (d_obs − d_null) / λ    →   AUROC_true = Φ(d_null/√2 항 포함)
```

- **탈감쇠는 한 방향으로만 움직인다(항상 키운다) → 이건 상한이다.** 그래서 판정이
  깨끗해진다: **상한조차 MDE 밑이면 자를 고쳐도 못 넘는다** = 자는 병목이 아니다
- ⚠️ **null 을 통째로 부풀리지 마라** — 관측 AUROC 를 그대로 λ 로 나누면 라벨셔플
  null 까지 커져 상한이 낙관적이 된다. `d` 공간에서 **신호분만** 나눠라
- λ ≤ 1 로 절단하라. λ>1 이면 탈감쇠가 값을 **줄여** 방향이 뒤집힌다
- 검증: 잡음을 주입해 λ 를 0.90→0.33 으로 낮춰도 복원 오차가 0.003 이내였다
- 코호트·표본율이 다른 데서 λ 를 가져오면 **전이 가정**이 붙는다. 방향을 밝혀라 —
  대상 쪽 해상도가 더 거칠면 실제 감쇠는 더 심하고, 상한은 **보수적**이 된다

### ⑤ ★ 오차를 **되돌릴 수 없으면 더 얹어라** (용량-반응)

정답 없는 자료에서는 지터를 뺄 수 없다. 대신 **실측한 오차를 한 번 더** 얹고
기울기를 본다. 무너지면 자 쪽, 평평하면 신호 크기 쪽이다.

- **k=0 은 주입 경로를 아예 거치지 않게 만들어라** — 그래야 항등이 **구성으로**
  보장된다. 원 결과와 어긋나면 파이프라인이 틀린 것이므로 **중단**
- 주입 연산자는 **라벨을 인자로도 받으면 안 된다**(무감독) — 픽스처로 강제
- 영점 팔(무정보 위치)에 **같은 주입**을 걸어라. 거기서 0.5 를 뜨면 주입 자체가
  신호를 만든 것이고 기울기를 해석할 수 없다
- 감쇠 상한(가정: 고전 측정오차)과 용량-반응(가정: 오차 전이)은 **가정이 다른 두
  경로**다. 2배 넘게 갈리면 **둘 다 인용하지 마라**

### ⑥ ★ 검토자가 우리 이력을 모를 수 있다 — 사실관계부터 갈라라

외부 검토는 「딜리니에이터에 정답 검증이 전혀 없다」고 했지만 **Q7-T·Q7-U 가 정확히
그것**이었다(BUT PDB 전문가 주석 · Se 0.9109 · PPV 0.7145). 검토를 받을 때는

- **사실오류 / 옳은 지적 / 처방이 죽은 지적**을 나눠서 답하라
- 사실오류라도 **기전 지적은 살아남을 수 있다** — 여기서는 「조용한 오검출」이
  가설이 아니라 **PPV 0.7145 로 이미 측정된 사실**이었고, 그게 Q7-V 를 낳았다
- 처방이 죽었으면 그렇게 말하라 — INCART 는 Q1 에서 이미 기각됐고(양성>0 36/75 ·
  중앙값 0), 「12리드 + 비트 주석 + SVEB 풍부 + 홀터 길이」를 동시에 만족하는
  공개 코호트는 확인된 바 없다. **권고가 아니라 탐색 과제로 강등**한다

### ⑦ ★ 데이터셋에 무엇이 **없는지**부터 세어라 — 방향 전환 제안을 받았을 때

검토가 「blocked PAC(비전도 P) vs 동정지 감별로 옮기자」고 했다. 좋은 제안이었고,
**주석을 세는 데 1분** 걸렸다.

```
SVDB 78레코드 전수 — 'x'(비전도 P) 0개 · aux_note(리듬 주석) 1레코드 1개
                     'a' 1개 · 'J' 9개 → S 12,188 중 12,178 이 무구분 'S'
```

- **라벨이 없으면 그 갈래는 그 자료에서 존재하지 않는다.** 설계 전에 센다
- 덤으로 오래된 미결 하나가 닫혔다 — 「`rhythm`·`rhythm_names` 를 한 번도 안 읽었다」의
  답은 **데이터에 없다**였다(사전등록한 「둘 다 없으면 데이터에 없다」 분기)

**보론(R37 ④⑤ 개정 — Q7-V 1판 실패에서)**: 「정답이 있는 자료에서 잰 오차를 정답이
없는 자료에 옮긴다」를 **파형 재계산으로** 하려다 실전 실행 중 죽었다.

```
점수 재계산 검증 — Q7-P0 자산과 corr 0.7122 · |Δ| 중앙 0.0000
```

**두 숫자가 같이 나온 게 진단이다** — 절반 이상은 **정확히 일치**하는데 상관은 0.71.
일부만 완전히 틀렸다는 뜻이다. 원 자산은 점수를 **연속 신호**에서 위치 중심 ±100ms
창으로 쟀는데, 소비 측은 **비트 절단 배열**에서 쟀다. 비트가 R−278ms 에서 시작하므로
앞쪽 P 후보는 창 왼쪽이 배열 밖이고, 코드가 조용히 `np.clip` 으로 **창 중심을 옮겼다**.

- **자산을 만든 좌표계와 소비하는 좌표계가 다르면, 「같은 함수」를 다시 써도 다른 자다.**
  절단·패딩·리샘플이 낀 자산은 **경계에서만** 어긋나므로 평균·중앙값으로는 안 잡힌다 —
  **상관과 중앙 |Δ| 를 같이** 봐라
- 우회로(직전 조각에서 문맥 복원)에도 조건이 붙는다(여기서는 `36 ≤ RR ≤ 300` 샘플).
  **부분적으로만 되는 복원은 새 선택편향**이다
- **더 나은 길: 값을 다시 재지 말고 분포로 옮겨라.** 레코드 안 **순위→정규점수** 공간에서
  `z' = a·z + e` 를 걸고 **같은 집합의 경험분위수**로 되돌리면 ⓐ 눈금·표본율·진폭에
  불변이고 ⓑ `a=1·e=0` 에서 **원값이 정확히 복원**돼 항등이 구성으로 보장되며
  ⓒ 주변분포가 보존돼 눈금 인공물이 안 생긴다
- ⚠️ 그 수송은 **집합 내부에서 자기완결**이어야 한다. 바깥에 고정한 분위수표를 쓰면
  용량이 올라 집합이 줄 때 길이가 어긋난다 — 실제로 `r/(m+1)` ↔ `q·(m−1)` 불일치로
  최대 |Δ| **1.29** 가 났고 **항등 검사가 잡았다**
- ⚠️ **대가를 적어라**: 이렇게 하면 상한(V1)과 재표집(V2)이 **같은 실측 쌍 분포를
  공유**한다. 「가정이 다른 두 경로」가 아니라 **「닫힌형 이론 상한」 vs 「그 분포를 실제
  추정량에 통과시킨 재표집」**이다 — 일치해도 **독립 증거로 인용하지 마라**

> 이 절의 실패 셋(경계 클립 · 되돌리기 지수 불일치 · 독립성 상실)은 전부 **항등 검사가
> 잡았거나 항등 검사를 세우다 드러났다.** R35 ④ 를 관문 자리에 두는 값어치가 여기 있다.

## R38 — 결론 문장 직전의 **산수 검산** · 통계량의 「창」이 어디 붙었나

**출처**: Q7-S″(`20260804T0809`) · Q7-V(`20260804T0834`) 와 그에 대한 외부 검토.
실행과 대조 설계는 통과했는데, **결론 문장을 쓰기 직전의 검산**에서 넷이 걸렸다.

### ① ★★★ 「이 숫자가 이 결론을 정말 지지하는가」를 한 번 더 곱하라

같은 자리에서 네 번 틀렸다. 전부 **곱셈 한 번**이면 걸렸다.

```
❌ 필요표본을 문턱 0.5 로 계산      → 측정된 null 은 0.5090. 초과가 0.0362 가 아니라 0.0272
                                     (필요 레코드 117 → 207 · 238 → 422)
❌ k=5 의 MDE(0.0107)를 k=20 에 인용 → k=20 의 MDE 는 0.0050 이고 −0.0066 은 그 **밖**
❌ 「MDE 가 2.6배 좁아졌다」만 적음   → 신호도 같이 줄어 SNR 0.60→0.56,
                                     필요표본은 154/315 → 179/365 로 **늘었다**
❌ 「λ 0.26 은 ±11ms 지터」를 SNR 논증으로 뒷받침 → 실측 λ(Δ) 곡선이 둘 다 정정했다
```

- **관문마다 그 관문의 MDE·null 을 쓴다.** 다른 k, 다른 팔의 값을 끌어오지 마라
- **정밀도 개선은 MDE 가 아니라 SNR(점추정/MDE)과 필요표본으로 말한다.** MDE 만 좁아지고
  효과가 같이 줄면 **아무것도 나아지지 않았다**
- 필요표본을 찍기 전에 **효과의 기준점이 0 인지, 0.5 인지, 측정된 null 인지** 확인하라

### ② ★★ 관문 문턱은 **측정된 null** 이다 — 명목값이 아니다

```
S3 관문:  CI 하한 > 0.5     ← 코드
라벨셔플 null: 0.5090       ← 실측 (CI 가 0.5 를 배제)
```

다음 런에서 CI 하한이 0.505 로 나오면 **null 아래인데 ✅ 가 찍힌다.** 초과의 25%가
이 오프셋이었다.

- null 이 명목값과 다르면 **문턱을 옮기고**, 왜 다른지 **따로 관문을 세워라**
- 치환 null 은 **관문의 구조를 보존하는 방식**으로 만들어라 — 매칭 층 안에서 라벨을
  교환하면 **구성상 0.5** 다. 레코드 안·전역 셔플은 층 구조를 안 보존한다

### ③ ★★★ 통계량의 「창」이 **분자에 붙었는지 분모에 붙었는지** 보라

```
p_score = |x_detrend(q)| / MAD(x[q±100ms])
          ↑ **단일 표본**    ↑ 창은 여기 — **스케일 정규화용**
```

검토자가 「이미 ±100ms 창 통계량이니 창으로 바꿔도 안 오른다」고 했는데, **창이 분모에만
있으면 그건 창 통계량이 아니다.** 실측이 그 차이를 확인했다:

```
λ(Δ=3ms)   점 0.8947   적분 0.9405
λ(Δ=11ms)  점 0.2891   적분 0.5694      ← 분자만 바꿔 λ 가 **두 배**
```

- 위치 민감도를 논할 때는 **신호를 재는 부분**이 점인지 구간인지가 전부다
- 비교하려면 **분모·창을 고정하고 분자 하나만** 바꿔라 — 그래야 축이 하나다

### ④ ★★ 위치 민감도는 **λ(Δ) 곡선**으로 재라 — 추론하지 마라

「P 파 반폭 45ms 니 ±11ms 이동은 진폭을 6% 바꾼다 → 상관 0.26 은 불가능」은
그럴듯하지만 **틀렸다**. 실측 λ(±11ms) = 0.2891 이다.

```
정답 위치를 강제로 Δ 이동시켜 다시 재고  λ(Δ) = corr(f@true, f@true+Δ)
Δ=0 은 **구성상 1.0** — 아니면 점수 계산이 위치에 결정적이지 않다(중단)
Δ 는 **양방향 평균** — 한쪽만 보면 비대칭 파형에서 왜곡된다
```

- 곡선 **모양**이 처방을 정한다: 작은 Δ 에서 이미 낮고 평탄 → **SNR 한계**(적분) ·
  작은 Δ 에선 높고 Δ 따라 감소 → **지터 한계**(이동 불변) · Δ 를 키워도 안 떨어짐 →
  **위치가 원인이 아니다**(출처를 다시 찾아라)
- 이 실험은 **검출기를 쓰지 않는다** — 정답 위치만 흔든다. 검출기 오차와 섞이면
  「통계량이 민감한가」와 「검출기가 부정확한가」를 못 가른다

### ⑤ ★ 포화 구간에서 곡률을 읽지 마라

```
k=0 → k=1  기울기 −0.0333
k=1 → k=2  기울기 −0.0025      ← 볼록성이 아니라 **0 근처 포화**
```

신호가 이미 다 죽었으면 더 죽을 게 없다. **정보가 있는 구간은 k0→k1 하나뿐**이고,
한 구간 기울기로 반대 방향에 외삽하면서 「볼록하니 과소추정」이라고 말할 수 없다.

### ⑥ ★★ 「같은 크기 아무 잡음이나 죽이는가」를 물어라

「측정 오차를 얹으면 신호가 죽는다」는 **그 오차가 병목이라는 증거가 아니다**. 같은
크기의 **무작위** 잡음도 죽인다면, 그건 **효과의 취약성**이지 그 오차의 특이성이 아니다.

- 대조 팔은 **같은 감쇠**가 나오도록 **역산해서 구성**하라(`z'=z+η` 의 `sd(η)` 를
  `ρ` 로부터 풀어라). 그래야 차이가 있을 때 「크기가 아니라 **구조**」라고 말할 수 있다
- 대칭으로 물어라 — 「잡음이 신호를 만드나」(영점)와 **「잡음이 신호를 특이적으로
  죽이나」**(특이성)는 다른 질문이고 **둘 다** 필요하다

### ⑦ ★ 노트북 요약이 셀 주석과 **모순되지 않게** 하라

Q7-V 의 V-E 셀은 「V1·V2 는 같은 쌍 분포를 공유한다 — 독립 증거로 인용하면 안 된다」고
적어 놓고, 요약 셀은 「**가정이 다른 두 경로**다」라고 찍었다. 설계를 고치면서 요약
문자열을 안 고쳤다.

- 셀을 고칠 때 **요약·`finish()` 문구를 같이 훑어라**. 사람이 읽는 건 요약이다
- 픽스처로 **핵심 주장 문구를 소스에서 검사**하면 이런 표류가 잡힌다
- 그리고 「독립 경로가 불일치」보다 **「같은 재료를 두 방식으로 처리했더니 다르다」가
  더 나쁘다** — 후자는 계산 하나가 틀렸다는 뜻이다

## R39 — 미규명인 채로 유리한 값을 고르지 마라 · 라운딩이 Δ 를 뭉갠다 · 비가 아니라 차

**출처**: Q7-X(`20260804T0933`)와 그에 대한 외부 검토 → **Q7-Z**(`quest46_q7z_direct_test`).

### ① ★★★ 재실행이 결론에 **유리한 쪽**으로 숫자를 움직이면, 불리할 때와 같은 강도로 의심하라

```
Q7-S′  null 0.5090 [0.5026, 0.5161]   ← CI 가 0.5 를 배제한다
Q7-X   레코드 안    0.4989 [0.4956, 0.5019]
Q7-X   쌍 내       0.5005 [0.4965, 0.5048]
```

새 값을 채택하면 **필요표본이 213/435 → 124/253** 로 바뀌고, 도달 가능 풀 126 과 견주면
**「도달 불가」가 「이미 도달」로 뒤집힌다.** 그런데 **왜 0.5090 이 나왔는지 아무도 모른다.**

- 「MC 잡음 탓」은 **틀린 설명**이다 — 몬테카를로 잡음은 **중심을 안 옮기고 CI 를 넓힌다**.
  치환 반복이 적어도 각 레코드의 null 추정은 여전히 **불편**이다
- 진짜 후보는 **선택 효과**다: 추정량이 조건 미달에서 `nan` 을 내는데(`tot < MIN_PAIR`),
  치환하면 그 조건이 **바뀌고**, `nanmean` 이 살아남은 것만 평균한다 →
  **드롭 수를 같이 찍어야** 가려진다
- **기전이 안 갈리면 두 값을 병기하라.** 카드에 하나만 실으면 그게 사실로 굳는다
- 이 프로젝트에서 두 번째다(Q7-R 의 누출 바닥 0.1204 → 0.1363)

### ② ★★ 표본율 라운딩이 Δ 를 **뭉갠다** — 그리고 소비 코호트의 층에서 계수를 뽑아라

```
128Hz:  Δ=3ms → 0 샘플 (안 움직임 · λ=1 로 부풀림)
        Δ=5ms → 1 샘플 = 7.8ms
        Δ=11ms → 1 샘플 = 7.8ms      ← Δ=5 와 **물리적으로 같다**
360Hz:  Δ=11ms → 4 샘플 = 11.1ms
```

- **Δ 는 ms 가 아니라 샘플로 잡아라.** ms 격자는 층마다 다른 물리량이 된다
- 층을 섞으면 **다른 이동을 평균**한다 — 층화해서 따로 보고하라
- ★★ **계수를 쓸 곳의 층에서 뽑아라.** 여기서는 SVDB 가 **128Hz** 이므로 탈감쇠
  나눗셈 계수는 128Hz 층의 λ 여야 한다. 실측: `w=40ms` 에서 360Hz 0.510 vs
  **128Hz 0.418**, 그리고 128Hz 는 `w=20ms`(0.436)에서 **정점을 찍고 내려간다** —
  **소비 코호트의 최적 설정이 다르다**

### ③ ★★ 주 통계량은 **비**가 아니라 **차**로 잡아라

「효과가 몇 배가 되나」를 묻고 싶어도, 비의 분모가 0 근처면 CI 가 폭발한다.

```
기준 초과가 0 근처일 때 실측 — 차 반폭 0.0069  vs  비 반폭 37.08
```

- **관문 판정은 차로**, 예측 대조는 비로 — 둘 다 찍되 **판정은 차**가 한다
- 비를 낼 때는 분모에 하한을 두고, 미달이면 `nan` 을 내라

### ④ ★★★ 「A 는 B 때문이 아니다」는 **A 와 B 가 대립 가설일 때만** 성립한다

「λ 붕괴는 지터 때문이지 SNR 때문이 아니다」라고 썼는데, 둘은 **대립이 아니다**.

> 잡음이 없고 매끄러운 파형을 점으로 샘플링하는 것뿐이라면 값은 `A_i·g(0)` vs
> `A_i·g(Δ)` 로 **둘 다 `A_i` 에 비례**하므로 비트 간 상관은 **Δ 와 무관하게 1** 이다.
> **즉 순수한 위치 민감도만으로는 λ 가 떨어질 수 없다.**

- λ 가 Δ 에 따라 떨어진다는 것 자체가 **위치에 따라 탈상관되는 비트별 성분 = 잡음**의
  존재를 뜻한다. 「지터 한계」와 「잡음 지배」는 **같은 현상의 두 이름**이다
- 픽스처로 구성 확인하라 — 무잡음 합성에서 점 통계량의 λ 는 **1.0000** 이다
- ★ 그리고 이 구분이 **처방을 가른다**: 위치 문제면 「최댓값으로 위치를 없애자」가
  맞지만, **잡음 지배면 최댓값은 잡음의 최댓값을 고른다**(양의 편의 · 신호가 아예 없는
  구간에서 최악). 좋은 일은 **적분**이 하고 max 는 위험만 얹는다 →
  **최댓값 팔과 고정위치 팔을 병행**하고, 신호 없는 구간의 최댓값을 **선택 편의 바닥**
  으로 같이 재라

### ⑤ ★★ **결론 검산표**를 코드에 고정하라

세 런 연속으로 같은 자리에서 걸렸다 — 실행과 대조 설계는 통과하는데 **결론 문장 직전의
검산**이 빠진다. 대화로 하지 말고 **노트북이 찍게** 하라.

```
판정마다:  (a) 근거 숫자   (b) 그 숫자가 의존하는 **미검정 가정**
           (c) 그 가정이 틀렸을 때 결론이 **어떻게 바뀌는지**
```

- 미검정 가정이 **없으면 「없음」이라고 쓰라** — 있는데 안 쓴 것과 구분돼야 한다
- 「점추정을 CI 없이 인용 금지」 같은 규칙도 표에 넣어라. Q7-X 의 `+0.017` 은
  실제로 `[−0.010, +0.049]` 로 **0 을 덮는데** CI 없이 「+4.0%」로 적힐 뻔했다
- ★ 그리고 **모형의 예측을 확정 문장으로 쓰지 마라.** 「λ 0.57 → 필요표본 31/63」은
  **미검정 모형의 예측**이었다. 직접 검정이 가능하면 **그 검정을 먼저 돌려라** —
  다음 런의 설계 전제가 그 모형이라면 더더욱

**보론(R39 ⑥ — Q7-Z 의 Z0 이 실전에서 발화)**: **버그 있는 코드의 출력에 재현 기준을
앵커하지 마라.**

Q7-Z 는 Z0 을 「Q7-V 1판이 잰 `corr 0.7122` 를 재현하는가」로 걸었다. 실행하니 **0.9312**
가 나와 관문이 발화했다. 그런데 **0.9312 가 맞고 0.7122 가 틀린 값**이었다.

```
Q7-V 1판:  np.clip(pos, HW, L-HW-1)      → 창 **중심을 옮긴다**   ❌ (그래서 갈아엎었다)
Q7-P0/Q7-Z: max(q-HW,0), min(q+HW+1,L)   → 창을 **자르고 중심 유지** ✅
```

**나는 이미 버그라고 판정해 폐기한 코드의 출력을, 새 코드의 정답으로 박아 두었다.**

- 재현 기준은 **살아 있는 규약**에서 와야 한다 — 폐기한 구현의 산출물이 아니라
- ★★ 더 나은 형태가 거의 항상 있다: **숫자 재현 대신 구성적 항등.** 여기서는
  「창이 배열에 **온전히 들어가는** 비트는 연속 신호 창과 **같은 표본**을 담으므로
  반드시 일치해야 한다」가 그것이고, 조건도 하나 더 붙는다 —
  **온전한 비트의 corr 이 전체 corr 보다 높아야** 불일치가 잘린 비트에만 있다는
  증명이 된다
- 픽스처로 규약 차이를 **구성으로** 보여라: 경계에서 두 규약은 **다른 값**을 내고,
  창이 온전한 위치에서는 **정확히 같다**. 그래서 「거기서만 항등을 요구」가 옳다

## R40 — λ 는 신뢰도이지 타당도가 아니다 · 예측 비교도 주 통계량으로 하라

**출처**: Q7-Z(`20260804T1031`) — 탈감쇠 모형의 **직접 검정**.

### ① ★★★ 신뢰도를 올려도 타당도는 안 올라간다

```
λ (실측 오차 분포 하)   w=0  0.2586  →  w=40  0.4898     거의 두 배
S3 초과                 w=0 +0.0421  →  w=40 +0.0407     **안 움직임**
차 −0.0015 [−0.0217, +0.0228]  vs  예측 차 +0.0354·+0.0409  → **둘 다 배제**
```

탈감쇠 `d_true = d_obs/λ` 는 **「정답 위치에서 잰 값이 판별 정보를 담는다」**를 가정한다.
λ 는 그 가정을 **검정하지 않는다** — λ 는 통계량이 **자기 자신과 얼마나 일치하는가**
(신뢰도)이지 **라벨과 얼마나 관계있는가**(타당도)가 아니다.

- 적분은 통계량을 **안정적**으로 만들었지 **정보를 담게** 만들지 못했다
- **모형이 다음 런의 설계 전제라면, 그 모형을 먼저 직접 검정하라.** Q7-Z 는 Q7-Y 를
  짓기 전에 돌렸고, 그 순서가 반나절을 아꼈다 — **Q7-Y 는 반증된 전제 위에 설 뻔했다**
- 직접 검정은 **부수 효과로 다른 가정도 우회한다**(여기서는 AUROC↔d 정규성).
  예측값과 실측을 비교하므로 변환의 타당성이 자동으로 검정된다
- ⚠️ 탈감쇠가 기각되면 **그것으로 부풀린 모든 상한이 죽는다.** 남는 건 원값이고,
  그 원값은 **어떤 자 개선으로도 커지지 않는다**

### ② ★★ 관문을 차로 하면서 **예측 비교를 비로** 남기면 아무것도 배제 못 한다

1판은 관문 판정을 **짝지은 차**로 옳게 바꿔 놓고, **예측 비교는 비**로 남겼다.

```
비 0.966 [−0.569, 2.564]   ← 폭 3.1. 예측 1.84·1.97 을 「CI 안」으로 찍었다
차 −0.0015 [−0.0217, +0.0228]  ← 예측 차 +0.0354·+0.0409 를 **둘 다 배제**
```

**같은 자료가 「미결」과 「기각」으로 갈렸다.** 비의 분모(기준 초과)가 0 근처라 CI 가
폭발했기 때문이고, 그건 **차를 주 통계량으로 고른 바로 그 이유**였다.

- **예측을 주 통계량의 단위로 환산해서 비교하라** — `pred_diff = e₀ × (pred − 1)`
- 판정과 예측 비교가 **다른 통계량 위에 있으면** 둘이 어긋나고, 보통 느슨한 쪽이 남는다

### ③ ★ 「reps 를 늘리면 수렴한다」는 확인해도, **기전은 따로 규명하라**

```
reps      3      5     10     20     50
null   .5081  .5045  .5036  .5017  .5005     ← 단조 수렴 (Q7-S′ 의 0.5090 재현)
드롭     66    110    220    440   1,100     ← reps 에 **정확히 선형**
```

수렴은 확인됐지만, 내가 제시한 기전(`nan` 드롭의 선택 효과)은 **지지되지 않았다** —
드롭이 reps 에 선형이면 치환당 드롭률이 상수이고, reps 에 따라 달라지는 선택 효과가 아니다.

- **실무 결론(reps ≥ 50 을 쓰면 null = 0.5)은 확정**하되, **기전은 미규명이라고 적어라**
- 「수렴을 봤으니 원인도 안다」로 넘어가지 마라 — 이 프로젝트에서 두 번 그렇게 틀렸다

### ④ ★ 부분군으로 자르는 것 **자체**는 공짜가 아니다

```
필요표본 = n × (반폭/효과)²
n 이 절반 → 반폭 √2 배 → **필요표본은 정확히 같다**
```

- **효과가 커져야 비로소 이득**이다. 「부분군이니 싸진다」는 자동이 아니다
- 부담·밀도로 자르면 **추정이 안정**된다(실측: 신호 0 인 합성에서 SD 0.0344 → 0.0131).
  그건 값을 올리지 않지만 **CI 를 좁혀** 유의해 보이게 만들 수 있다 →
  **각 부분군의 영점을 따로 재고, 그 기준으로 판정하라**
- 영점 판정은 **절대 편차 문턱이 아니라 CI 가 0.5 를 덮는가**로 — 작은 부분군만
  부당하게 통과/탈락한다
- ★ 그리고 **문턱을 훑으면 신호가 없어도 최댓값이 부풀려진다**(실측: 무신호 합성에서
  중앙값 고정 0.5083 → 17개 훑기 최댓값 0.5301). **단발로 사전등록하라**
