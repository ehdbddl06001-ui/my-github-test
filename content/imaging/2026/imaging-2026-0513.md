## 문제
55세 남자가 건강검진에서 대장암 선별용 혈액 검사 A 가 양성으로 나와 외래에 왔다. 증상은 없고 대장암 가족력도 없다. 이 연령대 무증상 성인의 대장암 유병률은 2 % 이고, 검사 A 의 민감도는 90 %, 특이도는 95 % 이다. 의사가 같은 날 채취한 혈액으로 원리가 다른 검사 B(민감도 90 %, 특이도 95 %)를 추가로 시행하였고 역시 양성이었다. 질병 유무가 같을 때 두 검사의 결과는 서로 독립이라고 가정한다. 이 남자가 실제로 대장암일 확률에 가장 가까운 것은?

- A. 87 %
- B. 27 %
- C. 50 %
- D. 81 %
- E. 99 %

## 정답 및 해설
> 정답: A

- **정답 핵심**: 10,000명으로 계산한다. 환자 200명 중 검사 A 양성은 180명, 비환자 9,800명 중 위양성은 490명이므로 A 양성의 양성예측도는 180/670 ≈ 27 % 다. 검사 B 는 독립이므로 A 양성 670명에 다시 적용한다 — 환자 180명 중 162명, 비환자 490명 중 24.5명이 B 양성이다. 두 검사 모두 양성인 사람 중 환자의 비율은 162/186.5 ≈ 87 % 다. 같은 식으로, 사전 확률 27 % 가 2차 검사의 사후 확률 계산에서 새 「유병률」이 된다.
- **원리**: <b>왜 같은 검사라도 양성예측도가 낮은가</b>: 양성예측도는 검사 성능만이 아니라 검사받는 집단의 유병률에 달려 있다. 유병률 2 % 에서는 비환자가 49배 많아서, 특이도 95 % 의 위양성 5 % 만으로도 비환자 쪽 양성(490명)이 환자 쪽 양성(180명)보다 훨씬 많다.<br> <b>왜 2차 검사가 확률을 크게 올리는가</b>: 1차 양성 집단은 유병률이 27 % 인 새로운 집단이다. 이 집단에 두 번째 독립 검사를 하면 위양성이 다시 5 % 로 걸러져 490명 → 24.5명으로 줄고, 환자는 90 % 가 남는다. 직렬 검사(둘 다 양성이어야 양성)는 <b>특이도를 높이고 민감도를 낮춘다</b>(민감도 0.9 × 0.9 = 81 %).<br> <b>왜 독립 가정이 필요한가</b>: 두 검사가 같은 원리(같은 표지자)를 보면 위양성이 같은 사람에게 겹쳐 생겨 2차 검사가 위양성을 걸러 내지 못한다. 실제로는 원리가 다른 검사를 짝지어야 이 계산에 가까워진다.
- **비교**: <table><thead><tr><th style="width:24%">구하는 값</th><th style="width:38%">두 검사 모두 양성의 양성예측도(정답)</th><th>1차 검사만의 양성예측도(가장 가까운 오답)</th></tr></thead><tbody> <tr><td>환자 중 양성</td><td>200 × 0.9 × 0.9 = 162</td><td>200 × 0.9 = 180</td></tr> <tr><td>비환자 중 양성</td><td>9,800 × 0.05 × 0.05 = 24.5</td><td>9,800 × 0.05 = 490</td></tr> <tr><td>양성예측도</td><td><b>162 / 186.5 ≈ 87 %</b></td><td>180 / 670 ≈ 27 %</td></tr> </tbody></table> 81 % 는 직렬 검사의 민감도(0.9 × 0.9)이고 양성예측도가 아니다 — 무엇을 분모로 두는지 먼저 정한다.
- **오답 이유**:
  - ② 27 % 는 검사 A 하나만 양성일 때의 양성예측도로, 검사 B 를 시행하지 않았거나 B 가 A 와 완전히 같은 결과를 주는 검사일 때 정답이 된다.
  - ③ 50 % 는 유병률을 고려하지 않고 「양성이면 반반」으로 직관할 때 나오는 값으로, 환자와 비환자 쪽 양성 수가 같을 때만 정답이 된다.
  - ④ 81 % 는 두 검사를 직렬로 시행했을 때의 민감도(0.9 × 0.9)로, 환자 중 두 검사 모두 양성인 비율을 묻는 문항일 때 정답이 된다.
  - ⑤ 99 % 는 두 검사 모두 음성일 때 대장암이 아닐 확률(음성예측도)에 가까운 값으로, 음성 결과의 해석을 물을 때 정답에 가깝다.
- **함정**: 특이도 95 % 면 양성일 때 95 % 암이라고 생각하거나, 직렬 민감도 81 % 를 양성예측도로 착각하는 것.
- **학습목표**: 유병률·민감도·특이도로 1차 양성예측도를 구하고, 독립인 2차 검사 양성을 더해 사후 확률(양성예측도)을 다시 계산한다
