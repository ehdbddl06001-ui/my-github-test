## Overview
`ailab-2026-0015`(모델 구조 퀘스트)가 **"어떻게 학습하나"** 라면, 이 카드는 **"무엇을 정상이라
부르고, 단일유도로 무엇까지 진단할 수 있나"** 를 정한다. 모델에 넣을 **정상 판정 규칙세트**와
**질환 라벨 범위**의 원본(Source of Truth)이다.

핵심 결론 3줄:
1. 정상 기준은 **상수가 아니라 조건부**다(연령·성별·심박수·체형). 상수 규칙을 그대로 넣으면
   노인·운동선수·서맥 환자가 전부 비정상이 된다.
2. **단일유도 측정값에 12유도 기준치를 그대로 쓰면 안 된다.** 유도 하나로 잰 QRS·QT는
   구조적으로 **더 짧게** 나온다(그 유도에서 등전위인 시작·끝 구간이 안 보임). 임계값 재보정 필요.
3. 라벨을 **질환이 아니라 소견(finding) 우선**으로 설계해야 한다. lead II가 관측할 수 있는 건
   소견이고, 질환은 소견 + 유도 가용성의 함수다.

## 1. 정상 ECG 판정 규칙세트

### 1-1. 기준표

| 항목 | 정상 기준 | 출처·주의 |
|---|---|---|
| 리듬 | 동율동: 모든 QRS 앞에 P, P가 **II 양성 / aVR 음성**, PR 일정 | AHA Part III |
| 심박수 | 60–100 bpm | <60 서맥, >100 빈맥. 운동선수·수면 시 40대도 정상 변이 |
| P 지속 | < 120 ms (lead II) | ≥120 ms = 좌심방 확대 시사 |
| P 진폭 | ≤ 0.25 mV (2.5 mm, lead II) | **논쟁 있음**: 최근 문헌은 0.15 mV를 우심방 확대 기준으로 제안 → `confidence: medium` |
| PR 간격 | 120–200 ms | >200 = 1도 AV 차단. 고령에서 210~220까지 허용하는 문헌 있음(충돌 → 조건부 처리) |
| QRS 지속 | **AHA: < 110 ms** / **Harrison·통용: < 120 ms** | 110–119 = 비특이적 지연. **출처 충돌 → 두 값 모두 보관, 임계값은 실험으로 결정** |
| QRS 축 | −30° ~ +90° | 일부 교과서 −30 ~ +100. **lead II 단독으론 측정 불가** |
| Q파 | 중격성 q: <30 ms, R의 <25% | 병적 Q: ≥30 ms(문헌따라 ≥40 ms) + 깊이 기준, 인접 2유도 이상 |
| ST 분절 | J점 편위 < 0.1 mV | 예외(V2–V3): 남<40세 ≥0.25, 남≥40세 ≥0.2, 여 ≥0.15 mV = 상승 — 4th UDMI 2018 |
| T파 | I·II·V3–V6 양성, aVR 음성 | III·aVL·V1(여성 V2) 역위는 정상 가능 |
| QT/QTc | QTc ≤450 ms(남) / ≤460 ms(여) | Bazett. **AHA Part IV는 극단 심박수에서 Bazett 비권고 → Fridericia/Hodges 병기** |
| 짧은 QT | QTc < 390 ms면 짧음 | SQTS 진단은 더 낮은 값(ESC 계열 ≤340) + 임상소견 필요 |
| U파 | T 진폭의 <25%, V2–V3에서 가장 잘 보임 | 두드러지면 저칼륨혈증 시사 |
| 저전압 | 사지유도 모두 <0.5 mV 또는 흉부 모두 <1.0 mV | **단일유도로 판정 불가** |
| R파 증가 | V1→V6 정상 증가, 이행부 V3–V4 | **단일유도로 판정 불가** |

### 1-2. "정상이라고 불러야 하는" 정상 변이 (오탐 방지 — 별도 화이트리스트 필수)
호흡성 동성부정맥 · 조기재분극 양상(양성형) · 운동선수 심전도(동서맥, 1도 AV 차단,
불완전 우각차단, 단독 전압기준 LVH, 조기재분극 — 2017 International Criteria) ·
소아·청소년 juvenile T 역위(V1–V3) · 드문 심실조기수축 · 유도 위치 변이.

> **이걸 안 넣으면 모델의 특이도가 무너진다.** PPT의 "정상만 학습" 데이터에 이 변이들이
> 충분히 들어있는지 반드시 확인할 것(→ Fantasia로 연령 변이, PTB-XL NORM으로 형태 변이).

### 1-4. ★ 단일유도 측정 보정 (거의 모든 논문이 놓치는 지점)
교과서 기준치는 **12유도 동시 기록에서 "가장 이른 onset ~ 가장 늦은 offset"** 으로 잰 값이다.
유도 하나만 보면 그 유도에서 등전위인 시작·끝이 안 보여 **QRS·QT가 수~십수 ms 짧게 측정**된다.
→ `QRS ≥ 120 ms` 를 lead II 측정값에 그대로 적용하면 **각차단을 놓친다.**
→ 대응: LUDB/QTDB에서 **(단일유도 측정값 ↔ 12유도 global 측정값) 회귀를 먼저 학습**해
   보정항을 구하고, 그 위에서 임계값을 적용한다. (실험 큐에 넣을 것 — `ailab-2026-0015`)

## 2. 단일유도(lead II)로 어디까지 가능한가

lead II는 **하벽 방향(+60°)의 1차원 투영**이다. 그래서 **심방 활동(P파)과 리듬을 보는 데는
12유도 중 최고**이고(역행 P·조동파가 가장 잘 보이는 유도), **국소화·벡터 진단에는 무력**하다.
근거: PhysioNet/CinC 2021 "Will Two Do?" 가 정확히 이 질문을 다뤘고 **2유도 구성이 I + II** 였다.

### Tier A — lead II 단독으로 진단 가능 (질환 라벨로 써도 됨)

| 질환/리듬 | lead II에서의 근거 |
|---|---|
| 정상 동율동 / 동성 서맥 / 동성 빈맥 / 호흡성 동성부정맥 | P 축·PP 규칙성 |
| 동정지·동휴지, 동방차단, **동기능부전증후군(SSS)** | 장시간 기록 필요 |
| **PAC(S) / PVC(V) / 융합(F)**, 이단맥·삼단맥·연발 | 조기성 + **보상휴지 물리**(퀘스트 A-4) |
| **심방세동(AF)** | P 소실 + f파 + RR 절대 불규칙 |
| **심방조동(AFL)** | **톱니파가 II·III·aVF에서 가장 잘 보임 — lead II가 최적 유도** |
| **AVNRT** | **가성 S파(pseudo-S)가 하벽유도 = lead II의 고전적 소견** |
| 심방빈맥(AT), 다소성 심방빈맥(MAT), 유주 심박조율(WAP) | P 형태 다양성 |
| **접합부 리듬·접합부 이탈** | **역행 P(II에서 음성) — lead II가 진단 유도** |
| **1도 / 2도 Mobitz I(Wenckebach) / Mobitz II / 3도 AV 차단** | **리듬 스트립의 표준 유도가 II** |
| 심실빈맥(VT) — "wide-complex tachycardia + AV해리·capture/fusion" 수준 | 형태 감별(Brugada/Vereckei 알고리즘)은 흉부유도 필요 |
| 심실세동(VF), 무수축, 촉진성 심실고유리듬(AIVR) | |
| **Torsades de Pointes** | 진폭 회전이 단일유도에서도 보임 |
| **긴 QT / 짧은 QT** | **QT 측정 표준 유도가 II와 V5** |
| **고칼륨혈증** | 뾰족한 T → P 소실 → QRS 확장 (전부 II에서 관측) |
| 디기탈리스 **중독 부정맥**(차단 동반 심방빈맥, 양방향성 VT) | |
| 인공심박동기 리듬 / 페이싱 스파이크 | |
| **노이즈·아티팩트**(기저선 동요, 근전도, 전극 이탈) | ★ **반드시 별도 클래스로** |

### Tier B — 의심·스크리닝만 (단독 확진 금지 → "12유도 필요" 출력 동반)

| 질환 | lead II에서 얻는 것 / 부족한 것 |
|---|---|
| 저칼륨혈증 | T 평탄·U파 → 얻음. U는 V2–V3가 최적이라 민감도 낮음 |
| 고칼슘혈증 / 저칼슘혈증 | ST 길이·QT 변화 → 얻음. 특이도 낮음 |
| 좌·우심방 확대(P mitrale/pulmonale) | P 형태 → **부분 가능**. 확진엔 V1 종말음성력 필요 |
| 각차단(LBBB/RBBB) | **"QRS ≥120 ms"까지만.** 좌우 구분은 V1·V6 형태 필수 |
| 급성 심낭염 | **PR 분절 하강 + 오목한 ST 상승이 II에서 관측** → 의심 가능. 광범위성 확인 불가 (ESC 2025 심근염·심낭염 지침) |
| 조기재분극 | J점 상승이 하벽유도에 흔함 → 의심 가능 |
| 저체온증(Osborn J파) | J파가 II·V5–V6에 두드러짐 → 의심 가능 |
| 심장눌림증(tamponade) | **전기적 교대(electrical alternans)는 단일유도로도 관측 가능**. 저전압은 불가 |
| LVH / RVH / HCM / DCM / RCM | 전압 기준이 흉부유도 기반 → 사실상 불가. 이차 변화(ST-T strain) 힌트만 |
| 심근염 | 비특이 → 의심만 |
| **하벽 심근허혈/경색** | **lead II ST 상승·Q파는 진짜 신호**. 다만 확진은 III·aVF 동반 필요 → **"하벽 ST상승 소견"이라는 소견 라벨까지만** |

### Tier C — lead II로 원리적으로 불가 (학습 라벨에서 제외하거나 abstain 처리)

STEMI 국소화 전부(전벽·측벽·**후벽**·**우심실**) · NSTEMI · 불안정협심증 ·
**Wellens 증후군**(V2–V3) · **De Winter T파**(V1–V6) · **브루가다 증후군**(V1–V2 전용) ·
**ARVC의 엡실론파·V1–V3 T역위** · **LAFB / LPFB**(축 측정 필요) · R파 증가 이상 ·
저전압 · 폐색전증의 **S1Q3T3**(I·III 필요) · 폐고혈압의 우축편위 · 전극 위치 오류 판정.

> **PPT의 44질환 중 실제로 lead II 단독 학습 가능한 것은 절반 수준이다.**
> 나머지를 그대로 라벨로 쓰면 모델은 **관측 불가능한 것을 추측하도록 훈련**된다(= 환각 학습).
> 이것이 `ailab-2026-0015` 실험0 "라벨-유도 정합성 필터"가 최우선인 이유다.

## 4. 라벨 온톨로지 제안 (finding-first)

```
Level 0  normal / abnormal / uninterpretable(noise)
Level 1  ├ rhythm      : sinus, AF, AFL, SVT, VT, VF, junctional, paced, asystole …
         ├ ectopy      : PAC, PVC, fusion, escape, bigeminy/trigeminy/couplet
         ├ conduction  : 1°AVB, Mobitz I, Mobitz II, 3°AVB, wide-QRS(≥120), short-PR
         ├ morphology  : peaked-T, flat-T, inverted-T, U-prominent, ST↑, ST↓, PR↓,
         │               pathologic-Q, long-QT, short-QT, J-wave, electrical-alternans
         └ quality     : baseline-wander, EMG, electrode-motion, saturation
Level 2  disease  = f(findings, lead availability, clinical context)
직교 헤드 AAMI beat class {N, S, V, F, Q}          ← PPT 설계 그대로 유지 (옳음)
직교 헤드 abstain: "이 소견 조합은 단일유도로 확정 불가 → 12유도 권고"
```

**왜 이게 PPT보다 나은가**: PPT의 "판단신호"가 사라지지 않고 **Level 1 = 판단신호 자체**가 된다.
질환 라벨은 데이터셋마다 정의가 다르지만(PTB-XL SCP vs Chapman vs mitdb), **소견은 데이터셋을
가로질러 공통**이다 → **여러 공개 데이터셋을 한 라벨공간으로 합칠 수 있는 유일한 방법**이기도 하다.
그리고 진단 근거가 자동으로 남는다: `RR 불규칙 + P 소실 + f파 → AF (0.93)`.
