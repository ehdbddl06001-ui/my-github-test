## 이 실험이 물은 것

**"코호트를 건너면 무엇이 먼저 무너지는가"** 를 축마다 **같은 자**로 재는 것.

지금까지 축마다 지표가 달랐다 — 형태(MI)는 AUROC, 비트(S·V)는 PR-AUC.
PR-AUC 는 유병률에 붙어 있어 코호트를 가로지르는 비교가 불가능하다(R4).
그래서 저장된 확률에서 **AUROC 를 다시 뽑아** 같은 표에 올렸다.

사전등록 가설: **S(심방조기박동)는 '평소보다 이르다'는 개인 기준 상대량이라 전이가
어렵고, V(심실조기박동)는 '넓은 QRS'라는 형태라 기기 불변이다.**

## 관찰

### ① 가설이 반대였다 — **형태 축이 먼저 무너진다**

`V` 낙폭 **+0.1124**(환자 CI 0 제외)로 표에서 가장 크다. 12유도 MI 부위 낙폭
(+0.0877 ~ +0.1246, 실험20)보다도 크거나 비슷하다. `S` 는 미결이다.

**왜 그런가 (의대생 버전).** PVC 를 "QRS 가 넓다"로 정의하는데, **QRS 가 얼마나 넓어
보이는지는 유도·전극 위치·필터 대역에 달려 있다.** MIT-BIH 는 2유도(MLII+V1/V5),
INCART 는 12유도 홀터다. 같은 PVC 라도 다르게 찍힌다.

반면 PAC 는 "평소보다 이르다"이고 **RR 간격은 시간**이다. 30% 이른 박동은 어느
기계로 재도 30% 이르다. **개인 기준이기 때문에 오히려 기기 불변**이다.

→ "형태는 객관적이고 타이밍은 주관적"이라는 직관이 **전이 관점에서는 거꾸로**다.

### ② 리듬 축은 S 만 구하는 게 아니라 **V 도 안정시킨다**

`V` 낙폭이 v1 **+0.1124** → v2 **+0.0209** 로 **5.4배 축소**된다(둘 다 환자 CI 0 제외).
within 은 0.9944 → 0.9979 로 천장이라 거의 안 변하는데 cross 가 0.8820 → 0.9769 로
올라서 생긴 축소다. **리듬 맥락이 있으면 모델이 부서지기 쉬운 형태에 덜 의존한다.**
웨어러블 배포(실험17·18) 관점에서 실용적으로 중요하다.

### ③ 【방법론】 **채점 단위가 결론을 뒤집는다**

같은 확률, 채점만 바꿨는데:

| | 전역 낙폭 | 환자 매크로 낙폭 |
|---|---:|---:|
| v1 raw S | −0.0181 | **+0.0663** |
| v2 raw S | +0.0321 | **−0.0158** |
| P-B | **−0.0502** | **+0.0821** |

**S 는 v1·v2 모두 부호가 뒤집히고, P-B 관문도 뒤집힌다.** 원인은 MIT-BIH DS2 에서
**#232 한 명이 S 의 75.2% 를 갖기** 때문이다 — 전역 S 지표는 사실상 한 명의 지표였다.

P-B 의 부호 반전은 `PAPER.md §6.5` 의 **"리듬 축이 전이를 구해준다"(1.8× → 7.9×)**
가 AUROC 매크로에서 재현된다는 뜻이다. 전역으로 재면 반대로 보였다.

→ 이 발견이 `SCORING_RULES.md` **R11**(맥락정의 클래스는 환자를 단위로 채점한다)
로 규약화됐다.

### ④ BN 적응은 아무것도 못 한다 (§6.5 재현)

`P-C′ = −0.0002` [−0.0043, +0.0050]. 무라벨 도메인 적응으로 배치정규화 통계만
맞춰줘도 회복이 없다 → 성능 하락이 **입력 분포가 달라서(covariate shift)가 아니다.**
**판별에 쓸 축 자체가 없거나 그 축이 옮겨간 것**이다.

### ⑤ 검정력의 벽 — S 는 채점 환자가 8/11명뿐이다

`S` 의 환자 부트스트랩 CI 가 시드 CI 의 **3.3배**로 넓다. 반면 `V` 는 9/52명이라
환자 CI 가 오히려 좁다. **S 에 대해서는 이 코호트로 판정할 수 없다** — 데이터가
부족한 것이지 효과가 없는 것이 아니다(R8: 넓은 쪽으로 판정).

INCART 는 S 지배 지분이 30.1% 로 DS2(75.2%)보다 훨씬 낫다. **S 방법론을 세울
코호트는 INCART 쪽이다.**

## 곁가지 — 2026-07-17 SVDB 증강 실험 회수 (G1)

이 실험 중에 **접혀 있던 07-17 실험**(타 DB 의 S 를 학습에 섞기)을 되살렸다.
당시 "전역 PR-AUC −0.219" 를 보고 S 가 망가졌다고 판단해 중단했던 것이다.

| 단계 | 결론 | 무엇이 뒤집었나 |
|---|---|---|
| 원래 | F1 −0.1229 → "S 악화" | — |
| G1-b | PR-AUC −0.2194 · AUROC 미결 → "**판별력** 손상" | 순위 지표 3종 |
| G1-c | #232 **안에서는 개선** → "**구성 효과**" | 층화 |
| G1-d | 정규화로 **95.4% 회복** → "**환자 간 눈금**" | 레코드내 순위정규화 |
| G1-d 부트스트랩 | 매크로 개선은 **#213 하나**가 만든 값 | 레코드 부트스트랩 |

**서는 것**: 전역 하락의 95% 는 환자 간 점수 눈금이 깨져서다. 환자 **안의** S
판별력은 거의 안 변했다(대부분 |Δ| < 0.03). **"타 DB S 를 섞으면 S 표현이
망가진다" 는 성립하지 않는다.**

**안 서는 것**: "증강이 S 를 개선했다" — 매크로 +0.0631 은 #213(S 28개, Δ +0.4857)
하나가 110% 를 기여했고, 7개 중 5개는 악화다. 레코드 부트스트랩 CI 가 0 을 포함한다.

기전: 진짜 S 가 9·7·0 개뿐인 #210·#219·#221 이 S 점수 상위 1,808 슬롯을 **497개**
가져가 #232·#222 의 진짜 S 를 밀어냈다. 진짜 S 가 379개 빠지고 N 이 378개 채웠다.

부수 성과 — 07-17 실행의 정체가 확정됐다(`mit-bih/forensics_0717_split.py`):
`train ∪ val = DS1` · `test = DS2` 정확히 일치 · 환자 누수 0 · 4클래스(F 포함) ·
데이터 손실 3,260비트는 **#228(80.6%)+#114(46.0%) 두 레코드가 77%** 를 차지.
