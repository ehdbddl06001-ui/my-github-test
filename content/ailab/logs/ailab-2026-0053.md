## ① ★ `#865` — AUROC **0.0595**. 모델이 이 환자에서 **뒤집혔다**

| | |
|---|---|
| AUROC | **0.0595** (SE **0.0044** — 실패 목록 중 가장 촘촘하다) |
| S 개수 | **1,818** = SVDB 전체 S 의 **14.9%** |
| **S 유병률** | **0.5764** — 이 레코드는 **S 가 다수 클래스**다 |

AUROC 0.06 은 "못 맞힌다" 가 아니라 **"거꾸로 맞힌다"** 는 뜻이다. S 비트가 N 비트보다
**일관되게 낮은 점수**를 받는다. SE 가 0.0044 라 잡음도 아니다 — **확신에 찬 역전**이다.

### 구조적 가설 — 이건 이 퀘스트의 명제가 실측으로 나타난 것이다

S 는 **"이 환자의 평소보다 이르다"** 는 **상대량**으로 정의된다. 우리 표현은 그 상대성을
레코드 내부에서 계산한다:

- `_medref` — 환자별 **중앙 파형**을 기준으로 삼는다
- RR innovation — 환자별 **MAD** 로 정규화한다

그런데 **비트의 57.6% 가 S 라면 그 '환자의 평소' 자체가 S 리듬**이다. 기준이 S 쪽으로
옮겨가므로 상대 특징이 뒤집히고, **오히려 N 비트가 '이상한 쪽'** 이 된다.

⚠️ **가설이다. 개체가 1개다.** 유병률 > 0.5 인 레코드가 전수에 이것 하나뿐이라
상관을 볼 표본이 없다. Q7-D 에서 확인한다.

임상적으로도 말이 된다: SVDB 는 상심실성 부정맥 전용 DB 이고, **심방 이단맥(bigeminy)**
이면 두 박동 중 하나가 APB 라 유병률이 50% 근처가 된다. 다만 `#865` 가 실제로 무엇인지는
`aux_note` 리듬 라벨을 봐야 안다 — **여기서 단정하지 않는다.**

## ⑤ ⚠️ SE 관문은 **'확신에 찬 오답'을 못 잡는다**

P2(최대 부트 SE ≤ 0.10)가 0.0824 로 통과했다. 그런데 **가장 망가진 개체 `#865` 의 SE 는
0.0044** — 실패 목록에서 **가장 촘촘하다.**

SE 는 "이 값을 얼마나 믿을 수 있나" 를 재지 "이 값이 좋은가" 를 재지 않는다. 모델이
**일관되게 틀리면** SE 는 오히려 작아진다(R15-b 의 천장 효과와 같은 구조 — 이번엔
**바닥** 쪽이다).

→ **정밀도 관문 통과를 성능 근거로 읽지 않는다.** 관문은 '잴 수 있다' 는 말이지
'좋다' 는 말이 아니다.
