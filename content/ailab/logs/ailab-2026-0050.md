## ① 점추정이 **정확히 1.0000** 이다 — 이게 전부를 말한다

가중 매크로가 뱉은 S AUROC 는 `1.0000`, CI 상한도 `1.0000` 이다. 모델이 완벽해진 게
아니다. **가중이 AUROC 가 1 에 붙은 개체로 빨려간 것**이다.

이유는 잡음이 아니라 **구조**다:

```
AUROC 는 천장이 1 이다.
개체의 분리가 완벽에 가까우면 → 부트 재표집이 거의 늘 같은 값을 낸다
                            → 부트 SE → 0
                            → w = 1/SE²  →  ∞
```

즉 **역분산 가중은 '가장 쉬운 개체' 에 무한대 가중을 준다.** 픽스처에서 잡았던
"SE 추정 잡음이 증폭된다" 보다 한 단계 더 나쁘다 — 잡음은 방향이 없지만 이건
**천장 쪽으로 편향**된다. Q8-3 이 기각된 게 그 증거다: 가중 CI 가 단순 점추정을
**품지 못했다**(0.9599 가 [0.9882, 1.0000] 밖).

ESS 2.0 · 최대가중 55.8% 이므로, 실질적으로 **두어 개체**의 값이다. 27개를 받았다는
말은 장부상의 숫자다.

## ② 양성수 가중의 최대가중 30.2% = INCART 지배 지분 30.1%

우연이 아니다. `w = n_pos` 로 두면 정의상

```
최대 가중 = max(n_pos) / Σ n_pos = 지배 지분
```

이다. 즉 **양성수 가중은 매크로를 전역(global) 지표 쪽으로 되돌린다.** 완전히
되돌리면 그게 바로 풀링한 전역 지표다. 그런데 R11 은 전역 지표를 피하려고 만든
규칙이다 — **양성수 가중은 R11 을 되감는 방향**이다.

픽스처 합성 코호트에서 양성수 가중이 좋아 보였던 건 거기서 `n_pos` 가 개체마다
**같았기** 때문이다(그러면 균등 가중과 동일하다). 지배당하는 실제 코호트에서는
ESS 5.3 으로 무너졌다. **내가 픽스처에서 '잡음 없는 안전한 대안' 이라고 쓴 건
과했다** — 잡음이 없을 뿐이지 지배에는 오히려 더 직통이다.

## ④ 픽스처가 맞힌 것 · 놓친 것

노트북을 돌리기 전에 합성 데이터로 예측한 것:

- ✅ **맞음**: "CI 폭이 좁아지는데 ESS 는 무너진다." 합성 −46.6%/ESS 1.8 →
  실측 **−64.3%/ESS 2.0**. 판독 순서 규칙(ESS 기각이면 CI 폭 안 읽음)이 그대로 작동했다.
- ❌ **놓침**: 천장 효과. 합성 데이터는 분리도를 0.85 근처로 깔아서 AUROC 가 1 에
  붙는 개체를 안 만들었다. 그래서 `1/SE² → ∞` 를 못 봤다. → **합성 시나리오에
  '완벽 분리 개체' 를 반드시 넣어야 한다**(R14-b).
- ❌ **놓침**: `w = n_pos` 의 최대가중이 지배 지분과 **같다**는 항등식. 합성에서
  `n_pos` 를 균등하게 줬기 때문에 안 보였다.

## ⚠️ 한계

**`se > 0` 필터가 모든 arm 에 걸려 있다.** 역분산 가중의 0 나눗셈을 막으려고 넣은
조건인데, **단순 매크로 arm 에서도** 완벽 분리 개체(SE = 0)를 떨궈낸다. 단순 매크로의
개체 수·CI 폭이 그만큼 낙관/비관 어느 쪽으로든 흔들릴 수 있다. → 노트북에서 이
필터를 **역분산 arm 에만** 걸도록 고쳤고, 떨어진 개체 수를 로그에 남기게 했다.

결론은 안 바뀐다: 결정 관문은 Q8-4(ESS 2.0)이고 그건 단순 arm 과 무관하며,
역분산의 실패는 구조적이라 개체가 몇 개 더 들어와도 같다. **재실행은 필요 없다.**
