> **과소**추정시킨다. Q7-N §8 이 세운 「침입이 헤드라인을 만들었다」 가설은
> **관측과 반대 방향**이고, 이 실행이 그걸 기각한다.

## 3. ★★ P1 이 답을 못 준 진짜 이유 — 검정력이 아니라 모집단

표면 수치는 검정력 이야기로 보인다.

```

```

**그런데 본질은 다르다.** 마스크가 요구한 `pre` ≥ **262샘플**은 중앙 RR(≈282)의 **93%** 다.
즉 **거의 조기가 아닌 S 만** 살아남는다. 결정적 증거는 n 이 아니라 **부호 반전**이다:

|---|---:|---:|

보상성 휴지가 **약해진 게 아니라 뒤집혔다.** SAFE 9명은 **느슨하게 결합한 SVEB** 라는
다른 모집단이다. 거기서 P 창이 뭘 하는지는 SVEB 일반에 대해 거의 정보를 주지 않는다.

> **P1 은 헤드라인을 구제할 수도 반증할 수도 없는 설계였다.** 실행 실패가 아니라

## 4. ★ 사다리 정정 — `raw` 가 앵커다 (R31 ③ 의 적용을 내가 틀렸다)

`p_full − stt` · 전체 55개체:

```
raw +0.0469  |  lin +0.0745 → hist +0.0621 → quad +0.0564 → rank +0.0466 → strat +0.0314
└ 무통제      └────────────────── 통제 축 ──────────────────┘
```

**교란이 차이를 만든다면 무통제인 `raw` 가 최댓값이어야 한다. 아니다.** `lin` 이 `raw`
보다 높다. 그러므로 `lin → strat` 의 단조 감쇠는 「교란이 제거되는 과정」이 아니라
**「잔차화가 부풀린 것이 기저가 촘촘해지며 꺼지는 과정」**이다.
**실제 통제 효과는 `raw → strat` = −0.0155 뿐이다.**

- Q7-N §5 가 「용량-반응 = 잔여 교란」이라 부른 것은 **잔차화 인공물**이었다.
- 이 카드 초판이 같은 오독을 반복했다. **`raw` 를 사다리에서 빼라**고 적은 §6 은 정확히
  거꾸로였다 — `raw` 야말로 그 오독을 막는 유일한 장치다. → **R32 ②**
- 진단 정확도로 보면 **R31 ⑤**(잔차 AUROC 는 팔 간 비교 불가)가 R31 ③ 보다 옳았다.

**그래도 Q7-N 의 「폭 85 우월성 지지(+0.0745)」는 철회된다** — 이유가 바뀔 뿐이다.
잔차화가 부풀린 값이고, 주 추정치는 **+0.0314 [−0.0318, +0.0942]** 로 0 을 못 뗀다.

## 5. ★ 창 안에서는 늦은 쪽이 이긴다 — 그런데 그게 P 파가 아닐 수 있다

`p_early − p_late`(둘 다 폭 32) 사다리 · 전체:

```
raw +0.0325 → lin +0.0311 → hist +0.0300 → quad +0.0200 → rank +0.0007 → strat −0.0826
```

층별로 보면 이 실행의 **유일한 유의 결과**가 나온다:

| 층 (전체 코호트) | n | `p_early − p_late` |
|---|---:|---|
| **고립 S** | **42** | **−0.1254 [−0.2218, −0.0277]** ← CI 가 0 을 뗀다 |
| 혼합 | 12 | +0.0946 [−0.0749, +0.3380] |
| 런 우세 | 5 | 측정 불가 |

⚠️ 사전등록 관문이 아니고 다중검정 보정도 없다 — **강한 단서이지 확정이 아니다.**

### ★ 그런데 이게 「P 형태」 서사와 안 맞는다

창을 ms 로 놓고 보면:

```
p_early = R−278 ~ −189ms   ← 정상 PR 에서 **P 파 본체**가 있는 자리
p_late  = R−131 ~  −42ms   ← PR 분절 + P 종말부, 그리고 **끝단이 QRS 개시(≈R−45ms)에 물린다**
```

SVEB 는 이소성 심방 초점이라 PR 이 오히려 **길어지는** 경향이 있다 → P 파는 **더 앞쪽**
(`p_early`)에 있어야 한다. **그런데 P 파가 더 많이 든 창이 두 배 못한다.**

> **대안 가설: 지금 잡히는 건 P 형태가 아니라 PR 분절 / QRS 개시 형태(이상전도)다.**
> SVEB 의 aberrancy 는 실재하므로 사실이어도 발견은 발견이지만, **결론 문장이 완전히
> 달라진다.** 그리고 이건 값싸게 가를 수 있다(§9 Q1).

## 8. 잘 된 것 · 규칙이 역효과를 낸 것

**P7 — 「순수 특징 null = 0.5」 가정은 옳았다(재서 확인).** 이탈 최대 [all] 0.0017 ·
[safe] 0.0075, 여유 ±0.02 안. Q7-N 의 미측정 가정 하나가 해소됐다. 반대로 **학습이 낀

부호 반전**이다. 이대로면 앞으로 모든 런이 음수로 끝난다.
→ **양의 초과분 중 max**([all] `f2_5` +0.1197)로 바꾸고, 음의 초과는 **과잉보정 진단**으로

「통제가 강해서」가 아니라 **「추정량이 다르고 시끄러워서」**일 수 있다.
→ **AIPW/이중강건**으로 가는 게 이 표본 크기에서 정공법이다. → **R32 ⑥**
