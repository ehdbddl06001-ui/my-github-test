## 2. ★ J1 의 「기각」은 내가 만든 것이다 — 바닥 구성 편향

관문 J1 은 R24-b ⑥ 을 그대로 코드로 옮긴 것이다: 영가설을 우연 0.5 가 아니라
**개체별 `max(정합 f1, 정합 STT)`** 로 잡았다. 문제는 **문턱을 0 으로 뒀다**는 것이다.

| | 매크로 |
|---|---:|
| `f1ₘ` | 0.5331 |
| `STTₘ` | 0.5708 |
| **바닥 = 개체별 `max`** | **0.6440** |
| `f3ₘ` | 0.5735 |

**바닥이 두 성분 중 어느 쪽보다도 0.073 높다.** 이건 신호가 아니라 `max` 의 성질이다 —
잡음 있는 추정치 둘의 개체별 최댓값은 각각의 평균보다 위로 뜬다(`E[max] ≥ max[E]`).
그러니 **`f1`·`STT` 와 실력이 똑같은 제3의 특징도 이 바닥에는 진다.** J1 의 문턱 0 은
틀린 문턱이다.

숫자가 정확히 그렇게 말한다:

```
바닥 팽창      = 0.6440 − 0.5708 = +0.0732
J1 본항 − 참고항 = (−0.0705) − (+0.0028) = −0.0733
```

**J1 의 −0.0705 는 전부 바닥 팽창이다.** 편향 없는 짝지은 비교는 참고 두 줄이고,
둘 다 0 을 걸친다:

- `f3ₘ − f1ₘ` **+0.0405** [−0.0161, +0.0943]
- `f3ₘ − STTₘ` **+0.0028** [−0.0802, +0.0835]

→ **`f3` 의 정직한 판정은 「기각」이 아니라 「미결」**이다. Q7-I 의 `I3 ✅` 는 취소되지만
Q7-I″ 가 그 자리를 채우지 못했다. `RuntimeWarning: All-NaN slice` 도 같은 자리에서
났다 — 두 팔이 모두 NaN 인 개체가 있어 `nanmax` 가 경고했고, 그 개체는 `MOK` 에서
빠지므로 값에는 영향이 없다(단, `np.nanmax` 를 마스크 안에서만 부르도록 고쳐야 한다).

**J2 의 참고항(`LR(f3,f4)ₘ − max` = −0.0246)도 같은 편향을 쓴다.** J2 의 본항
(`LR(f3,f4)ₘ − f1ₘ` = **+0.0864** [+0.0296, +0.1445])은 짝지은 정직한 비교라 편향이
없지만, **J3 이 미결이라 인용하지 않는다** — 대역 안에 조기성이 남아 있으므로
`f3`·`f4` 가 그걸 다시 주워 담았을 수 있다.

→ **R25** 로 규칙화했다.

## 3. 「닫혔다」고 쓰려다 멈췄다 — 정합기를 감사한 적이 없다

Q7-I 와 Q7-I″ 두 번을 「정합 조건에서 형태·`post_rr` 가 남는가」에 썼다. 결과:

- **정합은 원리적으로 이 질문에 안 맞는다.** S(상심실 조기박동)는 **정의가 조기성**이다.
  `pre_rr` 을 정합한다는 건 S 를 S 이게 하는 축을 없애는 것이고, 완전히 없애면
  **남은 표본이 S 의 대표가 아니다**. 실제로 대역을 좁혀도 `f1` 이 0.53 에서 멈춘
  게 그 증거다 — 없앨수록 「조기성이 우연히 작은 S」만 남는 게 아니라 **여전히 81% 가
  남으면서 방향도 남는다**.
- **검정력도 끝났다.** 짝지은 차이 `f3ₘ − f1ₘ` 의 CI 반폭이 ≈0.055(n=33)다. 이걸
  0 에서 떼려면 개체 수가 서너 배 필요한데 **SVDB 는 78개체(채점 가능 59)가 전부**다.
  개체 매크로가 검정력을 버리는 구조이므로, 굳이 더 간다면 **개체를 층으로 둔 비트
  수준 조건부 일치도**로 다시 짜야 한다(→ 큐에 Q7-I‴ 로 기록).

**여기까지 쓰고 「그러니 정합 노선을 접는다」로 끝내려 했는데, 코드를 다시 읽고 멈췄다.**
위 논증의 실증 부분(「좁혀도 `f1` 이 0.53 에서 멈춘다」)이 **정합기 자체를 한 번도
감사하지 않은 채** 나온 값이다. 셋이 걸린다:

1. ★ **`BAND_MIN` 이 가장 좁은 대역을 묶었을 수 있다.** 코드는
   `bw = max(BAND_MIN, bf × 중앙RR)` 이고 `BAND_MIN = 4`(**샘플**)다. `pre_rr` 은
   360 Hz 샘플 단위이므로(픽스처 `base=280` = 778 ms) 중앙 RR 이 ~280 이면
   `0.01 × 280 = 2.8 < 4` — **라벨 0.010 인데 실효는 ~0.014 다.** 0.020(=5.6)은 안 묶인다.
   그래서 마지막 두 점의 실효 간격이 표시보다 훨씬 좁고, `f1` 이 0.5347 → 0.5331 로
   거의 안 움직인 것도 이걸로 설명된다. **가장 좁은 대역은 시험된 적이 없다.**
2. **잔여 격차가 짝 단위가 아니다.** 코드의 `resid` 는 대역 안 **S 집합 중앙 vs N 집합
   중앙**이다. 짝 안에서 얼마나 벌어졌는지가 아니다. 그래서 대역(1%)보다 잔여(4.3%)가
   큰 이상한 표가 나온다.
3. **곡선의 각 점이 다른 코호트다**(46 → 42 → 38 → 33). 정합이 촘촘해진 효과와
   개체가 바뀐 효과가 섞여 **용량-반응 곡선이 아니다.**

→ 셋 다 한 번에 끝내는 방법이 있다: **`pre_rr` 값 자체를 빈으로 쓰는 정확 정합.**
SVDB 는 128 Hz 원본을 360 Hz 로 올렸으므로 RR 은 격자(≈2.8125 샘플) 위에 있고,
**같은 값끼리만 짝지으면 `f1 = 중앙 − pre` 는 빈 안에서 전부 동점 → AUROC 가
수학적으로 정확히 0.5** 다. 그게 안 나오면 정합기 구현이 틀린 것이고, 나오면 그때
비로소 「조기성을 통제했다」고 말할 수 있다. → **Q7-I‴ 로 큐잉**(§8).

**판단: 노선을 접지 않는다. 감사부터 한다.** 원리적 논증(S 는 정의가 조기성)은 그대로
유효하지만, 그걸 **실측으로 확정하려면 정합기가 먼저 옳아야** 한다.

## 4. J4 — `f2` 는 구하려던 환자를 못 구했다

`f2`(전역 중앙 RR 대신 국소 기저선 대비 조기성)는 **전역 중앙 RR 이 오염된 환자**,
즉 혼합·런 층을 구하려고 만든 특징이다. 층별 실측(무정합):

| 층 | 개체 | `f1` | `f2_8` | `f2_16` | 여유(1−`f1`) |
|---|---:|---:|---:|---:|---:|
| 고립 S | 42 | 0.9421 | 0.9492 | 0.9522 | 0.0579 |
| 혼합 | 12 | 0.8952 | 0.9081 | 0.9077 | 0.1048 |
| **런 우세** | 5 | **0.9905** | **0.6606** | 0.7166 | 0.0095 |

- **설계 대상 층(혼합+런 17개체)**: `f2_16 − f1` **−0.0718** [−0.1678, +0.0136] → 미결이지만
  **점추정이 음수**다.
- **대조 층(고립 S · 설계 대상이 아님)**: **+0.0101** [+0.0027, +0.0190] → 여기서만 CI 가 0 을 뗀다.

**⚠️ 처음엔 이걸 「실질 기각」으로 적었는데, 그건 과했다.** 층별 매크로를 보면
혼합 층은 `f1` 0.8952 → `f2_16` 0.9077 로 **올라가고**, 런 우세 층만 0.9905 → 0.7166 로
**무너진다**. 크기로 가중하면 (12·(+0.0125) + 5·(−0.2739))/17 ≈ **−0.072** — 보고된
짝지은 −0.0718 과 사실상 같다. 즉 **J4 의 음수는 런 5개체가 혼자 만든 것**이고,
**방향이 반대인 두 층을 한 관문에 묶은 내 설계 실수**다. 반대 방향을 평균한 값은
「`f2` 가 나쁘다」를 뜻하지 않는다.

런에서 `f2` 가 죽는 이유도 분명하다 — **국소창이 런 안에 갇힌다.** `f2` 의 창은
`k = 8·16` 비트인데 `#865` 의 최장런은 **665** 다. 창이 통째로 런 안에 들어가면 국소
중앙 RR = 런의 RR 이라 런 안의 S 는 「국소 기준으로 이르지 않은」 게 된다. 전역 중앙을
쓰는 `f1` 은 최소한 두 리듬을 걸치므로 살아남는다. **`f2` 의 실패가 아니라 창 길이의 실패**다.

→ **판정 보류**: `f2` 를 폐기하지 않는다. Q7-I‴ 에서 **혼합·런을 따로** 재판정하고,
라벨프리 처방으로 `f6`(= `1 − 국소기저선/전역중앙`, 「내가 리듬 전환 안에 있나」)를
더한 `LR(f1,f6)` 이 런 층을 구하는지 함께 잰다. 고립 층에서 CI 가 0 을 뗀 **+0.0101** 은
그대로 유효하다 — **`f2` 는 설계 대상이 아니던 층에서도 쓸모가 있다.**

## 7. 배운 것

1. **바닥을 `max` 로 잡았으면 문턱을 0 으로 두면 안 된다.** R24-b ⑥ 을 코드로 옮기다가
   정확히 그 규칙 때문에 새 편향을 만들었다. 규칙을 지키는 것과 규칙이 만든 통계량의
   영분포를 아는 것은 다른 일이다 → **R25**.
2. **자기 잠금이 작동했다.** J3 미결 시 J1·J2 인용을 금지하는 문장을 노트북에 미리
   박아뒀고, 그게 이번에 「+0.0864 지지」를 근거로 쓰려는 나를 막았다. 사후에 판단했으면
   분명히 인용했을 값이다.
3. **정합은 클래스 정의에 걸린 변수에는 못 쓴다.** 두 번을 써보고 알았다. 다음부터는
   「정합 대상이 클래스 정의의 일부인가」를 사전등록 단계에서 먼저 묻는다 → **R25 ④**.
4. **판정 기호를 읽지 말고 값과 설계를 읽는다.** J1 은 ❌ 로 찍혔지만 바닥 편향이라
   미결이고, J4 는 ⚠️ 로 찍혔지만 **방향이 반대인 두 층을 묶어서** 애초에 판정 불가다.
   **기호는 코드가 찍고, 판정은 사람이 한다.**
5. **관문을 설계할 때 「이 층들을 하나로 묶어도 되나」를 먼저 묻는다.** J4 는 사전등록
   단계에서 혼합(+)과 런(−)을 한 층으로 정의했다. 사전등록이 있다고 설계가 옳은 건
   아니다 — **사전등록은 사후조정을 막을 뿐, 잘못된 묶음을 고쳐주지 않는다.**

## 8. 다음 실험 — Q7-I‴ `match-exact` (노트북 준비 완료 · 학습 0회)

`notebooks/quest46_q7i3_match_exact.ipynb` · 픽스처 `pipelines/test_quest46_q7i3.py` **14/14 통과**.

| 관문 | 묻는 것 | 예측 |
|---|---|---|
| **K0** | (관문 아님) `pre_rr` 격자 Δ · 대역별 **실효** 폭 · `BAND_MIN` 이 묶었나 · 빈폭/격자 | 0.010 에서 묶임 |
| **K1** ★ | **정확 정합**에서 `f1ₘ` < 0.505 — 동점뿐이라 0.5 여야 한다 | 지지(아니면 정합기 결함) |

| **K7** | `LR(f3,f4,f5)ₘ − LR(f3,f4)ₘ` > 0 — **`f5` 의 짝은 `f1` 이 아니라 `f3` 다** | — |

설계에서 바뀐 것 넷:

1. **`max` 바닥 폐기.** 각 팔을 **자기 라벨셔플 영분포 위의 초과분**으로 환산해 비교한다.
   순수 특징(`f1`·`f3`)의 null 은 0.5 이고, 라벨을 쓰는 팔(`STT`·`LR(·)`)은 셔플로 실측한다.
   → 픽스처 ⑭: 라벨 무작위 코호트에서 초과분 **+0.0137**, 신호 코호트에서 **+0.1209**.
2. ★ **정확 정합.** `pre_rr` 값이 같은 비트끼리만. 픽스처 ⑪ 에서 `f1` 이 **0.500000000**,
   짝 단위 잔여 **0.0** 으로 나온다 — 이게 K1 의 항등식이다.
3. ★ **`f2` 를 정합 조건에서 채점한다.** 가설: **절대 RR 을 정확히 맞춰도 상대 조기성은
   안 맞는다.** 같은 절대 RR 이라도 S 는 **국소 기저선이 긴 자리**에서 나오기 때문이다.
   맞으면 Q7-I″ 에서 `LR(전부)` 가 대역에 전혀 안 움직인 것(0.7783 → 0.7782)이 설명되고,
   **지금까지의 「정합」이 조기성을 통제한 적이 없다**는 뜻이 된다.
   → 픽스처 ⑫: 국소 기저선이 흔들리는 코호트에서 정확 정합 `f2_16` **0.8012**(흔들림 없으면 0.4937).
4. **`f6` 신설**(`1 − 국소기저선/전역중앙` · 라벨프리) — 「내가 리듬 전환 안에 있나」.
   런 층에서 `f2` 가 죽는 원인(창이 런 안에 갇힘)의 처방이고, `LR(f1,f6)` 로 검정한다.

**Q7-I‴ 를 먼저 도는 이유**: `f2` 가 정합 조건에서 살아남으면 §3 의 「정합 노선 종료」
판단 자체가 바뀐다. 정합이 통제한 게 조기성이 아니라 **조기성의 절대 눈금**뿐이었다면,
지금까지 「정합 후 남은 값」이라고 부른 것들의 의미가 전부 다시 매겨진다.
