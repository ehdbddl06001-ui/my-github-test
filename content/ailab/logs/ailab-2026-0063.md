부호가 유지되면서 크기가 **절반으로 단조 감쇠**하는 건 강건성이 아니라
**잔여 교란이 차이의 상당 부분을 만들고 있다**는 신호다 → **R31 ③**.

## 2. ⚠️ N2a 미결 — 절반은 기저 누수, 절반은 **내가 도달 불가능한 여유를 걸었다**

```
f2_5   −0.0110 [−0.0456, +0.0237]  ⚠️ 미결   ← 점추정은 0, **CI 반폭 0.035 > 여유 0.02**
f2_10  +0.0251 [+0.0082, +0.0416]  ⚠️ 미결   ← 0 을 뗀다 = **진짜 누수 ~0.025**
f2_20  +0.0019 [−0.0135, +0.0190]  ✅ 등가
```

**둘을 갈라야 한다.**
- `f2_10` 은 CI 가 0 을 떼므로 **실제 누수**다(크기 ~0.025).
- `f2_5` 는 점추정이 −0.011 로 0 인데 **정밀도가 부족**하다. `±0.02` 등가를 얻으려면
  CI 반폭이 0.009 이하여야 하는데 실측 0.035 다 — **개체 59 로는 원리적으로 불가능**하다.

**내 사전등록 실수다.** N3(등가 여유 ±0.05)는 필요 표본을 미리 계산했는데
(59개체 → 반폭 0.038), **N2 의 `PROBE_MARGIN = 0.02` 는 계산을 안 했다.** R29 ① 을
쓰고 같은 노트북 안에서 절반만 지켰다 → **R30 ①**.

**정확한 진술**: 「기저가 `k` 계열을 못 덮었다」가 아니라 **「누수는 있어도 ≤0.03 규모이고,
그 이하를 판정할 정밀도가 없다」**이다.

## 3. ★ 봉인을 정량으로 푼다 — 누수 크기를 알면 깎아볼 수 있다

봉인은 「수준을 그대로 못 쓴다」이지 「아무 것도 못 쓴다」가 아니다. **누수 크기를
실측했으면 최악의 경우로 깎아서** 결론이 살아남는지 보면 된다.

**누출 바닥은 가장 보수적인 것으로 잡아야 한다** — `f2` 프로브가 아니라 **기저 밖에
남은 리듬 특징**(`f4`·`f5`)이다.

| 차감할 바닥 | 크기 | `STT`(lin) 0.2144 | `STT`(hist) 0.2061 |
|---|---:|---:|---:|
| `f2_10` 누수 상한 | 0.0416 | +0.1728 | +0.1645 |
| `f1_rank` 함수형 | 0.0924 | +0.1220 | +0.1137 |
| **`f4`·`f5` (가장 보수적)** | **0.1180** | **+0.0964** | **+0.0881** |
| `STT` (rank 기저) | — | **+0.2465** ← 오히려 **더 높다** | |

**가장 보수적인 바닥(0.118)을 빼도 +0.09 로 0 을 넘는다.** 다만 마진이 2.3배 줄고,
「형태가 강하게 남는다」가 아니라 **「누출 바닥의 1.7~1.8배로 남는다」**가 정확한 진술이다.

**결정적인 건 마지막 줄이다.** `rank` 기저는 단조 비선형(=`f1_rank` 누수)을 **정의상
흡수**한다. 거기서 `STT` 초과가 줄기는커녕 **+0.2144 → +0.2465 로 오른다.**
→ **함수형 누수가 형태 신호를 만든 게 아니다.** 사전등록해둔 민감도가 바로 이걸
가르려고 있었다 → **R30 ②**.

⚠️ **N4 는 순수 수준량이라 봉인 대상이다.** 처음에 요약이 「이력을 확장해도 형태가
남는다」를 `+0.2061` 에 그대로 얹었는데, **N2a 미결 상태에서 수준을 인용한 것**이라
내가 만든 R27 ② 를 내가 어겼다. **차이형으로 재표현해야 한다** — 보수적 바닥
0.118 을 빼면 **+0.2061 − 0.118 = +0.088**. 여전히 0 을 넘지만:

> **정확한 진술은 「rate hysteresis 로 설명되지 않는다」가 아니라
> 「이 13차원 이력 기저가 표상한 이력으로는 설명되지 않는다」**이다.
> 재분극 rate hysteresis 의 **긴 시정수**를 이 기저가 실제로 span 하는지는 별개 문제다.

⛔ `post_rr` 은 하류 변수라 안 넣었다(R28 ②).

## 4. ★★ 그런데 P 창 **안에서** 이른 쪽이 더 세다 — 뒤집힘을 제한한다

둘 다 **폭 32** 로 공정하게 비교하면:

```
p_early (0, 32)   = R−278 ~ −189ms   초과 +0.2426
p_late  (53, 85)  = R−131 ~ −42ms    초과 +0.2116
차이                                   +0.0310
```

**P 파가 실제로 사는 자리는 `p_late` 인데, 거기보다 `p_early` 가 더 세다.**
Q7-F 의 F2(`late < early`)가 **잔차화 + 폭 정합 조건에서 재현**됐다.

Q7-F 【F-D】는 그 이유도 실측했다 — **S 비트의 `p_early` 창은 직전 T 파에 55.7% 덮인다**
(N 은 10.3%). 즉:

> **「R 앞쪽 창이 ST/T 창을 이긴다」와 「P 파 고유의 신호는 없다」는 동시에 성립한다.**
> 앞쪽 창이 담는 건 P 파가 아니라 **직전 T** 일 가능성이 높다.

⚠️ 이건 **사전등록 관문이 아니라 사후 관찰**이다(점추정만 있고 CI 를 안 냈다).
다음 실험에서 `p_early − p_late` 를 **관문으로** 걸어야 한다.

## 7. 배운 것

1. ★ **폭 하나가 결론의 부호를 바꿨다.** Q7-M 의 「P 창이 못 이긴다」(−0.0141)는
   폭 32 vs 85 의 산물이었고, 맞추니 **+0.0745(우월성 ✅)** 다. R27 ③ 을 규칙으로
   써놓고 어겼던 대가를 이번에 정확히 확인했다.
2. ★ **등가 여유는 모든 등가 관문에서 필요 표본을 계산해야 한다.** N3 는 했고
   N2 는 안 했다. `f2_5` 의 CI 반폭 0.035 로는 ±0.02 등가가 **원리적으로 불가능**하다
   → **R30 ①**.
3. ★ **봉인은 이분법이 아니다.** 누수 크기를 실측했으면 **최악으로 깎아서** 결론이
   사는지 본다. `STT` +0.2144 는 최대 누수 0.0924 를 다 빼도 +0.122 고, 무엇보다
   **누수를 정의상 흡수하는 `rank` 기저에서 오히려 +0.2465 로 오른다** → **R30 ②**.
4. ★ **두 결론이 동시에 성립할 수 있다.** 「R 앞쪽 창이 이긴다」(N3b ✅)와
   「P 파 고유 신호는 없다」(`p_early` > `p_late`)는 모순이 아니다 — 앞쪽 창이 담는 게
   **직전 T** 라면 둘 다 맞다.
5. **잔차화의 과보정이 실제로 나타났다**(`f3` 0.7146 → 0.3608). 사전등록에 적어둔
   한계가 그대로 나왔고, **순위 기저가 교정**했다(+0.0112).
6. ★ **잔차 AUROC 는 팔 사이에 비교할 수 없다.** 잔차의 크기는 「그 팔이 라벨 정보를
   얼마나 더 갖나」가 아니라 **「그 팔의 분산이 기저와 얼마나 겹쳤나」**에 좌우된다.
   겹침이 큰 팔은 잔차가 잡음만 남고(`f3`·`lr_all`), 작은 팔은 자기 신호를 대부분
   보존한다(`p_full`). 증상이 표에 그대로 있다 — **전부 넣은 `lr_all` 초과 +0.1424 가
   단일 성분 `stt` +0.2144 보다 낮다.** 결합기가 성분보다 나쁠 수 없으므로 이건
   **잔차화가 만든 인공물**이다. **봉인이 옳았다** → **R31 ⑤**.
7. ★ **통제를 조일수록 차이가 줄면 그건 강건성이 아니다**(§1). 부호만 보고
   「네 기저 전부 일치」로 읽었던 걸 정정한다 → **R31 ③**.
8. ★ **등가 프레임을 잘못 걸었다.** 점추정이 여유 밖이면(`p_full−stt` +0.0745 > 0.05)
   **어떤 표본으로도 등가 판정이 불가능**하다. 그 항목은 처음부터 **우월성 프레임**으로
   물었어야 한다 → **R31 ①**.

- **`post_rr` 의 독립 기여는 없다** — 세 번째 독립 경로(실험1′ · Q7-M 정합 · Q7-N 순위잔차)
- **창 폭은 그 자체가 축이다** — 같은 계열 안에서 폭 32 → 85 로 단조 상승

**방어 가능한 문장은 지금 딱 하나다**

> **선행 RR 이력을 선형·순위·이차·이력 어느 기저로 통제해도 형태 창은 누출 바닥의
> 1.7~1.8배로 살아남는다**(`STT` +0.2144 vs 바닥 0.118).
> **단 P 창의 직전 T 침입은 아직 배제되지 않았다.**

~~「형태 신호가 층에 관계없이 있다」~~ → 층별 표가 **폭 불일치**라 헤드라인의 층 분해가
안 된다(§6). ~~「rate hysteresis 로 설명되지 않는다」~~ → **「이 이력 기저가 표상한
이력으로는」**까지만(§3).

**미결**
- ★★ **P 창의 직전 T 침입** — `STT` 쪽엔 `stt_safe`(post 문턱)가 있는데 **P 쪽엔
  `p_safe` 가 없다.** 중앙 RR 282.5 샘플에서 `p_full` 은 R 이전 85 샘플이고, 직전 T 종료가
  직전 R + 110~145 샘플이면 **`pre_rr` 이 ~230 샘플 아래로 내려갈 때 P 창이 직전 T 를
  문다.** S 는 정의상 조기라 `pre_rr` 이 짧다 → **창의 내용물 자체가 라벨과 상관된
  조기성 누출 경로**이고, **RR 특징에 대한 잔차화로는 못 지운다**(점수의 선형 성분이
  아니라 창의 내용물이라서). 관측이 이 가설과 전부 일치한다:

  | 예측 | 관측 |
  |---|---|
  | 창이 넓을수록 침입↑ → 차이↑ | 폭 85 **+0.0745** > 폭 32 +0.0310 |
  | R 에서 멀수록 침입↑ | `p_early` **+0.2426** > `p_late` +0.2116 |
  | 조기성 통제가 강할수록 차이↓ | lin .0745 → hist .0621 → quad .0564 → rank .0466 → 층화 **.0359** |
- **폭 32 에서 P 가 음성 대조를 이기는가**(+0.0310 · `rank` 기저 하한 +0.0088)
- **헤드라인이 런 5개체에 얹혀 있나**(§6 · 폭 정합 층 분해 필요)
- `k` 계열 누수의 정확한 크기(≤0.03 규모라는 것까지만)
- **등가 검정력의 하드 리밋** — 폭 32 는 ±0.05 등가에 **개체 276** 필요(SVDB 78).
  폭 85 는 **어떤 표본으로도 불가**(점추정이 여유 밖) → **프레임을 우월성으로 전환**

**다음 — Q7-P `p-safe`** (외부 검토 반영해 재설계)

**이거 하나가 P 축의 생사를 정한다.**

- **P1 ★★ `p_safe`** — `pre_rr ≥ (P창 폭 + 직전 QT)` 인 비트만 남기고 N3 를 재계산.
  침입 가설이 맞으면 **차이가 무너지고**, 살아남으면 P 주장이 훨씬 단단해진다.
  **침입률(S vs N)도 실측**한다(Q7-K L9 가 `STT` 에 했던 방식 그대로)
- **P2 ★ `p_early` − `p_late`** 를 **관문으로**(둘 다 폭 32) — §4 는 점추정뿐인 사후 관찰
- **P3** 개체별 **직전-T 중첩률**(Q7-F 【F-D】)과 개체별 `p_early` 초과의 **상관**
- **P4 ★ 프레임 전환** — 등가가 원리적으로 불가능한 항목(점추정 > 여유)은
  **우월성 + 효과크기**로 사전등록한다. 필요 표본은 **모든 관문에서** 계산(R30 ①)
- **P5 ★ 층 분해를 폭 정합으로** — 헤드라인이 런 5개체에 얹혀 있는지 확인(§6)
- **P6** 누출 바닥을 **`f4`·`f5` 포함 가장 보수적인 것**으로 잡아 깎은 하한 병기(R31 ②)
- **P7** 프로브에도 **셔플 null 을 실측**해 붙인다. 이론상 순수 특징의 영분포는
  치환 대칭으로 **정확히 0.5**(점수 벡터가 라벨에 안 변하므로 추정 오차 0)이지만,
  **싸니까 재서 확인**한다 — 지금 N2 판정은 측정 안 한 가정 위에 서 있다
- **P8** (검토) 주 분석을 **층화로 승격**하고 잔차화를 보조로 — 층화가 세 지표에서
  일관되게 가장 보수적이고, 잔차 AUROC 의 팔 간 비교 불가 문제(§7-6)가 없다

⏸ **Q7-O(교차환자 템플릿)는 그 다음** — 전이시킬 대상이 P 인지 **직전 T** 인지
모르는 채로 템플릿을 만들면 무엇을 옮겼는지 해석할 수 없다.
