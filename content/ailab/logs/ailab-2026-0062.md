## 3. ⚠️ M3a — 「P 파 고유의 신호는 없다」는 **과한 진술이었다**

처음에 이 절을 「P 파 고유의 신호는 없다 (세 번째 확인)」으로 썼다. **철회한다.**
외부 검토가 세 가지를 짚었고 셋 다 맞다.

### ① **미결 ≠ 등가.** 우월성이 없다는 것과 차이가 없다는 것은 다른 주장이다

```
(P_late 초과) − (STT 초과) = −0.0141 [−0.0892, +0.0476]  → 미결
```

미결은 「차이가 없다」가 아니라 **「차이가 있는지 모른다」**다. 「고유 신호가 없다」는
**등가성 주장**이고, 그건 여유를 사전등록해 CI 가 그 안에 들어가야 한다. 반폭이
**0.0684**(SE 0.0286 · n=18)이므로:

| 등가 여유 | 필요 개체 | 현재 |
|---|---:|---:|
| ±0.05 | **34** | 18 ❌ |
| ±0.04 | 53 | 18 ❌ |
| ±0.03 | 94 | 18 ❌ |

이 프로젝트는 실험1′ 에서 이걸 **제대로 했다** — `B3R − B3` 반폭 0.0287 < 사전등록
0.03 이라 「기각(확정)」이었다. 여기선 안 했다.

**→ 지금 말할 수 있는 건 「P 창이 음성 대조를 이기지 못한다(우월성 미확립)」까지다.**

### ② **창 폭이 불공정하다** — 내가 R27 ③ 을 쓰고 바로 다음 실험에서 어겼다

| 창 | 폭 | 초과 |
|---|---:|---:|
| `p_full` | **85** | +0.2169 |
| `stt` | **85** | +0.1837 |
| `stt_safe` | 45 | +0.1620 |
| `p_late` | **32** | +0.1696 |
| `p_early` | **32** | +0.1231 |

**M3a 는 폭 32 짜리 P 창을 폭 85 짜리 음성 대조와 비교한다.** 창이 넓으면 기계적으로
정보가 더 들어가므로 P 쪽이 구조적으로 불리하다. 폭을 맞추면 **부호가 뒤집힌다**:

```
같은 폭 85 vs 85 :  p_full − stt      = +0.0332 [−0.0201, +0.0857]
근사 폭 32 vs 45 :  p_late − stt_safe = +0.0076
불일치 32 vs 85 :  p_late − stt      = −0.0141   ← M3a (사전등록 주지표)
```

**세 값 중 P 에 가장 불리한 것을 사전등록 주지표로 골랐다.** 폭을 통제하면 P 창이
음성 대조를 근소하게 **이긴다**(전부 미결이지만).

### ③ 그래서 **「세 번째 독립 확인」이 아니다**

폭이 맞은 비교는 둘뿐인데 **부호가 반대**다:

| | 비교 | 폭 | 결과 |
|---|---|---|---|
| Q7-F (F3) | `STT` vs `P_full` | 85 vs 85 | `STT` 0.8515 > `P_full` 0.8290 |
| **Q7-M** | `p_full` − `stt` | 85 vs 85 | **+0.0332** (P 가 위) [−0.0201, +0.0857] |

Q7-K(L7)는 이번과 같은 폭 불일치(32 vs 85)를 썼다. **정확한 종합은
「P 창과 음성 대조 창은 지금까지 어느 조건에서도 서로 구별되지 않았다 — 전부 미결」**
이다. 이건 여전히 의미 있는 진술이지만 **「P 파 신호가 없다」보다 약하다.**

### ④ 상쇄 검증은 **검정력이 없어 근거로 못 쓴다**

`rho(개체별 (P_late−STT) 초과차, 개체별 f2 짝잔여) = −0.007 **[−0.540, +0.523]**`.
이 CI 는 `rho = ±0.5` 도 배제하지 못한다. **「0 을 포함한다」는 확인이 아니라 검정력이
없다는 뜻**이고, R27 ② 의 「봉인 밖 인용」 근거로 쓰기엔 부족하다. **판단에서 뺀다.**

### ⑤ 유일하게 M3a 를 받쳐주는 것 — **지표를 바꿔도 안 바뀐다**

| | 층화 | 매크로 |
|---|---:|---:|
| `stt` | 0.6032 | 0.6566 |
| `p_late` | 0.6007 | 0.6475 |
| **차이** | **−0.0025** | −0.0091 |

매크로에서 층화로 바꾸면 두 창의 차이가 오히려 **더 0 에 가까워진다.** 추정량을 바꿔도
결론이 안 바뀌는 건 진짜 강건성 증거다. (⚠️ 층화는 null 을 안 잰 원값 비교라 근사다.)

### ⑥ LOO 부호 반전은 여기서 경고가 아니다

M3a 기준 −0.0141 · LOO [−0.0247, +0.0044] 로 `#866` 을 빼면 부호가 뒤집힌다.
**효과가 0 인 양은 당연히 부호가 흔들린다** — 오히려 0 근처라는 증거다.
(M3b 는 [+0.1227, +0.1821] 로 **진짜 안정**하다.) → R28 ④.

## 6. ⚠️ 내가 놓친 것 셋

### ① `f2_8` 이 살아남았다 — M2 에 구멍이 있다

null SE(±0.0078) 기준으로 초과분을 σ 로 환산하면:

| 팔 | 초과 | **σ** | |
|---|---:|---:|---|
| `f1` | +0.0000 | 0.0 | 죽음 |
| `f2_16` (정합 대상) | +0.0090 | 1.2 | 죽음 ✅ |
| **`f2_8`** (정합 안 함) | **+0.0632** | **8.1** | **살아 있음** ❌ |
| `f6` | −0.0090 | 1.2 | 죽음 |
| `f4` | +0.0307 | 3.9 | 살아 있음 |

**`LB_K = 16` 으로 맞췄더니 `k = 8` 기저선은 그대로 살아남았다.** 우연이 아니라
구조다 — **「상대 조기성」은 하나의 양이 아니라 창 길이 `k` 에 딸린 무한 계열**이다
(`k = 4, 8, 16, 32, …`). 하나를 맞춰도 나머지는 안 맞는다. Q7-K 에서 두 축이 서로
얽혀 막혔던 것과 **같은 구조가 새 형태로 재발**했다.

→ **정확한 진술은 「`f2_16` 을 통제했다」이지 「상대 조기성을 통제했다」가 아니다**
(→ **R28 ①**). M2 는 `k` 하나가 아니라 **모든 `k` 에 대해** 판정해야 한다 — 교차합집합
검정(전부 통과해야 통과)이고, 다중검정 보정을 `k` 에 건다.
⚠️ **「`max` over k」로 잡으면 안 된다** — 잡음 추정치의 최댓값은 위로 뜬다(R25).

**그리고 이게 M3a·M3b 해석에 직접 걸린다**: 형태 창의 초과(+0.17~0.22)가
`k = 8` 규모의 잔여 조기성(+0.0632) 위에 얹혀 있을 수 있다. 그래서 수준보다
**차이**(M3a·M3b)가 여전히 나은 지표다(R27 ②).

### ② 고정 코호트를 안 썼다

대역 곡선에서 `STT` 가 0.5881(정확pre) → 0.6321 → 0.6628 → 0.6532 → **0.6566** 으로
**올라간다.** 그런데 개체가 40 → 27 → 24 → 20 → 18 로 바뀐다. **통제 효과와 코호트
효과가 섞여 있다** — Q7-I‴ 【K-E】 에서는 고정 코호트를 썼는데 여기서 빠뜨렸다.
곡선의 상승을 「통제할수록 형태가 강해진다」로 읽으면 안 된다.

### ③ ★ 요약 출력이 「측정 불가」를 결론으로 승격시켰다 — **코드 분기 버그**

실행 요약이 이렇게 찍혔다:

```
M4   ⛔ 측정 불가   3축 가능 개체 6 < 10 — 표본이 없다
...
관문 요약

```

원인은 분기 조건 `elif "M4" in VERD:` 다. **`VERD["M4"]` 는 「⛔ 측정 불가」일 때도
존재**하므로, 측정 못 한 항목이 기각 분기를 탔다. **관문이 스스로 「측정 불가」를
발화한 것을 요약이 결론으로 승격시킨 것**이고, 이 프로젝트가 R24-b·R27 로 가장
철저히 막아온 종류의 사고다.

**「형태 축 종료」 선언을 철회한다.** 유일한 관련 실측은 Q7-K L8(개체 6 ·
+0.0621 [−0.0242, +0.1653])인데 CI 가 0 도, 원래 값 0.1753 도 거의 포함해 **아무 것도
배제하지 못한다.** 노트북 분기를 고쳤다(측정 불가면 어떤 결론 분기도 타지 않는다)
→ **R29 ②**.

### ④ M4 는 표본 문제 이전에 **인과적으로 잘못된 질문**이다

3축 정합은 6/59 로 측정 불가였는데, 사실 **표본이 있었어도 해석이 안 됐다.**
`post_rr` 은 **현재 박동보다 뒤에 오는 간격**이다. 현재 박동의 재분극(ST/T)이
미래 간격의 원인일 수는 있어도 그 반대는 아니다. 즉 `post_rr` 은 교란이 아니라
**S 이기 때문에 생기는 결과**(하류 변수)다. **결과를 통제하면 신호가 지워진다** —
`STT` 가 사라져도 「형태가 가짜였다」가 아니라 「매개변수를 막았다」일 뿐이다.
→ **M4 를 rate hysteresis 의 시험으로 쓰지 않는다. 설계를 폐기한다** → **R28 ②**.
**잔차화로 바꿔도 같다** — `post_rr` 을 회귀항으로 넣는 것도 하류 변수 통제다.
**rate hysteresis 는 선행 이력의 문제**이므로 `f2_k` 계열·국소 추세로 물어야 한다.

**rate hysteresis 는 이미 다른 경로로 반증에 가깝다**: QT 는 **직전** RR 의 함수인데
정확 pre 정합이 그걸 맞춘다. 그리고 이력 의존성은 국소 기저선이 대리하는데 그것도
0.02 로 맞췄다. 그 조건에서 `STT` 가 **+0.1837** 로 남는다.

쓰되 이 간극을 함께 적는다.

## 8. 배운 것

1. ★ **정당화 없는 상수는 결론을 바꾼다.** `MIN_CELL = 3` 하나가 개체 25 → 40,
   남은 S 46% → 81% 를 좌우했고, 그것 때문에 Q7-K 가 설계를 바꿔 실패했다 → **R28 ③**.
2. ★ **미결을 등가로 읽지 않는다.** 「우월하지 않다」와 「차이가 없다」는 다른 주장이고,
   후자는 **여유를 사전등록**해 CI 가 그 안에 들어가야 한다. 실험1′ 에서는 제대로
   했는데(반폭 0.0287 < 0.03) 여기선 안 했다 → **R29 ①**.
3. ★ **관문이 「측정 불가」를 발화하면 어떤 결론 분기도 타지 않아야 한다.**
   `elif "M4" in VERD` 한 줄이 표본 없음을 「형태 축 종료」로 승격시켰다 → **R29 ②**.
4. ★ **내가 쓴 규칙을 내가 다음 실험에서 어겼다.** R27 ③(창 비교는 같은 폭끼리)을
   쓰고, 바로 다음 사전등록에서 `P_late`(32) vs `STT`(85)를 주지표로 골랐다.
   **사전등록 체크리스트에 기존 규칙을 넣어야 한다** → **R29 ③**.
5. ★ **「통제했다」는 그 특징의 특정 파라미터화에만 성립한다**(`f2_16` ✅ · `f2_8` 8.1σ ❌)
   → **R28 ①**.
6. ★ **교란만 정합한다. 하류 변수를 정합(또는 잔차화)하면 신호를 지운다**(`post_rr`)
   → **R28 ②**.
7. **사전등록한 반증 시험이 값을 했다.** M5 가 사전등록한 두 갈래 **어디에도 안 갔고**,
   제3의 결과를 **사후 해석으로 명시**해 남겼다(§5).
8. **검정력 없는 강건성 검사는 강건성 증거가 아니다.** 상쇄 검증 `rho` CI 가
   [−0.540, +0.523] 이면 아무 것도 확인한 게 아니다.

## 9. 확정된 것 / 격하한 것 / 다음

**확정**
- **`post_rr`(보상성 휴지)의 독립 기여는 없다** — Icentia11k 580환자(실험1′)와

- **`f1`·`f2_16` 을 동시에 통제할 수 있다** — `f1` 0.5000(짝잔여 0) · `f2_16` 0.5078
- **`MIN_CELL` 은 표본을 세 배 가까이 좌우한다** — 감사 없이 물려받으면 안 된다

**격하 / 철회**
- ~~「P 파 고유의 신호는 없다」~~ → **「P 창이 음성 대조를 이기지 못한다(우월성 미확립)」**.
  등가는 ±0.05 여유로도 개체 **34** 가 필요한데 18 이다. 게다가 폭이 불공정하고,
  폭을 맞춘 두 비교(Q7-F vs Q7-M)는 **부호가 반대**다
- ~~「형태 축 종료」~~ → **철회.** M4 는 측정 불가이고 설계 자체가 인과적으로 틀렸다
- ~~「두 축 동시 통제」~~ → **「`f1`·`f2_16` 통제」**. `f2_8` 이 8.1σ 로 살아 있다
- 상쇄 검증 → **검정력 없음. 판단에서 뺀다**

**남은 미결 셋 — 셋 다 정합으로는 못 푼다**

| 미결 | 정합이 막히는 이유 |
|---|---|
| `STT` 가 rate hysteresis 인가 | 3축 정합 = 6개체(Q7-K·Q7-M 둘 다). 그리고 `post` 는 하류 변수 |
| P 파 고유 신호가 있는가 | ±0.05 등가에 34개체 필요 · 현재 18 |
| `k` 별 상대 조기성 전부 통제 | `k` 가 무한 계열 — 축을 늘릴수록 표본이 반토막 |

**다음 — Q7-N `residualize` (정합 → 잔차화 + 층화 전환)**

정합은 **목표를 달성했고 한계에 닿았다**(`f1`·`f2_16` 동시 통제 ✅ / 3축·다중 `k` ❌).
남은 질문은 **표본을 안 버리는 설계**로만 답이 나온다.

- **N1 ★ 잔차화** — 개체 안에서 `점수 ~ f1 + f2_4 + f2_8 + f2_16 + f2_32 + f6` 로
  적합하고 **잔차의 AUROC** 를 잰다. 라벨셔플 null 도 **같은 절차**를 통과시킨다.
  `k` 를 몇 개든 한꺼번에 넣을 수 있고 **개체 59개 · S 100%** 를 쓴다.
  ⚠️ 선형 성분만 제거하므로 **비선형 잔여**가 남을 수 있다 → 이차항 민감도 병기.
  ⚠️ 조기성에 귀속되는 형태 성분까지 지우므로 **보수적**이다 — 그렇게 적는다.
- **N2 ★ 통제 검증 관문** — 잔차의 `f1`·`f2_{4,8,16,32}` AUROC 가 **전부** 0.5±0.02
  (교차합집합 · `k` 에 다중검정 보정). 정합의 M1·M2 에 대응하고, `f2_8` 구멍을 닫는다.
- **N3 ★ 폭 정합 등가성** — **폭 32 짜리 음성 대조 `stt_32`(130–162)를 신설**하고
  `p_late(32) vs stt_32(32)` · `p_full(85) vs stt(85)` 를 비교. **등가 여유 ±0.05 를
  사전등록**하고 CI 가 그 안에 들어가면 **처음으로 「구별되지 않는다」를 확정**할 수 있다
  (59개체면 반폭 **0.038** 예상 — 도달 가능하다).
- **N4** rate hysteresis 를 **선행 이력**으로 재정의 — `f2_k` 계열 + 국소 추세·분산으로
  잔차화한 뒤 `STT` 가 남는가. ⛔ **`post_rr` 은 넣지 않는다**(R28 ②).
- **N5** 층별(고립/혼합/런) 각각 보고 — 잔차화는 59개체를 다 쓰므로 **층이 다 살아난다**.
  정합에서 혼합 3 · 런 1 이던 제약이 풀린다.
- **N6 삼각검증** — 층화 판본(`f1 × f2_16` 칸 · 쌍 가중)이 잔차화와 **같은 부호**인가.
  가정이 다른 두 추정량이 같은 답이면 결론이 설계와 무관하게 선다.
  ⚠️ 층화도 **칸 안에 두 클래스가 있어야** 하므로 「비트 100%」는 아니다 — 개체 수준
  문턱을 없애 **더 많은 개체가 기여**하는 것이 이득이다. 그렇게 정확히 적는다.
- **N7** 고정 코호트 · LOO 경고 문구 수정(R28 ④) · 층화-매크로 간극 병기

**Q7-N(교차환자 템플릿)은 그 다음으로 미룬다** — 형태 신호의 **수준**이 아직
`k=8` 잔여 위에 얹혀 있을 수 있어서, 전이 실험 전에 잔차화로 수준을 확정하는 게 순서다.
