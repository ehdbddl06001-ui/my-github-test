stem: "위팔세갈래근 세 갈래의 이는곳을 각각 쓰고, 셋 중 **어깨관절을 넘는 갈래**가 무엇이며 그래서 어떤 작용이 더해지는지 밝히시오. 표본에서 위팔 뒤칸을 얕은층부터 벗겨 갈 때 **노신경과 세 갈래가 어떤 깊이 순서로 나타나는지** 쓰고, 긴갈래·안쪽갈래·큰원근이 만드는 두 공간을 구분하시오."
answer: "**세 갈래의 이는곳** · **긴갈래 (long head)** — 어깨뼈 **접시아래결절 (infraglenoid tubercle)** · **가쪽갈래 (lateral head)** — 위팔뼈 뒤면, **노신경고랑보다 위쪽 (몸쪽·가쪽)** · **안쪽갈래 (medial head)** — 위팔뼈 뒤면, **노신경고랑보다 아래쪽 (먼쪽·안쪽)** · 셋의 공통힘줄이 자뼈 **팔꿈치머리 (olecranon)** 에 닿고, 신경은 셋 모두 **노신경** · **어깨관절을 넘는 갈래** — **긴갈래만** 어깨뼈에서 일어나 어깨관절을 넘으므로 팔꿈치 폄 외에 **어깨의 폄·모음**에도 관여한다 (나머지 둘은 위팔뼈에서 일어나 팔꿈치만 넘는 단관절근) · **깊이 순서 (얕은 → 깊은)** — ① 긴갈래와 **가쪽갈래**가 표면을 이룬다 ② 두 갈래 사이를 벌리면 **노신경 + 깊은위팔동맥**이 **노신경고랑** 위에서 드러난다 ③ 그보다 **깊은 바닥**이 **안쪽갈래** 다 → 즉 **가쪽갈래보다 깊고 안쪽갈래보다 얕은 층**에 신경혈관다발이 낀다 · **두 공간의 구분** · **세모공간 (triangular space)** — 위 = 작은원근, 아래 = 큰원근, 가쪽 = 위팔세갈래근 **긴갈래** → **어깨휘돌이동맥 (circumflex scapular a.)** 이 지난다 · **네모공간 (quadrangular space)** — 위 = 작은원근, 아래 = 큰원근, 안쪽 = 긴갈래, 가쪽 = 위팔뼈 **외과목** → **겨드랑신경 (axillary n.) + 뒤위팔휘돌이동맥**이 지난다 · **세갈래사이공간 (triangular interval)** — 위 = **큰원근**, 안쪽 = 긴갈래, 가쪽 = 위팔뼈(안쪽갈래) → **노신경 + 깊은위팔동맥**이 뒤칸으로 들어오는 문 · **팔꿈치근 (anconeus m.)** 은 안쪽갈래의 연장으로 보며 폄 보조와 관절주머니 당기기를 한다"
explanation: "이 문항의 핵심은 ==노신경이 두 갈래 사이에 끼어 있다== 는 한 줄이다.\n\n가쪽갈래는 고랑보다 ==위==에서, 안쪽갈래는 고랑보다 ==아래==에서 일어난다. 그래서 해부하면 가쪽갈래를 젖혀야 신경이 나오고, 신경을 젖히면 안쪽갈래가 바닥으로 보인다. 태깅에서 「이 신경보다 깊은 갈래는?」이라고 물으면 답은 ==안쪽갈래== 다.\n\n긴갈래만 어깨뼈에서 일어난다는 사실은 두 곳에서 쓰인다. 하나는 작용(어깨 폄·모음), 다른 하나는 ==공간의 경계== 다. 긴갈래가 큰원근을 앞뒤로 가로지르면서 세모공간과 네모공간을 가른다.\n\n세 공간을 헷갈리지 않는 방법은 ==무엇이 지나는가== 로 되짚는 것이다.\n\n- 어깨휘돌이동맥만 → 세모공간\n- 겨드랑신경 → 네모공간\n- 노신경 → 세갈래사이공간(큰원근 아래)\n\n큰원근이 위 경계로 올라오면 세갈래사이공간이다. 즉 ==큰원근보다 아래면 노신경== 이다."
