title: "갑상샘 여포세포 — 염색 세포를 직접 움직이는 것은 TSH"
objective: "갑상샘 조직 사진에서 염색된 세포를 위치로 여포세포·C 세포로 가르고, 그 세포의 호르몬 생산을 직접 자극하는 신호(TSH·칼슘)를 축의 윗단계 호르몬과 구분해 연결한다"
objective_kind: 기전
condition: 정상 갑상샘 여포세포·C 세포와 시상하부–뇌하수체–갑상샘 축
exams: [usmle, kmle]
summary:
  - "결론: 콜로이드 여포를 고리처럼 둘러싼 양성 세포 = 여포세포 → 호르몬 생산의 직접 자극 = 뇌하수체 전엽 TSH."
  - "시험 단서: 갑상샘 IHC(TPO·Tg)에서 여포 테두리가 갈색 + 「염색 세포를 가장 직접 자극하는 것은?」(TSH, follicular cell)."
  - "왜: TSH 수용체는 여포세포 기저측막의 Gs 결합 수용체다 — TRH 는 그 한 단계 위, 뇌하수체 갑상샘자극세포에 작용한다."
  - "여포 사이에 흩어진 C 세포(칼시토닌)라면 직접 자극은 혈청 칼슘 상승이다. ACTH 는 부신피질의 영양호르몬이다."
  - "TSH 반감기 약 50분 — 한 번 측정으로 충분하지만, 시상하부·뇌하수체 병에서는 TSH 단독으로 기능을 판단하지 않는다."

pitfalls:
  - contrast: "TRH vs TSH — 「축의 맨 위가 가장 근본」"
    point: "TRH 는 뇌하수체 갑상샘자극세포의 TSH 생산을 자극하고, 여포세포를 움직이는 것은 TSH 다 [[harrison-21: 382장 p.2927]]. 여포세포에 있는 수용체는 TSH-R 이다 [[harrison-21: 382장 p.2928]] — 「가장 직접」은 한 단계 위가 아니라 그 세포의 수용체로 정한다."
    exception: "질문이 염색 세포가 아니라 뇌하수체 갑상샘자극세포를 무엇이 자극하는지 묻는다면 TRH 가 답이다."
    covers: ["imaging-2026-0341:B"]
  - contrast: "여포세포 vs C 세포 — 칼슘 상승"
    point: "칼슘 상승에 반응해 칼시토닌을 내는 것은 여포 사이에 흩어진 C 세포다 [[harrison-21: 382장 p.2926]] [[?guyton-14]]. 여포 테두리를 고리처럼 따라가는 염색(TPO)은 여포세포이므로 칼슘은 답이 아니다."
    exception: "칼시토닌 염색처럼 여포 사이의 흩어진 세포만 양성이면 혈청 칼슘 상승이 답이 된다."

    covers: ["imaging-2026-0341:A"]

## 판단 — 위치가 세포를, 세포가 자극을 정한다
- 갑상샘에는 내분비 세포가 둘이다. 콜로이드를 둘러싼 **여포세포(follicular cell)** 는 T4·T3 를 만들고, 여포 사이에 흩어진 **C 세포(parafollicular cell)** 는 칼시토닌을 만든다 [[harrison-21: 382장 p.2926]].
- TPO 는 여포세포 정단막의 효소라 [[harrison-21: 382장 p.2927]] 염색이 여포마다 갈색 고리를 그린다 — 그 세포의 수용체는 기저측막의 TSH 수용체(TSH-R)다 [[harrison-21: 382장 p.2926]].
- 「가장 직접」은 그 세포에 수용체가 있는 호르몬이다. TRH 는 TSH 를 거쳐서만 여포세포에 닿는다 [[harrison-21: 382장 p.2927]].

## 기전 — TRH 에서 TSH, TSH 에서 여포세포로
시상하부 TRH 가 뇌하수체 전엽 갑상샘자극세포의 TSH 생산을 자극하고, TSH 가 갑상샘호르몬 합성·분비를 자극한다. 갑상샘호르몬은 TRβ2 를 통해 TRH·TSH 를 누르며, 축의 「설정점」은 TSH 가 정한다 [[harrison-21: 382장 p.2927]].
- **여포세포 안**: TSH-R 은 7회 막관통 G 단백 결합 수용체로 Gsα → 아데닐산고리화효소 → cAMP 를 올리고 포스포리파제 C 도 활성화한다 [[harrison-21: 382장 p.2928]]. TSH 가 결합하면 내강의 Tg 가 다시 흡수되고 세포 안에서 분해되어 호르몬이 혈류로 나간다 [[harrison-21: 382장 p.2926]].
- **수용체 변이가 증명한다**: 기능소실 변이는 갑상샘 형성저하·선천 갑상샘저하증, 기능획득 변이는 자율 기능 결절·가족성 갑상샘항진증을 만든다. 그레이브스병의 갑상샘자극 항체(TSI)도 같은 수용체를 자극한다 [[harrison-21: 382장 p.2928]].
- **다른 조절자**: IGF-1·EGF·TGF-β 같은 국소 성장인자도 합성에 영향을 주지만 주된 호르몬 조절자는 TSH 다 [[harrison-21: 382장 p.2928]].

## 가르는 소견 — 여포 테두리 vs 여포 사이
- **여포세포 표지(TPO·Tg)**: 여포를 한 층으로 둘러싼 입방상피가 양성, 여포 사이 간질은 음성. 문항 사진도 이 양상이다(HPA 병리의사 주석: 샘세포 강양성) [[?hpa-tpo]].
- **C 세포 표지(칼시토닌)**: 여포 사이에 하나씩·작은 무리로 흩어진 세포만 양성. C 세포는 샘 위 1/3 과 아래 2/3 경계에 가장 많다 [[harrison-21: 382장 p.2926]].
- **배경 수치의 한계**: 정상 TSH·칼슘은 판단을 바꾸지 않는다 — 질문은 염색된 세포를 「무엇이」 움직이는지다. 정상 TSH 는 일차 갑상샘 이상을 대개 배제하지만, 시상하부·뇌하수체 병에서는 TSH 가 낮은 T4 에 부적절하게 낮음~정상이어서 TSH 단독으로 기능을 판단하지 않는다 [[harrison-21: 382장 p.2931]] [[harrison-21: 382장 p.2932]].

## 권고와 예외
- 「위치 → 세포 → 수용체 → 질문의 단계」 순서로 읽는다: 여포 테두리 = 여포세포 = TSH, 여포 사이 = C 세포 = 칼슘.
- TSH 는 반감기가 약 50분이라 한 번 측정으로 혈중 농도를 평가할 수 있다 [[harrison-21: 382장 p.2927]]. 바이오틴은 면역측정에서 TSH 를 거짓으로 낮추므로 검사 전 최소 2일 끊는다 [[harrison-21: 382장 p.2931]].
- 임신 초기 hCG 는 TSH-R 에 약하게 결합해 TSH 를 낮춘다 — 여포세포를 자극할 수 있는 다른 리간드의 예다 [[harrison-21: 382장 p.2929]].

## (심화) 왜 한 장기에 두 축인가
여포세포와 C 세포는 기원이 다르다. 여포세포는 TTF-1·PAX-8 같은 전사인자로 Tg·TPO·NIS·TSH-R 을 함께 켜는 갑상샘 고유 세포이고 [[harrison-21: 382장 p.2926]], C 세포는 새후체에서 온 신경능선 세포다 [[harrison-21: 382장 p.2926]]. 그래서 여포세포는 뇌하수체 축(TSH)의 지배를, C 세포는 혈중 칼슘이라는 다른 신호를 따른다. 사진에서 어느 구획이 양성인지가 곧 어느 축의 질문인지를 알려 준다.
