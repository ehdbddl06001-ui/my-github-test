## 정상 — 프로인슐린 한 분자에서 둘이 나온다
베타세포는 인슐린을 한 사슬의 프리프로인슐린으로 만들고, 신호 펩티드를 떼어 프로인슐린을 만든다. 프로인슐린 안쪽의 31 잔기 조각이 잘려 나가면 그 조각이 C 펩티드(연결 펩티드)이고, 남은 A · B 사슬이 이황화 결합으로 이어진 것이 인슐린이다. 둘은 같은 분비 과립에 담겨 함께 분비된다 [[harrison-22: 415장 p.3198]].
- **분비를 켜는 경로** — 포도당이 베타세포로 들어가 글루코키나아제로 인산화되고(속도 결정 단계), 해당에서 생긴 ATP 가 ATP 민감 칼륨 통로를 닫는다. 막이 탈분극되면 전압 의존 칼슘 통로가 열려 인슐린이 분비된다 [[harrison-22: 415장 p.3199]].
- **꺼지는 방향** — 혈당이 떨어지면 인슐린 분비가 먼저 줄어든다. 이것이 저혈당에 대한 첫 방어다 [[harrison-22: 418장 p.3231]].

## 고장 — 인슐린이 어디서 왔는가
- **베타세포가 멈추지 않는다** — 인슐린종이나 분비촉진제에서는 저혈당에서도 분비가 계속되어 인슐린 · C 펩티드 · 프로인슐린이 함께 억제되지 않는다 [[harrison-22: 418장 p.3235]]. 설포닐우레아 · 메글리티나이드는 ATP 민감 칼륨 통로의 한 단백에 붙어 포도당 신호 없이 통로를 닫는다 [[harrison-22: 415장 p.3199]].
- **밖에서 들어온 인슐린** — 상품 인슐린에는 C 펩티드가 없다. 주사한 인슐린이 만든 저혈당은 베타세포 분비를 눌러 C 펩티드가 낮아진다 [[harrison-22: 418장 p.3236]].

## 소견으로 — 저혈당 때 세 가지를 함께 재는 이유
- 수치는 정상 범위와 견주지 않고 그때의 혈당과 견준다 — 혈당 < 55 mg/dL 에서 인슐린 ≥ 3 μU/mL · C 펩티드 ≥ 0.6 ng/mL · 프로인슐린 ≥ 5 pmol/L 이면 억제되지 않은 것이다 [[harrison-22: 418장 p.3235]].
- C 펩티드는 인슐린보다 천천히 제거되어 분비량을 더 안정적으로 보여 준다 [[harrison-22: 415장 p.3198]].

## 임상 판단으로 — 이 기전이 가르는 선택
- 인슐린↑ · C 펩티드↓ → 외인성 인슐린 — 은밀한 또는 악의적 투여를 생각한다 [[harrison-22: 418장 p.3236]].
- 인슐린↑ · C 펩티드↑ → 베타세포 분비 — 혈중 분비촉진제 선별이 음성이면 인슐린종을 찾는다 [[harrison-22: 418장 p.3235]].
