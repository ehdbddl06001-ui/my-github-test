# OncoReg Studio — 자유서술/PICO 검색 · 유사도 가중 · 문서 스튜디오

기존 `oncoreg-ai`(드롭다운)를 전면 재설계한 새 모듈. **Gemini 또는 OpenAI 자동감지**로 구동
(`GEMINI_API_KEY` 있으면 Gemini, 없고 `OPENAI_API_KEY` 있으면 OpenAI. `LLM_PROVIDER`로 강제 가능).

## 무엇이 달라졌나
1. **자유 서술(챗) + PICO 단답형** 두 입력 방식. 전형 케이스는 P·I·C·O를 단답으로, 특이
   케이스는 자유 서술로. LLM이 조건을 해석하고 결과 상단에 PICO 요약을 보여준다.
2. **근거수준을 '필터가 아니라 가중치'로** — 유사도 6축(**유전적 동일성·증상·나이·기저질환·
   병리·기존 투약**) + 근거수준을 가중 블렌딩해 가장 알맞은 논문을 맨 위로. 슬라이더로 즉시
   재정렬되며, 가중치에 따라 **상위 논문이 바뀐다(들어왔다 나갔다)**. `다시 검색`으로 변주.
3. **왜 유사한지 상세히** — 논문마다 6축 점수 + 축별 근거(sim_detail) + `왜 유사한가` 설명.
4. **논문 URL** — 각 논문에 PubMed·Google Scholar 검색 링크(제목 기반)와 DOI(있으면).
5. **약제 선택 모드(예시 20종)** — 약제를 고르면 지정(긴급승인·희귀의약품)·대상 환자군·
   가이드라인·근거 논문을 모아 보여준다(규제 사실은 반드시 공고 확인).
6. **문서 스튜디오** — 오른쪽 **실제 별지 제1호서식**, 왼쪽은 서식 칸마다 **후보 근거 칩**이
   붙어 있어 클릭하면 `값 — "원문 한 문장" (출처, 위치) [번호]` 형태로 그 칸에 삽입되고,
   선택한 원문 인용이 하이라이트로 표시된다. 문서 자동 서술 없이 **선택으로만** 채운다.
7. **뒤로가기** 버튼으로 검색↔스튜디오 이동.

```
[자유서술/약제] --OpenAI--> [근거수준·유사도 랭킹] --선택--> [스튜디오: 좌 근거삽입 / 우 실제 서식]
```

## 파일
| 파일 | 역할 |
|---|---|
| `OncoReg_Studio_Colab.ipynb` | Colab 업로드용 노트북 |
| `server.py` | Flask + OpenAI (`/api/search`, `/api/drug`, `/api/fill`, `/api/health`) |
| `templates/index.html` | 단일 페이지 앱(검색·약제·스튜디오 3화면) |
| `build_notebook.py` / `requirements.txt` | 노트북 생성기 / 의존성 |

## 실행 — Colab (권장)
1. OpenAI 키 발급: <https://platform.openai.com/api-keys>
2. Colab → 파일 → 노트북 업로드 → `OncoReg_Studio_Colab.ipynb`
3. 셀 순서대로: ⓪초기화 → ①설치 → ②파일 기록 → ③**키 입력 칸**에 붙여넣기 → ④**서버 실행**
4. 출력된 `trycloudflare.com` 주소를 새 탭에서 열기.

## 실행 — 로컬
```bash
cd prototypes/oncoreg-studio
pip install -r requirements.txt
export OPENAI_API_KEY="sk-..."          # Windows(PS): $env:OPENAI_API_KEY="sk-..."
export OPENAI_MODEL="gpt-4o-mini"       # 선택
python server.py                         # http://localhost:8000
```
> 모델: 기본 `gpt-4o-mini`(저렴). 더 정교하게는 `gpt-4o`. 비용은 <https://openai.com/api/pricing> 참고.
> 결제수단 없이 무료 크레딧이 없으면 401/429가 날 수 있음 — 키/크레딧 확인.

## 쓰는 법 (시연 순서)
1. **① 자유서술 검색**: 상황을 줄글로 적고 검색 → 해석 요약 + 가중치 슬라이더 + 근거수준 배지가 달린
   논문이 적합도순으로. 맨 위 = ‘최적’.
2. **② 약제·질환 기준**: 약명/질환명 조회 → 지정·대상군·가이드라인·근거 논문.
3. **③ 문서 스튜디오**: ‘이 근거로 서류 작성 →’ → 오른쪽 실제 서식, 왼쪽에서 칸을 클릭(활성화)하고
   팔레트의 근거(예: `52.6% 객관적 반응률 [1]`)를 눌러 삽입. 클릭 시 원문 인용이 아래에 표시됨.
   체크(유형/희귀/병용/질환유형)와 주성분명도 좌측에서 조정 → 우측 서식이 실시간 반영. 인쇄/PDF.

정적 호스팅(GitHub Pages 등)에서 열면 상단 **엔진 배지 클릭 → Colab 백엔드 URL** 을 넣어 라이브로 붙일 수 있고, 넣지 않으면 **데모 데이터**로 UI 전체가 동작한다.

## 백엔드 프레임만 실제 서식이고 나머지는?
서식(별지 제1호)은 실제 HWP 좌표로 재현. 검색·지정·가이드라인은 LLM 생성이므로 **참고용**이며,
실데이터가 필요하면 `/api/search`를 PubMed/식약처·심평원 공고/ClinicalTrials.gov 등으로 교체하면 된다.
