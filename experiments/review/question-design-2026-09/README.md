# 출제 설계(`design`)·정보 선별 해설 — 검토용 예시 3건 (2026-09-18)

> 이 폴더는 **검토용**이다. `content/` 밖에 있어 색인·웹 번들·일일 배포에 섞이지 않는다
> (`test_question_design.py::test_examples_are_not_in_deployed_content` 가 지킨다).
> 실제 문항에 반영할지는 사람이 검토한 뒤 정한다. 세 예시 모두 `review_status: unreviewed` 다.

개선의 방향은 하나다 — **정상 소견·배경 정보가 있는 실전형 문항을 유지하면서**, 채점 후 학습자가
「무엇을 근거로 답했고 무엇은 넘겨도 되었는지」를 보게 한다. 그래서 정보를 줄이지 않았고, 대신
각 정보가 이 질문에서 어떤 역할을 하는지 적었다.

---

## 1. 기존 어루러기 문항 — `kmle-2026-1063` → `ex1-pityriasis-versicolor-revised.md`

**무엇을 평가하는가.** 질문이 「가장 적절한 치료는?」이니 **치료 선택**이다(진단은 전제). 이 전제에서 보면
피부 소견·KOH·우드등이 모두 같은 진단을 가리키는 중복은 결함이 아니다 — 진단을 묻지 않으므로 진단 단서가
겹쳐도 치료 판단을 방해하지 않는다. **정보가 많다는 것 자체는 문제가 아니었다.**

**실제로 걸린 것은 보기 구성이었다.** 원문 보기(국소 케토코나졸 / 스테로이드 / 경구 그리세오풀빈 /
타크로리무스 / 경구 이버멕틴)에는 말라세지아에 듣는 치료가 A 하나뿐이다. 그래서 치료 수준을 가르는 정보 —
병변이 몸통 위쪽에 국한됐는지, 처음인지, 면역저하가 있는지 — 가 답에 **아무 영향도 주지 않는다.**
「치료 선택」을 평가하려 했지만 실제로는 「어루러기 + 아졸이 듣는다」 한 단계로 풀린다.

| | 변경 전 (kmle-2026-1063) | 변경 후 (검토안) |
|---|---|---|
| 평가 판단 | 사실상 「이 균에 듣는 약은?」 | **국소 vs 경구** — 범위·첫 발병·면역 상태로 치료 단계 결정 |
| 보기 E | 경구 이버멕틴(옴 약 — 명백히 무관, 해설이 억지 이유를 붙임) | **경구 이트라코나졸**(실제로 경쟁하는 대안) |
| 「처음 생겼다」 | 발문에 없는데 해설이 「첫 발병」이라고 씀 | 발문에 명시 → 해설과 일치 |
| 일반 사부로 배양 음성 | 있음 | **삭제** — 어루러기에 일상적으로 시행하지 않는 검사, 「음성」이 진균 감염이 아니라는 오해를 부를 수 있음 |
| 혈당 / HIV 음성 | 검사 결과로 제시 | **병력으로 대체**(「당뇨병·면역억제제 복용 없음」) — 첫 발병 어루러기에 HIV 검사는 부자연스럽다 |
| 가려움 | 검사표 한 줄 + 발문(중복) | 발문에만 둠 |
| 병변 감각/발한 정상, 손발톱·두피·서혜부 정상 | 있음(역할 설명 없음) | **유지** — 한센병 무감각 반점 가능성을 낮추고, 다른 부위 백선이 없어 경구 백선 치료가 필요 없음을 보여 주는 의미 있는 정상 소견 |
| 활력징후 | 정상 4종 | 유지(판단에는 쓰이지 않는 배경임을 표시) |
| 채점 후 | 정답근거·오답감별·임상핵심·출처 | 기존 4항목 **그대로** + 「정보를 어떻게 선별했는가」(핵심 판단 요약, 접힌 단서별 분류, 가장 헷갈리는 E, 조건이 바뀌면 E) |

**학습자가 연습하는 판단:** 진단이 이미 분명할 때 치료 수준을 가르는 정보(범위·재발·면역 상태)를 찾아
쓰는 것, 그리고 「효과 있는 더 강한 치료」가 항상 답이 아니라는 것.

원문 파일(`content/kmle/2026/kmle-2026-1063.md`)은 **바꾸지 않았다** — 검토 후 반영 여부를 정한다.

## 2. 정상·음성 소견이 처치에 결정적인 문항 — `ex2-febrile-seizure-meaningful-normals.md`

**무엇을 평가하는가.** 다음 처치 — 18개월 첫 단순 열성경련에서 **요추천자가 필요한가**.

**남긴 정보와 역할.** 이 문항은 **정상·음성 소견이 곧 답의 근거**다. 목이 뻣뻣하지 않음·점상출혈 없음·
의식 회복·신경학적 검사 정상은 세균수막염과 구조적 병변의 가능성을 **낮추고**(배제한다고 쓰지 않았다),
Hib·폐렴구균 접종 완료와 항생제 선행 없음은 요추천자 고려 기준에 해당하지 않음을 보여 준다. 혈당·나트륨
정상은 대사성 경련 가능성을 낮춘다. CRP 0.9(약간 높음)·빈맥 138·열성경련 가족력은 **넘겨도 되는
정보**로 남겼다 — 학습자가 끌려가기 쉬운 값이라 「왜 결정적이지 않은지」를 적었다. 아무도 끌려가지 않을
정상 백혈구는 역할 목록에서 뺐다(자료에는 남아 있다).

**학습자가 연습하는 판단:** 「비정상만 찾는」 습관으로는 풀 수 없다 — 정상·음성 소견의 목록이 곧
「요추천자가 필요한 조건」을 하나씩 지우는 과정이다. 조건 전환은 한 가지만 적었다(「목이 뻣뻣하거나 의식이
돌아오지 않으면 요추천자」).

## 3. 배경 정보가 섞인 다단계 판단 문항 — `ex3-hyperkalemia-multistep.md`

**무엇을 평가하는가.** 다음 처치 — 고칼륨혈증에서 **가장 먼저 줄 약**(3단계: 고칼륨 인지 → 심전도로 긴급도
판단 → 막 안정화가 먼저).

**남긴 정보와 역할.** 결정적 단서는 칼륨 7.1과 심전도(QRS 확장·PR 연장). 동서맥은 긴급도를 올린다.
원인 약물(리시노프릴·이부프로펜)과 크레아티닌 상승은 **다음 단계 처치**(중단·배설)에 쓰이지만 첫 약물은
바꾸지 않는다. 고혈당은 인슐린을 줄 때 포도당을 함께 줄지 정하는 데 쓰인다 — 첫 약물 선택에는 무관하다.
경한 산증(중탄산 19)은 탄산수소나트륨을 떠올리게 하는 **미끼가 아니라 자연스러운 동반 소견**으로, 왜 첫
약물 근거가 되지 않는지 적었다. 정상 칼슘은 「칼슘이 정상이어도 칼슘 투여는 막 안정화 목적으로 필요하다」는
흔한 오개념을 짚는 의미 있는 정상값이다. 흉통·두근거림 없음은 「증상이 없으면 급하지 않다」는 착각을 막는다.

**학습자가 연습하는 판단:** 정보가 많은 증례에서 **첫 행동**을 고르기 — 원인·동반 이상이 모두 사실이어도
지금 순서에서 결정적인 것은 심전도 변화 하나라는 것. 가장 헷갈리는 선택지는 인슐린·포도당(B)이고, 조건
전환은 「심전도 변화가 없다면 B」 한 가지다.
